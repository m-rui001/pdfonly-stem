# 二维有机–无机杂化钙钛矿的研究进展

*Advances in two-dimensional organic–inorganic hybrid perovskites* · 2020 · https://doi.org/10.1039/c9ee03757h

本文系统评述了二维（2D）及准二维有机–无机杂化钙钛矿在光电器件中的应用进展，重点讨论其晶体结构、基本光电性质、太阳能电池中的多种工程策略，以及发光二极管、自旋电子学和光电探测器等超越太阳能电池的应用。作者认为，2D 钙钛矿因有机大阳离子带来的疏水屏障和化学可调性，有望改善三维钙钛矿太阳能电池的长期运行稳定性，同时为研究激子物理、Rashba 劈裂等基础结构–性质关系提供了平台；但纯 2D 相宽带隙和电荷输运各向异性仍是主要挑战，3D/2D 混合结构和界面修饰是兼顾效率与稳定性的有效路径。

## 1. 引言与背景

钙钛矿太阳能电池在约十年内取得快速发展，单结效率已认证达 25.2%。2009 年 Miyasaka 等以 MAPbI₃ 为吸光层在染料敏化电池中取得 3.8% 效率；2012 年 Park 和 Snaith 等用固态空穴传输层将效率提升至 9.7% 和 10% 以上。此后研究重点转向长期运行稳定性。三维钙钛矿中 A 位小阳离子（MA⁺、FA⁺、Cs⁺）受 Goldschmidt 容差因子限制，而 2D 钙钛矿采用较大的有机阳离子，其疏水性和空间位阻可抑制水汽侵入，因此被用于提升稳定性。2014 年首次将 2D 钙钛矿用作吸光层时效率仅 4.73%，此后 2D 太阳能电池效率达到约 18%，仍低于三维的约 25%。另一种思路是将 2D 结构用于修饰 3D 钙钛矿晶粒或表面（即 3D/2D 混合维度），可在较宽组分范围内同时改善稳定性与性能。此外，2D 钙钛矿为化学家提供了探索结构–性质关系的平台，可通过化学调控结构畸变、量子与介电限制、激子–声子耦合及 Rashba 劈裂，进而调控光学、电学和自旋性质。

## 2. 晶体结构与基本光电性质

三维钙钛矿通式为 ABX₃，B 位二价金属（Sn²⁺、Pb²⁺）与 X 位卤素形成 BX₆ 八面体框架，A 位单价阳离子占据八面体间隙。可否形成稳定结构常用 Goldschmidt 容差因子 t=(r_A+r_X)/[√2(r_B+r_X)] 估计，t 约在 0.8–1.0 时可形成三维结构；八面体因子 μ=r_B/r_X 通常介于 0.4–0.9，用于判断 B 位原子是否偏好八面体配位。2D 钙钛矿通式可写为 (A′)ₘ(A)ₙ₋₁BₙX₃ₙ₊₁，其中 A′ 可为二价（m=1）或一价（m=2）有机阳离子，n 表示金属卤化物片层厚度；n=1 为纯 2D，1<n≤5 常称准二维，n=∞对应三维。高 n 值时各相热力学稳定性差异变小，难以制备纯相，故 n 值通常指前驱体配比。沿三维结构的 ⟨100⟩、⟨110⟩、⟨111⟩ 方向切割可得到三类 2D 家族；⟨100⟩ 取向最常见，进一步分为 Ruddlesden–Popper（RP）、Dion–Jacobson（DJ）和交替阳离子夹层（ACI）相。RP 相（A′₂Aₙ₋₁BₙX₃ₙ₊₁）中两个单价阳离子与相邻无机片形成弱范德华间隙，典型阳离子如 PEA⁺、BA⁺；DJ 相（A′Aₙ₋₁BₙX₃ₙ₊₁）由二胺阳离子通过两端氢键连接无机层，无层间偏移，代表如 3AMP²⁺、4AMP²⁺；ACI 相（A′AₙBₙX₃ₙ₊₁）目前仅有胍离子（Gua⁺）能形成，小阳离子同时存在于无机片和夹层中。适合作为间隔阳离子的条件包括：锚定位点的正电荷与取代度（伯铵>仲胺>叔胺>季胺）、氢键能力、空间填充能力以及立体构型（芳香烃优于柔性脂肪烃）。

在电子结构方面，无机片与有机层交替形成多量子阱结构，有机层介电常数低、与无机层介电对比大，导致 2D 钙钛矿具有很大的激子结合能 E_b（数百 meV），室温下激子可稳定存在。带隙 E_g 随 n 增大而减小，例如 BA₂Aₙ₋₁PbnI₃ₙ₊₁ 系列从 n=1 的 2.24 eV 降至 n=∞的 1.52 eV，源于量子限制减弱；卤素和金属离子的尺寸及电负性也会调节 E_g。低 n（n<5）的 2D 钙钛矿因 E_b 大和量子阱间输运势垒高，不利于光伏电荷分离，但对发光有利。电荷输运方面，面内导电性和迁移率远优于面外，面外输运受有机层势垒限制，通常认为通过隧穿进行，隧穿距离和势垒高度是决定因素。改善电荷输运的策略分为四类：工艺工程（热浇铸、溶剂比例调节）、添加剂工程（NH₄SCN、NH₄Cl、MACl、PbI₂、HI 等）、小阳离子工程（FA⁺、MA⁺、Cs⁺）和大阳离子工程（如 F-PEA、MeO-PEA）。

## 3. 太阳能电池应用

**低 n（n≤5）2D 钙钛矿作为吸光层**
2014 年 Karunadasa 等将 PEA₂MA₂Pb₃I₁₀（n=3）用于介观太阳能电池，效率 4.73%，但该膜在 52% 相对湿度下储存 40 天仍保持性能，而三维对照在 4–5 天内迅速退化。热浇铸法由 Tsai 等首次用于(BA)₂(MA)₃Pb₄I₁₃（n=4），使无机框架垂直于基底取向，效率首次超过 10%。随后发展出基底加热滴铸（14.9%）、慢速后退火 SPA（17.26%）、真空极化处理（(PEA)₂MA₄Pb₅I₁₆ n=5，18.04%）。溶剂工程方面，DMF/DMSO 混合溶剂可将效率从约 6% 提至 11% 左右；DMAC 作为溶剂时效率由 DMF 的 7.33% 提升到 12.15%；反溶剂法中用 DMF/DMSO 5:5 混合溶剂使效率从 6.78% 升至 12.29%。添加剂工程中，NH₄SCN 可使(PEA)₂(MA)₄Pb₅I₁₆ 效率由 0.56% 提高至 11.01%；NH₄Cl 与 NH₄SCN 协同作用得到 14.1%；MACl 处理(ThMA)₂(MA)₂Pb₃I₁₀ 使效率从 1.74% 提升至超过 15%；加入第二间隔阳离子 PEAI 的 BA₂MA₄Pb₅I₁₆ 达 14.09%，未封装器件在空气中 1000 小时仅降解约 10%；GuaSCN 与 MACl 顺序后处理使 ACI 相 GAMA₄Pb₄I₁₃ 效率达 15.27%。小阳离子工程中，Cs⁺ 取代部分 MA⁺ 的(BA)₂(Cs₀.₀₅MA₀.₉₅)₃Pb₄I₁₃ 效率从 12.3% 提至 13.68%；FA⁺ 掺入 BA₂(MAₓFA₁₋ₓ)₃Pb₄I₁₃ 在 x=0.8 时效率 12.81%；三重阳离子 BA₂(Cs₀.₀₂MA₀.₆₄FA₀.₃₄)₄Pb₅I₁₆ 效率达 14.23%；另一报道 BA₂(MA₀.₇₆FA₀.₁₉Cs₀.₀₅)₃Pb₄I₁₃ 效率 15.58%。大阳离子工程中，F-PEA 取代 PEA 可改善层间电子耦合，使(F-PEA)₂MA₄Pb₅I₁₆ 效率达 13.64%；DJ 相 3AMP 基器件效率 7.32%，高于 4AMP 的 4.24%；缩短间隔阳离子的 PDA 基器件效率 13.0%；ACI 相(Gua)(MA)₃Pb₃I₁₀ 在加入 MACl 后效率高达 18.48%；BEA 形成的 B-ACI 结构效率 14.86%，通过 Cs/FA/Br 合金化后达 17.39%。

**3D/2D 混合钙钛矿吸光层**
将少量 2D 组分引入三维前驱体可平衡效率与稳定性。(MAPbI₃)₀.₉₈[(PEI)₂PbI₄]₀.₀₂ 效率 15.2%，湿度稳定性优于纯 MAPbI₃；(AVA₂PbI₄)₀.₀₃(MAPbI₃)₀.₉₇ 在 10×10 cm² 组件上效率 11.2%，55°C 连续光照 10 000 小时无衰减。Snaith 等在 FA₀.₈₃Cs₀.₁₇Pb(I₀.₈Br₀.₂)₃ 中加入 BA⁺ 形成 2D 薄片，显著抑制非辐射复合，BA₀.₀₅(FA₀.₈₃Cs₀.₁₇)₀.₉₅Pb(I₀.₈Br₀.₂)₃ 效率达 20.6%；提高 BA 和 Br 含量后器件在空气中 1000 小时仅衰减 20%。胍离子掺入 Cs₀.₁(FA₀.₈₃MA₀.₁₇)₀.₉Pb(I₀.₈₃Br₀.₁₇)₃ 在 10% Gua⁺ 时效率 21.12%。2D 添加剂还可稳定 CsPbI₃ 的 α 相，EDAPbI₄ 掺入后 CsPbI₃ 效率 11.8%；FA 基钙钛矿中加入 BA₂Pb(I/Br)₄ 并配合 Lewis 碱钝化，效率 20.62%。GuaSCN 用于 Sn–Pb 混合低带隙薄膜可在晶界形成 2D 结构，改善光电性能。

**2D 钙钛矿界面修饰**
在三维钙钛矿表面旋涂长链烷基卤化铵的异丙醇溶液，可经阳离子交换形成 2D 钙钛矿薄层，增强耐湿性并减少表面缺陷。Nazeeruddin 等在 Cs₀.₁FA₀.₇₄MA₀.₁₃PbI₂.₄₈Br₀.₃₉ 上形成 PEA₂PbI₄ 层，效率 20.1%，800 小时光照下衰减低于 15%；Grätzel 等用五氟苯乙基碘化铵（F5PEAI）处理，XPS/XRR 证实约 8–9 nm 2D 层，效率超过 22%；Seo 等用 HTAB 处理形成宽带隙层，效率 23.3%，封装器件 MPPT 1370 小时保持 95% 初始效率。其他阳离子如 BAI、CAI、OAI、5-AVAI、BABr 等也有类似效果。Bawendi 等用选择性前驱体溶解策略形成透明 2D 层，基于 C6Br 的器件效率 23.4%，认证稳定效率 22.6%。还需注意：部分处理仅形成有机阳离子层而非 2D 钙钛矿层，也能钝化缺陷；对于全无机 CsPbI₂Br，采用原位生长法可形成 2D/3D 异质结并改善效率与湿度稳定性。

**无铅 2D 钙钛矿**
为降低铅毒性，研究者用 Sn²⁺ 替代 Pb²⁺。Sn 基 2D 钙钛矿的无机框架畸变较 Pb 基小，带隙略窄。PEA₂MA₃Sn₄I₁₃ 用三乙基膦（TEP）辅助成膜后效率 2.53%；(PEA)₂(FA)₈Sn₉I₂₈ 效率 5.94%，开路电压 0.59 V 优于 3D FASnI₃；(PEA)₂FA₄₉Sn₅₀I₁₅₁ 效率 9%（3D FASnI₃ 对照 6%）；混合大阳离子(BA₀.₅PEA₀.₅)₂FA₃Sn₄I₁₃ 效率 8.82%。DJ 型(4AMP)(FA)₃Sn₄I₁₃ 效率 4.22%，未封装器件在 N₂ 中 1 个太阳光照 100 小时仅衰减 9%。DFT 计算还筛选出(TMA)(FA)₃Sn₄I₁₃、(PMA)(FA)₃Sn₄I₁₃、(ATMA)(FA)₃Sn₄I₁₃ 具有 type-II 能带排列和较快电荷输运。

## 4. 超越太阳能电池的应用与展望

**发光二极管（LED）**
2D 钙钛矿因大激子结合能（数百 meV）、混合 n 相中从低 n 到高 n 的级联能量转移（亚纳秒级）、有机配体的疏水稳定性和化学可调性，成为高效 LED 候选。n=1 单层器件（如 PEA₂PbBr₄）需很高开启电压（约 24 V），室温外量子效率（EQE）低，问题源于面外输运差和强激子–声子耦合。2016 年 Jin 等用 PEA₂PbBr₄ 纳米片实现 410 nm 紫色 LED，EQE 仅 0.04%；Sargent 等通过调控有机阳离子增大晶体刚性，使 PEA₂PbBr₄ 单晶 PLQY 达 79%。准二维体系中，PEA₂(MA)ₙ₋₁PbnBr₃ₙ₊₁ 绿光 LED 电流效率 4.90 cd/A、亮度 2935 cd/m²；碘化物准二维 LED 近红外 EQE 8.8%（80 W sr⁻¹ m⁻²）；(NMA)₂(FAPbI₃)ₙ₋₁PbnI₃ₙ₊₁ 的 EQE 11.7%、辐射亮度 82 W sr⁻¹ m⁻²；嵌入高带隙聚合物体异质结后 EQE 达 20.1%。DJ 结构准二维 LED 的 T50（EQE 降至初始一半的时间）超过 100 小时，比 RP 结构长约两个数量级。稳定性方面，BA₂(MA)ₙ₋₁PbnI₃ₙ₊₁ 相纯 RP 膜辐射亮度 35 W sr⁻¹ m⁻²、T50>14 h，远优于准二维或三维对照。

**宽带发射与白光**
2D 钙钛矿中宽带发射被认为源于激子自俘获（self-trapped exciton），光激发引起晶格畸变，自俘获时间约 400 fs。Karunadasa 等最早在(EDBE)PbBr₄ 中观察到亮宽带发射，PLQY 9%，CRI 84；后续发展出(N-MEDA)PbBr₄₋ₓClₓ、α-(DMEN)PbBr₄、PEA₂PbI₄:Sn 等体系。Sn 掺杂可诱导外禀自俘获，PEA₂PbI₄:Sn（0.36%）PLQY 6%，1% 时达 23%。目前宽带发射体系的 PLQY 总体较低，结构–发射关联仍在建立中；Karunadasa 等发现面外八面体畸变程度与宽带/激子发射比呈线性相关，DFT 计算表明低电子维度（而非结构维度）是形成宽带发射的前提。

**自旋电子学**
重元素（Pb、I）带来强自旋–轨道耦合，与反演对称性破缺结合产生 Rashba 效应，能带分裂为 E(k)=ℏ²k²/2m*∓α_R|k|。Vardeny 等在 n=1 PEA₂PbI₄ 中测到巨 Rashba 劈裂，能量劈裂（40±5）meV，Rashba 参数（1.6±0.1）eV；但 Mohammed 等认为本征大 Rashba 劈裂仅出现在偶数无机层的 n=2 晶体中，而非 n=1 或 n=3。Beard 等用圆偏振光泵浦–探测研究 n=1–4 和三维单晶，发现自旋相干寿命从 n=1 到 n=4 增加，再向三维下降，归因于 Rashba 劈裂和声子散射的竞争。手性有机分子引入后，Sargent 等在 2D Pb–Br 多层膜中于零磁场、2 K 下观察到 3% 的圆偏振光致发光；Li 等报告(R-MBA)₂PbI₄ 和(S-MBA)₂PbI₄ 在 77 K 下 CPL 度分别为 9.6% 和 10.1%。Lu 等通过磁性导电探针 AFM 确认手性诱导自旋选择性（CISS）输运，自旋极化度最高达 86%，远高于手性自组装单分子层常见的 30–50%，并实现了基于单一铁磁电极的半自旋阀器件。

**光电探测器与展望**
2D 钙钛矿光电探测器通常依赖单晶。Priya 等利用表面张力效应生长 BA₂PbI₄ 单晶膜，暗电流 10⁻¹³ A，开关比约 10⁴；Liu 等耦合逆温结晶与表面张力控制，获得 36 μm 尺寸的 PEA₂PbI₄ 单晶，(001) 面器件响应度 139.6 A/W，EQE 37719.6%，探测率 1.89×10¹⁵ Jones，响应时间 trise=21 μs、tdecay=37 μs。

展望部分指出：需要发展合成工具获得纯相 2D 钙钛矿；控制晶体取向以利用或规避各向异性；抑制非辐射激子淬灭以提高 PLQY；建立结构–性质（畸变、杂质、维度与宽带发射、Rashba 劈裂、自旋寿命）的定量关联。对太阳能电池而言，即使 2D 钙钛矿不作为主吸光层，也可作为钝化层或覆盖层提升 3D 器件稳定性和效率，未来研究重点将是 2D/3D 混合体系及新型大阳离子设计。
