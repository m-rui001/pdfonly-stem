# 基于MODIS福莱尔-乌勒指数的全球内陆水体营养状态评估

Trophic state assessment of global inland waters using a MODIS-derived Forel-Ule index · 2018 · https://doi.org/10.1016/j.rse.2018.08.026

本文提出利用MODIS影像和Forel-Ule指数（FUI）评估全球内陆水体营养状态的新方法。作者从MODIS地表反射率产品中提取FUI，基于实测数据建立FUI与卡尔森营养状态指数（TSI）的关系，并利用645 nm波段区分CDOM主导的水体，最终对2012年夏季全球2058个大型水体（面积>25 km²）进行了营养状态分类。摘要报告FUI反演精度92.5%（R²=0.92），正文中基于135对实测数据的验证显示R²=0.87、斜率0.92、平均相对差7.5%；独立验证总体精度80.0%（R²=0.75，Kappa=0.67）。结果显示富营养化水体数量占63.1%但面积仅30.5%，寡营养大湖集中在青藏高原和巴塔哥尼亚等高原地区。

## 1. 背景与数据

传统营养状态评估依赖Chl-a、SD、TP、TN等变量，但在全球复杂光学水体中，遥感反演算法受时空局限和光谱分辨率限制。作者选用FUI——一种将自然水色分为21级（从深蓝到黄棕）的颜色指数，因为它可由卫星客观获取、覆盖广泛的水色范围，且与水色相关的水质参数联系密切。研究数据源为MODIS Terra的MOD09A1产品（8天合成、500 m分辨率，含469、555、645、859、1240、1640、2130 nm波段），选取2012年夏半年（北半球6-9月，南半球12-3月）共6400多幅影像，因该季节浮游植物生物量峰值对水色影响最大。实测数据集来自10个湖泊共469个采样点，覆盖亚洲、北美和欧洲，包含从寡养到富养、高总悬浮物（太湖）和高CDOM（佩普西湖、温尼伯湖）等类型，表1列出了各湖泊的Chl-a均值（从Lake Maggiore的2.41 μg/L到滇池的85.2 μg/L）。另采用Hydrolight模拟数据集（IOCCG 2006，Chl-a 0.03–30.0 μg/L，均值6.08 μg/L）补充寡养-中养水体，并使用100个全球水体（来自中国环境状况公报、USEPA国家湖泊评估等）作为独立验证数据集。

## 2. 方法：FUI反演、水体识别与营养状态算法

先从MOD09A1提取水体：用1640 nm波段和修正直方图双峰法（MHBM）以动态阈值自动分割水/陆，阈值范围0.005–0.11；结合QA数据去除云、冰、雪和低质量像素，并以500 m缓冲消除岸边混合像元和邻近效应（该距离由实测对比确定，超过500 m的邻近效应可被约30%的Rrs不确定性掩盖）；再与GLWD数据库相交，去除河流、湿地和间歇性水体。随后排除光学浅水：SWIR波段阈值使大型水生植物区域被移除，再用蓝光阈值Rrs(469 nm)=0.015 sr⁻¹识别高反射浅底，最后经Google Earth和文献人工复核。水体的离水反射率通过简单波段相减法获得：Rrs(λ) = (R(λ) − min(R_NIR:R_SWIR))/π，其中min(R_NIR:R_SWIR)为NIR和SWIR波段的最小正值，用于扣除残余气溶胶和天空光等噪音。

FUI计算采用CIE颜色系统。利用MODIS三个可见光波段（645、555、469 nm）通过RGB转换得到三刺激值：X = 2.7689R + 1,7517G + 1.1302B，Y = 1.0000R + 4.5707G + 0.0601B，Z = 0.0000R + 0.0565G + 5.5934B。随后计算色度坐标(x,y)，并平移至新坐标(x′,y′)（原文公式提取有乱码，上下文推断为x′ = y − 1/3, y′ = x − 1/3），定义角度α为(x′,y′)向量与负x′轴的夹角（0°–360°）。由于MODIS波段设置与人眼感知存在差异，作者用Hydrolight模拟数据拟合多项式偏差delta进行校正，最终通过21级FUI查找表（Novoa等）确定FUI值。

基于Hydrolight模拟数据，FUI与Chl-a衍生的TSI在较清水体中呈正相关（R²=0.94，N=500，TSI范围0–68）。但实测数据（N=469）显示单峰关系：当FUI<10时，TSI随FUI上升（R²=0.633），对应水色从蓝转绿、从寡养到中养；FUI≈10时TSI达峰值（高Chl-a使富养水体呈绿色）；FUI>10时TSI与FUI呈散乱负相关（R²=0.112），反映浊度或腐殖质的影响。基于实测，82.7%的FUI≥10样本为富营养（TSI≥50），83.3%的7≤FUI<10样本（12个中有10个）为中营养（其余两个TSI为29.5和50.5），FUI<7则归为寡营养。为区分FUI≥10的高CDOM或高TSM中养水，采用红波段阈值Rrs(645)：高CDOM低TSM水体红波段反射率较低，应用该阈值后富营养分类精度提升至86.8%。据此构建决策树（图10）完成三个营养状态分类。季节平均处理采用湖泊平均FUI与平均TSI，基于每湖至少3幅有效8天合成影像（16个周期），并计算空间CV和时间CV（CV=δ/μ）以表征变异性。

## 3. 结果：精度验证与全球评估

MODIS FUI与实测FUI的比较（135对数据，来自7个湖泊）显示强相关（R²=0.87，斜率0.92），平均绝对差0.85，平均相对差7.5%，营养状态分类差异10.5%。独立验证（100个水体）总体精度80.0%（R²=0.75），Kappa系数0.67；混淆矩阵显示用户精度：寡营养100.0%、中营养66.7%、富营养78.3%；生产者精度：寡营养79.2%、中营养51.9%、富营养95.5%。未出现寡-富错分，错分主要发生在富-中之间。

对2012年夏季2058个大型水体（总面积173万km²）的评估显示，季节平均FUI范围3.1–16.0，全球均值11.1（CV=26.6%）；空间CV均值12.9%（范围0–41.2%），时间CV均值9.9%（0–54.3%）。营养状态分布：富营养水体占数量63.1%但面积仅30.5%，中营养占数量26.2%面积39.4%，寡营养占数量10.7%但面积30.1%。寡营养大湖集中在亚洲中部高原（青藏高原）和南美南部（巴塔哥尼亚），富营养大湖集中在非洲中部、东亚（中国东部）、北美中北部和东南部。按洲统计数量比例：大洋洲寡营养最高（23.1%），欧洲中营养最高（35.2%），非洲富营养最高（88.8%）；按面积比例：北美寡营养最高（49.8%），亚洲中营养最高（71.2%），非洲富营养最高。

区域案例分析：北美五大湖中苏必利尔、密歇根、安大略和休伦为寡养，伊利湖为中养（西部伊利湖FUI≈11为富养，与文献一致）；中欧湖泊FUI多为7–9，属中养；非洲大湖中维多利亚湖中养（有富养部分），图尔卡纳湖富养，坦噶尼喀湖寡养；青藏高原湖泊FUI 2–7，纳木错寡养（FUI 2–4），色林错寡养渐近中养，昂孜错和孜桂错中养；长江中下游湖泊FUI 9–14，为富养-浊水系统，而新安江和柘林水库为中养。

## 4. 讨论与结论

敏感性分析基于辐射传输模拟，假设非耦合水-大气系统，用瑞利校正反射率Rrc表示气溶胶和观测条件影响：Rrc(λ) = ρt(λ) − ρr(λ) = ρa(λ) + π t(λ) t0(λ) Rrs(λ)。比较由Rrs和Rrc计算得到的FUI，在海岸气溶胶（C50）和海洋气溶胶（M90）及不同观测几何下，整体R²=0.967，平均相对差10.9%，9.5%样本改变了营养状态分类，表明FUI算法对气溶胶和观测条件不敏感，这得益于色度归一化和21级聚类过程。与传统指标的比较（20个与USEPA NLA2007匹配的美国湖泊）显示，FUI分类与SD（R²=0.80）和Chl-a（R²=0.65）相关性最好，与TP相关（R²=0.29），与TN几乎无关（R²=0.03，RD=55%）。FUI方法倾向于将寡养湖错分为中养，部分原因是TSI边界差异（本研究用1和7 μg/L，USEPA用2和7 μg/L），另一原因是CDOM或TSM等光学活性组分改变了水色。对于高CDOM高TSM的水体，红波段无法区分中养与富养，需更高光谱分辨率传感器。季节平均可能掩盖局部富养区域，但减少了偶然误差；云覆盖和极端事件（藻华、泥沙）会增加CV。MODIS Terra数据经校准后质量可用，而Aqua因band 6条带噪声严重未被采用。该算法通过delta校正可移植至Landsat-8、Sentinel-3/2等新传感器，有望扩展到更小水体。结论是FUI方法以水色为基础，在全球尺度上实现了约80%精度的营养状态分类，且对大气扰动不敏感，为全球大型水体监测提供了有效工具。
