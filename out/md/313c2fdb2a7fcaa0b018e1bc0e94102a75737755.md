# 变化世界中的河流生态系统代谢与碳生物地球化学

*River ecosystem metabolism and carbon biogeochemistry in a changing world* · 2023 · https://doi.org/10.1038/s41586-022-05500-8

本文综述了河流生态系统代谢研究现状，整合了目前最佳的河流代谢估算，量化了陆地到河流再到沿海海洋的有机碳与无机碳通量，指出河流净生态系统生产（NEP）和二氧化碳排放会沿程改变有机碳与无机碳的比例。作者主张河流网络是连接陆地、海洋和大气的最大的生物地球化学纽带，但长期以来被当作被动输送碳的“管道”；实际上河流是“生物地球化学反应器”，代谢有机碳并向大气排放CO₂和CH₄，同时埋藏部分有机碳。全球尺度的河流代谢评估此前尚属空白，这限制了预测全球变化如何改变河流碳封存和温室气体排放的时间与空间格局的能力。作者采用质量平衡方法，结合气候、土地利用和流量调节等全球变化因素，提出建立全球河流观测系统（RIOS）以推进机制理解和预测。

## 河流生态系统代谢及其环境驱动

河流生态系统代谢由自养能量（水生初级生产）和异养能量（陆地输入）共同驱动。总初级生产（GPP）和生态系统呼吸（ER）的平衡定义为净生态系统生产（NEP = GPP − ER）。正NEP表示系统自养，负NEP表示异养。大多数河流呈异养状态，ER超过GPP的部分需由陆地有机碳或上游淡水生态系统产生的有机碳补足，这支撑了河流中CO₂（以及少量CH₄）的广泛过饱和与排放。代谢的季节节律还驱动河流生态系统物候，联系能量与元素通量。早期研究通过比较数日尺度的多个河流识别出光、流量、土地利用和养分是GPP和ER的驱动因子；溶解氧传感器的改进和过程模型的发展使逐日、多年连续的GPP、ER和NEP估算成为可能。代谢时间序列可分类为春季或夏季GPP峰值、春秋双峰或无明显季节模式。潜在GPP的年际上限由太阳辐射决定，而流量干扰、养分、消费者牧食等次级驱动将潜在GPP约束为实际GPP。一项涵盖美国222条河流的研究表明，年光可利用量和水分扰动是年GPP和ER变化的主要驱动。与陆地生态系统不同，河流中温度和光的变化常不相关，因为河岸植被、溶解有机碳浓度和浊度会衰减光。温带地区落叶树展叶前的光窗可在春季刺激GPP峰值，使代谢短暂转向自养；浊度常与高流量相关，会限制代谢接近理论最大值。同一驱动因子对不同河流等级的影响不同，增加了网络尺度预测的难度。温度对河流代谢的影响仍不清晰：沿热梯度和跨生物群系的研究显示GPP和ER的活化能相似，但一项开放冠层溪流的实验性升温（+3.3 °C）使GPP增至3倍，远超理论预期；光、流量与温度共变使温度效应难以分离。养分富集的作用也有分歧：阿拉斯加Kuparuk河长期磷添加使代谢从异养转向自养并增加了苔藓生长，而一条高度遮荫的阿巴拉契亚溪流中养分富集对GPP无影响但增强了ER。西班牙Oria河在污水治理后观测到GPP和ER双双下降。

## 全球河流异养性与碳通量预算

基于现有最可靠的预算研究，作者总结了热带（GPP 153 g C m⁻² yr⁻¹，ER −760，NEP −606）、温带（GPP 331，ER −591，NEP −260）和高纬度（GPP 279，ER −827，NEP −438）河流的年均面积通量。尽管存在纬度差异，但热带和高纬度时间序列很少覆盖完整年周期、样本量少且偏向小河。全球平均NEP约426 g C m⁻² yr⁻¹，表明河流是地球上异养性最强的生态系统之一；其异养由陆地生态系统净初级生产支持（全球平均陆地NEP为74 g C m⁻² yr⁻¹）。相比之下，河口NEP约为−189 g C m⁻² yr⁻¹，大陆架的NEP介于−6至2 g C m⁻² yr⁻¹。河流网络层面的代谢测量很少，但已有模型研究揭示：理论河网中大河对网络尺度生产力的贡献随流域面积增大而增加，而众多小河流因其总表面积巨大而产生不成比例的影响；西班牙Deva和Cares河的网络模型显示了地貌和人类活动对NEP的塑造；奥地利Ybbs河流域通过机器学习预测，源头溪流驱动年际网络异养性，尽管春季存在明显的自养峰。作者将质量平衡拓展至全球碳通量（图2）。估算全球陆地到河流的侧向有机碳通量为0.72 Pg C yr⁻¹（LB 0.58，UB 1.23），无机碳通量为2.44 Pg C yr⁻¹（LB 2.37，UB 3.17），总碳通量3.2 Pg C yr⁻¹（UB 4.2）。有机碳与无机碳之比（OC:IC）仅为0.3（LB 0.20，UB 0.47），凸显了来自高地土壤和湿地土壤的CO₂输入的主导地位，其中不仅包含化学风化和异养呼吸，还包含自养根呼吸——例如亚马逊河网中根呼吸对CO₂排放的贡献几乎与土壤和水生异养呼吸的总和相当。陆地总侧向碳通量相当于全球陆地NEP（11 Pg C yr⁻¹）的四分之一左右。河流NEP约为−0.27 Pg C yr⁻¹（LB −0.13，UB −0.33），意味着约37%（LB 12%，UB 42%）的陆地有机碳通量被河流呼吸转化为CO₂；低处理效率部分归因于短停留时间和低生物可利用性。部分有机碳在洪泛区和水库中暂时埋藏，但全球小型水库的贡献仍难以约束。作者采用保守的排放估计（0.037 Pg C yr⁻¹，UB 0.3）和埋藏估计（0.027 Pg C yr⁻¹，UB 0.18）。河流NEP贡献了全球河流碳排放（2.3 Pg C yr⁻¹，含水库；UB 2.9）的约12%（LB 4%，UB 14%），但美国河流（19%–39%）、亚马逊河及洪泛区（20%）和密西西比河（22%）的观测值更高，北极（>80%）和北方（75%）河流更高；这种差异可能源于全球预算未包含源头溪流中大量陆地CO₂的贡献。尽管普遍异养，高自养期也可能出现CO₂不饱和，此时自养生物可能利用碳酸氢盐，从而改变碳收支。质量平衡显示，从陆地-内陆水界面到内陆-沿海水界面，OC:IC比从0.3升至1.1；扣除化学风化来源后，仅约26%（LB 21%，UB 32%）的陆地碳到达沿海海洋。河流碳输入可能使海洋在工业化前期成为CO₂净源（约0.3 Pg C yr⁻¹），再加上人为增加的0.1 Pg C yr⁻¹。作者采用较保守的河流有机碳输出估计0.38 Pg C yr⁻¹（UB 0.7）。Box 1汇总了温室气体排放：基于两种方法，全球河流CO₂排放分别为1.9和2.3 Pg C yr⁻¹，热带占>70%；低等级高坡度河流贡献不成比例。全球河流CH₄排放约0.005（均值）和0.008（中位数）Pg C yr⁻¹。

## 全球变化对河流代谢与温室气体排放的影响

全球变化通过多种途径影响河流代谢与碳排放。气候变化使陆地NPP增加并改变其物候，进而增加高纬度和热带的有机碳输入，但这些增强的输入大多在河网内被呼吸代谢，支撑更高的ER和CO₂排放。地球系统模型预测，21世纪陆地碳输送和河流CO₂排放将加速。高纬度降水增加可能加剧碳淋溶，但温带地区长期CO₂过饱和下降趋势可能与土壤CO₂生产减少、筑坝、土地利用变化和酸化恢复有关。气候驱动的径流变化是关键——湿季输送更多陆地碳，瑞典河流DOC浓度上升与降水增加相关。脉冲式有机碳输入也会改变代谢：阿尔卑斯山一场冬春融雪提前导致河流向异养转变，CO₂排放增加。土地利用变化方面，刚果盆地森林砍伐和东南亚泥炭地油棕种植激活古老活性有机质，进入河流后被呼吸为CO₂；农业土壤本身是河流OC和养分的主要来源，改变GPP和ER的季节性及幅度，但农业河流的CO₂和CH₄中自养与异养来源的比例尚未厘清。流量情势的变化在干旱和洪水两方面影响代谢：非永久性河流在全球广泛分布，流量消退时GPP崩溃而ER继续，促进异养；实验性干旱使北方河流出现缺氧并促进CH₄生产。2018年欧洲热浪导致北方河网代谢发生类似转变。洪水频率增加使222条美国河流的年GPP和ER下降，且对ER影响更强；城市河流因不透水面频繁出现“闪峰”扰动。冰盖退缩可能通过增加光照提高GPP，但预测不确定。筑坝和调水会截留沉积物、OC和养分，水库可大量排放CO₂和CH₄；下游尾水排放可导致“碳峰”（carbopeaking）。水库内氧气充足水域促进ER和CO₂生产，而深部厌氧区促进CH₄产生；水库还可引发藻华使代谢转向自养。亚洲大河因筑坝而出现自养化现象，中国河流CO₂排放过去三十年下降32%。许多全球变化效应最终导致富营养化和脱氧——当ER超过GPP和大气再供氧时，代谢转向厌氧途径，产生N₂O和CH₄。河流脱氧日益受到关注，可危及生物多样性、鱼类洄游和生态系统健康。

## 研究重点与全球河流观测系统

作者提出建立全球河流观测系统（RIOS），以应对两大挑战。第一大挑战是约束河网代谢及相关碳通量的不确定性，关键是大幅增加覆盖多种河流生态系统的多年代谢、GHG排放和元数据时间序列，填补热带、高纬度和高海拔地区空白，并发展廉价GHG传感器和智能传感网络。第二大挑战是将单点测量的碳通量上推到河网尺度，这需要整合地面传感网络、卫星观测、尺度定律和流域机制模型。目前卫星遥感可量化河网拓扑、水面面积、蓄水量、流量、悬沙和冰盖，但全球河面分析排除了<90 m宽的窄河，而窄河占全球河网大部分；河岸植被也构成障碍。建议统一遥感方法以量化河道宽度和光可利用性。尺度定律可用于预测河网中河道长度和水力几何变化，但仅适用于稳态条件，不能反映河网的扩张-收缩动态；需要跨尺度验证，包括最小常流河。当前生物地球化学模型常不能准确表征河流代谢和碳命运，也未能整合养分循环与脱氧。需要将河流过程纳入地球系统模型，因为忽略陆地碳渗漏会低估陆地净碳汇、高估生物圈碳储量增长。RIOS将促进跨尺度观测与模拟的迭代，最终实现陆-河-气-海界面碳通量的精确核算，支撑对全球变化响应的预测。
