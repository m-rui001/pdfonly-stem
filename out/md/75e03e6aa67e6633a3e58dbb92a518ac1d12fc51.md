# 生物可降解聚合物的寿命预测：从水解动力学到环境降解的机理框架

**Lifetime prediction of biodegradable polymers** · 2017 · https://doi.org/10.1016/j.progpolymsci.2017.02.004

本文主张：生物可降解聚合物（biodegradable polymers）的“安全使用寿命”可以通过统一的水解降解机理框架加以预测，其关键在于理解并量化水的扩散、酯键水解速率以及由此引起的分子量下降与力学性能丧失之间的关系；环境（尤其酶介导）降解虽然表面上是“终极矿化”问题，但材料失效（embrittlement，脆化）的规律仍受控于同一套链断裂与分子量临界值逻辑。作者指出，若把注意力从“总矿化时间”转向“聚合物力学失效时间”，则生物医用、药物递送、包装与农业地膜等不同领域的研究结果可以互相翻译，并可借助加速老化中的Arrhenius外推、临界厚度与临界分子量（Me, Mth）等概念来评估真实服役寿命。

## 失效判据、基本变量与通用降解概念

生物可降解塑料主要分为源于可再生资源的聚酯（如淀粉、polyhydroxyalkanoates, PHA，PLA等）和石油基合成聚酯（如PCL、PBS、PBAT等）。其降解的初级方式是主链酯键的水解（abiotic或enzymatic），这与耐水解的oxo-degradable聚烯烃体系有本质差别。四个控制侵蚀机理的关键变量是：水在聚合物中的扩散速率D（由扩散系数描述）、水解的准一级速率常数λ′、样品厚度L、以及临界厚度Lcrit。当λ′ > D且L > Lcrit时，聚合物以表面侵蚀（surface erosion）方式降解，表面材料被不断剥落，芯部仍保持较高分子量和力学性能，直到剩余厚度小于Lcrit时，转为本体侵蚀（bulk erosion）；当λ′ < D且L < Lcrit时，水快速渗透到整个样品内部，水解在整个体积内均匀进行，链断裂使数均分子量Mn持续下降，直至达到链缠结临界分子量Me，材料急剧失去强度，然后进一步水解为可溶于水的低聚物和单体，最终被微生物同化或矿化为CO₂、H₂O、CH₄等。这四个变量之间的相对关系是全部后续模型的共同骨架。

力学失效的判据在文献中并不统一。聚烯烃类常把断裂能（fracture energy）降至初始值的50%视为失效；对热塑性聚合物，更常用“断裂伸长率降至初始（拉伸）极限伸长率的5%”作为脆性失效的标志，或者直接用断裂韧性来追踪裂纹尖端的能量耗散。最基础的结构因子有三：聚合物链长（即聚合度）、链间作用力（以内聚能密度δ²描述，δ² = δ₁² + δ₂² + δ₃²，其中δ₁²、δ₂²、δ₃²分别为色散力、极性力和氢键贡献）以及结晶度（结晶区对水不可渗透，从而减缓水解，但也可能因局部应力和微裂纹导致脆化）。聚合物强度σ与分子量之间满足经验关系σ = A − B/Mn（式1）；当Mn降至Me时强度趋于零。对PLA，Me约为8–10 kg/mol；对PHA约为13 kg/mol。每根数均链上的断链数s定义为s = (Mn0/Mnt) − 1（式2）。寿命预测通常依赖加速老化（提高温度或辐射强度）再外推，但Arrhenius关系在跨越Tg时会出现曲率，因此必须严格控制测试温度范围，并且对每一种新配方（包括添加剂改变）都需重新表征。

## 水解降解的动力学与建模：从宏观到微观

水解是生物可降解聚合物失去力学性能的核心化学过程。酯键水解可为酸、碱或酶催化，其速率受链长、结晶度、分子量分布、基质形状与几何、孔隙率、加工条件和水扩散性等多种因素影响。水解降解的建模方法可分为三大类：经验模型（empirical）、现象学模型（phenomenological，基于确定性反应–扩散–溶解方程）、以及随机/计算模型（stochastic/probabilistic，如Monte Carlo、cellular automata）。早期的经验模型多以描述分子量下降为目标，对力学性能的预测能力有限。随机模型（如Kuhn 1930年的随机断链统计）则能给出分子量分布随时间演化的解析解。

水在聚合物中的扩散通常用Fick定律描述。对平面薄片，早期吸水阶段可用Stefan近似：Mt/M∞ = (4/L)(Dt/π)^{1/2}（式6），水渗透过平均距离〈x〉所需时间Tdiff ≈ 〈x〉²/(6Deff)（式7）。这些模型假设水浓度恒定的前提是存在“结合水”概念：只有部分被吸收的水具有反应活性。结晶区对水不可渗透，因此水解主要发生在无定形区；水解后产生的孔隙又反过来增加吸水率和链的迁移性。表面侵蚀与本体的转移由扩散速率与水解反应速率的相对大小决定：对PLA、PGA、PCL、PBS等聚酯，本体侵蚀是主导；而聚酐、聚原酸酯、聚碳酸酯等则倾向于表面侵蚀。在表面侵蚀中，材料厚度随时间线性减小，而芯部分子量几乎不变；在本体侵蚀中，力学性能先因链断裂而丧失（由于Mn降至Me），随后质量才开始明显下降。两种模式都不是绝对的，实际聚合物往往同时具有两种特征。

本体侵蚀聚合物（如PLA）的水解可以分成四个阶段：(a) 水分吸收（由扩散系数控制）；(b) 稳态水解（由水量控制）；(c) 自催化加速（因酸端基增多，且与临界Mn对应）；(d) 水溶性产物释放与总溶解。酯水解的反应式简写为 -RCOOR′- + H₂O → -RCOOH + HOR′-（式8）。若羧酸端基自催化，则链断裂速率可用式(10)–(18)中的多组方程表示。早期阶段，由于[E]和[H₂O]可视为常数，体系呈现自催化特征；Lyu等提出将反应分为无自催化和有自催化两个阶段，并引入解离氢离子浓度的影响，得到式(15)。Siparsky等对PLA、PLA-co-PCL和PLA-PEG共混物验证该式拟合良好，但PCL在该条件下不呈现自催化。Martens等对透明质酸（hyaluronan）的水解采用随机断链模型（式19–20），拟合良好。Perale等用人口平衡模型描述PCL水解，假设m长链断裂为n长与(m−n)长链（式23，24），可较好预测PCL单丝分子量随时间的演化。Soares和Zunino对支架涂层建立了多尺度模型（分子级水解，本体级Fick扩散），引入Thiele模数Λ = L[λρW∞/(D∞)]^{1/2}（式25）来控制侵蚀模式，Λ高则本体侵蚀、Λ低则表面侵蚀。Antheunis等针对无定形聚酯推导了包含初始酸浓度、结晶度修正和酯键类型比例的表达式（式26，27），能预测PLA和PLGA在质量损失前的S形Mn下降。Pan及同事发展了一系列模型（式28–30），计入非催化与自催化水解、端链与随机断链、再结晶效应。Heljak等简化了自催化模型（式31–33），假设聚合物瞬间被水饱和并忽略水扩散项，可以拟合Agrawal等在静态与流动条件下的降解数据。Zhao等考虑受阻扩散与孔生长；Arosio等提出shrinking-core模型；Casalini等用质量守恒和统计矩方法拟合PLGA微球。

随机建模方面，Monte Carlo方法可为每个聚合物网格单元赋予生命周期。Guaita等发现完全随机断链时聚合物多分散度趋近于2；Nishida等观察到同样结果。Siepmann等在二维网格中同时考虑聚合物、药物和孔隙，并给结晶像素分配较长寿命（式35）。Gleadall和Pan模拟了PDLA分子量分布，发现随机断链对Mn的影响比端链断裂大1000倍以上，且PLA只有Mn降至5000 g/mol以下才会有显著质量损失（其他文献给出Me约10,000或4,000 g/mol）。Lin等引入分子量反应指数Rind：无定形PLLA的Rind恒为0.4，而结晶PLLA的Rind从1.0随时间降至0.7。实验方面，Knight重新审查了醋酸纤维素膜的“自催化临界点”概念，认为不存在一个突然的临界点，反应在所有氢离子浓度下都是自催化的。

表面侵蚀聚合物的动力学模型通常把水解速率与比表面积关联。Hopfenberg给出了线性移动侵蚀前沿方程（式36），其中形状因子n = 1、2、3分别对应薄片、圆柱和球。Cooney扩展了该模型，考虑了降解产物通过相邻静止溶剂层的释放（式37）。Thombre和Himmelstein为聚原酸酯建立了扩散–反应模型（基于侵蚀前沿跟随水扩散前沿的概念），后来Larobina和Kipper等也采用类似方法处理聚酐共聚物。Rothstein等提出了同时覆盖表面和本体侵蚀的统一模型，以水的扩散系数（对广泛聚合物取约10⁻¹² m²/s）和降解速率常数为基础，并耦合孔隙率与结晶度的时空变化。Von Burkersroda等给出了侵蚀数的定义：εt = λ·(〈x〉³/(4Deff))（式39），当εt < 1为本体侵蚀，εt > 1为表面侵蚀，εt = 1对应临界厚度Lcrit。Lcrit与温度的关系可用Arrhenius方程描述（式40）。对Lexan 141聚碳酸酯，Lcrit在20°C约11 mm，70°C约2 mm。Lyu等给出了另一个临界厚度Wc的表达式（式41），通过水在聚合物中的溶解度和水解所消耗的总水量来界定侵蚀模式的转换。

## 从水解动力学到力学性能与寿命预测

水解链断裂对力学性能的影响机制是寿命预测的核心。随机断链比端链断裂更能有效降低强度，因为前者能快速减少链缠结。Farrar和Gillson通过研究发现，PLA水溶性低聚物水解时，α-酯（链端附近）的水解速率比β-酯（链内）约高2.5倍，但由于商业PLA聚合度通常>1000，β-酯数量远多于α-酯，因此链内随机断链在早期水解中占主导。将强度与Mn的关系（式1）代入水解动力学方程，可以得到强度随时间下降的预测曲线（式42），但该关系在描述无定形聚合物Tg以下强度损失时效果有限；Deng等改用经验式BSR = a·MW^b（式43），Weir等则发现简单的线性关系。Vieira等对PLA-co-PCL纤维的研究显示，一级强度衰减规律（式44）在前八周内能较好描述强度与Mn同步下降；该纤维在pH 8磷酸盐缓冲液中浸泡16周后，质量只损失10%，但强度丧失80%。Bellenger等提出了线形聚合物寿命（time-to-fail）的公式（式46），以Me为失效判据，并定义了临界断链数sc = Mn0/Me − 1（式47）。Pickett对聚碳酸酯、PET和间苯二酚聚芳酯的研究发现，这些材料在Mn下降20–50%时失去延展性，并提出了寿命与相对湿度（RH）的关系tfail = A·exp(Eh/(RT))·RH^−2（式49），指出酯水解在无外加酸碱时为二级反应，机理上涉及过渡态中两个水分子。

机械性能对分子量变化的响应并非单调：许多研究观察到水解初期模量几乎不变甚至略有上升，随后急剧下降。这可用熵弹性理论（式51）解释：在链高度受约束时，单次断链不改变有效交联网络结构，直到分子量降至阈值Mth以下，整条链才不再贡献熵弹性。对半结晶聚合物，Shirazi等将反应–扩散模型与链模型耦合，预测较厚膜因内部酸浓度更高而模量下降更快。Ding等的分子动力学模拟（基于聚乙烯的united atom模型）表明，Tg以下由范德华力控制弹性的区域，断链会立即降低模量；Tg以上则由熵控制，孤立断链不立即影响模量。值得注意的是，Tsuji等发现初始结晶度较高的PLA膜水解反而更快，这被归因于有效tie chain密度降低和无定形区缺陷增多。Gleadall用原子尺度模拟表征断链附近的“有效空腔”概念。Vieira等提出了一种“4D”方法，通过超弹性本构模型（Neo-Hookean、Mooney-Rivlin等，见式53–55）结合有限元方法来模拟PLA-PCL纤维的降解行为，其中Neo-Hookean模型拟合效果最好，但所有模型都依赖经验参数。Tang等用ABAQUS模拟了PLA支架的本体侵蚀（以热传导函数模拟Fick扩散，式56中β取4000 day⁻¹，降解速率常数0.0117 day⁻¹），当水浓度达到临界值0.0293 g/cm³时（临界Mw为10,000 g/mol）自催化加速开始。Deroiné等对PHBV在蒸馏水中的加速老化显示，分子量与力学性能之间存在明显的两段式关系：当Mn高于约110,000 g/mol时，力学性能几乎不变；低于该阈值后，材料快速失去力学完整性，并以应变断裂伸长率定义寿命（活化能约93 kJ/mol）。

## 酶促降解与环境降解：表面过程的控制与挑战

酶促水解是生物可降解聚合物在真实环境中降解的重要途径，但它比非生物水解复杂得多，因为酶是大分子蛋白质，无法渗入聚合物基质内部，因此酶促水解本质上是一种表面侵蚀过程。酶的催化能力可使反应速率提高10⁸至10²⁰倍，其活性取决于酶与底物的特异性结合（如α-淀粉酶、脂肪酶、蛋白酶K、PHA解聚酶、壳聚糖酶等）。底物的结晶度、链分支、疏水性和分子量都会显著影响降解速率；较高的亲水/疏水比、较低的结晶度和分子量、较少的支链和交联都更有利于降解。表面酶解过程包括酶扩散、吸附（通常符合Langmuir或Freundlich等温线）、表面催化反应和产物扩散（式57–60），但这些模型大多未把表面粗糙度变化或选择性侵蚀纳入，因此通常只能用于特定聚合物体系。PLA在环境中通常先经历非生物水解（导致分子量降低和脆化），然后低聚物被微生物分解；酶促水解仅在表面进行。PHA在酶作用下同样呈表面侵蚀，如Ralstonia pickettii T1的PHB解聚酶对PHB单晶的侵蚀沿a、b、c轴均有发生；PHBV的酶促降解速率随共聚物中3-羟基己酸酯(3HHx)链节的增多而加快。活性酶促降解受多种因素影响：温度、pH、微生物种群、营养物质等。Deroiné等对PHBV在蒸馏水中施加不同温度的研究发现，吸水速率与温度无关，但扩散系数和降解速率都符合Arrhenius关系。

环境降解中的另一个重要因素是生物因素：土壤、海水和堆肥中的微生物群落通过产生酶和改变局部pH来影响聚合物寿命。聚合物的表面粗糙度、疏水性和电荷状态决定了生物膜的形成速率，而生物膜又反过来促进降解；Woolnough等人的研究表明，降解速率与表面粗糙度和生物膜覆盖率正相关。PLA在土壤中降解较慢（约1年），但在堆肥高温条件下降解较快（2–3个月）；其降解是先水解后矿化的两阶段过程，链断裂次数在脆化点为2.5、总碎裂点为4.4，而此阶段仅释放约20%的CO₂。PCL、PBS、PBAT等聚合物在环境中降解速率差异很大，取决于微生物种群、环境湿度和温度。PHA在环境中的降解主要通过表面侵蚀进行，分子量往往变化不大，但力学性能（如断裂伸长率）因表面缺陷而显著下降；PHBV在海水中降解速率较快，而PHB在海水和土壤中相对较慢。酸性土壤、高湿度和高温一般加速降解。此外，PBAT地膜在自然环境中受紫外线照射会形成交联（凝胶含量可达25%），从而抑制后续的矿化；PLA在短波UV下主要发生Norrish型断裂和光氧化，但在自然阳光下的降解速率比模拟试验慢得多。加速老化（高温、高湿、UV）用于寿命预测的前提是降解机制不随温度或湿度改变；但PLA在超过40°C的海水中因塑化效应而机理改变，使外推失效。力学应力（静态或动态载荷）会显著影响降解速率：应力可降低链断裂活化能（Zhurkov方程，式62），或通过应力集中产生微裂纹从而加速水解；动态载荷通常比静态载荷更有效地加速力学性能丧失。加工条件（如熔融剪切）造成的分子量损失和分子取向也会改变后续降解行为。

总之，现有模型对生物可降解聚合物的机理理解已相当深入，但要实现“统一的、全环境寿命预测”仍面临挑战。作者认为，可以从现有模型和实验数据中提炼的核心规律有四：① 水解动力学与水的扩散速度的相对关系（以及由此决定的表面/本体侵蚀模式）是控制因素；② 材料强度随时间的变化可以通过断链数与水解动力学的关联来建模；③ 随机建模能可视化异质性降解过程，将降解区的生长与裂纹临界尺寸联系起来；④ 酶介导降解提供了一条独特的、受链结构和表面控制的过程，其建模尚不成熟。未来研究应结合先进分析技术追踪聚合物化学变化的早期信号，以补充加速老化的外推结果，并覆盖更广泛的真实环境条件。
