# 青少年脑认知发展研究的图像处理与分析方法

*原题：Image processing and analysis methods for the Adolescent Brain Cognitive Development Study*


Hagler DJ Jr. 等，NeuroImage，2019，DOI: 10.1016/j.neuroimage.2019.116091（与OCR正文首页一致）

本文是ABCD研究（Adolescent Brain Cognitive Development Study）基线神经影像处理与受试者层面分析方法的参考文档，服务于2019年3月发布的ABCD Data Release 2.0及2019年7月的Fix Release 2.0.1。ABCD研究自2016年9月启动，计划在两年内招募超过11,000名9–10岁儿童（含800多对双胞胎），随访十年，采集多模态脑影像、生物测定、认知与临床评估、物质使用与环境等信息。本文聚焦影像处理流程，包括结构MRI（sMRI）、扩散MRI（dMRI）、任务态功能MRI（fMRI）与静息态fMRI（rs-fMRI）的模态特异性校正、脑分割与皮层表面重建、微结构分析、任务激活分析与功能连接分析，并简要描述影像采集、质量控制以及数据与方法共享。

## 影像采集与处理挑战

ABCD影像协议沿用PING与HCP的思路，采集$T_{1}$加权（$T_{1}w$）和$T_{2}$加权（$T_{2}w$）sMRI、dMRI以及fMRI（含rs-fMRI和任务fMRI）。任务包括修改版货币激励延迟任务（MID）、停止信号任务（SST）和情绪n-back任务（EN-back），分别探测奖赏加工、执行控制与工作记忆。协议与Siemens、GE、Philips合作，在3 Tesla系统（Siemens Prisma/Prisma Fit、GE MR 750、Philips Achieva dStream/Ingenia）上实现HCP风格时空分辨率，不使用非商用升级。

为应对儿童MRI运动问题，sMRI采集在Siemens和GE上使用前瞻性运动校正（navigator或PROMO序列），Philips平台即将实施。Siemens站点使用FIRMM软件实时监测fMRI头动，操作者可依据是否达到“FD<0.2 mm的数据>12.5分钟”的标准提供反馈或调整扫描（如跳过最后一次rs-fMRI）。

多模态处理面临头动、失真和强度不均匀等挑战。头动会降低图像质量并偏倚各模态衍生指标；对退化帧/层进行删失可减少dMRI和fMRI污染；失真校正对dMRI/fMRI与sMRI的精确整合至关重要，并可减少纵向变化估计中因体位差异带来的方差；高密度相控阵头线圈导致的强度不均匀若不校正，会造成脑分割或皮层表面重建不准确。处理流程预期随时间演进，以应对纵向分析中扫描仪或头线圈升级/更换等挑战。

数据与方法共享是ABCD的组成部分：处理后数据和ROI分析结果通过NIMH Data Archive（NDA）公开；处理流程以平台无关工具共享。本文针对Data Release 2.0和Fix Release 2.0.1，提供基线数据的初步特征描述，更深入的受试者特征、影像描述统计和质量控制优化将另文报告。

## 方法

处理由ABCD Data Analysis and Informatics Center（DAIC）集中完成，使用UCSD CMIG开发维护的Multi-Modal Processing Stream（MMPS），主要包含MATLAB函数以及python、sh、csh脚本和C++可执行文件，依赖FreeSurfer、AFNI和FSL等公开软件。流程用于Data Release 2.0，并以平台无关可执行文件形式提供beta版本（https://www.nitrc.org/projects/abcd_study）。处理分为五个阶段：1）解包与转换：按序列分类DICOM并转为压缩卷文件，自动检查协议合规性和文件数；2）处理：校正失真和头动，进行跨模态配准（Fig. 1A）；3）脑分割：重建皮层表面，分割皮层下和白质区域；4）分析：进行模态特异性单受试者分析，提取ROI衍生指标；5）汇总：跨受试者汇总ROI结果。Fig. 1B展示流程输出。

标准扫描会话包括sMRI（$T_{1}w$和$T_{2}w$）、一个dMRI序列、四个rs-fMRI序列，以及三个任务（MID、SST、EN-back）各两个任务fMRI序列。扫描顺序固定为：localizer、3D T1w、2个rs-fMRI、扩散加权图像、3D T2w、2个rs-fMRI、3个任务fMRI；任务顺序在受试者间随机，但兄弟姐妹顺序相同，同一受试者纵向波次间任务顺序保持不变。扫描约需2小时，可中途休息；3.5%的受试者分两次在一周内完成。超过79%的受试者成功完成整个影像协议。无法完成某些fMRI行为任务的受试者可在扫描仪外通过笔记本电脑完成。

$T_{1}w$为1 mm各向同性3D反转准备RF spoiling梯度回波，可用时使用前瞻性运动校正（目前仅Siemens和GE）。$T_{2}w$为1 mm各向同性3D可变翻转角快速自旋回波，同样可用时使用前瞻性运动校正。dMRI为1.7 mm各向同性，使用multiband EPI，切片加速因子3，包含96个扩散方向、7个b=0帧和四个b值（6方向b=500 s/mm$^{2}$、15方向b=1000 s/mm$^{2}$、15方向b=2000 s/mm$^{2}$、60方向b=3000 s/mm$^{2}$）。fMRI为2.4 mm各向同性，TR=800 ms，multiband EPI切片加速因子6。dMRI和fMRI采集块均包含用于$B_{0}$失真校正的fieldmap扫描。

数据从站点加密传输至DAIC后，通过夜间rsync复制到网络附加存储，并用JSON元数据自动分类序列类型。缺失数据通过比较接收序列数与REDCap中记录的采集数识别。GE平台在软件升级前采集的dMRI/fMRI需从原始k空间离线重建为DICOM。协议合规性检查包括关键参数（如体素大小、重复时间）是否匹配，dMRI/fMRI是否具有对应$B_{0}$ fieldmap，以及文件数完整性。自动QC计算SNR和头动统计：sMRI包括脑值均值和SD；dMRI通过将每帧配准到张量拟合合成图像估计头动，FD为帧间头动平均，暗层通过原始数据与张量拟合合成数据的RMS差异离群值识别；fMRI包括平均FD、FD<0.2/0.3/0.4 mm的秒数以及运动校正后的tSNR。训练有素的技术人员对$T_{1}w$、$T_{2}w$、dMRI、dMRI fieldmap、fMRI和fMRI fieldmap进行视觉审查，多帧图像以9×9矩阵展示81帧，dMRI展示平均b=0、FA、MD、张量拟合残差和DEC FA图，fMRI展示时间平均和时间SD。所有序列由两名以上审查者共识评级，拒绝时需记录伪影类型。

sMRI预处理中，$T_{1}w$和$T_{2}w$使用扫描仪厂商提供的非线性变换校正梯度非线性失真；$T_{2}w$经同模态粗刚性预对齐后以互信息配准到$T_{1}w$。强度不均匀校正使用平滑变化的$B_{1}$偏置场，基于稀疏空间平滑和白质分割，假设白质内$T_{1}w$（或$T_{2}w$）强度均匀。目标白质强度设为110，与FreeSurfer标准偏置校正的白质值匹配。白质掩膜由快速图谱分割定义，并经邻域滤波剔除强度离群体素。使用正则化线性逆和高效稀疏求解器估计偏置场，平滑约束刚度优化为足够宽松以容纳线圈邻近导致的极端强度变化，同时避免过拟合白质局部变化。偏置场在平滑脑掩膜内估计，并沿上下轴线性插值到体积边缘。图像刚性配准并重采样到标准空间平均参考脑（1.0 mm各向同性，大致对齐AC/PC轴），该参考脑由500名成人$T_{1}w$图像经DCT非线性配准后平均得到。若同一类型有多个扫描，仅使用一个；根据手动QC排除质量差的扫描，若多个可接受则选问题最少者，平局时选会话中最后一个可接受扫描。

脑分割使用FreeSurfer v5.3进行皮层表面重建和皮层下分割，该版本已在儿童中验证并用于大型儿科研究。由于已进行强度缩放和不均匀校正，标准FreeSurfer流程被修改为跳过初始强度缩放和N3校正。截至Data Release 2.0.1，$T_{2}w$未用于皮层表面重建和皮层下分割，未来可能纳入。FreeSurfer 6.0在ABCD测试和数据采集开始后发布，未充分测试，因此Data Releases 1.0–2.0.1使用5.3，未来预期使用6.0或更高。皮层下结构使用自动图谱体积分割标记；皮层灰质和白质体素基于表面非线性配准到图谱和贝叶斯分类规则标记；基于表面积遗传相关的模糊聚类分区用于计算皮层表面测量平均值；基于rs-fMRI功能连接定义的分区从图谱空间重采样到个体空间用于rs-fMRI分析。

sMRI形态测量包括皮层厚度、面积、体积和沟深；图像强度测量包括$T_{1}w$、$T_{2}w$以及$T_{1}w$和$T_{2}w$皮层对比度（灰白质强度归一化差异）。皮层对比度反映影响灰白质边界位置的因素（如皮层周围髓鞘含量），可能对脑发育和精神病理学更敏感。在灰白质边界沿法线方向$\pm0.2$ mm处采样强度值，计算皮层对比度 [white - gray] / [white + gray] / 2。对两种标准FreeSurfer分区方案计算每个皮层分区的平均值，使用未平滑的表面图；对模糊聚类分区使用平滑表面图（~66 mm FWHM）计算加权平均（权重0–1）；对体积皮层下ROI计算未平滑强度测量平均值及每个结构的体积。

sMRI后处理QC中，技术人员审查皮层表面重建准确性，对运动、强度不均匀、白质低估、软膜高估和磁敏感伪影五类伪影或重建不准确按0–3评分（无、轻、中、重），并给出总体QC评分：推荐使用（1）或推荐排除（0）。任一类评为3（严重）则推荐排除。

dMRI预处理中，涡流校正（ECC）使用基于模型的方法，根据扩散梯度方向和幅度预测整个扩散加权体积集的失真模式，校正限于相位编码方向位移。共12个自由参数，将相位编码方向位移建模为空间位置、梯度方向和梯度强度的函数。由于突然头动常导致单帧某些层严重信号丢失，使用稳健张量拟合排除暗层以免影响涡流失真估计。暗层识别：先对log变换图像进行标准线性张量估计，计算每帧每层残差RMS，按该层内帧的中位RMS归一化，归一化RMS>3.2的帧从后续张量拟合中删失，三次迭代稳定。暗帧-层用删失张量拟合的合成图像替换。ECC通过牛顿法最小化每个涡流校正图像与删失张量拟合合成图像之间的RMS误差优化，考虑帧间对比变化。校正后重新估计张量（再次排除暗帧-层），共五次迭代。头动校正将每帧刚性配准到后ECC删失张量拟合合成体积；暗帧-层用张量拟合插值替换；扩散梯度矩阵根据头旋转调整；计算平均FD供组水平统计作为协变量。$B_{0}$场不均匀导致的空间和强度失真通过反转相位编码极性方法最小化：对齐一对相反相位编码极性的b=0图像，估计位移场体积并校正每帧失真；然后校正梯度非线性失真。b=0 dMRI经同模态粗预对齐后以互信息配准到$T_{1}w$；dMRI重采样为1.7 mm各向同性，相对于已刚性重采样到图谱脑的$T_{1}w$有固定旋转和平移，提供标准方向；扩散梯度矩阵再次根据头旋转调整；重采样使用三次插值；提供dMRI与$T_{1}w$之间的刚性变换矩阵。

纤维束分割使用AtlasTrack，一种基于概率图谱的自动白质纤维束分割方法。纤维图谱包含特定长程投射纤维的先验概率和方向信息，包括原始描述中未包含的额外纤维束（如皮质-纹状体连接和额叶上下皮质-皮质连接）。每个受试者的sMRI经DCT非线性配准到图谱，DTI衍生扩散方向与图谱纤维方向比较，细化先验束位置概率，个体化纤维束ROI，并最小化与图谱不一致区域的贡献。主要含灰质或脑脊液的体素（由FreeSurfer自动脑分割识别）从分析中排除。

dMRI微结构分析使用DTI计算FA和平均、纵向（轴向）、横向（径向）扩散率（MD、LD、TD）。扩散张量参数使用标准线性估计方法对log变换扩散加权信号计算。计算两种张量模型拟合：DTI内壳（DTI$_{IS}$）排除b>1000 s/mm$^{2}$的帧（保留b=500的6方向和b=1000的15方向），使扩散率测量更接近传统单b值采集；DTI全壳（DTI$_{FS}$）包括所有梯度强度/壳（b=500的6方向、b=1000的15方向、b=2000的15方向、b=3000的60方向）。利用多b值采集，还拟合限制谱成像（RSI）模型，一种允许体素内“受限”和“受阻”扩散混合的线性估计方法。RSI建模两个体积分数，代表细胞内（受限）和细胞外（受阻）扩散，具有独立的纤维方向密度（FOD）函数，建模为四阶球谐函数，允许单个体素内多个扩散方向。两个分数中LD固定为$1\times10^{-3}$ mm$^{2}$/s；受限分数TD建模为0；受阻分数TD建模为$0.9\times10^{-3}$ mm$^{2}$/s。RSI模型衍生指标包括：受限归一化各向同性（N0）、受限归一化方向性（ND）、受限归一化总量（NT）、受阻归一化各向同性（N0_s2）、受阻归一化方向性（ND_s2）和受阻归一化总量（NT_s2）。每个指标定义为对应模型系数的欧几里得范数除以所有模型系数的范数，无量纲，范围0–1；各指标平方等于相应模型组分的信号分数。N0和NT_s2分别来自受限和受阻分数的0阶球谐系数，反映细胞内和细胞外空间对体素内各向同性扩散相关信号降低的贡献。ND和ND_s2分别由受限和受阻分数的2阶和4阶球谐系数范数计算，反映方向性扩散。ND定性上类似FA，但设计上不受交叉纤维影响。NT和NT_s2反映细胞内和细胞外空间对扩散信号的总体贡献，分别由受限和受阻分数的0、2、4阶系数范数除以所有模型系数范数计算。

DTI和RSI平均指标计算于AtlasTrack白质纤维束ROI和FreeSurfer自动皮层下分割ROI。纤维束表示为阈值化概率图，概率估计用于计算DTI和RSI指标的加权平均。DTI和RSI指标也采样到FreeSurfer皮层表面网格，生成皮层灰质和邻近白质的扩散属性图，并计算解剖皮层分区的表面ROI平均值。采样沿灰白质边界（“white”表面）法线方向以0.2 mm增量进行，范围双向0.8–2 mm。白质和灰质值通过基于每个体素白质或灰质比例的加权平均合并组织类型内的样本。对于皮层下ROI，通过加权平均抑制CSF部分容积污染：根据ROI内MD值与中位数的差异计算每个体素的权重因子；典型离散度定义为ROI内MD值的中位绝对偏差（MAD）跨受试者平均；权重使用Tukey bisquare函数计算，MD值离中位数越远（相对于离散度乘以4.7）权重越低。

dMRI后处理QC针对Data Release 1.1的子集，时间允许时可能审查其余受试者。审查者比较RSI衍生ND图像与共配准$T_{1}w$图像，沿五个维度评分：残余$B_{0}$失真、与$T_{1}w$的配准、图像质量、分割完整性和视野（FOV）截断，各0–3分。残余失真通过观察ND图像中白质束相对于刚性共配准$T_{1}w$的拉伸或压缩评估，重点关注胼胝体和额叶。配准差根据$T_{1}w$与RSI-ND图像间可见旋转或平移评分。图像质量基于ND图像中条带、颗粒感、运动、伪影或灰白质对比差评分。自动白质束分割评估不完整、缺失或严重错位。FOV截断指示皮层背侧或腹侧裁剪。每个dMRI序列给出总体QC评分：推荐使用（1）或推荐排除（0）。若$B_{0}$扭曲、配准、图像质量或分割评为3（严重），则推荐排除；FOV截断虽评估但不用于总体QC评分。

fMRI预处理中，头动校正使用AFNI 3dvolreg将每帧配准到第一帧，同时提供头动时间过程估计用于任务fMRI和rs-fMRI单受试者分析。$B_{0}$失真使用与dMRI相同的反转极性方法校正。为避免梯度回波采集中的体素内场梯度导致信号丢失，位移场从独立自旋回波校准扫描估计，根据扫描间头动调整后应用于梯度回波图像序列。然后校正梯度非线性失真。扫描间运动校正通过三次插值将每个扫描重采样到参考扫描（选择最接近该受试者fMRI扫描集中间的扫描），基于每个扫描第一帧到参考扫描第一帧的刚性配准。自旋回波$B_{0}$校准扫描（即fieldmap）与$T_{1}w$结构图像之间的自动配准使用互信息，基于同模态图谱粗预对齐。提供fMRI与$T_{1}w$之间的刚性变换矩阵。所得fMRI图像保持“native-space”，2.4 mm各向同性分辨率。

任务fMRI行为测量针对每个任务计算，以评估表现并识别准确率低或反应慢的受试者。MID：三种试次（赢钱、输钱、无得失），输赢进一步分小和大。短暂反应窗口后正性或负性反馈告知表现。行为指标包括每种试次的试次数、对不同激励幅度的反应时均值和SD、总金钱收益。若任一运行中任一试次类型在正性或负性反馈中事件少于4，则行为表现标志变量指示表现差。SST：Go试次中受试者在短暂反应窗口内按键指示箭头方向；较少见的Stop试次中呈现延迟停止信号，指示抑制运动反应。主要试次-反应组合类别为“Correct Go”、“Incorrect Go”、“Correct Stop”和“Incorrect Stop”。每类行为指标包括试次数、反应时均值和SD、平均停止信号延迟和平均停止信号反应时。表现差的标准：Go试次<50、Correct Go百分比<60%、Incorrect Go>30%、Late Go（正确和错误）>30%、No Response Go>30%、Stop试次<30、Stop试次准确率<20%或>80%、或Correct Go反应时<Incorrect Stop反应时。EN-Back：0-back和2-back工作记忆任务块设计，受试者按键指示图像重复呈现。图像类型包括情绪正性、负性或中性面孔或地点图片。行为指标包括总试次数、正确反应数、准确率（正确反应/总试次）、正确反应的反应时均值和SD。影像会话后，EN-Back再认记忆任务要求受试者判断图片是否在EN-Back任务中见过。对每种刺激类型（旧和新）计算命中率和虚报率。额外指标包括校正准确率（工作记忆任务命中率减去回忆任务虚报率）、反应偏差和d-prime。若0-back或2-back块总体反应准确率<60%，则表现差。

任务fMRI分析在单受试者水平使用一般线性模型（GLM）和ROI方法估计任务相关激活强度。分析前处理：fMRI预处理后的步骤包括去除初始帧以确保$T_{1}w$信号平衡，并将体素时间序列除以时间均值归一化。表面采样：预处理时间过程采样到每个受试者皮层表面。含皮层灰质的体素通过沿每个顶点表面法线方向从灰白质边界向皮层灰质内1 mm处采样投影到表面（使用FreeSurfer mri_vol2surf，"white"表面，"-projdist 1"选项，默认"nearest"插值）。ROI值提取：使用FreeSurfer解剖定义分区和皮层下ROI计算平均时间过程。干扰回归量：时间序列数据中的基线和二次趋势纳入分析；运动估计及其导数也作为回归量；FD>0.9 mm的时间点删失。用于回归和删失的运动时间过程经无限脉冲响应（IIR）陷波滤波器时间滤波，衰减0.31–0.43 Hz范围信号，该频率范围对应呼吸相关的运动估计振荡信号（18.6–25.7次呼吸/分钟）。去除这些与呼吸相关的快速振荡后，滤波运动估计和FD值更准确反映实际头动。一般线性模型：使用AFNI 3dDeconvolve中的GLM在单受试者水平估计任务相关激活强度。血流动力学响应函数使用gamma变体基函数加其时间导数两参数建模（使用3dDeconvolve中'SPMG'选项）。任务模型包括每个条件的刺激时序和条件的线性对比。MID和SST分析中事件建模为瞬时；EN-back中线索（~3 s）和试次块（~24 s）持续时间建模为与两参数gamma基函数卷积的方波（即使用'SPMG'选项时指定块持续时间）。输出包括每个体素、顶点或ROI时间序列的GLM beta系数和均值标准误（SEM；由beta与t统计量比值计算）。跨运行平均：对两个运行分别计算ROI平均beta系数和标准误。按名义自由度（运动删失后剩余帧数减模型参数数，不考虑时间自相关）加权计算每个受试者跨运行平均值，因运动删失而运行间不同。自由度少于50的运行从跨运行平均中排除。删失无效对比：儿童头动频率和幅度差异大。一些受试者频繁运动导致用于估计模型参数的时间点大幅减少。根据超阈值头动（FD>0.9 mm）相对于给定事件类型发生的时间，罕见条件在某些受试者中可能代表性不足或完全缺失。未代表的条件beta和SEM值未定义，在表格数据中共享为空单元格。若条件代表性不足，GLM设计矩阵变得病态，使这些条件及包含它们的对比的beta权重估计不可靠。罕见情况下，这导致beta和SEM估计极端值，与给定对比的典型值相差数个数量级。极端离群值违反标准参数假设，组水平统计分析可能产生无效和无意义结果。为防止此情况，若beta和SEM值被识别为具有极高SEM值因而beta估计可靠性低，则删失这些值。对于给定受试者特定对比和ROI的极端值，通常同一受试者和对比在其他脑区也有离群值，且脑区间变异通常更大。对于皮层表面SEM RMS大于5%信号变化的对比，删失所有ROI的beta和SEM值。这占所有受试者-任务-对比-运行组合的不到0.5%。删失值替换为空单元格。

静息态fMRI分析使用基于种子的相关方法计算功能连接，适配皮层表面分析。分析前处理（不属于fMRI预处理）包括去除初始帧、归一化、回归、时间滤波和ROI平均时间过程计算。去除初始帧后，将体素时间序列除以时间均值归一化，然后使用线性回归去除二次趋势、与估计运动时间过程相关的信号、脑白质、脑室和全脑的平均时间过程及其一阶导数。用于计算平均时间过程的白质、脑室和全脑ROI来自FreeSurfer自动脑分割（aseg），重采样到与fMRI数据体素对齐，然后腐蚀一个fMRI分辨率体素。运动回归包括六个参数及其导数和平方。如任务fMRI分析所述，估计运动时间过程经时间滤波衰减呼吸相关信号。FD>0.3 mm的帧从回归中排除。回归后，时间过程进行0.009–0.08 Hz带通滤波。表面采样和ROI平均：预处理时间过程以与任务fMRI数据相同的方式采样到每个受试者皮层表面。使用FreeSurfer解剖定义分区和基于静息态功能连接模式的功能定义分区（从图谱空间重采样到个体空间）计算皮层表面ROI平均时间过程。也计算皮层下ROI平均时间过程。计算每个ROI的时间方差，反映低频振荡幅度。网络相关分析：计算每对ROI的相关值，Fisher变换为z统计量，并在网络内或网络间平均，提供网络相关强度的汇总测量。在Gordon分区中，ROI分组为若干网络（如默认、额顶、背侧注意等）。网络内平均相关计算为该网络内每个独特ROI配对组合的Fisher变换相关的平均值。网络间平均相关类似地通过平均第一个网络ROI与第二个网络ROI的每个独特配对组合的相关计算。此外，计算每个网络与每个皮层下灰质ROI之间的相关，通过平均网络内每个ROI与给定皮层下ROI之间的相关。运动删失：运动删失用于减少可能存留于回归后的头动残余效应。FD>0.2 mm的时间点从方差和相关计算中排除（比回归步骤阈值稍保守）。少于五个连续亚阈值时间点的时间段也排除。头动效应可能在突然头动后持续数秒（如自旋历史或$T_{1}$弛豫效应），因此基于检测相对于全脑空间变异的离群时间点进行额外一轮删失。计算每个时间点的跨ROI SD，SD值低于或高于中位SD值三倍中位绝对偏差（MAD）的离群时间点从方差和相关计算中排除。跨运行平均：ROI方差和网络相关值跨rs-fMRI运行平均，按运动删失后每个运行剩余帧数加权。可用时间点少于100（共采集375）的运行从平均中排除。无可用运行的受试者在表格结果中接收空值。

fMRI后处理QC：对于Data Release 2.0.1，仅执行上述自动和手动fMRI QC。DAIC和合作者正在研究最佳的后处理fMRI审查，部分类似于后处理dMRI QC程序。

数据与方法共享与NDA合作进行。DICOM文件通过“Fast Track”机制在数据采集后约一个月内持续公开。预处理NIfTI文件和ROI分析表格结果在年度数据发布中共享。本文记录的方法作为第二次年度发布ABCD Data Release 2.0的一部分共享，该发布于2019年3月提供，包括完整的2016–2018基线样本结果。本文数据结合了ABCD Data Release 2.0与2019年7月修订的ABCD Fix Release 2.0.1。处理流程打包为便携容器格式（Docker容器），包含轻量虚拟化Linux环境和完整执行环境及所有软件依赖。用户目前可从NITRC下载beta测试版可执行Docker容器。

## 结果与讨论

ABCD Release 2.0.1中的影像衍生表格数据是来自大型多样化9–10岁儿童样本（n=11759接受了MRI检查）的多模态测量和多种解剖区域化方案的丰富集合。部分受试者因疲劳和/或时间限制可能省略某些扫描；初始QC中严重伪影导致额外序列排除。Fig. 3和Fig. 4的流程图展示各模态表格数据可用受试者数减少的数据丢失来源。红框显示阻止处理或分析步骤的主要排除；白框代表各模态表格数据；额外数据丢失反映结果因各种原因从整理数据集中排除，罕见情况下为可恢复的处理失败。任务fMRI缺失结果与刺激/反应时序文件损坏、时间戳与fMRI采集不一致或其他采集异常，以及高RMS SEM值结果删失有关。rs-fMRI缺失结果反映运动删失后缺乏足够有效时间点的可用扫描。通过未来修改处理或分析软件和参数，一些当前排除的受试者结果可能在未来数据发布中恢复。蓝框代表推荐纳入标准中指定的可选过滤步骤。

初步技术调查聚焦于各模态选定测量及扫描仪制造商间差异。尽管努力标准化跨平台影像协议，仍发现制造商间差异，其幅度因模态和测量而异。平均皮层厚度、总皮层面积和$T_{1}w$灰白质对比是组均值在制造商间存在差异的sMRI测量（Fig. 5A-C）。DTI和RSI分析的dMRI衍生指标也在制造商间变化（Fig. 5D-F）。fMRI数据的体素平滑度和tSNR因制造商而异，EN-back任务测量的任务相关激活也如此（Fig. 5G-I）。对于rs-fMRI，平均运动因制造商略有差异，导致删失后可用时间点数不同；网络内相关强度也变化（Fig. 5J-L）。由于各模态的这些差异以及同一制造商不同扫描仪间的潜在差异，建议组分析使用每个扫描仪的唯一标识符（即DeviceSerialNumber, mri_info_deviceserialnumber）作为分类协变量以考虑扫描仪间变异，或使用类似的统计协调程序。

讨论指出，ABCD研究将提供迄今为止最全面的纵向调查，涵盖从儿童晚期到青春期到成年早期的脑和行为发展神经生物学轨迹。青春期许多风险过程导致晚年慢性疾病，包括烟草使用、酒精和非法物质使用、不安全性行为、肥胖、运动损伤和缺乏体力活动；许多精神疾病（焦虑、双相、抑郁、进食障碍、精神病和物质滥用）也在青春期发病。ABCD研究能够捕捉健康发育、前驱行为问题、药物和酒精实验以及先前神经解剖变化中的行为和神经生物学变化。识别神经心理、结构和功能测量作为精神、神经和物质滥用障碍的潜在生物标志物，可能更好地为早期身心健康问题的青年提供诊断和治疗信息。

对大型种族多样化年轻人群在青春期定期进行严格采集监测和统一图像处理，对于表征可塑性发育期的细微神经解剖和功能变化是必要的。整理后的ABCD数据发布提供规范神经影像测量，使科学界能够检验无数关于脑和认知发展的假设。DAIC和ABCD合作者将继续改进和扩展图像处理流程，产生新的和演变的影像指标，评估其纳入未来整理数据发布的潜力。将新指标与规范测量一起考虑，能够比较和对比新旧分析技术。本文描述的框架使所有数据能够定期重新处理以适应新分析流程。目标是使这里开发的方法可共享和可部署于其他大规模神经影像研究。

局限与注意事项：Fast Track数据共享机制在数据采集后不久进行，未经处理、质量控制或整理，包括所有可用且允许共享的ABCD影像数据。具有最严重伪影或DICOM文件缺失/损坏的影像序列从后续处理中排除，因此不包含在最小处理或表格数据共享中。对于给定模态，额外受试者可能因脑分割或模态特异性处理分析失败而从表格数据中缺失。然而，成功处理且具有中度影像伪影的数据包含在最小处理和表格数据共享中，这对于某些研究（如影像伪影对衍生指标影响的方法学研究）是必要的。对于大多数组分析，建议排除有显著偶然发现、过度运动或其他伪影的病例，并提供多种QC相关指标用于应用模态特异性纳入标准。一些研究者可能希望以此作为自定义纳入标准的模板，包括额外QC指标或更保守阈值。

虽然Fast Track提供DICOM数据的早期访问，但警告用户可能不当处理数据，导致不准确或虚假发现。ABCD处理流程的目的是使用共识方法为整理后的ABCD数据发布提供图像和衍生指标。由于处理流程预期随时间变化，建议作者明确说明使用的发布版本（例如Adolescent Brain Cognitive Development Study (ABCD) - Annual Release 2.0, DOI: 10.15154/1503209）。每个新发布记录变化并包含先前发布的数据，必要时重新处理以保持特定发布内的一致性。不建议在整理数据发布之间合并数据，但Fix Release部分替换先前发现错误的Data Release（ABCD Fix Release 2.0.1, DOI: 10.15154/1504041）。

未来方向：未来ABCD数据发布使用的处理流程预期随时间演变，反映领域内神经影像处理工具和分析方法的总体进展。必须考虑纵向分析特有的未来挑战，如研究期间扫描仪和头线圈升级或更换的可能性。其他最近或即将开发的分析方法可能更好地解决特定问题，例如提供更优的影像伪影校正、更准确的脑分割或额外类型的生物学相关影像衍生指标。例如，FreeSurfer当前皮层下分割流程与手动分割金标准相比存在某些结构低估和高估的偏差。此外，有多种优秀的神经影像工具箱可用于dMRI数据预处理，如FSL、TORTOISE和DTIprep，它们使用类似方法但不同实现来解决主要挑战。在ABCD联盟内，正在努力使用替代方法处理ABCD数据以比较各处理或分析阶段的方法，使用衍生结果可靠性的定量指标。此外，计划未来公开发布使用修改版HCP流程处理ABCD数据的结果。总体而言，我们寻求通过纳入已实施和验证的新方法，随时间增强和扩展ABCD图像分析。

为帮助研究者更容易利用这一数据资源，DAIC提供基于网络的ABCD Data Exploration and Analysis Portal（DEAP，数据发布后不久更新）。该工具提供对完整ROI多模态影像衍生测量集的便捷访问，以及使用广义加性混合模型分析重复测量并适当建模站点、扫描仪、家庭相关性和一系列人口统计学变量效应的复杂统计程序。未来发布还将支持体素（体积）和顶点（表面）分析。

作为十年纵向研究，参与者每两年返回进行连续影像波次，未来ABCD数据发布将包括每个受试者的多个时间点。基线时间点提供的所有影像衍生指标也将为每个连续时间点独立生成。此外，受试者内纵向分析将为某些影像指标提供更敏感的纵向变化估计。例如，FreeSurfer纵向处理流程减少变异性并提高皮层厚度和皮层下结构体积变化测量的敏感性。通过Quantitative Analysis of Regional Change（QUARC）可获得对皮层和皮层下体积变化更敏感的分析。QUARC的变体也可用于dMRI数据的纵向分析，具有改进的敏感性。未来开发和测试的目标是提供一系列影像衍生指标的纵向变化估计，这些估计对微小变化最敏感、对时间点顺序无偏，并且相对于独立处理时间点估计的变化斜率为1。

分析多站点和纵向影像数据时的一个重要因素是确保扫描仪间图像可比性，称为数据协调。统计协调程序目前可用于校正扫描仪间变异。例如，每个扫描仪的唯一标识符（即DeviceSerialNumber）可作为分类协变量，以考虑个体扫描仪间给定测量均值的潜在差异。最近，一种基因组批次效应校正工具被提出作为跨多个扫描仪数据协调的工具，用于皮层厚度和扩散率测量。该程序可由个体研究者应用于整理数据发布，或如果被认为可靠和稳健，可纳入统计操作前端工具（DEAP）。另一种协调方法试图通过为每个扫描仪生成研究特异性图谱来保留站点特异性特征，在纵向衰老研究中显示出适度改进。对于扩散成像，一种有前景的方法在多模态图像配准框架内使用旋转不变球谐函数。DAIC正在积极测试在分割、分区和DTI/RSI拟合之前协调图像的新方法，以提高跨站点和时间的兼容性。未来几年，ABCD研究将纳入这些协调技术的改进，并重新处理先前发布的数据以减少扫描仪间差异。

结论：我们描述了用于生成ABCD Data Release 2.0（DOI: 10.15154/1503209, 2019年3月）和ABCD Fix Release 2.0.1（DOI: 10.15154/1504041, 2019年7月）中预处理影像数据和衍生指标的处理流程，这些数据通过NDA提供。该资源包括多模态影像数据、全面的行为评估组合和人口统计学信息，涵盖11873名9至10岁典型发育儿童。神经影像衍生指标包括形态测量、微结构、功能关联和任务相关功能激活。完成后，ABCD数据集将提供全面研究脑与认知发展、物质使用和其他经历以及社会、遗传和环境因素之间关系的非凡机会。它将使科学界能够解决许多关于脑和行为发展以及神经和其他行为相关表型遗传结构的重要问题。我们描述的处理流程提供全面的多模态影像衍生指标组合。处理方法包括各种失真校正、dMRI和fMRI图像中的头动校正以及结构图像中的强度不均匀校正。这些校正共同旨在减少估计变化的方差、提高模态间配准准确性，并改善脑分割和皮层表面重建的准确性。
