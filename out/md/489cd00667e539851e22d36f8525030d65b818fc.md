# 基于局部梯度流优化与全局细化的视频显著性检测

*Consistent Video Saliency Using Local Gradient Flow Optimization and Global Refinement* · 2015 · https://doi.org/10.1109/tip.2015.2460013

本文提出一种新的视频显著性检测方法，通过梯度流场与能量优化同时利用帧内边界信息和帧间运动信息，对前景与背景进行估计，并在此基础上引入局部与全局对比度显著性线索，最终通过一个时空能量函数使输出的显著性图在时间轴上保持一致。实验表明，该方法在多个视频数据集上优于当时的代表性图像与视频显著性检测方法。

## 引言与相关工作

显著性检测旨在预测人眼注意的视觉区域，早期多用于注视点预测，后扩展为显著物体检测。图像显著性方法可分为自底向上与自顶向下两类，自顶向下方法依赖具体类别的监督学习，而多数自底向上方法基于对比度先验，利用颜色、亮度、方向等低层特征。然而，这些方法往往只突出高对比度边缘，难以均匀地高亮整个物体，且周围上下文范围的选择存在困难：范围过大时前景和背景中的相似颜色难以区分，范围过小则导致物体内部衰减。对于视频显著性，虽然运动信息是重要线索，但已有方法大多将运动特征简单叠加到图像显著性模型上，逐帧处理，忽略了视频显著性应具有时空一致性，即前后背景区域的显著性值不应随时间剧烈变化。受特征整合理论启发，本文将边缘与运动特征深度结合为梯度流场，用于显著区域定位，并针对对比度先验的不足设计了局部与全局对比度线索，最后引入时空能量函数以保证一致性。

相关工作分为两条线。图像显著性方面，频率域方法如光谱残差、相位谱分析被用来估计显著性，空间域方法则大多利用颜色、对比度或中心‑周围机制，也有方法利用边界先验将图像边界视为背景来增强计算。视频显著性方面，多数方法只是把运动通道加入图像模型，例如基于中心‑周围假设或动态纹理的扩展，或利用局部回归核、聚类等，但普遍逐帧计算，缺乏对时间一致性的全局考虑。与这些方法相比，本文的梯度流场同时利用帧内边界和帧间运动信息，能够在复杂场景中更稳健地估计物体与背景。

## 方法

方法分为三个主要步骤：显著性估计、显著性线索细化、时空显著性优化。

第一步，给定输入视频序列，先用SLIC将每帧I_k抽象为超像素R_k = {R_{k,1}, R_{k,2}, …}，得到抽象帧I_k^×。颜色梯度幅度M_k^c(x) = ‖∇I_k^×(x)‖。运动信息采用大位移光流估计算法计算光流场v_k，并取其梯度幅度M_k^o(x) = ‖∇v_k(x)‖。将两者融合为时空梯度场M_k(x)：当max(M_k^o)>1时，M_k(x) = M_k^c(x) · (1 − exp(−λ·M_k^o(x)))；当max(M_k^o)≤1时，M_k(x) = M_k^c(x)。实验中发现M^o在最大值大于1时更具判别力，故用指数函数强调，λ在所有实验中取1；场景近静态时M^o很小，不具区分性。融合后的时空梯度场能更好地揭示视觉重要区域。

在此基础上，定义梯度流：从帧的四条边出发，沿水平和垂直方向到达对边。以从左到右的流F^l为例，该流包含同一行所有像素，其值定义为V^{F^l}(x) = M(x) + V^{F^l}((x, y−1))。类似定义右到左、上到下、下到上的流。梯度流场T取四个方向流的最小值：T(x) = min(V^{F^l}, V^{F^r}, V^{F^t}, V^{F^d}) = M(x) + min(V^{F^l}((x, y−1)), V^{F^r}((x, y+1)), V^{F^t}((x+1, y)), V^{F^d}((x−1, y)))。但由于只考虑4邻域，容易受孤立噪声点影响，因此重新定义：考虑上下(2t+1)条相邻流，即V^{F^l}(x) = M(x) + min(V^{F^l}((x−t, y−1)), …, V^{F^l}((x, y−1)), …, V^{F^l}((x+t, y−1)))。当t=0时即为原式。实验表明t∈{1,2,3}时结果优于t=0，但t过大会忽略更多物体边界，故所有实验取t=2。随后在区域级别平均梯度流场，得到T_k^R(x)，并按区域大小归一化到[0,1]。

当光流估计不准确时，梯度流场可能引入错误结果。由于相邻帧的背景具有一致性，可假设某一帧中不显著的背景区域在下一帧中也不显著。据此，将颜色梯度幅度修正为：当上一帧区域梯度流场值T_{k−1}^R(x)<η时，M_k^c(x)乘以ε^c；否则不变。同样对光流梯度幅度施加ε^o。实验中η=0.2，即梯度流场值小于0.2的区域被视为虚拟背景B_k。经此修正，前景与背景能大致分离，但前景内部仍有不完整的部分，需要进一步细化。

第二步，显著性线索细化。传统区域对比度显著性C(R_{k,p}) = Σ_{p'} φ(R_{k,p}, R_{k,p'}) ‖c_{k,p} − c_{k,p'}‖²，其中φ为空间距离加权，但这种方法无法区分前景与背景，存在物体衰减问题，且尺度参数σ难以设定。本文利用梯度流场估计的背景区域B_k，定义“周围背景对比度”局部线索l^C(R_{k,p})，仅对B_k中的区域计算颜色对比，并按空间距离自动调整邻域范围：距离近的背景影响范围小，距离远的背景影响范围大。该线索能有效抑制背景、突出前景。同时定义全局线索g^C，即超像素到背景区域的最短路径距离，路径上的颜色距离和梯度流场距离同时考虑，D_g(R_{k,p}, R_{k,p'})通过Johnson算法求解。g^C(R_{k,p})为超像素到所有背景超像素的最短距离。将局部与全局线索归一化到[0,1]后，取两者最小值作为综合显著性S^C(R_{k,p}) = min{l^C, g^C}，实践表明该组合能产生突出且均匀的显著性结果。

第三步，时空显著性优化。设整个视频所有超像素集合Q = {1, 2, …, N}，每个超像素q有坐标和帧索引。定义能量函数F = F_unary + F_smooth = α Σ_q (s_q − S_{k_q}^C(x_q))² + Σ_{q,q'∈ℵ} w_{q,q'} (s_q − s_{q'})²，其中第一项约束最终显著性接近初始估计，第二项约束时空相邻超像素的显著性尽可能一致。ℵ包含同一帧内空间相邻的超像素以及时间上相邻帧中距离不超过800的对应超像素；w_{q,q'} = exp(−‖c_q − c_{q'}‖)基于CIELab颜色相似度加权。写成矩阵形式后，最优解为s = α(B − W + αE)^{-1} s*，其中W为权重矩阵，B为对角阵，α在所有实验中取0.5。该二次能量可用凸优化高效求解。

## 实验与结论

实验在三个数据集上评估：SegTrack（6个视频，21–70帧）、FBMS（59个视频序列），以及作者新构建的ViSal数据集（17个挑战性视频，30–100帧，覆盖复杂颜色分布、杂乱背景、多种运动模式、快速拓扑变化和相机运动）。评价指标包括精确率‑召回率曲线（PR曲线）、F-measure（γ²=0.3）和平均绝对误差（MAE）。对比方法包括图像显著性方法IG（频率调谐）和SF（显著性滤波），以及视频显著性方法SS（滑动窗口）、CS（聚类）、SD（自相似）、QS（四元数傅里叶变换）和ST（时空显著性）。在SegTrack和FBMS上，所提方法在PR曲线、F-measure和MAE上均显著优于所有对比方法；在ViSal上同样取得最优结果。在运行时间方面，除频率域方法QS外，本文方法比其他对比方法更快。实验表明，该方法能适应静态、快速、动态等多种运动模式，并能均匀高亮整个物体，而生成了与标注最接近的显著性图。

本文提出了一种结合梯度流场、局部与全局对比度线索以及时空能量优化的视频显著性检测方法，能够生成时空一致的高质量显著性图，适用于前景和背景外观或运动模式变化剧烈的复杂场景。代码可从指定网址获得。
