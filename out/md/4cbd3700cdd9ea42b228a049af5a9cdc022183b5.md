# 遗传学习粒子群优化：一种基于遗传算法构造优质示范粒子的级联混合框架

*Genetic Learning Particle Swarm Optimization* (2015) · DOI: https://doi.org/10.1109/tcyb.2015.2475174

本文提出一种遗传学习粒子群优化（GL-PSO）算法，核心思想是将遗传算法（GA）用作粒子群优化（PSO）的“示范粒子”构造器，以级联而非并行方式混合两种算法。标准PSO中粒子只向个体历史最优（pbest）和全局最优（gbest）学习，容易早熟收敛；已有GA-PSO并行混合算法耦合松散、效果不稳定。GL-PSO采用上下两层级联结构：上层用GA的交叉、变异、选择操作对粒子的历史最优信息（pbest和gbest）进行进化，生成多样化且高质量的示范粒子；下层粒子按标准PSO规则向这些示范粒子学习，同时粒子的搜索经验又反馈回上层供GA继续改良。这种正反馈机制同时增强了全局搜索能力和搜索效率。算法在42个基准函数（含Yao等提出的f1–f14和CEC2013的f101–f128）上进行了验证，并与多种PSO变体及进化算法比较，实验结果支持其在精度、速度、可靠性和可扩展性上的优势。

## 引言与背景

PSO自1995年由Kennedy和Eberhart提出以来，因概念简单、效率高而被广泛用于工程优化，但其规范形式中粒子只受pbest和gbest引导，容易出现早熟收敛。改进方向分为四类：拓扑/多群、参数控制、混合方法、学习方案。混合类研究中，多数GA-PSO混合算法将种群分成并行子群，分别由GA和PSO控制，再定期交换个体，这种并行叠加存在两个困难：一是无法明确刻画交换个体对对方种群的影响（例如无法回答GA个体是否更新了PSO的pbest、迁移个体能否在GA选择中存活）；二是文献报道的性能并不稳定，且多在低维（≤10维）问题上测试，结果介于GA和PSO之间，未实现“1+1>2”。

技术背景上，GA的交叉和变异具有随机、全方向性，探索能力强但收敛慢；PSO方向性强、收敛快但容易陷入局部最优。生物背景上，行为遗传学（如蜜蜂采蜜、鸟类迁徙）表明动物行为受基因控制，而学习获得的行为技能又会反过来影响自然选择压力，进而改变基因频率。这为在PSO中引入遗传机制提供了类比依据：让GA为PSO“繁殖”引导粒子飞行的示范粒子。

## 遗传学习PSO：算法设计与机制分析

规范PSO中，第i个粒子的速度和位置分别为`Vi = [vi,1, ..., vi,D]`、`Xi = [xi,1, ..., xi,D]`，pbest为`Pi`，gbest为`G`。d维更新公式为：
`vi,d ← ω·vi,d + c1·r1,d·(pi,d − xi,d) + c2·r2,d·(gd − xi,d)` (1)
`xi,d ← xi,d + vi,d` (2)
其中ω为惯性权重，c1、c2为加速系数，r1,d、r2,d为[0,1]均匀随机数。该式可等价写为单一复合示范粒子形式：
`vi,d ← ω·vi,d + c·rd·(ei,d − xi,d)` (3)
其中`ei,d = (c1·r1,d·pi,d + c2·r2,d·gd)/(c1·r1,d + c2·r2,d)` (4)
即规范PSO的示范粒子是pbest和gbest的线性组合。FIPS、CLPSO、OLPSO等改进算法都在构造更复杂的示范向量，但均为线性或正交组合。

GL-PSO的遗传学习方案对每个粒子i进行以下三步操作。

**交叉**：以粒子i的pbest Pi和全局gbest G为亲本，生成后代`Oi = [oi,1, ..., oi,D]`：若`f(Pi) < f(Pk)`（k为随机选出的粒子，f为最小化目标），则`oi,d = rd·pi,d + (1−rd)·gd`，否则`oi,d = pk,d` (5)。即质量较好的粒子与gbest做算术交叉，较差粒子的后代则更多取另一个更优粒子的维度，从而利用群体历史经验提升基因质量。

**变异**：对Oi的每个维度，以概率pm重新在搜索空间内随机初始化：`oi,d = rand(lbd, ubd)` 若`rd < pm` (6)。变异增加示范粒子的多样性，使其可触及搜索空间任意位置。

**选择**：评估后代Oi的适应值，若优于当前示范粒子Ei则替换，否则保留：`Ei ← Oi` 若`f(Oi) < f(Ei)`，否则`Ei ← Ei` (7)。该精英策略保证示范粒子逐代进化且不会变差。若示范粒子连续sg代无改进，则用20%M锦标赛（随机选20%M个示范粒子，取最优者）替换当前示范粒子，帮助粒子跳出局部最优。

算法主体为重复执行上述操作：每代对每个粒子先更新示范粒子（交叉/变异/选择），再用式(3)（c=1.49618，ω=0.7298）更新粒子的速度和位置，并评估更新后的粒子、更新Pi和G。GL-PSO保留了规范PSO的框架，GA仅作为辅助工具，其计算复杂度为O[(D+M)·MaxFEs]，与规范PSO的O(D·MaxFEs)同阶（MaxFEs通常取10000·D，故总体为O(D²)）。

搜索行为分析（以Sphere函数和Schwefel 2.26函数为例）显示：在优化初期，随机初始化使pbest分布广泛，交叉构造的示范粒子远离当前粒子，表现为探索；随种群收敛，pbest与gbest接近，交叉的示范粒子位于粒子附近，转为开发。变异在解决多峰问题时作用突出，使D值曲线（示范粒子与粒子适应度之差）出现跳跃。此外，选择操作避免了规范PSO中由于pbest和gbest同时移动导致的示范粒子退化问题——例如二维Sphere最优[0,0]，若Pi从[6,5]变为[5,4]而G从[2,2]变为[2,1]，线性组合的示范粒子可能从[3,3]变为[4,3]，反而变差；而精英选择保证示范粒子单调不劣。

## 广义*L-PSO范式与实验验证

GL-PSO可推广为一个广义混合范式*L-PSO：将PSO分成上下两级联层，上层用任意学习/优化技术生成示范粒子，下层按普通PSO更新粒子；上层信息通过式(3)和(2)传给下层，下层的历史搜索信息作为素材反馈给上层。除遗传学习外，还可采用差分学习（DL-PSO）、分布估计学习（EL-PSO）等。已有的FIPS、CLPSO、OLPSO可视为该范式的特例，但它们上层未涉及适应值评估。

实验设置：两套共42个测试函数。第一套f1–f14来自Yao等，其中f1–f4为单峰、f5在2/3维单峰但高维多峰、f6为阶梯函数、f7为带噪声的二次函数，f8–f13为多峰、f14为f9的不连续版本；第二套f101–f128为CEC2013偏移和旋转函数，含单峰、多峰和混合复合函数。对比算法包括GPSO、HPSO-TVAC、FIPS、CLPSO、OLPSO、GAPSO、DEPSO。所有算法种群规模50，30维，MaxFEs=10000·D，每个函数独立运行30次，采用单侧Wilcoxon秩和检验（α=0.05）。GL-PSO参数：ω=0.7298，c=1.49618，pm=0.01，sg=7。

在第一套单峰函数（f1–f7）上，FIPS、CLPSO、GAPSO和DEPSO的精度低于规范GPSO，而HPSO-TVAC、OLPSO和GL-PSO达到高精度；GL-PSO在7个函数中4个取得最好结果。f7为噪声函数，随机扰动干扰了示范粒子的选择。搜索速度与可靠性比较中，GL-PSO一般具有最高速度和成功率。在7个多峰函数（f8–f14）上，GL-PSO在5个上精度最优，尤其Schwefel函数f8，GL-PSO是所有算法中唯一能以标准差0达到3.82×10^-4低误差的算法；Rastrigin函数f9上，变异操作维持了种群多样性，GL-PSO表现最好。在与单独GA和PSO的对比（补充材料S-I）中，GL-PSO在Sphere和Schwefel上同时优于两者，实现“1+1>2”。

在第二套28个CEC2013函数上，GL-PSO排名第一14次、第二6次、第三4次、第四3次，总体优于对比算法；唯一表现不佳的是f104，因其局部平滑性特殊。Wilcoxon检验显示GL-PSO在更多函数上显著优于对比算法。

参数敏感性研究：变异概率pm在[0.005, 0.05]范围内较好，过大扰动搜索、过小不能防止多峰早熟；停止间隔sg在[4,7]内能提高搜索效率，过小导致种群振荡，过大则粒子长时间困于局部最优。拓扑实验（补充材料S-V）显示全局拓扑版本优于局部版本。

可扩展性分析（50-D和100-D）中，GL-PSO在多数函数上保持最优，尤其f8、f9、f14在高维仍获高精度，而其他算法严重退化。与ACOR、SaDE、EDA、ABC、CMA-ES等非PSO算法比较（30-D，1秒最大运行时间）时，GL-PSO整体排名第一，显著优于多数对比。

## 结论

本文提出级联混合范式*L-PSO，并实现其具体实例GL-PSO——用GA的交叉、变异、选择构造示范粒子。交叉利用pbest和gbest生成高质量后代，变异注入多样性，选择保证示范粒子定向进化。实验表明GL-PSO在全局搜索能力、精度、速度、可靠性和可扩展性上显著优于现有PSO变体和多种进化算法。该范式为未来将PSO与新兴学习技术级联混合提供了开放思路，也可推广到动态、多目标优化和实际应用。
