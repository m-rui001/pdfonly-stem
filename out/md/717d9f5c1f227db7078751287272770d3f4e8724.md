# 结构相似性指数（SSIM）重新审视：一种数据驱动的方法

*Structural similarity index (SSIM) revisited: A data-driven approach* · 2021 · DOI: 10.1016/j.eswa.2021.116087

本文提出一个数据驱动框架，利用遗传算法（GA）和粒子群优化（PSO）对单尺度SSIM（SS-SSIM）及其多尺度扩展（MS-SSIM）的参数进行联合优化，以提高它们与人类主观评价（MOS/DMOS）的秩相关性（SRCC）。在五个公开IQA数据库（包括两个距离变化数据库）上的实验表明：在平均意义上，SS-SSIM的SRCC可提升约8%，MS-SSIM提升约3%；结构分量（γ）被优化为比对比度（β）和亮度（α）更重要，从而在数据层面支持了HVS优先提取结构信息的假设；使用“标准尺度选择”（SSS）时，优化后的SS-SSIM可以达到与更复杂的“最优尺度选择”（OSS）或MS-SSIM相当的性能；从某个数据库学到的参数可以迁移到其他未见数据库。论文最终给出了一套建议参考参数及解释。

## 引言、背景与相关工作

图像处理与计算机视觉系统常依赖全参考图像质量评估（FR-IQA）指标。传统MSE类指标与主观感知相关不佳，而结构相似性指数（SSIM）通过分别比较亮度、对比度和结构三个成分，并以加权乘积合成，成功模拟了人类视觉系统（HVS）的结构提取特性，从而获得广泛应用。SSIM在众多应用中作为代理评价指标，例如去雨、去雾、医学图像增强、JPEG修复等。但SSIM原本设计为单尺度（SS-SSIM），其性能受观察距离等观看条件影响显著。为此，研究者提出了多尺度SSIM（MS-SSIM）以及最优尺度选择（OSS）等方法。本文聚焦于SSIM参数的重新校准，挑战三个常见假设：各分量权重相等（α=β=γ=1）、正则化常数K1=0.01与K2=0.03、以及滑动窗口大小等默认设置。

SS-SSIM的核心公式如下。对参考图像x和失真图像y，首先用11×11圆对称高斯窗（σ=1.5）提取局部统计量：均值μ、标准差σ、协方差σxy。亮度比较、对比度比较和结构比较分别为：

- 亮度：l(x,y) = (2μxμy + C1) / (μx² + μy² + C1)，C1=(K1L)²
- 对比度：c(x,y) = (2σxσy + C2) / (σx² + σy² + C2)，C2=(K2L)²
- 结构：s(x,y) = (σxy + C3) / (σxσy + C3)，C3=C2/2，σxy = (1/(N-1)) Σ(xi-μx)(yi-μx)

最终SSIM = [l(x,y)]^α · [c(x,y)]^β · [s(x,y)]^γ。默认α=β=γ=1，K1=0.01，K2=0.03，L=255（8位灰度）。

MS-SSIM在M个尺度上计算对比度与结构相似度，并仅在最高尺度（M）计算亮度：MS-SSIM = [l_M(x,y)]^αM ∏_{j=1}^M [c_j(x,y)]^βj [s_j(x,y)]^γj。当改变尺度时，对图像进行低通滤波并按因子2下采样。

尺度选择方面，本文比较了标准尺度选择（SSS）和最优尺度选择（OSS）。SSS假设典型观看距离为图像高度的3~5倍，下采样因子Zd = max(1, round(Hi/256))，Hi为图像高度。OSS基于自适应高频裁剪（AHC）和自适应尺度变换（SAST）模型，在离散小波域处理，并考虑观看距离、分辨率、纵横比等因素。具体公式包括AHC权重函数和SAST缩放参数。

相关工作方面，已有研究尝试优化SSIM的正则常数（Silvestre-Blanes等，仅枚举6种组合）、MS-SSIM的指数（Charrier等用GA，Skurowski等用回归），但搜索空间有限或仅针对特定失真。本文扩展至连续空间与更广参数集合，并比较GA与PSO两种元启发式，且进行跨数据库验证。

## 提出的方法：搜索空间与优化框架

优化目标为最大化SRCC，即fitness = SRCC(SSIM参数化后的预测值, 主观MOS/DMOS)。每个候选解（染色体/粒子）被编码为实数向量，各维映射到(0,3]区间。共定义六个搜索空间，逐步增加参数数量与复杂度：

1. SS-SSIM(α,β,γ)：仅优化三个指数，3维连续立方体。但即使离散化到0.001步长，仍有3000³个候选，穷举不现实；GA单次运行约720秒（TID2008）。
2. SS-SSIM_full：在α,β,γ基础上加入K1,K2（限制(0,0.3]）、滑动窗口尺寸w∈{7,9,...,25}、高斯标准差σ∈(0,3]、步长s∈{(1,1),...,(7,7)}、膨胀率d∈{1,2,3,4,5}。连续空间通过均匀子区间映射到整数集合，染色体为9维。
3. MS-SSIM(αj=βj=γj)：优化五个尺度的权重ιj=βj=γj（j=1..4）及ι5=α5=β5=γ5，5维。
4. MS-SSIM(αM, βj≠γj)：放宽假设，优化βj和γj（j=1..5）以及α5，共11维。
5. MS-SSIM(αj=βj=γj)^(0,1)：联合优化各尺度参数（每个尺度有ι, K1, K2, s, d, w, σ）以及一个5维二进制向量指示是否包含该尺度，连续部分35维，组合部分5维。
6. MS-SSIM(αM, βj≠γj)^(0,1)：将第5个空间的连续部分扩展至40维（β1,γ1,...,β5,γ5,α5及每个尺度的其余6个参数）。

对于混合空间，GA被改进为GA2：同时操作连续子空间（几何交叉、球变异）和二元子空间（点交叉、位翻转），二进制更新频率为每8代一次。PSO采用同步全局邻居（gbest），C1=C2=1.0，惯性权重w=0.79，越界坐标重新初始化为U(0,3]。所有算法种群大小40、代数50（GA2种群25、代数80），每次运行2000次适应度评估，重复10次（不同随机种子）。适应度评估中，使用蒙特卡洛交叉验证：每轮随机留出30%参考-失真对作为未见数据，训练时每次迭代随机选取训练部分的50%作为批次，以加速计算。

## 实验设置与结果

实验使用五个数据库：TID2008（25参考图，17种失真，1700对，观看距离3倍图高）、TID2013（25参考图，24种失真，3000对）、CSIQ（30参考图，6种失真，866对，观看距离5倍图高，DMOS）、CID:IQ（23参考图，6种失真，690对，双观看距离2.45/4.75）、VDID2014（8参考图，4种失真，160对，双观看距离4/6）。参数优化分别针对每个数据库进行，并报告未见数据上的SRCC。

总体性能：箱线图（图3）显示，SS-SSIM_full（优化全部9个参数）通常优于仅优化α,β,γ的SS-SSIM(α,β,γ)，也优于基线SSIM和MS-SSIM。对于两个距离变化数据库（CID:IQ、VDID2014）和CSIQ，排名前五的实验主要包含SS-SSIM_full；对于TID2008和TID2013，最佳为放松α=β=γ假设的MS-SSIM(αM,βj≠γj)，其与最佳SS-SSIM_full的SRCC差异仅为0.01~0.02。比较尺度选择方法，OSS在VDID2014上优势明显，但在CSIQ和CID:IQ上SSS更好，总体无统计显著差异。比较GA与PSO，两者性能接近，但GA秩略优。学习曲线显示优化在10-15代后基本收敛，无严重过拟合。

统计评估（Wilcoxon符号秩检验，α=0.05）：相对各自基线，所有优化变体（除SS-SSIM(α,β,γ)和MS-SSIM(αM,βj≠γj)^(0,1)外）均有显著提升；其中MS-SSIM(αM,βj≠γj)^(0,1)数值上甚至劣于基线。GA与S-PSO比较中GA显著更好（p=0.032）；SSS与OSS比较无显著差异（p=0.565）；SS-SSIM_full与MS-SSIM(αM,βj≠γj)比较无显著差异（p=0.083和0.268），但SSS下的p值约为OSS的三倍，表明OSS更接近MS-SSIM性能。

跨数据库分析（表7）：在相同数据库上训练得到最高SRCC，但迁移效果良好。MS-SSIM(αM,βj≠γj)用GA训练于CID:IQ、CSIQ、TID2008或TID2013时，几乎在所有测试数据库上都超过基线；SS-SSIM_full（SSS或OSS）在CSIQ、TID2008、TID2013训练后也表现出高迁移性。VDID2014因参考图少、失真种类少，迁移效果最差。

按失真类型（表8，基于TID2008）：优化后的SSIM在大多数失真类型上优于基线，尤其是SS-SSIM_oss_full（在TID2008上训练）提升最明显。跨数据库训练（如CSIQ）也优于基线，进一步佐证参数可迁移性。

参数分布：对SS-SSIM_full（表9），优化建议的γ普遍大于β，β大于α；K1通常约为0.2（默认0.01的20倍），K2约为0.1（默认0.03的3倍）；窗口尺寸多在15×15到21×21，步长多为(4,4)或(5,5)，膨胀率多为2~4（CID:IQ时1）。这解释了为何需要调整默认值。对MS-SSIM(αM,βj≠γj)（表10），结构权重γj在深尺度（j=3,4,5）最大，对比度βj在j=2或j=3/4达到峰值，α5普遍较小。对带尺度选择的MS-SSIM^(0,1)（表11），各数据库倾向保留尺度2-5，但VDID2014仅保留尺度3-5；参数K1、K2、窗口大小等与默认接近，作者推测可能是因为GA2初始种群包含默认解且精英过快主导，导致优化未充分探索。

## 结论与未来工作

本文以数据驱动方式重新校准SS-SSIM和MS-SSIM参数，证明优化后能显著提升与主观评价的SRCC。主要结论包括：1）结构信息优先于对比度和亮度，支持HVS理论；2）正则常数、窗口大小、步长、膨胀率等默认值需上调；3）经过恰当参数化的SS-SSIM可媲美甚至超过MS-SSIM，且计算量低约一个数量级；4）尺度选择上，OSS并不总是优于SSS；5）参数可跨数据库迁移。建议的新参数集可直接嵌入现有SSIM实现，且保持可微性，适用于神经网络损失。未来方向包括引入其他元启发式（如差分进化、樽海鞘算法），将观看距离作为显式输入，以及融合深度学习特征。

**局限性**：当前方法依赖图像下采样处理观看距离，未显式建模距离；缺少多观看距离的MOS标注数据集；对MS-SSIM^(0,1)的优化可能受算法参数（如GA2精英过度）限制。
