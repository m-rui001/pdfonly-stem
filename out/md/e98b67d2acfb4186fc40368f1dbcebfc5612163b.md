# 结合理论与实验的电催化：材料设计的启示

*Combining theory and experiment in electrocatalysis: Insights into materials design* · Science, 2017 · DOI: 10.1126/science.aad4998

本文是一篇综述，主张以描述符（descriptor）和火山图（volcano）为核心的理论框架来理解并指导多类电化学反应（涉及水、氢、氧）的催化剂设计，并将该框架延伸至过氧化氢生产、二氧化碳还原和氮还原等新兴反应。作者强调：多数反应的性能瓶颈可追溯到不同吸附中间体能量之间的标度关系（scaling relations），因此需要新的催化剂设计范式来解耦这些关系。

## 能源背景与催化剂设计策略

全球能源需求在2013年达到18 TW，其中约80%来自化石资源；预计到2040年在“新政策”或“当前政策”情景下将增至24或26 TW，二氧化碳排放相应从2013年的32 Gt yr⁻¹升至37或44 Gt yr⁻¹。可再生能源在电力部门占比重要（2010年占全球能源需求12%，即17.6 TW中的2.1 TW），但交通（2010年占19%，3.3 TW）和化工（2010年占8%，1.5 TW）也需可持续路径。全球重要工业化学品如氢气（50 Mt yr⁻¹）、过氧化氢（2.2 Mt yr⁻¹）、乙烯（115 Mt yr⁻¹）、丙烯（73 Mt yr⁻¹）、甲醇（40 Mt yr⁻¹）、氨（175 Mt yr⁻¹）的化石-free生产可显著减排。地球大气提供水、二氧化碳和氮的通用原料，若开发出所需性能的电催化剂，可通过电化学过程耦合可再生能源转化为上述产品。

提高电催化剂活性有两条策略：（i）增加电极上的活性位点数量（如提高负载量或改进催化剂结构以暴露更多活性位点每克）；（ii）提高每个活性位点的本征活性。两者可同时进行，但负载量受电荷与质量传输限制，实践中高负载量出现平台效应；提高本征活性可降低负载量并节省成本。好催化剂与差催化剂的活性可相差超过10个数量级，而高负载与低负载之间可能仅差1至3个数量级。

本综述以描述符方法为主线：建立少数关键表面性质，这些性质是高活性的必要但可能不充分条件。作者先介绍理论结果，再讨论如何将建模扩展到更复杂的催化剂与电极-电解质界面，以及发展能在操作条件下提供原子/分子尺度图像的先进实验方法。描述符方法覆盖广泛体系，结合单体系详细研究（如微观动力学模型）已被证明富有成效。

## 氢析出/氧化反应

氢析出反应（HER; 2H⁺ + 2e⁻ → H₂）是2电子转移、1个催化中间体H*的经典例子，可通过Volmer-Heyrovsky或Volmer-Tafel机制进行：

Volmer步：H⁺ + e⁻ + * → H*

Heyrovsky步：H* + H⁺ + e⁻ → H₂ + *

Tafel步：2H* → H₂ + 2*

总反应速率主要由氢吸附自由能ΔG_H决定。若氢结合太弱，吸附（Volmer）步限制速率；若太强，脱附（Heyrovsky/Tafel）步限制速率。因此高活性HER催化剂的必要但不充分条件是ΔG_H ≈ 0。将实验测量的交换电流密度对DFT计算的适当覆盖度下的ΔG_H作图，出现火山关系（Fig. 3A），定量说明Sabatier原理：活性催化剂对反应中间体的结合既不太强也不太弱。Fig. 3A的火山是本文多个火山中的第一个，代表可广泛审视各类化学反应的框架。

简单描述符模型无法定量确定绝对反应速率，例如不同材料类别间动力学势垒大小的变化。这解释了为何MoS₂尽管ΔG_H接近最优，其交换电流密度仍低于Fig. 3A中的贵金属。动力学势垒还可随pH（相对于可逆氢电极RHE的给定电位）变化，导致电流密度的pH依赖性。尽管如此，活性火山不会左右移动，只会上下移动，描述符仍能识别最优HER催化剂的结合特征。但完整定量理解需要更详细高效的电化学势垒计算方法，涉及氢氧根和水合氢离子的质子转移反应，这是未来建模的重要目标。

Pt位于氢火山顶部附近，ΔG_H几乎热中性，是酸性溶液中最佳HER催化剂，过电位可忽略。但Pt稀缺昂贵，促使寻找地球丰产替代品，MoS₂基HER催化剂是理论指导发现与设计的典范。几十年来MoS₂被认为对HER无活性，但受氢化酶和固氮酶启发，对MoS₂的Mo(10-10)边缘进行DFT计算，发现50%氢覆盖度下ΔG_H为0.08 eV，接近最优0 eV（Fig. 3A）；而基面ΔG_H为1.92 eV，解释了块体MoS₂晶体活性差。据此在炭黑载体上合成MoS₂以暴露边缘位点，在膜电极组件中测试，在约175 mV过电位下达到10 mA cm⁻²_geo的几何面积归一化电流密度，当时是酸性中最活跃的非贵金属HER催化剂。随后实验证实MoS₂边缘确为HER催化活性位点：在Au(111)上沉积单层MoS₂纳米颗粒，用扫描隧道显微镜测量颗粒面积和边缘长度，HER活性与MoS₂周长线性相关而非表面积（Fig. 3B, D）。理论与实验结合提供关键见解：只有MoS₂边缘有活性，推动开发暴露大量边缘位点的MoS₂催化剂。

一种有前景的方法是纳米结构化MoS₂（Fig. 2）。三维介孔MoS₂双陀螺形貌（double gyroid）被探索（Fig. 3D），其纳米级曲率最小化扩展基面形成，暴露高密度活性边缘位点。结果双陀螺MoS₂的平均周转频率（TOF_avg，对所有表面位点平均）比类似硫化技术制备的MoO₃-MoS₂纳米线高2至4倍（Fig. 3D）。但双陀螺结构缺点是活性位点到导电基底的长电子传输距离，因垂直于MoS₂基面的电子迁移率比面内低约3个数量级，导致电阻损失增加。为缓解此问题，合成了垂直排列的MoS₂纳米结构，既暴露大量表面边缘位点，又便于电子传输到导电基底（Fig. 3D）。

另一种策略是将纳米颗粒分散在高比表面积载体上（Fig. 2）。例如在还原氧化石墨烯（RGO）纳米片上制备MoS₂纳米颗粒，RGO载体使MoS₂分散更好、聚集减少，因边缘位点增加和电荷传输增强而活性更优（Fig. 3B）。

将锂离子嵌入MoS₂的范德华间隙也被研究，通过调节MoS₂电子性质提高HER活性（Fig. 2）。锂嵌入导致MoS₂化学剥离和从2H半导体多晶型到1T金属多晶型的相变（Fig. 2, 3D）。有研究提出1T-MoS₂比类似制备的2H-MoS₂活性增强，归因于活性边缘位点数量增加和电荷转移电阻降低；另一研究进一步提出1T-MoS₂的边缘不是主要活性位点，基面可能具有催化活性；最近表明MoS₂基面中的空位也表现出高活性，可通过应变MoS₂片调节。

非晶硫化钼也显示高HER活性，主要归因于其高比表面积形貌（Fig. 3D）。非晶硫化钼可通过电沉积或湿化学合成制备，无需热处理，适用于避免高温硫化的应用（如光电化学器件制造）。合成态非晶硫化钼组成接近MoS₃，但在电化学池中施加还原电位后，原位研究表明表面转变为MoS₂。非晶硫化钼可进一步掺杂过渡金属如Fe、Co和Ni，显著提高活性；酸性条件下改善主要因表面积增加，中性条件下TOF_avg提高。

多年来对MoS₂基催化剂的广泛工程化以增加活性位点数量成果显著，但整体电极活性仍受限，因为通常只有小部分位点（边缘位点）对反应速率贡献显著（Fig. 3B-D）。这促使设计表面具有欠配位硫、类似MoS₂边缘的分子簇，如[Mo₃S₄]⁴⁺立方烷、Mo^IV-二硫化物和硫代钼酸盐[Mo₃S₁₃]²⁻配合物（Fig. 3D）。进一步负载催化剂材料是增加活性位点的另一手段，但最终会受质量/电荷传输限制（Fig. 2）。这推动开发更高本征活性的其他催化剂，利用ΔG_H ≈ 0描述符的理论框架，包括过渡金属磷化物、硒化物、硼化物、碳化物、氮化物，其中一些在达到10 mA cm⁻²_geo的过电位指标上接近Pt，但由于高催化剂负载和大表面积，非贵金属体系在酸性条件下TOF_avg仍比Pt低数个数量级（Fig. 3B-D）。碱性介质中也开发了最先进的非贵金属催化剂，如Ni-Mo体系在达到10 mA cm⁻²_geo时过电位低，但其TOF_avg值显著低于Pt，与酸性中非贵金属体系相似，仍有很大改进空间。高TOF_avg的均相催化剂也已开发，但通常需要大过电位才能达到可观电流密度（Fig. 3B）。

在酸和碱中开发Pt的非贵金属类似物用于HER仍是重要挑战。除活性外，长期稳定性是同等重要的指标，应与活性一起报告。加速循环伏安测试、量化催化剂浸出到电解液中的长期稳定性研究、以及使用薄膜催化剂形貌是评估耐久性的有用方法。

与HER大量非贵金属催化剂开发工作相比，相关氢氧化反应（HOR）研究少得多，HOR涉及与HER相同的反应步骤但方向相反。理论上最优HOR催化剂也应具有ΔG_H ≈ 0，位于Fig. 3A同一火山顶部。因此预期Pt是酸中HER和HOR的最佳纯金属催化剂，实验确实如此。但MoS₂催化剂并非如此，其HOR活性比HER差得多。理解贵金属与非贵金属催化剂在HOR与HER中的差异仍是研究前沿。一个区别涉及催化中的覆盖度效应：金属Pt的ΔG_H对氢覆盖度依赖性小，而MoS₂的ΔG_H变化显著。表面氧化对某些催化剂体系（如非贵金属和金属合金）也有影响，HER条件下预期的金属表面与HOR条件下可能形成的金属氧化物/氢氧化物表面相当不同。准确模拟不同操作条件下催化剂材料的预期表面结构和化学计量是催化中的更广泛挑战。因此，寻找具有金属导电性和几乎不变的ΔG_H的地球丰产材料，可为HER和HOR高性能电催化剂设计开辟新机会。

## 氧还原/析出反应

4电子氧还原反应（ORR; O₂ + 4H⁺ + 4e⁻ → 2H₂O）需要改进电催化剂以提高速率和效率。ORR通常涉及4质子-电子转移将氧还原为水（燃料电池所需），或2质子-电子路径（有利于过氧化氢生产，下节讨论）。4电子路径可通过多种机制进行：直接4电子机制可为解离型或缔合型，取决于催化剂表面氧解离势垒；间接4电子机制先经2电子路径生成过氧化氢，再进一步还原为水。

解离型：

O₂ + 2* → 2O*

2O* + 2H⁺ + 2e⁻ → 2OH*

2OH* + 2H⁺ + 2e⁻ → 2H₂O + 2*

缔合型：

O₂ + * → O₂*

O₂* + H⁺ + e⁻ → OOH*

OOH* + H⁺ + e⁻ → O* + H₂O

O* + H⁺ + e⁻ → OH*

OH* + H⁺ + e⁻ → H₂O + *

上述所有中间体的自由能已在多种密堆积金属表面计算，构建了关联理论ORR活性与ΔE_O的火山图，Pt接近顶部（Fig. 4A）。对氧结合太强的金属，活性受限于质子-电子转移到O*或OH*；对氧结合太弱的金属，活性受限于质子-电子转移到O₂*（缔合机制）或O₂中O-O键断裂（解离机制），取决于施加电位。

尽管Fig. 4A的火山框架与HER/HOR的Fig. 3A相似，但有本质区别。HER/HOR只有1个反应中间体，而4电子ORR涉及多个中间体（OOH*、OH*、O*），其结合能强相关，因标度关系难以解耦。事实上，标度关系ΔG_OOH = ΔG_OH + 3.2 ± 0.2 eV普遍适用于面心立方（fcc）金属及其合金的密堆积(111)和开放(100)晶面（Fig. 4B）。由于OOH*和OH*之间的非理想标度，即使计算位于ORR火山顶部的催化剂具有最优ΔE_O，也会有0.3至0.4 V的非零理论过电位。这是即使最佳ORR催化剂（包括本节重点的广泛研究的Pt基体系）也存在过电位的根源（Fig. 4C）。

在Pt基催化剂开发中，大量努力致力于形状控制合成以调整ORR活性（Fig. 2）。在非吸附电解质如高氯酸中，单晶Pt低指数晶面的ORR活性顺序为(110) > (111) > (100)；当使用吸附性电解质如硫酸时，(100)晶面活性反而高于(111)，因硫酸根阴离子强吸附在(111)晶面阻塞位点。这些趋势启发了不同形貌和暴露晶面的Pt基催化剂开发，包括纳米立方体、纳米管、纳米线、纳米枝晶、纳米笼等（Fig. 4D）。

载体效应也影响催化剂活性和稳定性（Fig. 2）。目前炭黑是Pt基催化剂最常用载体，但炭黑在高电位下因Pt-C相互作用弱而不稳定，促使寻找更稳定载体以牢固锚定Pt催化剂，包括Ti₀.₇Mo₀.₃O₂和锡掺杂氧化铟，也显示增强催化活性。

合金化是增强Pt基催化剂ORR性能的另一广泛使用策略（Fig. 2）。合金化可降低Pt₃M合金（M = Ni, Fe, Co, Ti）顶层Pt的氧吸附能。理论上预测Pt₃Sc和Pt₃Y是有前景且稳定的Pt基ORR合金，用块体多晶Pt₃Sc和Pt₃Y催化剂实验证实，其比活性分别比纯Pt增强1.5至1.8倍和6至10倍。该方案已扩展到碱土金属和镧系。为利用纳米结构化效应，还制备了直径4至9 nm的尺寸选择PtxY纳米颗粒，最佳者质量活性比Pt纳米颗粒高3倍。发现催化剂活性随平均Pt-Pt距离减小而增加，表明合金核施加在表面Pt原子上的压缩应变导致催化活性提高，对质量选择PtxGd纳米颗粒的进一步研究支持此点。

另一种优于纯Pt的合金是Pt₃Ni。制备了Pt₃Ni(111)扩展单晶表面，经热退火和近表面区重构形成Pt-rich最外层，即所谓Pt-skin结构，其比活性分别是Pt(111)和最先进Pt/C催化剂的10倍和90倍。随后从溶液中PtNi₃多面体的结构演化合成三维Pt₃Ni纳米框架（Fig. 4D），这些具有大而高度可及表面积的纳米框架在10,000次电位循环后，比活性和质量活性分别比最先进Pt/C催化剂提高22倍和36倍。最近报道用过渡金属掺杂Pt₃Ni八面体进一步增强ORR活性（Fig. 4D），特别是掺杂Mo使比活性和质量活性分别比商业Pt/C催化剂提高81倍和73倍。计算结果表明，在吸附氧存在下Mo优先占据表面顶点和边缘位点，形成相对强的Mo-Pt和Mo-Ni键以稳定Pt和Ni原子抗溶解。尽管活性显著提高，Mo掺杂Pt₃Ni体系仍需约280 mV过电位才能达到2 mA cm⁻²_Pt，远未达到ORR平衡电位，仍有大量改进机会（Fig. 4C）。

如前所述，Pt是酸中HER和HOR的最佳纯金属催化剂，本质上由于微观可逆性：两反应涉及相同步骤，只是方向相反。基于同样推理，可能预期作为最佳纯金属ORR催化剂的Pt在氧析出反应（OER）中也表现同样好；但实验并非如此。一个原因是微观可逆性仅适用于接近平衡的过程。当需要大过电位驱动两方向反应时，各方向的催化要求可能大不相同。此外，在OER所需的高正电位下，包括Pt在内的金属通常发生显著氧化，尤其是表面，呈现与ORR条件下不同的表面类型。再次，催化研究的重要前沿是开发改进的实验和理论方法，能快速准确确定不同操作条件下催化剂材料的表面结构和化学计量。此类信息对全面理解反应动力学至关重要，将使社区能够开发最佳催化剂材料。

由于OER催化剂材料通常是金属氧化物，已使用ΔG_O - ΔG_OH作为描述符为多种金属氧化物表面（包括金红石、钙钛矿、尖晶石、岩盐和方铁锰矿氧化物）构建OER火山图。在1 mA cm⁻²_cat下的实验过电位对该简单描述符作图，与理论过电位火山吻合良好（Fig. 5A）。更完整的模型应纳入更精确的催化活性表面描述；例如观察到Fig. 5A中一些钙钛矿在OER条件下发生A或B金属阳离子浸出和表面非晶化。在所得催化活性表面结构未完全阐明的情况下，Fig. 5A构建使用了理想化学计量终止面的结合能。这些广泛类别金属氧化物材料中研究的所有表面都遵守OOH*和OH*之间的非理想标度关系（ΔG_OOH = ΔG_OH + 3.2 ± 0.2 eV），与ORR金属情况类似，再次阻碍了零理论过电位催化剂的开发。对于酸中OER催化，IrO₂是相当活跃的金属氧化物催化剂，理论基于对反应中间体的合理结合能帮助解释了原因。尽管该催化剂在活性和稳定性方面确为当今较好OER催化剂之一，但远非理想OER催化剂活性，且在高氧化电位下不完全稳定。最近报道IrOx/SrIrO₃薄膜在酸中显示极高OER活性（270 mV at 10 mA cm⁻²_oxide，归一化到氧化物表面积）及有前景的稳定性。相关几何面积归一化活性也异常出色（Fig. 5B），尽管薄膜表面积低；利用优异本征活性与更高表面积配方（Fig. 2）可进一步改善整体电极活性。

由于Pt、Ru和Ir等贵金属成本高且稀缺，非贵金属氧化物催化剂包括镍氧化物、钴氧化物、锰氧化物和多阳离子钙钛矿也被大力研究，尽管它们仅在碱性条件下稳定。最近制备了三元FeCoW羟基氧化物高表面积电极（Fig. 5B），在碱性电解液中OER过电位低（191 mV at 10 mA cm⁻²_geo）。当归一化到催化剂表面积时，许多非贵金属氧化物OER催化剂在碱中至少与贵金属基体系一样活跃或更活跃。其中一些催化剂在碱性介质中对ORR/OER均显示双功能活性。通过研究一系列钙钛矿，建立了ORR/OER活性与表面金属阳离子e_g填充之间的火山型关系，可作为另一活性描述符。最优活性出现在e_g占据接近1时，过渡金属-氧键共价性高。

无金属催化剂最近也作为碱性条件下有前景的ORR/OER催化剂类别出现，如杂原子掺杂碳。通过用更电负性原子如氮掺杂碳，在相邻碳原子上产生净正电荷（C⁺），促进氧吸附和电荷转移，增强ORR/OER活性。该策略也扩展到比碳电负性更小的掺杂原子（如硼），产生类似电荷位点（如B⁺）促进催化过程。为利用不同掺杂原子的协同效应，碳催化剂的共掺杂也成功实现。

然而，非贵金属氧化物和无金属催化剂的典型缺点是在酸性环境中稳定性差。总体而言，开发在酸性介质中兼具高活性和稳定性的地球丰产ORR/OER催化剂（如用于质子交换膜燃料电池和电解槽）仍是严峻挑战。为此需要更深入理解这些催化剂的工作状态和活性位点性质，以便适当控制和调整其性能。理论、计算研究和先进原位/操作表征技术的结合将有助于解决这些关键问题。

尽管Fig. 4A的热力学极限电位火山有助于阐明ORR/OER催化趋势，但希望转向基于微观动力学建模的火山。除构建热力学火山所用的基元步骤反应能外，此类模型还需要每个基元步骤动力学势垒大小的信息。非电化学步骤的动力学势垒计算已很好理解，但电化学动力学势垒（包括其电位依赖性）的计算用当前技术困难得多。此困难很大程度上源于DFT固有局限于恒电荷而非恒电位计算，导致反应坐标上电位变化。一种规避方案是外推到无限大晶胞极限，其中单次电荷转移对模拟电位影响可忽略，从而在恒电位下获得反应能和势垒。通过用逐渐增大的晶胞计算，已能外推到无限晶胞极限，发现Pt(111)上OH*还原为H₂O在零驱动力下动力学势垒为0.26 eV，电荷转移系数为0.5。

进一步研究使用这些动力学参数用于ORR所有四个耦合质子-电子转移步骤，并采用稳态微观动力学模型研究Pt(111)。此外，模型中使用的反应能/势垒在显式水溶剂化双层和实验与理论均发现的最稳定覆盖度下计算（蜂窝√3×√3)R30图案，2/3 ML H₂O和1/3 ML OH）。还考虑了2电子产物H₂O₂的形成，如自由能图所示（Fig. 6A）。Fig. 6B比较实验（黑/灰）和模拟（粉/蓝）极化曲线。额外考虑扩散步骤（粉）后，实验与理论在起始电位和饱和电流密度上均达到显著一致。最后，使用标度关系将模型推广到结合能描述符空间，从而创建基于微观动力学建模的理论火山（Fig. 6C）。该研究展示了在复杂电极-电解质界面建模多步电化学反应的进展，但前进道路需要更详细高效的电化学势垒确定方法，这是重要前沿。

尽管多年来在酸和碱中开发ORR/OER催化剂研究广泛，大多数最先进催化剂仍需0.25至0.4 V的远离理想的过电位才能达到感兴趣电流密度（Fig. 4C, 5B）。上述理论框架表明这主要由于ORR/OER中反应中间体间的标度关系。克服此限制需要解耦不同中间体的结合能，例如通过稳定OOH*相对于OH*。尽管火山框架有助于阐明此关键概念，其实施需要大量努力。更深入理解电极-电解质界面及相关动力学将允许更详细的策略设计真正低过电位的ORR/OER催化剂。开发围绕已知标度关系工程化催化剂材料的方法只是第一步，为创建接近理想的ORR/OER催化剂体系开辟机会，将大幅提高广泛能源转换设备的效率。

## 新兴反应

除上述HER、HOR、ORR和OER外，还有许多相对较少探索的新兴能源转换反应。若能开发出具有合适性质的电催化剂，其中一些可能具有变革性。尽管这些反应可能涉及不同的反应中间体、机制和电子转移数，描述符和火山概念评估活性和选择性在此也是加速催化剂开发所需理解的重要第一步。

**过氧化氢生产**

开发直接将氧还原为过氧化氢的电化学过程（O₂ + 2H⁺ + 2e⁻ → H₂O₂）将是有利的，因为它可取代传统高能耗蒽醌法，与可再生电力直接耦合，以模块化、去中心化方式更安全部署。氧电化学还原为过氧化氢通常在酸性环境中探索，因为过氧化氢在碱性条件下分解。总体而言，从氧生产过氧化氢涉及2个耦合电子-质子转移和1个反应中间体（OOH*），复杂度与HER相似：

O₂ + * + H⁺ + e⁻ → OOH*

OOH* + H⁺ + e⁻ → H₂O₂ + *

因此，可能找到零理论过电位且具有最优ΔG_OOH的催化剂，OOH*结合既不太强也不太弱。尽管已探索若干催化剂如Pt、Ag、Au、Au-Pd合金、氮掺杂碳和分级多孔碳，但它们在过氧化氢生产中仅显示中等性能。合适的电催化剂需要对2电子路径而非4电子路径具有高选择性。

DFT计算建立了关联理论过电位与ΔG_OOH的火山框架，用于氧2电子还原为过氧化氢，实验过电位（1 mA cm⁻²）叠加在此图上（Fig. 7A）。对OOH*结合强的金属，4电子ORR将主导2电子路径；对OOH*结合弱的情况，2电子和4电子火山图重叠，表明弱OOH*结合时活性与过氧化氢选择性之间的折衷。因此，兼具高活性和对过氧化氢高选择性的最有前景催化剂将位于2电子火山顶点。理论预测的Pt-Hg、Pd-Hg和Ag-Hg合金不仅显示令人印象深刻的质量活性，而且在过氧化氢合成中具有高选择性（> 95%）。该工作的理性设计方法揭示了开始筛选和识别更具吸引力催化剂候选的重要概念，特别是绕过Hg的毒性。基于热力学框架并扩展到更详细理解动力学势垒和界面过程，覆盖更广泛材料和反应条件，将有助于为开发可扩展、对过氧化氢选择性高且在低过电位下运行的催化剂提供进一步见解。

**二氧化碳还原反应**

另一重要能源转换反应涉及以可再生能量为输入将二氧化碳电还原为增值产品。与ORR类似，这是涉及许多不同表面结合反应中间体的多电子还原反应。但与ORR只有两个主要最终产物（水或过氧化氢）不同，二氧化碳还原产物众多，包括一氧化碳、甲酸、甲醛、甲烷、甲醇以及C₂₊烃和含氧化合物；许多产物需要大量质子和电子转移，可能通过不同中间体进行。因此，在众多碳基产物中引导催化剂选择性是主要挑战，加之大多数二氧化碳还原半反应的平衡电位接近0 V vs. RHE，使HER成为除不需要的碳基副产物之外的额外竞争反应。因此，二氧化碳还原要商业可行，电催化剂需要对特定目标产物兼具高活性和高选择性。

1980年代，二氧化碳还原在多种多相元素表面上被研究。研究的催化剂根据对主要产物的选择性大致分类：（i）一氧化碳（如Au、Ag），（ii）甲酸（如Pb、Sn），（iii）烃（如Cu），（iv）氢（如Pt、Ni）。基于上述理论-实验结合框架，构建了初始火山图以理解二氧化碳还原催化趋势。Fig. 7B由DFT计算组成，关联理论极限电位与DFT计算的ΔE_CO，并叠加了甲烷和/或甲醇形成的实验起始电位（检测到任一产物的最早电位）。对CO*结合太强的金属，过电位由CO*质子化为CHO*决定；对CO*结合太弱的金属，过电位由CO(g)质子化为CHO*决定，其中CO脱附是竞争反应。对于甲烷/甲醇形成，发现Cu位于火山顶部附近，具有最优ΔE_CO，尽管由于标度关系限制，理论过电位显著约0.8 V。鉴于每种产物涉及许多反应步骤和中间体，这并不意外；若干中间体是C₁物种，可能以类似方式与金属结合，例如碳原子与金属表面之间。再次，这指出打破各种反应中间体间标度关系的必要性，这是二氧化碳还原催化剂以高活性生产甲烷/甲醇的必要但可能不充分条件。理论指导表明，相对于CO*增强CHO*（或实际上吸附CO的耦合质子-电子转移的过渡态能量）的结合能，将使CO*在较不负面电位下质子化为CHO*，导致过电位大幅降低。这可通过多种策略实现，包括合金化、电解质添加剂、离子液体、系留表面物种、促进剂和氢键供体/受体。

C₂₊物种的形成更复杂，因为C-C键形成是另一反应步骤。已确定两条路径：一条路径中一氧化碳先加氢，使C-C键形成更容易；另一路径中吸附的一氧化碳先二聚。对于乙醇形成，最近确定乙醛是重要中间体。鉴于二氧化碳还原反应的复杂性，需要更多计算和实验工作阐明潜在反应机制和中间体。研究相关的一氧化碳还原反应也可获得进一步见解，其与二氧化碳还原相似但避免甲酸形成的潜在毒化效应。

**氮还原反应**

氮电还原（N₂ + 6H⁺ + 6e⁻ → 2NH₃）的灵感可来自细菌中在室温和常压下进行固氮的固氮酶。早期研究已证明该过程在合成环境中的可行性，启发了包括Pt、Rh和Ru的催化剂开发。与二氧化碳还原一样，氮还原反应涉及多个中间体，HER是主要竞争反应，使选择性成为巨大挑战。迄今实验结果性能极差：高过电位、低电流密度和低选择性；有很大改进空间。

为提供理论指导，使用DFT计算构建了火山图，关联理论极限电位与多种金属表面的ΔE_N（Fig. 7C）。该框架再次提供理解元素金属催化剂此反应关键考虑点的方法：氮结合太弱的金属受限于第一步反应中N₂吸附为N₂H*；强结合金属受限于NH*质子化为NH₂*（平面表面）或NH₂*作为NH₃移除（阶梯表面）。计算发现Ru、Rh、Mo和Fe等金属位于火山顶部附近，氮结合既不太强也不太弱。不幸的是，即使位于火山顶部附近的金属，由于中间体间非理想标度关系，也显示至少0.5 V的大理论过电位。建模表明，改善氮还原活性的必要但可能不充分条件可能是通过稳定N₂H*相对于NH₂*或NH*来实现。

对于火山顶部附近的催化剂，理论和实验均发现HER是竞争反应，从而损害氮还原的法拉第效率（Fig. 7C）。有研究提出Re、Sc、Y、Ti和Zr的平面表面能在-1至-1.5 V vs. RHE下进行氮还原，且因对氮的结合强于氢而显著抑制HER，但结论是需要抑制HER的机制才能获得合理性能。总体而言，氮还原和HER的理论极限电位火山之间的差异对平面强结合表面最小。进一步DFT研究还表明过渡金属氮化物如VN和ZrN在低起始电位下对氮还原高活性同时抑制HER。从初始理论见解中出现的材料设计策略是开发改进催化剂的第一步且重要。需要进一步工作阐明电极-电解质界面的原子尺度过程，包括溶剂、阳离子和阴离子的作用，以及质子/电子转移和N-N断裂的动力学。更深入理解界面机制细节将为实施更有针对性的策略提供指导，以开发这一有前景但很大程度上未充分探索的反应的先进电催化剂。

**展望**
近年来先进电催化剂用于清洁能源转换的发展兴趣蓬勃。我们强调了初步方法的效用，即检查每个反应的基元步骤以识别关键中间体、其与表面的键合以及每步的能量学。对每个反应，我们说明了该方法如何帮助理解已知催化剂体系的关键限制，以及这些知识如何导致成功策略开发改进的电催化剂。在大多数反应中，迄今已知催化剂的有限成功可追溯到不同吸附中间体能量之间标度关系设定的限制。主要结论之一是需要新的催化剂设计范式来规避这些约束，特别聚焦于调整一个中间体相对于另一个的稳定化。

一种策略是构建三维催化活性位点，以不同方式结合不同反应中间体（和过渡态）。例子可包括合金化、掺杂或引入缺陷。或者，可通过某种外部机制选择性稳定中间体来规避标度。例如，尺寸差异可通过以多个位点结合较大中间体的催化剂结构来区分（如限域）；化学官能化差异（如氢键）或物理性质差异（如偶极强度）可通过向电解质添加分子或向表面添加促进剂/配体来利用，如Fig. 2所示。

还需要进一步努力阐明电极-电解质界面许多至今仍知之甚少的细节。当前挑战包括界面附近溶剂、阳离子和阴离子的原子和分子级描述，以及涉及质子/电子转移的关键基元步骤的动力学和反应势垒，所有这些都在相关反应条件下。电催化研究的前沿就在于此；通过更快、更高效的方法在理论和实验中使用更先进方法捕捉这些理解，将揭示更多信息，进一步指导社区开发能以接近理想效率和选择性运行的催化剂。
