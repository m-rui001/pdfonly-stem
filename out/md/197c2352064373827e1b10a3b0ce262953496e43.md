# 通过拥挤铂物种在α-MoC上构建稳定低温产氢催化剂

**英文原题：** A stable low-temperature H2-production catalyst by crowding Pt on α-MoC（2021, DOI: 10.1038/s41586-020-03130-6）

水煤气变换（WGS）反应是工业上生产纯氢的重要途径，但低温燃料电池应用需要兼具高活性和稳定性的催化剂。本文报道一种将孤立铂原子（Pt1）与亚纳米铂团簇（Ptn）高密度共负载于α-碳化钼（α-MoC）上的催化剂（Pt1–Ptn）/α-MoC，在313 K即可催化WGS反应，并具有4,300,000 mol H2/mol Pt的创纪录周转数。作者证明，高密度拥挤的Pt表面物种能防止α-MoC载体被氧化，这是催化剂长效稳定的关键；同时，催化剂存在直接CO解离的非常规产氢路径。

## 催化剂结构：从单原子到拥挤表面物种

前期研究表明，金属/载体界面密度最大化可提高WGS活性，但单原子易团聚或载体易氧化失活（如Au/α-MoC在473 K以上失活）。作者采用改进的初湿浸渍法：先将α-MoC在10% H2/N2中523 K预还原60 min，以制造更多锚定位点，再负载Pt并经CH4/H2活化。XRD显示，Pt负载高达5 wt%时仍无Pt衍射峰，8 wt%才出现宽化金属Pt峰，表明Pt高度分散。原子分辨STEM和XAFS表征进一步确认：0.02–0.2 wt%负载为纯Pt1单原子，密度约9 Pt1/100 nm²；2 wt%时Pt1密度升至42/100 nm²并出现亚纳米Ptn团簇；8 wt%时Pt1密度达80/100 nm²，同时出现纳米Pt颗粒（Ptp）。EXAFS拟合的Pt–Pt配位数从0.02 wt%时的0增至2 wt%的3.8和8 wt%的5.6，与结构演变一致。据此将催化剂命名为Pt1/α-MoC（0.02–0.2 wt%）、(Pt1–Ptn)/α-MoC（2 wt%）和(Pt1–Ptp)/α-MoC（8 wt%）。

## WGS性能：低温活性与超高标准

在无产物（product-free）和全重整气条件下测试WGS活性。纯α-MoC和商用Cu/ZnO/Al2O3在373 K以下无活性，而0.2 wt% Pt1/α-MoC在313–373 K即有可观CO转化。2 wt% (Pt1–Ptn)/α-MoC在313 K即达22% CO转化，373 K接近完全转化，且在高气时空速（180,000 h−1）下393–673 K窗口内保持90–100%转化率，优于在523 K以上迅速失活的Au/α-MoC。动力学区（CO转化<15%）测得的摩尔比活性显示，0.2 wt% Pt1/α-MoC在313、393、423、473、523 K的Pt归一化活性分别为0.11、2.2、4.7、15.5和21.2 mol H2 mol Pt−1 s−1，远超已报道的Ir1/FeOx、Au1/CeO2、Au/α-MoC等催化剂。2 wt%和8 wt%催化剂因团簇/颗粒内部Pt原子不可接触导致比活性下降，但整体活性仍高于文献值。更重要的是，作者根据美国能源部2004年燃料电池车技术目标（成本<1美元/kW、重量<0.11 kg/kW）换算得到最低质量比活性为4.57 μmol g−1 s−1，金属比活性目标对Au为5.25 s−1、对Pt为3.12 s−1（基于Au $10,503/mol、Pt $6,242/mol价格）。本文催化剂是迄今为止唯一同时满足这些技术目标的WGS催化剂。

## 反应路径：水解离与CO直接解离的协同

原位近常压XPS（NAP-XPS）显示，活化后的2 wt% (Pt1–Ptn)/α-MoC在室温下暴露水蒸气后，O 1s谱中出现532.3 eV的OH物种峰，同时检测到H2生成，表明催化剂可在室温解离水。随后通入CO，从323 K起OH峰强度显著下降，并观察到CO2和H2生成，说明CO（吸附于Pt）与α-MoC表面OH反应。但373 K反应后仍有大量OH残留，说明存在两类OH：邻近Pt的可被CO消除，远离Pt的则成为不参与反应的旁观者。同位素瞬态动力学（TKA）实验采用13C16O和H218O，在423 K切换气流后，水到达前已出现13C16O2，直接证明CO可解离；同时观察到13C16O18O、13C18O2和13C18O等产物，确认存在非常规路径：CO解离产生的表面碳物种可再与水反应生成额外H2。根据反应式（如下）估算，非常规路径贡献了约35%的氢气产量。

反应路径包括：水解离（式1）、常规WGS路线（式2-3，即CO+OH*生成CO2和H*）、CO直接解离（式4）、CO歧化（式5）、表面碳与水重整（式6-8）。这些反应式如下（*表示α-MoC上的水吸附/解离位点，*'表示Pt或Pt/α-MoC界面上的CO吸附/解离位点）：

2H2O + 2* → H2 + 2OH*   (1)

13C16O*′ + *′ →13C*′ +16O*′   (2)

13C16O*′ +16O*′ →13C16O2 + 2*′   (3)

2H218O + 2* → H2 + 218OH*   (4)

OH* +13C16O*′ →13C16O18O*′ + H*   (5)

2H* → H2 + 2*   (6)

213C*′ + 218OH* → 213C18O + H2 + 2* + 2*′   (7)

13C*′ + 218OH* →13C18O2 + H2 + 2* + *′   (8)

稳态下13C16O18O/H2比实测为0.65，而常规路径预期为1，进一步佐证了非常规路径的存在。

## 稳定性：拥挤的Pt物种保护载体免于氧化

稳定性测试在523 K、全重整气、高空速（743,800 ml g−1 h−1）下进行。0.02 wt% Pt1/α-MoC虽然初始活性极高，但10小时内活性几乎消失；而2 wt% (Pt1–Ptn)/α-MoC在头20小时轻微下降后，100小时仍保持54%初始活性，263小时累计周转数达4,300,000 mol H2/mol Pt。原位XPS和XRD表明，反应后两种催化剂体相α-MoC均保持完整，但0.02 wt%催化剂表面被深度氧化，而2 wt%催化剂表面未氧化，且Pt物种在263小时后仍稳定存在（STEM确认）。这证实了拥挤的Pt1和Ptn物种能够消除多余的表面氧物种，防止α-MoC氧化失活，是高稳定性的根本原因。
