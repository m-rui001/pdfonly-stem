# 基于血浆游离DNA甲基化组的敏感肿瘤检测与分类

*Sensitive tumour detection and classification using plasma cell-free DNA methylomes* · Nature 563, 579–583 (2018) · DOI: 10.1038/s41586-018-0703-0

当前基于cfDNA体细胞突变的ctDNA检测方法受限于可用的复发性突变数量有限及测序技术误差，在早期癌症患者中灵敏度可能偏低。本文提出并验证了一种基于免疫沉淀的免亚硫酸氢盐甲基化组分析方案cfMeDIP-seq，用于小量循环cfDNA的甲基化分析，并证明其能够检测富集肿瘤特异性模式的大规模DNA甲基化变化，在多种肿瘤类型的血浆样本中实现稳健的癌症检测与分类。

## 研究背景与cfMeDIP-seq方法开发

ctDNA分析具有广泛的潜在临床应用，但癌症筛查和治疗后微小残留病灶检测等场景对分析灵敏度的要求往往超出当前基于突变的ctDNA检测方法的技术极限。主要障碍包括：(1) 可用于经济有效地区分肿瘤与正常循环cfDNA的复发性突变数量有限；(2) 测序过程中引入的技术伪影（错误）。作者推断，从cfDNA中特异性富集甲基化DNA片段可同时克服这两个障碍。

为评估癌症中较高数量的DNA甲基化变化能否在较低测序成本下转化为更高灵敏度，作者进行了生物信息学模拟，考察不同数量的差异甲基化区域（DMR）、覆盖度和ctDNA丰度下的检测概率（Fig. 1a和Extended Data Fig. 1a）。结果显示，随着DMR数量增加，即使在较低测序深度和ctDNA丰度下，灵敏度也有所提高，表明回收癌症特异性DNA甲基化变化可实现高灵敏度、低成本的癌症检测、分类和监测。

然而，这在实践中具有挑战性，因为血浆cfDNA丰度低且片段化，限制了以往大多数血浆甲基化分析仅能采用基于PCR的位点特异性检测。虽然已有cfDNA全基因组亚硫酸氢盐测序（WGBS）的尝试，但该方法因亚硫酸氢盐转化过程中约84–96%的输入DNA降解、高成本以及CpG在全基因组中丰度低导致信息回收有限而效率低下。因此，作者开发了cfMeDIP-seq（cell-free Methylated DNA Immunoprecipitation and high-throughput sequencing），用于全基因组免亚硫酸氢盐的血浆DNA甲基化分析，基于其富集CpG丰富、可能更具信息量的片段的能力，从而提高成本效益。

简言之，作者优化了现有的低输入MeDIP-seq方案（该方案在低至100 ng输入DNA时仍稳健），使用外源性Enterobacteria phage λ DNA（填充DNA）来扩充起始量（Extended Data Fig. 1b）。这对于基于血浆cfDNA样本的应用至关重要，因为血浆cfDNA的产量远低于100 ng。随后作者对优化方案进行了广泛基准测试。首先，将低输入cfMeDIP-seq与金标准MeDIP-seq进行比较，使用剪切至模拟cfDNA大小的结直肠癌（CRC）HCT116 DNA，结果显示稳健的CpG富集（Extended Data Fig. 2a-c）和重复间相关性（Extended Data Fig. 2d）。cfMeDIP-seq（1至10 ng输入DNA）也重现了金标准MeDIP（100 ng）、RRBS（Reduced Representation Bisulfite Sequencing）（1,000 ng）和WGBS（2,000 ng）的图谱（Extended Data Fig. 2e）。

接下来，将cfMeDIP-seq与基于超深度、独特分子标识符（UMIs）的杂交捕获突变测序进行比较，使用CRC DNA掺入多发性骨髓瘤（MM）MM.1S细胞系DNA的系列稀释（Extended Data Fig. 3a）。前者在观察值与预期DMR数量（5%错误发现率（FDR）阈值）及DMR内信号之间显示出近乎完美的线性关联，低至0.001%稀释度（两者r²=0.99，p<0.0001）（Fig. 1b和Extended Data Fig. 3b-e）。后者仅在单链一致性序列（SSCS）和双链一致性序列（DCS）下分别检测到低至0.1%和1%的CRC特异性突变（Extended Data Fig. 3f-g）。这凸显了cfMeDIP-seq在检测癌症来源DNA方面出色的分析灵敏度。作者还评估了cfMeDIP-seq通过偏向性测序CpG丰富序列（这些序列在癌症中相对于正常组织频繁高甲基化）来富集ctDNA的能力。使用携带患者来源异种移植瘤（PDX）的小鼠血浆进行cfMeDIP-seq，发现免疫沉淀后人类肿瘤来源cfDNA相较于输入样本富集了2倍（Fig. 1c）。

## 胰腺导管腺癌中的验证与转录因子网络推断

为研究cfMeDIP-seq能否检测早期癌症中的ctDNA，作者从24例原发性早期胰腺导管腺癌（PDAC）患者（病例）和24例年龄性别匹配的健康对照（对照）的术前血浆cfDNA中生成了cfMeDIP-seq图谱（Fig. 2a和Extended Data Fig. 4a-f）。除血浆cfDNA外，同一PDAC患者的显微切割原发肿瘤和癌旁正常组织也通过RRBS生成了DNA甲基化图谱。作者在病例与对照cfDNA之间鉴定出14,716个DMR（基于片段计数的负二项广义线性模型（GLM），Benjamini Hochberg FDR（BHFDR）显著性水平0.1，其中9,931个在病例中高甲基化，4,785个在对照中高甲基化）（Fig. 2b-c和Supplementary Table 1）。

相比之下，RRBS数据在肿瘤与正常组织之间发现45,173个差异甲基化CpG（DMC）（Supplementary Table 2）。通过置换检验估计cfMeDIP-seq游离DMR与RRBS组织DMC之间重叠的显著性，发现一致高甲基化的DMR/DMC对显著富集（p=3.39e-47），病例cfDNA和肿瘤组织中一致低甲基化的DMR/DMC对也显著富集（p=1.43e-22）。在cfDNA与肿瘤DNA之间不一致的甲基化模式中未观察到这种显著富集（Fig. 2d）。此外，重叠的血浆cfDNA和组织DNA甲基化信号具有相关性（Extended Data Fig. 5a）。这些发现表明，血浆cfDNA的cfMeDIP-seq可检测ctDNA中肿瘤来源的DNA甲基化事件。

由于非肿瘤来源的cfDNA主要从血细胞释放，作者在病例-对照cfMeDIP-seq DMR与PDAC肿瘤组织（n=24）和正常外周血单核细胞（PBMC）（n=5）之间的95,388个RRBS DMC之间进行了类似的基于置换的富集检验（Supplementary Table 3）。再次观察到cfMeDIP-seq DMR与肿瘤vs. PBMC DMC中一致高甲基化（p<1e-745）和低甲基化（p=6.12e-82）位点的显著富集，而不一致判定则代表性不足（Fig. 2e）。此外，重叠DMR/DMC中的信号具有相关性（Extended Data Fig. 5b），共同表明使用cfMeDIP-seq在病例与对照之间鉴定的DMR很可能来源于ctDNA（Extended Data Fig. 5c）。

基于肿瘤来源DMR的富集以及已知的转录因子（TF）甲基化特异性可变结合，作者假设cfMeDIP-seq甲基化组可利用血浆cfDNA鉴定肿瘤或其他组织中的活跃转录网络。对cfMeDIP-seq DMR进行基序富集分析并纳入候选转录因子的甲基化偏好后，鉴定出42个TF在健康对照中结合，52个TF在胰腺癌病例中结合（Supplementary Table 4-5）。正如预期，前者包括造血谱系特异性TF如PU.1、NFE2和GATA1，而后者包括胰腺相关TF PTF1a、Onecut1（HNF6）和NR5A2（Extended Data Fig. 6a和c）。与随机TF集相比，推断在健康对照中活跃的TF基于GTEx数据在血液中过表达，而推断在胰腺癌病例中活跃的TF在GTEx胰腺组织和TCGA PDAC组织中过表达（Extended Data Fig. 6b、d和e）。总体而言，这些发现表明cfMeDIP-seq可能允许对癌症中活跃TF网络进行无创表征。

## 多癌种检测与分类的机器学习评估

鉴于能够在PDAC病例血浆中相对于对照检测到肿瘤特异性DMR，作者随后研究了cfMeDIP-seq能否从健康对照中无创分类多种癌症类型。因此，作者在一个包含来自7种不同肿瘤类型（PDAC、结直肠癌（CRC）、乳腺癌（BRCA）、肺癌（LUC）、肾癌（RCC）、膀胱癌（BLCA）和AML）及健康对照的189份血浆样本的发现队列中进行了cfMeDIP-seq（Extended Data Fig. 7a-1和Extended Data Fig. 8a）。

作者首先鉴定了每种肿瘤类型相对于健康对照的血浆游离DMR，并利用TCGA肿瘤组织甲基化数据（n=4032）检验这些在血浆cfDNA上鉴定的癌种特异性DMR是否富集了每种癌症类型的预期肿瘤DMR（Fig. 3a）。观察到在原发肿瘤组织（TCGA）中高甲基化的位点在每种癌症类型的血浆cfDNA中鉴定为高甲基化的区域内显著富集，同时cfMeDIP-seq血浆甲基化与TCGA 450k肿瘤数据之间的信号显著相关（Extended Data Fig. 8b-h）。这些结果表明能够在多种癌症类型中回收ctDNA相关的甲基化图谱。

最后，作者对发现队列进行了一系列机器学习分析，以严格评估cfMeDIP图谱在癌症检测和分类中的效用。作者最初将数据集缩减至505,027个映射到CpG岛、shore、shelf和FANTOM5增强子的窗口以提高计算效率。随后从缩减后的数据集得出无偏性能估计，同时考虑训练集偏倚。将发现队列按80%-20%分为平衡的训练集和测试集。仅使用训练集样本，通过limma-trend检验统计量为每个类别相对于其他类别选择前300个DMR。然后使用这些特征在训练集数据上训练一系列一对其他类别的正则化二项GLM。训练过程包括3轮10折交叉验证（CV），在alpha和lambda值的网格上进行，以Cohen's Kappa为优化目标。使用多轮10折CV的动机是希望利用额外的随机化实现更可泛化的模型调优。

随后使用未用于DMR选择或模型训练的测试集样本得出的受试者工作特征（ROC）统计量评估这些分类器的性能。整个过程重复100次以防止训练集偏倚（此处称为E100）。在测试集样本中观察到各类别的高AUROC值（Fig. 3b和Extended Data Fig. 9a）。

随后，作者通过将集成模型应用于199份样本的验证队列（35例AML、47例PDAC、55例LUC和62例健康对照）来评估跨批次性能。对每个样本的E100输出的类别概率取平均，得到AML vs. 其他（0.980）、PDAC vs. 其他（0.918）、LUC vs. 其他（0.971）和正常 vs. 其他（0.969）的高ROC（Fig. 3c）。值得注意的是，早期和晚期样本之间的性能相似，表明适用于癌症早期检测（Fig. 3d和Extended Data Fig. 9b）。

作者随后研究了E100训练期间选择的DMR（非零系数）是否具有肿瘤特异性。使用t分布随机邻域嵌入（tSNE）图可视化显示血浆队列中按肿瘤类型清晰分离（Fig. 4a）。这在4,032例TCGA癌症和正常血液样本以及400个COSMIC癌细胞系和PBMC的450k数据集中显著重现（Fig. 4b-c）。这表明血浆cfDNA甲基化分类器主要由肿瘤特异性DNA甲基化模式驱动，而非血细胞波动或肿瘤微环境中的细胞组成。

然而，这些结果不能排除某些血浆游离DMR可能源于循环免疫细胞比例的变化。为进一步检验推断，作者在IHEC WGBS数据中鉴定了38,352个在多种白细胞类型中低甲基化的cfMeDIP窗口，其中27,088个与TCGA 450k数据重叠（Extended Data Fig. 10a）。在这27,088个区域中，作者分离出通过每种癌症类型血浆cfDNA与健康对照比较鉴定为高甲基化的区域。然后使用每种癌症类型的TCGA数据检查这些区域在肿瘤组织与PBMC中的甲基化状态。对于PDAC，作者使用了匹配患者（cfDNA和组织DNA）生成的本室甲基化数据。确实发现这些区域在肿瘤组织中高甲基化（Extended Data Fig. 10b），强化了这些血浆游离DMR是肿瘤来源DNA（即ctDNA）直接测量的假设。

## 方法概要

**生物信息学模拟。** 创建了145,000个模拟基因组，包含1、10、100、1,000和10,000个独立位点，癌症特异性DMR比例为0.001-10%（10倍递增）。从这些混合物中采样14,500个二倍体基因组（100 ng cfDNA中的预期拷贝数），然后在每个位点以10倍递增采样10至10,000次。每种参数组合重复100次。绘制成功检测>1和>5个DMR的概率曲线（Fig.1a和Extended Data Fig.1a）。

**cfMeDIP-seq方案。** 样本先使用Kapa HyperPrep Kit进行文库制备，末端修复和加A尾后，连接0.181 μM NEBNext adapter，20°C孵育20 min，AMPure XP beads纯化。洗脱文库用USER酶消化，Qiagen MinElute PCR Purification Kit纯化后进行MeDIP。制备的文库与填充λ DNA混合（确保总DNA量[cfDNA+填充]为100 ng），使用Diagenode MagMeDIP kit进行MeDIP。填充DNA由不同CpG密度的未甲基化和体外甲基化λ扩增子混合物组成（Supplementary Table 6），大小与接头连接的cfDNA文库相似。其添加确保抗体与输入DNA的恒定比例，帮助维持不同样本间相似的免疫沉淀效率，同时最小化抗体非特异性结合和因结合塑料器皿导致的DNA损失。MeDIP时，制备的文库/填充DNA混合物与0.3 ng对照甲基化和0.3 ng对照未甲基化A. thaliana DNA及缓冲液混合。混合物加热至95°C 10 min，立即置于冰水浴10 min。每个样本分装到两个0.2 mL PCR管：一个用于10%输入对照（7.9 μl），另一个用于免疫沉淀（79 μl）。5-mC单克隆抗体33D3稀释1:15后加入样本。洗涤磁珠也加入，4°C孵育17小时。样本用Diagenode iPure Kit v2纯化，50 μl Buffer C洗脱。通过qPCR检测掺入的甲基化和未甲基化A. thaliana DNA回收率验证反应成功（QC1）。未甲基化掺入DNA的回收率应<1%（相对于输入对照，校正输入对照为总样本的10%），反应特异性应>99%（计算公式：(1-[未甲基化掺入对照DNA回收率/甲基化掺入对照DNA回收率])*100），方可进入下一步。通过qPCR确定每个文库扩增的最佳循环数，然后使用Kapa HiFi Hotstart Mastermix和NEBNext multiplex oligos（终浓度0.3 μM）扩增。最终文库扩增条件：95°C激活3 min，随后预定循环数的98°C 20 s、65°C 15 s、72°C 30 s，最终72°C延伸1 min。扩增文库用MinElute columns纯化，然后用3% Nusieve GTG琼脂糖凝胶进行片段大小选择以去除接头二聚体。所有最终文库在测序前提交BioAnalyzer分析，在Princess Margaret Genomics Centre（PMGC）使用Illumina HiSeq 2500、SBS V4化学、单端读取50 bp、7样本/泳道多重测序。测序后，读取序列使用Bowtie默认设置比对到λ和hg19。基于几乎无λ基因组比对，填充DNA不干扰测序数据生成（Supplementary Table 7和8）。hg19比对生成的SAM文件转换为BAM格式，使用SAMtools去除重复读取、排序和索引，随后使用R包MEDIPS分析。CpG富集分数作为免疫沉淀反应的质量控制指标，在MEDIPS包中计算。

**cfMeDIP-seq与MeDIP-seq的验证。** 使用PureLink Genomic DNA Mini Kit从人结直肠癌细胞系HCT116提取DNA。选择HCT116是因为有公开DNA甲基化数据可用。基因组DNA使用Covaris超声仪剪切以模拟cfDNA，使用AMPure XP beads排除较大片段以模拟cfDNA片段大小。对1、5、10和100 ng剪切DNA进行cfMeDIP-seq，100 ng代表金标准MeDIP-seq方案，每个输入量2个生物学重复。在测序文库至饱和前，使用MagMeDIP kit提供的引物测定甲基化人DNA区域（TSH2B）相对于未甲基化人DNA区域（GAPDH启动子）的倍数富集（Extended Data Fig. 2a-c，Supplementary Table 7）。

**细胞系DNA稀释系列。** 与CRC DNA相同，使用相同的提取和剪切方案处理多发性骨髓瘤（MM）细胞系MM.1S。按照Extended Data Fig. 3a方案进行CRC掺入MM DNA的稀释系列。该稀释系列用于cfMeDIP-seq（Supplementary Table 9）和超深度靶向测序检测CRC点突变，起始输入60 ng DNA。突变检测中，DNA文库使用Kapa HyperPrep Kit和Illumina兼容的分子条形码接头（含2-bp在线条形码（UMIs））制备，以确保最佳的分析灵敏度。使用定制的生物素化DNA捕获探针面板（xGen Lockdown Custom Probes Mini Pool）靶向5个基因（13kb）的外显子。简言之，条形码文库混合，按照制造商说明进行杂交捕获（IDT xGEN Lockdown protocol version 4）。捕获后扩增文库使用Illumina HiSeq 2500、SBS V4化学、双端125 bp、4样本/泳道测序至>100,000X读取覆盖度。未处理读取的平均目标覆盖度为186,312X（范围：154,419X-216,434X）（Supplementary Table 9）。测序后，读取使用样本特异性索引去多重化为单独的配对末端FASTQ文件。从每个读取中去除两个碱基对的分子条形码和一个碱基对的不变间隔序列。在第三位编码胸腺嘧啶碱基用于接头连接，并强制执行间隔过滤以去除不符合此设计的读取。从配对末端读取提取的条形码分组并写入每个序列的头部用于下游计算机分子鉴定。FASTQ文件使用BWA比对到人类参考基因组hg19，使用GATK IndelRealigner处理，使用SAMtools排序和索引。条形码与内源性序列特征（基因组坐标、比对、读取方向、配对中读取数）结合用于区分来自单个分子的序列。从支持同一分子的两个或更多读取形成一致性序列，要求Phred质量分数(Q)30以上的碱基一致性达70%。来自独特片段同一链的读取折叠形成单链一致性序列（SSCS），抑制聚合酶和测序仪错误。这些压缩读取随后与其互补链组合成双链一致性序列（DCS）。这实现了额外的错误抑制层，因为双链整合序列可以校正第一轮PCR期间累积的或由氧化诱导的不对称损伤。基于CCLE注释的SNP选择变异，与目标面板重叠。使用MuTect调用SNV，参数如下：--enable_extended_output --tumor_f_pretest 0.000001f --downsampling_type NONE --force_output --force_alleles --gap_events_threshold 1000 --fraction_contamination 0.00f --coverage_file。对每个变异强制调用每个碱基以评估条形码介导错误校正各阶段的检测限和背景噪声。UMI处理的错误抑制读取分析显示独特分子（即SSCS）和DCS平均目标覆盖度分别为6,276X（4,284X-8,068X）和1,043X（654X-1,602X）（Supplementary Table 9）。

**患者来源异种移植（PDX）cfDNA。** 所有小鼠工作按照University Health Network动物护理委员会批准的动物使用方案和伦理规定进行。经患者同意和UHN研究伦理委员会批准从UHN Biobank获得的人结直肠肿瘤组织，使用胶原酶A消化为单细胞。单细胞皮下注射到4-6周龄NOD/SCID雄性小鼠。小鼠通过CO₂吸入安乐死，随后通过心脏穿刺收集血液并储存在EDTA管中。从收集的血液样本中分离血浆并储存在-80°C。使用QIAamp Circulating Nucleic Acid Kit从0.3-0.7 ml血浆中提取cfDNA。两个含10 ng起始cfDNA的生物学样本按照前述cfMeDIP-seq方案处理、测序和分析（Supplementary Table 10）。

**供体招募和样本获取。** 所有患者提供书面知情同意，所有样本在University Health Network（UHN）和Mount Sinai Hospital（MSH）机构伦理委员会和研究伦理委员会批准下获得，符合所有相关伦理规定。胰腺导管腺癌病例（PDAC）来自Ontario Pancreatic Cancer Study和UHN Biobank。结直肠癌和乳腺癌血浆样本来自UHN Biobank。肺癌血浆样本来自UHN Thoracic Biobank。AML样本来自UHN Leukemia Biobank。膀胱癌和肾癌血浆样本来自UHN Genitourinary（GU）Biobank，来自同意的泌尿肿瘤患者，分别在肾切除术和膀胱切除术前采集。最后，健康对照通过加拿大多伦多MSH的家庭医学中心招募。

**PDAC样本纯化肿瘤和正常细胞的标本处理和甲基化分析。** 对于原发性PDAC样本，标本在切除后立即处理，使用代表性切片确认诊断。在Leica LMD 7000仪器上对新鲜液氮冷冻组织样本进行激光捕获显微切割（LCM）。LCM在切片当天进行以最小化核酸降解。使用Qiagen Cell Lysis Buffer提取基因组DNA。每样本定量10 ng基因组DNA，按照Gu et al., 2011方案稍作修改进行RRBS分析。连接Illumina TruSeq甲基化接头的DNA文库使用Zymo EZ DNA methylation kit按照制造商方案进行亚硫酸氢盐转化，随后凝胶大小选择160 bp-300 bp片段。确定每个纯化文库扩增的最佳循环数后，使用Kapa HiFi Uracil+ Mastermix扩增，AMPure beads纯化。最终文库在测序前提交BioAnalyzer分析，在PMGC使用Illumina HiSeq 2000、SBS V3化学、单端读取50bp、4样本/泳道多重测序。测序后，每个样本的原始数据使用Trim Galore!以RRBS设置修剪，然后使用Bismark with Bowtie比对到hg19（Supplementary Table 11）。生成的SAM文件转换为BAM格式，使用SAMtools排序和索引。

**患者cfDNA标本处理。** 使用EDTA和ACD管收集的血浆样本来自UHN BioBanks和MSH，保持冷冻直至使用。使用QIAamp Circulating Nucleic Acid Kit从0.5-3.5 mL血浆中提取cfDNA，使用Qubit定量。性别、年龄和病理分期见Supplementary Table 12，提取的DNA量见Extended Data Fig. 8a。

**胰腺癌患者和健康供体cfDNA差异甲基化区域的计算和可视化。** 使用MEDIPS和DESeq2 R包计算24例胰腺癌（PDAC）患者和24例健康供体（对照）cfDNA样本之间的DMR。对每个样本，计算每300 bp非重叠窗口的计数，过滤掉所有样本中计数少于10的窗口，拟合负二项模型以FDR<0.1（Wald检验）调用DMR。使用DMR RPKM值的Z分数、欧几里得距离和Ward聚类进行可视化。

**PDAC中血浆来源DMR在肿瘤特异性甲基化信号中的富集分析。** 从GEO（GSE89473）下载5个RRBS分析的正常PBMC样本，与24个胰腺癌组织RRBS样本比较。使用R包MethylKit解析文件，保留在24个PDAC中至少18个和5个PBMC中至少4个检测到的常染色体CpG用于进一步分析。以FDR<0.01、delta-Beta>0.25获得DMC。然后从1000次重采样生成零分布，保留RRBS特征与cfMeDIP DMR之间原始交集所见的窗口内CpG数量的关系。然后计算两者均高甲基化、一个高甲基化而另一个不高甲基化、一个低甲基化而另一个不低甲基化、以及两者均低甲基化的DMR之间重叠频率。分布基于z分数标准化，用于计算Bonferroni校正p值以确定富集。本手稿中后续富集检验采用相同程序。

**cfMeDIP DMR在TCGA 450K DMC中相对于正常组织和PBMC的富集分析。** 从7种癌症类型（AML、膀胱（BLCA）、乳腺（BRCA）、结直肠（CRC）、肺（LUC）、胰腺（PDAC）和肾癌（RCC））和健康供体（正常）获得189份cfDNA样本（Supplementary Table 12）。处理这些样本的cfMeDIP-seq数据后，使用DESeq2按上述方法计算每种癌症类型与健康供体之间的DMR。还使用limma计算每种相应癌症类型的TCGA 450K甲基化阵列样本（n=3979，来自SAGE synapse）与PBMC样本（n=53，来自GEO）之间的DMC（FDR<0.01，绝对delta-Beta 0.25）。富集统计检验按上述PDAC RRBS样本方法进行。对BLCA、BRCA、CRC、LUC和RCC，还进行了癌症类型TCGA 450K甲基化阵列样本与同一组织正常样本之间DMC的相同程序。

**cfMeDIP-seq DMR中与差异甲基化基序相关的转录因子检查。** 从GTEx联盟获得53种人类组织的RNA-seq数据中位RPKM（Supplementary Table 13），组织中位表达在热图中可视化。为寻找TF表达和DMR相关TF基序的富集，选择1000个随机TF集。分析中考虑了每个TF对甲基化状态的已知敏感性，产生42个在健康供体中富集的TF和52个在胰腺导管腺癌病例中富集的TF。计算这些TF在每个样本中表达的ssGSEA分数，针对胰腺癌（TCGA）、血液（GTEx）和正常胰腺（GTEx），并使用Wilcoxon秩和检验与随机TF集的分布进行比较。

**机器学习分析。** 为在不产生高计算成本的情况下评估cfMeDIP数据在肿瘤分类中的性能，将初始候选特征集缩减为包含CpG岛、shore、shelf和FANTOM5增强子的窗口（“调控特征”），得到189个样本和505,027个特征的矩阵。然后使用caret R包将发现队列数据按80%-20%分为100个类别平衡的独立训练集和测试集。然后使用limma-trend在训练数据分区上为每个类别相对于其他类别选择前300个DMR（150个高甲基化，150个低甲基化）。然后使用这些DMR（最多300个DMR x 7个其他类别=2100个特征）训练二项GLMnet，使用3次10折交叉验证（CV）优化混合参数（alpha，值=0、0.2、0.5、0.8和1）和惩罚参数（lambda，值=0–0.05，增量0.01），以Cohen's Kappa为性能指标。对每个训练集，产生8个一对其他类别二项分类器的集合。然后使用AUROC估计保留测试集上的分类性能。这些估计代表无偏分类测量，因为保留测试集样本未用于DMR预选择或GLMnet训练和调优。100个独立训练和测试集也允许最小化因训练集偏倚导致的乐观估计。对于每个验证队列cfMeDIP样本，估计AML、PDAC、LUC和正常一对所有二项分类器的类别概率，这些分类器在发现队列内的100个不同训练集上训练。100个模型的概率取平均产生单一分数，用于AUROC估计。还通过估计当特定类别的早期（I和II期）或晚期样本（III和IV期）被排除时的一对所有分类器AUROC，评估疾病分期（仅适用于LUC和PDAC）是否影响性能。从Iorio et al (2016)获得的1,028个细胞系的450K图谱以IDAT文件形式获取。数据使用minfi包中的ssNoob方法统一处理。将该数据集缩减为有cfMeDIP数据的组织类型（n=400）。

总之，作者开发了一种稳健、灵敏且免亚硫酸氢盐的基于免疫沉淀的cfDNA甲基化模式分析方法。该方法有待在完全独立的数据集中进一步验证，但研究结果强调了cfDNA甲基化谱作为无创、经济有效、灵敏且准确的早期肿瘤检测基础用于癌症拦截和多癌种分类的潜在效用。
