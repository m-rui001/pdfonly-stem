# 地缘政治风险对比特币收益率与波动率的影响

**原题：** Effects of the Geopolitical Risks on Bitcoin Returns and Volatility（2018）· DOI: https://doi.org/10.1016/j.ribaf.2018.09.011

本文研究全球地缘政治风险（GPR）指数对比特币日收益率和价格波动率的预测能力。作者使用2010年7月18日至2017年11月30日的日度数据（共2693个观测），采用贝叶斯图示结构向量自回归（BSGVAR）模型、普通最小二乘（OLS）回归和分位数对分位数（QQ）回归，发现GPR指数变化对比特币收益率和波动率均具有预测力：在均值意义上，GPR上升显著降低比特币收益率并提高其波动率；但在高分位（极端情形）下，GPR的影响转为正且显著。据此作者认为比特币在极端地缘政治风险时期可作为对冲工具。

## 研究背景与文献定位

比特币自2008年问世以来备受关注，尤其在2017年价格剧烈波动后，相关文献迅速增加。已有研究讨论了比特币市场效率（如Cheah等2018；Urquhart 2016；Sensoy 2018）、投机泡沫（如Cheah和Fry 2015），以及比特币的对冲和多元化功能（如Dyhrberg 2016a,b；Guesmi等2018），但也有证据表明比特币对冲能力有限（Bouri等2017a），且多元化收益在熊市下降（Ji等2018）。同时，地缘政治风险（GPR）指数由Caldara和Iacoviello（2018）构建，已有研究显示其影响股票市场、伊斯兰股票、新兴经济体等。作者指出，GPR上升可能导致投资者卖出传统金融资产，资金流入加密货币市场，从而推高比特币价格。Demir等（2018）发现经济政策不确定性（EPU）能预测比特币收益；Bouri等（2017b）表明比特币对冲不确定性。本研究将其扩展至GPR，利用日度数据考察GPR对比特币收益率与波动率的预测作用。

## 数据与模型

数据区间为2010年7月18日至2017年11月30日，频率为日度。比特币价格来自CoinDesk网站（与Demir等2018、Katsiampa 2017一致）。价格波动率定义为最近五天比特币收益率的动态标准差。GPR指数采用Caldara和Iacoviello（2018）构建的全球指数，该指数基于11份国际报纸的电子档案，通过自动化文本搜索统计每月涉及地缘风险的文章占比（归一化至2000–2009年均值为100）。样本期内，2014年俄乌危机和2015年巴黎恐袭期间GPR明显上升。

核心回归模型如下（式1–4）：

$$\Delta\ln(R_{BC})_t = \alpha_1 + \beta_1 \Delta\ln(GPR)_t + \varepsilon_{1t}$$

$$\Delta\ln(R_{BC})_t = \alpha_2 + \beta_2 \Delta\ln(GPR)_{t-k} + \varepsilon_{2t}$$

$$V_{BC} = \alpha_3 + \beta_3 \Delta\ln(GPR)_t + \varepsilon_{3t}$$

$$V_{BC} = \alpha_4 + \beta_4 \Delta\ln(GPR)_{t-k} + \varepsilon_{4t}$$

其中$\Delta\ln(R_{BC})_t$为比特币价格的自然对数收益，$V_{BC}$为价格波动率，$\Delta\ln(GPR)_t$和$\Delta\ln(GPR)_{t-k}$为GPR指数的对数变化（当期及滞后k期），$\varepsilon$为误差项。作者还报告比特币收益与GPR对数变化的相关系数为–0.011。模型还考虑多个滞后阶（1至24）作为稳健性检验。

## 实证结果

**BSGVAR模型的结果**
作者采用Bouri等（2018b）的方法，用三年（1095天）滚动窗口估计BSGVAR模型，窗口覆盖2013年7月19日至2017年11月30日。对比特币收益率，贝叶斯信息准则（BIC）显示多元自回归（MAR）结构优于多元即时（MIN）结构（图1）。图2显示，GPR变化到比特币收益率的MAR连接中，最高的互联性出现在2016年4月15日至2017年6月3日之间，从而确认了GPR与收益率之间存在领先-滞后关系。对价格波动率，同样选择MAR结构（图3），且GPR与波动率之间最高互联性出现在2017年初（图4）。作者由此总结GPR能够预测比特币收益率和波动率。

**OLS与QQ回归结果**
表1报告了GPR对比特币收益率的OLS和QQ回归结果。OLS估计显示，GPR变化对收益率的系数为–0.01，在5%水平显著；各滞后项（滞后1至24）均为负但不显著。QQ结果中，GPR及其一阶滞后（GPR(–1)）在较低和中心分位（如0.05至0.70）为负且多数显著；但在高分位（0.85、0.90、0.95）转为正且统计显著。其他滞后项（如GPR(–2)、GPR(–4)等）在高分位也多为正，但仅GPR和GPR(–1)显著。这表明极端GPR事件对极端正收益的预测能力仅存在于短期（约一个交易日）。

表2报告了GPR对比特币价格波动率的OLS和QQ结果。OLS中系数为正（0.10）但不显著，滞后项也均不显著。QQ结果中，GPR和GPR(–1)在较低和中心分位为正但不显著，而在上分位（0.85、0.90、0.95）变为正且显著（例如0.95分位系数0.26，p<0.01）。其他滞后项在上分位也为正但几乎不显著。因此，GPR极端事件对波动率的极端值有预测力，同样仅存在于当前日或极短滞后。

综合来看，GPR上升在平均意义上降低比特币收益，但在比特币牛市（高收益分位）和极高波动环境下，GPR的正向影响显著，表明比特币在极端风险时期可充当对冲工具。作者强调投资者应关注GPR指数来管理加密货币组合，并提醒政策制定者注意地缘政治事件对加密货币市场的溢出风险。

## 结论与展望

作者总结了核心发现：BSGVAR确认GPR的预测力；OLS显示GPR对收益有负效应、对波动率有正效应（后者不显著）；QQ显示在较高分位上影响均为正且显著。因此比特币在极端全球地缘政治风险时期可作为对冲工具。未来研究可使用其他风险指标（如大国国内政治风险）或高频数据（日内数据）进一步探讨。
