# 面向高光谱成像的分段堆叠自编码器：降维与特征提取的改进方法

**Novel segmented stacked autoencoder for effective dimensionality reduction and feature extraction in hyperspectral imaging** (2015) · DOI: https://doi.org/10.1016/j.neucom.2015.11.044

本文提出一种分段堆叠自编码器（S-SAE）用于高光谱影像的降维与特征提取。传统堆叠自编码器（SAE）在处理高光谱像素时，需要让隐藏节点同时面对数百个光谱波段，导致计算复杂且抽象能力受限。S-SAE 将原始光谱特征分割为若干子段，分别用多个较小的 SAE 单独处理，再拼接各段得到的降维特征。实验表明，S-SAE 在降低复杂度的同时，提升了特征抽象能力和分类精度，在 92AV3C 和 Pavia CA 数据集上优于常规 SAE 及 PCA、ICA、MNF、EMD 等对比方法。

## 背景与相关工作

高光谱成像（HSI）获取的是二维空间图像在数百个波长上的光谱响应，形成三维超立方体，每个像素由一组光谱值表示。大量光谱波段使分类等应用需要先进的特征提取与数据约简技术。既有方法可分为两类：一类仅做特征表示、之后需要单独分类器，如经典的主成分分析（PCA）、独立成分分析（ICA）、最大噪声分数（MNF），以及较新的经验模态分解（EMD）、奇异谱分析（SSA）、形态学剖面（MPs），这些文献通常用支持向量机（SVM）做后续分类；另一类直接完成分类，如图形学习、稀疏表示、随机子空间集成、谱间约束、多特征学习等。近年深度学习（DL）被引入高光谱特征表示，其中堆叠自编码器（SAE）通过多层神经网络在深层节点中形成高层次的抽象表示，可有效降维。但标准 SAE 的输入层需同时处理全部光谱波段，隐藏节点在激活函数中评估所有波段，复杂度高且难以找到恰当抽象，最终限制分类精度。本文针对此问题提出分段处理方案。

## 堆叠自编码器与分段方案

基本自编码器（AE）将输入信号 p 经中间层映射得到低维特征 y，再由 y 重建输出 z，要求 z 尽量接近 p。满足 y = f(w_y p + b_y)，z = f(w_z y + b_z)，其中 f 为非线性激活函数，w、b 为权重和偏置。训练时最小化 p 与 z 之间的误差。堆叠自编码器（SAE）是在输入输出之间加入多层隐藏层，逐层实现更高抽象；在高光谱应用中，用训练好的 SAE 对每个像素取最深层的输出 y 作为降维特征。

常规 SAE 将所有光谱波段同时、等同处理，忽略了不同谱区信息量差异。本文提出的 S-SAE 将光谱域分割成 K 个区域 p_k（k=1,…,K），每个区域分别用一个较小的两层 SAE 处理，得到局部特征 y_k，再拼接为最终特征向量，总特征维数 F = Σ F_k。分段依据来自光谱波段间的相关矩阵——高相关区域构成自然分段，这与文献中分段 PCA 的思路一致。

## 实验配置与分类精度

实验使用两个数据集。92AV3C（Indian Pine）为 145×145 子场景，原始 220 波段，去掉噪声和水吸收波段后保留 200 波段，共 16 类地物；Pavia CA 为 150×150 子场景，ROSIS 传感器，102 波段，7 类城市地物。特征提取后的特征送入 SVM（LIBSVM），核函数用高斯 RBF，惩罚参数 c 取 {10^0,…,10^5}，γ 取 {10^-3,…,10^2}，通过网格搜索确定；每类随机抽取 5% 样本训练，其余测试，重复 10 次取平均总体精度和 McNemar 检验值。

表 I（原文 Table I）考察了层数和隐藏单元数对 F=10 时分类精度的影响。结果显示更高的层数或更多隐藏单元并不必然提升精度，例如 92AV3C 上 2 层 40 单元精度 74.01%，6 层 60 单元仅 67.06%；Pavia CA 上各配置差异不大。据此选用两层、第一层 40 个单元（Table II），F 取 5、10、15、20。S-SAE 的分段配置见原文 Table III：92AV3C 分为三段（波段 1-35、36-104、105-200），每段第一层 13 个单元，特征按段分配；Pavia CA 分为两段（1-80、81-102），每段第一层 20 个单元。

分段选择对 S-SAE 性能影响显著。以 92AV3C、F=20 为例，原文 Table IV 显示，按相关矩阵确定的原配置（3 段，L_k={13,13,13}, F_k={6,7,7}）总体精度 80.66%；两种同样依据相关矩阵的备选配置 C-1（5 段）和 C-2（4 段）分别获得 79.57% 和 79.23%，与提议配置接近；而随机分段 C-3（2 段）仅 75.39%，明显下降，说明分段必须遵循相关矩阵的谱间相关性。

分类精度对比（原文 Table V）：92AV3C 上，PCA 77.01%（F=15），ICA 76.90%（F=20），MNF 78.03%（F=10），常规 SAE 74.01%（F=10），S-SAE 80.66%（F=20），EMD 65.40%（F=200），SSA 82.13%（F=200）。S-SAE 精度最高，但 SSA 用了 200 个特征，远多于 S-SAE 的 20 个。Pavia CA 上，PCA 97.06%（F=5），ICA 96.93%（F=5），MNF 97.16%（F=5），SAE 97.29%（F=15），S-SAE 97.42%（F=5），EMD 90.71%（F=102），SSA 97.35%（F=102）——S-SAE 仍为最高，且特征数最少。McNemar 检验以 PCA 为参照，S-SAE 在 92AV3C 上 z=+8.14，在 Pavia CA 上 z=+1.60，均显著优于 PCA。类级精度（原文 Table VI、VII）显示 S-SAE 在大多数类别上优于或持平其他方法，但 MNF 和 SSA 在某些类别中表现更好，作者推测与其噪声抑制模型有关；少数样本数极少的类别中常规 SAE 偶尔超过 S-SAE，但整体不影响结论。

## 计算复杂度与结论

S-SAE 虽然使用多个 SAE，但因局部网络规模小，总体神经连接数更少。常规 SAE 连接数为 N×L + L×F + F×N；S-SAE 为 Σ_k [N_k L_k + L_k F_k + F_k N_k]。若各参数均匀分割，S-SAE 复杂度约为常规的 1/K（K 为段数）。实际测得（Table VIII）：92AV3C 在不同 F（5–20）下连接数从约 9200–12800 降至 3030–4225，减少约 67%；Pavia CA 从 4790–6920 降至 2424–3460，减少约 50%。用乘累加次数（MACs）估计，训练后每次前向传播常规 SAE 需 [N×L + L×F] 次 MAC，S-SAE 为其 1/K；而 PCA/MNF/ICA 仅需 [N×F] 次，经典方法复杂度最低，但 F 增大时可能超过 S-SAE。实际计算时间（Table IX）显示，S-SAE 比常规 SAE 快：92AV3C 提速约 56%–61%，Pavia CA 提速约 42%–46%。

总之，S-SAE 通过光谱分段降低了网络内部连接和计算量，同时利用局部谱区提取更有效的特征，在分类精度和计算效率上均优于常规 SAE，并与经典降维方法相比具有竞争力。未来工作可探索将 S-SAE 与 2D SSA、自适应稀疏表示、弱监督学习等结合。
