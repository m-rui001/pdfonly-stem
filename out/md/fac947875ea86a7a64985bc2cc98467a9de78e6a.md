# 产生IL-17的γδT细胞与中性粒细胞协同促进乳腺癌转移

*原题：IL-17-producing gamma delta T cells and neutrophils conspire to promote breast cancer metastasis*


Coffelt, Kersten, Doornebal 等，Nature，2015，DOI: 10.1038/nature14282

转移性疾病仍是乳腺癌患者的主要死因。肿瘤微环境及远端器官中的免疫细胞及其介质可促进转移形成，但肿瘤诱导的全身性炎症对转移的确切贡献及其调控机制尚不清楚。本文在小鼠自发性乳腺癌转移模型中证明，肿瘤通过引发全身性炎症级联反应来最大化其转移机会：IL-1β 促使 γδ T 细胞表达 IL-17，进而以 G-CSF 依赖的方式引起中性粒细胞的全身性扩增与极化；这些中性粒细胞获得抑制携带 CD8 抗原的细胞毒性 T 细胞的能力，而后者限制转移灶的建立。中和 IL-17 或 G-CSF、或去除 γδ T 细胞，均可阻止中性粒细胞积聚并下调其 T 细胞抑制表型；去除 γδ T 细胞或中性粒细胞可显著减少肺和淋巴结转移，而不影响原发肿瘤进展。这些数据表明，靶向这一由癌细胞启动的免疫系统“多米诺效应”——γδ T 细胞/IL-17/中性粒细胞轴——是抑制转移性疾病的新策略。

在乳腺癌患者中，中性粒细胞丰度增加预示转移特异性生存恶化。目前中性粒细胞在转移中的作用存在争议，既有促转移也有抗转移功能的报道。作者发现，在乳腺肿瘤荷瘤 K14cre;Cdh1^F/F;Trp53^F/F（KEP）小鼠中，中性粒细胞较野生型（WT）同窝小鼠出现显著的全身性扩增（Extended Data Fig. 1a, b）。中性粒细胞定义为 CD45⁺CD11b⁺Ly6G⁺Ly6C⁺F4/80⁻ 细胞，在所检查的每个器官中均有积聚（Extended Data Fig. 1c, d）。在作者近期描述的基于 KEP 的自发性乳腺癌转移模型中（Fig. 1a），也观察到全身性中性粒细胞扩增（Fig. 1b 和 Extended Data Fig. 1e, f）。中性粒细胞扩增是肿瘤诱导的，因为手术切除原发肿瘤后其立即减少（Extended Data Fig. 1g）。

为确定中性粒细胞在转移中的功能意义，使用抗 Ly6G 抗体清除中性粒细胞（Extended Data Fig. 2a-c）。治疗在肿瘤可触及时开始，持续至小鼠出现明显转移性疾病。中性粒细胞清除不影响肿瘤生长（Extended Data Fig. 2d）、肿瘤组织病理学（Extended Data Fig. 2e）或微血管密度（Extended Data Fig. 2e,f）。相反，中性粒细胞清除导致肺和淋巴结转移显著减少（Fig. 1c）。这些数据表明中性粒细胞协助癌细胞向多个部位扩散。

接下来，作者评估中性粒细胞在转移级联不同阶段的作用。在原发肿瘤生长期间（早期阶段）或原发肿瘤切除后（晚期阶段）清除中性粒细胞（Fig. 1a）。有趣的是，中性粒细胞清除在早期阶段减少了多器官转移，但在晚期阶段没有（Fig. 1d）。转移结节大小未受影响（Extended Data Fig. 2g），提示中性粒细胞在转移级联的早期步骤中促进多器官转移。

为理解中性粒细胞促进转移的机制，作者研究了其表型。既往报道在促转移髓系细胞上发现造血干细胞标志物 cKIT，且 CD11b⁺VEGFR1⁺ 细胞被认为参与转移前微环境。荷瘤 KEP 小鼠中性粒细胞中表达 cKIT 的比例更高，而 WT 和 KEP 小鼠的中性粒细胞和单核细胞均表达 VEGFR1（Extended Data Fig. 3a, b）。在转移模型中，随着肿瘤增大，cKIT⁺ 中性粒细胞也全身性扩增（Extended Data Fig. 3c），肿瘤切除后降至基线水平（Extended Data Fig. 3d）。核形态分析显示未成熟细胞特征，包括带状、圆形和非分叶核，而大多数 WT 中性粒细胞呈高分叶（Extended Data Fig. 3e），提示 KEP 乳腺肿瘤促进未成熟中性粒细胞释放入循环。

对 WT 和荷瘤 KEP 小鼠循环中性粒细胞进行下一代 RNA 测序（RNA-seq），发现 100 个差异表达基因（Extended Data Fig. 4a 和 Extended Data Table 1）。KEP 小鼠中性粒细胞中上调的若干基因，包括 Prok2（又称 Bv8）、S100a8 和 S100a9（Fig. 2a），此前已被与转移关联。Nos2（编码诱导型一氧化氮合酶 iNOS 的基因）是最强上调基因，上调超过 150 倍（Fig. 2a）。由于 iNOS 抑制 T 细胞，作者假设中性粒细胞通过免疫抑制促进转移。确实，与 WT 中性粒细胞相比，KEP 小鼠中性粒细胞在体外抑制了 CD3/CD28 诱导的 naive 脾 CD8⁺ T 细胞增殖，而 iNOS 抑制剂逆转了此效应（Fig. 2b 和 Extended Data Fig. 4b）。在对照和中性粒细胞清除的荷瘤小鼠肺中，CD8⁺ T 细胞比例无差异（Extended Data Fig. 4c）。然而，中性粒细胞清除后 CD8⁺ T 细胞的效应表型显著增强，表现为 CD62L⁻CD44⁺ 和 IFN-γ⁺ 细胞比例显著增加（Fig. 2c 和 Extended Data Fig. 4d, e）。为进一步建立中性粒细胞与 CD8⁺ T 细胞活性之间的机制联系，在转移模型中同时清除两种细胞群。同时清除中性粒细胞和 CD8⁺ T 细胞逆转了单独清除中性粒细胞的转移表型（Fig. 2d），而不影响原发肿瘤生长（Extended Data Fig. 4f）。单独清除 CD8⁺ T 细胞未改变肿瘤生长或多器官转移（数据未显示）。这些数据提示中性粒细胞通过抑制 CD8⁺ T 细胞促进癌细胞扩散。因此，KEP 模型中的中性粒细胞可归类为髓源性抑制细胞的一个亚群。

随后作者探究乳腺肿瘤如何诱导全身性中性粒细胞扩增。WT 乳腺腺体与 KEP 乳腺肿瘤的细胞因子谱比较显示，粒细胞-巨噬细胞集落刺激因子（GM-CSF）和 G-CSF——中性粒细胞生物学的两个关键调节因子——在 KEP 肿瘤中未显著增加（Extended Data Fig. 5a, b）。然而，IL-1β、IL-6 和 IL-12p40（IL-23 的一个亚基）表达增加（Extended Data Fig. 5a, b）。这些细胞因子已知可刺激淋巴细胞产生 IL-17。

在银屑病等炎症性疾病中，淋巴细胞来源的 IL-17 通过全身性诱导 G-CSF 调节中性粒细胞扩增。作者假设同样的炎症级联在乳腺癌转移中重要。确实，荷瘤 KEP 小鼠血清中 IL-17A 和 G-CSF 水平高于 WT 小鼠（Fig. 3a）。在荷瘤 KEP 小鼠中中和 IL-17A 降低了 G-CSF 血清水平，而阻断 G-CSF 不影响 IL-17A 水平（Fig. 3a），表明 IL-17 位于 G-CSF 上游。抑制任一细胞因子均减少循环中性粒细胞、降低 cKIT⁺ 中性粒细胞比例（Fig. 3b）并逆转中性粒细胞表型（Fig. 3c）。向抗 IL-17 处理的荷瘤 KEP 小鼠注射重组 G-CSF 可克服抗 IL-17 处理的效应（Extended Data Fig. 5c-e）。此外，用重组 G-CSF 处理 WT 小鼠导致中性粒细胞扩增、cKIT⁺ 中性粒细胞比例增加并改变中性粒细胞表型（Extended Data Fig. 5c-e）。这些数据证明 IL-17/G-CSF 信号级联对中性粒细胞扩增和表型均是必需的。

接下来，作者确定 IL-17 的来源。由于已知 T 细胞产生 IL-17，使用 T 细胞特异性基因表达阵列分析脾 CD3⁺ T 细胞。该分析验证了荷瘤 KEP 小鼠 T 细胞中 IL-17 相关细胞因子的上调（Extended Data Fig. 5f）。随后作者探究淋巴细胞是否是 IL-17 的唯一来源以及它们是否驱动转移。将 KEP 小鼠与缺乏 T 和 B 细胞的 Rag1⁻/⁻ 小鼠杂交。KEP;Rag1⁺/⁻ 与 KEP;Rag1⁻/⁻ 小鼠的肿瘤起始、增殖和组织学相同（Extended Data Fig. 6a 及数据未显示）。然而，KEP;Rag1⁻/⁻ 小鼠血清 IL-17A 和 G-CSF 水平较低（Fig. 3d），中性粒细胞计数减少（Fig. 3e）且中性粒细胞表型改变（Fig. 3f）。KEP;Rag1⁺/⁻ 与 KEP;Rag1⁻/⁻ 小鼠间转化生长因子 β1（TGFβ1）水平无变化（Extended Data Fig. 6b），提示与其他模型不同，TGF-β 在调节中性粒细胞表型中的作用小于 IL-17 诱导的 G-CSF。重要的是，KEP;Rag1⁻/⁻ 小鼠肺和淋巴结转移较少（Fig. 3g）。KEP;Rag1⁻/⁻ 小鼠的转移表型在转移模型中得到验证，其中 Rag1⁻/⁻ 小鼠作为移植 KEP 肿瘤碎片的受体，导致肺转移减少（Extended Data Fig. 6c）。因此，产生 IL-17 的淋巴细胞驱动中性粒细胞积聚、表型和转移。

进行直接离体胞内细胞因子染色以确定哪个 T 淋巴细胞亚群产生 IL-17。CD4⁺ T 细胞和 γδ T 细胞均表达 IL-17A（Fig. 4a），且两个产生 IL-17 的亚群在荷瘤 KEP 小鼠的多个器官中较 WT 小鼠增加（Fig. 4b 和 Extended Data Fig. 7a）。在原发肿瘤中，γδ 和 CD4⁺ T 细胞的丰度太低（分别 <0.2% 和 <2% 的所有活细胞），无法可靠评估 IL-17 表达。γδ T 细胞的 IL-17A 水平高于 CD4⁺ T 细胞（Fig. 4a 和 Extended Data Fig. 7b）。清除两种细胞群以确定其功能重要性。清除 CD4⁺ T 细胞降低了 cKIT⁺ 中性粒细胞，但未能影响总中性粒细胞扩增、IL-17A 或 G-CSF 水平（Extended Data Fig. 7c-e）。相反，清除 γδ T 细胞降低了 IL-17A 和 G-CSF 血清水平（Fig. 4c），减少循环中性粒细胞、降低 cKIT⁺ 中性粒细胞比例（Fig. 4d 和 Extended Data Fig. 7c）并逆转中性粒细胞表型（Fig. 4e）。这些数据表明产生 IL-17 的 γδ T 细胞促进中性粒细胞扩增和表型改变。荷瘤 KEP 小鼠中产生 IL-17 的 γδ T 细胞为 CD27⁻，大多为 Vγ4⁺，一部分表达 CCR6、IL-1R1 和 ROR-γt（Extended Data Fig. 8a, b），与其他炎症性疾病相似。

随后作者探究 KEP 乳腺肿瘤如何激活产生 IL-17 的 γδ T 细胞。基于文献和细胞因子分析（Extended Data Fig. 5a, b），作者聚焦于 IL-23 和 IL-1β。中和 IL-1β 降低了 γδ T 细胞的 IL-17A 表达、G-CSF 血清水平和中性粒细胞扩增，但抑制 IL-23 无影响（Fig. 4f-h）。巨噬细胞是 KEP 肿瘤中表达 IL-1β 最丰富的细胞类型（Extended Data Fig. 8c, d）。这些数据提供了乳腺肿瘤与 γδ T 细胞之间的机制联系。

在转移模型早期阶段清除 γδ T 细胞不影响肿瘤组织病理学、微血管密度或原发肿瘤生长（Extended Data Fig. 8e 及数据未显示）。然而重要的是，γδ T 细胞清除小鼠的肺和淋巴结转移显著减少（Fig. 4i）。这些数据在缺乏 γδ T 细胞的 Tcrd⁻/⁻ 小鼠中得到验证。将 KEP 肿瘤碎片原位移植到 Tcrd⁺/⁻ 和 Tcrd⁻/⁻ 小鼠中，生长后切除。遗传性消除 γδ T 细胞也导致肺转移显著减少（Fig. 4j），而不影响原发肿瘤生长（Extended Data Fig. 8f）。这些数据证实 γδ T 细胞的促转移作用。

总之，作者表明乳腺肿瘤诱导的产生 IL-17 的 γδ T 细胞驱动中性粒细胞的全身性扩增和向 CD8⁺ T 细胞抑制表型的极化，以及随后在远端器官中转移灶的形成（Extended Data Fig. 9）。中性粒细胞在转移级联早期步骤中的重要性以及中性粒细胞中 Prok2、S100a8 和 S100a9 的上调提示中性粒细胞可能帮助建立转移前微环境；然而，这些中性粒细胞来源因子及其他因子的作用在 KEP 模型中仍有待确定。在乳腺癌患者中，独立临床研究一致指向中性粒细胞、γδ T 细胞和 IL-17 的促转移作用。本文建立了这些独立临床观察之间的机制联系。在感染和炎症性疾病中，γδ T 细胞/IL-17/中性粒细胞轴驱动疾病发病机制。作者现在证明这一可靶向通路也促进乳腺癌转移。

方法部分：小鼠。K14cre;Cdh1^F/F;Trp53^F/F（KEP）小鼠——浸润性小叶乳腺癌的条件模型——的生成和表征已有描述。KEP 小鼠回交至 FVB/N 背景。KEP 小鼠与 Rag1⁻/⁻ 小鼠（FVB/N；来自 L. Coussens 的赠予）杂交以生成 KEP;Rag1⁺/⁻ 和 KEP;Rag1⁻/⁻ 小鼠。从 4 月龄开始，通过触诊和卡尺测量每周两次监测乳腺肿瘤形成。FVB/N 背景的 Tcrd⁻/⁻ 小鼠来自 A. Hayday 的赠予。自发性转移模型也已有描述。简言之，该模型基于将 KEP 肿瘤块原位移植到 10-12 周龄雌性受体 FVB/N 小鼠、Rag1⁻/⁻ 小鼠、Tcrd⁺/⁻ 或 Tcrd⁻/⁻ 小鼠中。这些肿瘤块生长后，在 100 mm² 时手术切除，之后 100% 小鼠发生明显转移性疾病。

为清除免疫细胞或中和细胞因子，小鼠腹腔注射：抗 Ly6G（克隆 1A8；BioXCell）初始 400 μg 后每周三次 100 μg；抗 CD8（克隆 2.43；BioXCell）每周两次 200 μg；抗 γδ TCR（克隆 GL3；NKI 蛋白设施纯化）每周两次 100 μg。对于细胞因子中和实验，KEP 小鼠腹腔注射：抗 IL-17A（克隆 17F3；BioXCell）每周两次 50 μg；抗 G-CSF（克隆 67604；R&D Systems）每周三次 50 μg；抗 IL-23p19（克隆 G23-8；eBioscience）每周两次 50 μg；抗 IL-1β（克隆 B122；BioXCell）每周两次 50 μg。对照小鼠接受等量同型对照抗体或等体积 PBS。在指示处，WT 和 KEP 小鼠腹腔注射 5 μg rG-CSF（Peprotech）连续四天，第五天处死。注射 rG-CSF 的荷瘤 KEP 小鼠按上述相同方案接受抗 IL-17。抗体注射在 KEP 乳腺肿瘤达到 25 mm² 时开始直至死亡（225 mm²），或移植肿瘤达到 9 mm² 时开始直至手术（100 mm²）。在三个独立的 KEP 供体肿瘤中测试了中性粒细胞清除实验，结果相同。其中一个供体肿瘤用于研究其余部分。在抗体注射前和期间采集血样用于流式细胞术分析。动物在开始治疗方案前随机化。小鼠饲养在独立通风和开放笼中，食物和水随意提供。动物实验经荷兰癌症研究所动物伦理委员会批准，并按照机构、国家和欧洲动物护理和使用指南进行。

免疫组织化学。福尔马林固定组织按常规程序处理。苏木精和伊红染色如所述进行。所有染色程序均使用柠檬酸抗原修复。当原发肿瘤达到 100 mm² 时，使用抗 Ly6B（克隆 7/4；Cedarlane）或抗 Ly6G（克隆 1A8；BD Biosciences）检测中性粒细胞。中性粒细胞丰度的定量分析通过计数每个组织五个高倍（×40）视野（FOV）中的细胞进行。使用抗细胞角蛋白 8（克隆 Troma 1；Developmental Studies Hybridoma Bank, University of Iowa）检测转移灶。在转移模型中，对每只动物的一张肺切片中细胞角蛋白 8⁺ 结节总数进行评分。使用 ImageJ 测量每个结节的大小，然后以任意单位表示。淋巴结转移根据细胞角蛋白 8⁺ 转移灶的存在评分为阳性或阴性。发生明显转移性疾病（即呼吸窘迫或 225 mm² 腋窝淋巴结转移）的小鼠纳入分析；因局部复发而处死的小鼠排除。波形蛋白、E-钙粘蛋白和 CD34 染色如先前所述进行，并由两名盲法研究人员独立评分。微血管密度通过平均每个肿瘤切片五个视野中血管总数进行评分。对于 K14cre;Cdh1^F/F;Trp53^F/F;Rag1⁺/⁻ 和 K14cre;Cdh1^F/F;Trp53^F/F;Rag1⁻/⁻ 小鼠的转移定量，根据细胞角蛋白 8⁺ 转移灶的存在，将单张肺或淋巴结切片评分为阳性或阴性。染色玻片使用 Aperio ScanScope 数字化处理，并使用 ImageScope 软件版本 11.0.2 捕获。代表性图像的亮度和对比度在各组间同等调整。

Giemsa 染色。通过尾静脉穿刺在肝素包被管中收集血液。用 NH₄Cl 裂解缓冲液裂解红细胞。将白细胞涂布在玻璃载玻片上，然后用递减浓度的 Wright-Giemsa 溶液染色。

RNA-seq。通过磁柱（Miltenyi）从小鼠血液中分离 Ly6G⁺ 中性粒细胞。使用乳腺肿瘤约 225 mm² 的 KEP 小鼠和年龄匹配的 WT 小鼠。通过流式细胞术验证分离中性粒细胞的纯度，仅使用纯度大于 90% 的样品。使用 Trizol 分离 RNA，然后用 DNase I（Invitrogen）处理。样品过 Qiagen RNeasy 柱进行纯化。用 Agilent 2100 Bioanalyzer 确认 RNA 质量。使用 Illumina TruSeq RNA Sample Preparation Kit 中提供的试剂，按照制造商方案制备 RNA-Seq 文库。文库 PCR 扩增 12 个循环，并在 Illumina HiSeq 2000 系统上使用 TruSeq 试剂盒和软件测序，产生双端 51 碱基对读长。使用 TopHat 将序列读长比对到小鼠参考基因组（National Center for Biotechnology Information build 37）。然后使用 HTSeq-count 生成每个基因和样品的唯一比对读长总数列表。序列读长标准化为每样品 1000 万读长，并用公式 log₂((expression gene X ÷ library size) 10⁶)+1 进行 log₂ 转换，其中 library size 是每个样品所有表达值的总和。为确定样品间差异表达的基因，使用 R 包 Limma。使用绝对基因表达作为输入，在任何样品中无表达的基因从数据集中移除。使用 Voom 将计数数据转换为 log₂ counts per million 并估计方差。P 值设定为 0.05 的截断值，产生 100 个显著的差异表达基因。对这 100 个基因进行无监督聚类，数据转换为热图。

实时 PCR。如上提取中性粒细胞 RNA，然后使用 Oligo(dT) 引物（Invitrogen）用 AMV 逆转录酶转换为互补 DNA（cDNA）。cDNA（每孔 20 ng）通过 SYBR green 实时 PCR 使用 500 nM 引物在 LightCycler 480 热循环仪（Roche）上分析。β-actin 用作参考基因。每个基因使用以下引物序列：Nos2 正向 5′-GTTCTCAGCCCAACAATACAAGA-3′，反向 5′-GTGGACGGGTCGATGTCAC-3′；Prok2 正向 5′-CTTCGCCCTTCTTCTTTCCT-3′，反向 5′-GCATGTGCTGTGCTGTCAGT-3′；S100a8 正向 5′-TGAGCAACCTCATTGATGTCTACC-3′，反向 5′-ATGCCACACCCACTTTTATCACC-3′；S100a9 正向 5′-GAAGAAAGAGAAGAGAAATGAAGCC-3′；反向 5′-CTTTGCCATCAGCATCATACACTCC-3′；Il1b 正向 5′-CAACCAACAAGTGATATTCTCCATG-3′，反向 5′-GATCCACACTCTCCAGCTGCA-3′；Actb 正向 5′-CCTCATGAAGATCCTGACCGA-3′，反向 5′-TTTGATGTCACGCACGATTTC-3′。倍数变化使用公式 2^{-(ΔC_t - X̄[ΔC_t WT])} 计算。

T 细胞增殖测定。通过磁柱（Miltenyi）分离 WT 小鼠血液中性粒细胞和 WT 小鼠脾 CD8⁺ T 细胞。还使用乳腺肿瘤约 225 mm² 的 KEP 小鼠血液中性粒细胞。按照制造商说明（Invitrogen）用 Cell Trace CFSE 标记 CD8⁺ T 细胞。在 96 孔平底板中共培养等量细胞（2×10⁵）。按照制造商说明加入 CD3/CD28 Dynabeads（Invitrogen），并在指示处加入 0.5 mM 的 iNOS 抑制剂 L-NMMA（Sigma）。48 小时后，使用 BD LSRII 流式细胞仪和 Diva 软件评估 T 细胞增殖，使用以下抗体：CD8a-PE（1:600；克隆 53-6.7）、CD11b-APC（1:400；克隆 M1/70）、Ly6C-eFluor 450（1:400；克隆 HK1.4）、Ly6G-AlexaFluor 700（1:400；克隆 1A8）和 7AAD 活力标记。数据分析使用 FlowJo 软件版本 9.7.1。增殖指数使用公式（增殖的共培养 CD8⁺ T 细胞百分比）/（无共培养的增殖 CD8⁺ T 细胞百分比）×100 对每个重复实验计算。
