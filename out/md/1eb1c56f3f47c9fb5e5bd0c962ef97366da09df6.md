# 基于静力触探（CPT）的土体行为类型（SBT）分类系统——更新

**Cone penetration test (CPT)-based soil behaviour type (SBT) classification system — an update** · 2016 · https://doi.org/10.1139/cgj-2016-0044

本文主张：现有CPT-based土体行为类型（SBT）分类系统虽然基于原位力学行为测量，却仍沿用纹理描述（如砂、黏土），造成实践混淆。作者提出一套更新，将分类组改用行为描述（如砂状剪胀、黏状剪缩），引入判别土体微结构存在的方法，并给出案例说明其优势与局限。文章的基本出发点是：传统USCS等纹理分类与现场行为联系较弱，而CPT测量能反映内在原位行为，但现有SBT图表对无微结构的正常固结土有效，对有微结构的土则不够可靠。作者为此发展了三张配套的归一化图表（Qtn–Fr、Qtn–U2、Qtn–IG），并以大量已发表的SCPTu场地数据验证。全文的论证顺序为：先讨论一般土体分类与广义土体行为框架，再评价现有CPT分类方法，进而提出修改后的SBTn图表与微结构识别指标，最后用工程案例说明各图表的适用性并给出讨论与结论。

## 土体分类与广义土体行为

现有最常用的USCS系统按粒度与塑性分类：粗粒土为#200筛上留存超过50%者，细粒土为50%及以上通过者。粗粒土一般具有高强度、低压缩性、高渗透性，细粒土则具有中低强度、中等至高压缩性和低渗透性。但真实原位行为受沉积过程、应力历史、龄期与胶结等影响；纹理指标与行为的联系在年轻、未胶结的硅质土中最可靠。作者指出，理想土（ideal soil）指少或无微结构、以年轻与未胶结为主的土；结构土（structured soil）指具有由龄期和胶结等造成的显著微结构。In-situ土体行为的关键特征包括：体积变化、摩擦特性（强度刚度随正应力增加）、非弹性非线性响应，以及剪胀特性。Critical State概念为行为分类提供了理论基础：临界状态与初始状态无关，只取决于土颗粒特性；细粒土常用OCR定义原位状态，粗粒土则常用状态参数ψ。Jefferies和Been（2006）提出粗粒理想土ψ < −0.05时排水剪切大应变下趋向剪胀；细粒理想土OCR > 4也有剪胀倾向。Idriss和Boulanger（2008）将土分为砂状（sand-like，PI < 10%）与黏状（clay-like，PI > 18%），两者过渡发生在较窄的塑性指数区间。作者据此提出行为分类应围绕大应变下剪胀/剪缩、以及砂状/黏状/过渡三组构建。

对于分类测试，作者强调需要简单、经济、可重复且提供多个独立测量。CPT满足这些要求：标准贯入速率20 mm/s下连续记录锥尖阻力qc与侧摩阻力fs。CPTu增加孔压u2与消散时间t50；SCPTu进一步提供剪切波速Vs，最多可获7个独立测量。作者认为，行为分类系统主要适用于无显著微结构的理想土，因此需要同时提供识别微结构存在的方法。

## 现有CPT分类与修改后的SBTn图表

早期荷兰图表使用机械锥的qc与fs，Douglas和Olsen（1981）首先用qc和摩阻比Rf = fs/qc（%）制图，Robertson等（1986）和Robertson（1990, 2009）的图表最流行。这些图表预测的是SBT，因为锥体响应的是力学行为而非颗粒特征。Robertson（1990）归一化SBTn方法使用以下参数：Qt = (qt − σvo)/σ′vo，Fr = [fs/(qt − σvo)]×100%，Bq = (u2 − u0)/(qt − σvo) = Δu/(qt − σvo)。其中qt = qc + u2(1 − a)，a为锥面积比（约0.8），σvo为原位总垂直应力，σ′vo为有效垂直应力，u2为锥后孔压，u0为静水孔压。作者建议Qt–Fr图更可靠，因u2易因饱和失效而重复性差。Jefferies和Davies（1993）引入土体行为类型指数Ic表示SBTn区域，Robertson和Wride（1998）修正为：Ic = [(3.47 − log Qt)² + (log Fr + 1.22)²]^0.5。Ic = 2.6曾作为砂状/黏状的近似边界，但只对年轻无微结构、正常固结的硅质土有效。

Robertson（2009）用可变应力指数更新了归一化锥尖阻力：Qtn = [(qt − σv)/pa](pa/σ′vo)^n，其中pa为大气参考压力，n = 0.381(Ic) + 0.05(σ′vo/pa) − 0.15，且n ≤ 1.0。作者指出Qtn与Qt的最大差异出现在浅层粗粒土。Schneider等（2008）提出基于Qt–U2（U2 = Δu2/σ′vo）的孔压图，主要适用于黏状土，用于区分排水、不排水或部分排水状态。

作者提出用归一化小应变刚度指标识别微结构。Eslaamizaad和Robertson（1996）与Schnaid（2009）建议通过Go/qt与Qtn的关系识别，因龄期与胶结对Go的提升远大于对qt的提升。Schneider和Moss（2011）定义KG = (Go/qt)(Qtn)^0.75，其中Go = ρ(Vs)²，ρ = γ/g。Robertson（2015）认为KG本质上是归一化刚度指标。Robertson（2009）将其扩展到细粒土：IG = Go/qn，其中qn = qt − σv。相应地修改为K*G = (Go/qn)(Qtn)^0.75。Schneider和Moss（2011）显示大多数年轻未胶结硅质砂100 < KG < 330，平均值约215。作者建议K*G < 330为年轻未胶结土（理想土，传统经验关系适用），K*G > 330为结构土（传统经验关系可靠性下降）。计算K*G存在尺度效应：CPT测量间隔10–50 mm，而Vs间隔500–1000 mm，需将qn在Vs测量间隔内平均。各向异性也有影响，建议使用SCPT测得的GoVH。

作者进一步提出剪缩−剪胀（CD）边界：CD = 70 = (Qtn − 11)(1 + 0.06 Fr)¹⁷，CD > 70为剪胀；下界CD = 60 = (Qtn − 9.5)(1 + 0.06 Fr)¹⁷。此边界只适用理想土。作者还提出修改的土体行为类型指数IB = 100(Qtn + 10)/(Qtn Fr + 70)，IB = 32为砂状土下界，IB = 22为黏状土上界（对应PI约18%），22 < IB < 32为过渡土。敏感性估计：St = 7.1/Fr，Fr < 2%对应St > 3～4。作者还提出Qtn–U2图用于识别微结构：Qtn > ~12且U2 > 4预示显著微结构且大应变下呈剪缩；结构土在两图上分类不同可作为识别依据。

## 案例验证

作者用多个已发表SCPTu场地数据验证三个图表。无微结构土中：KIDD场地（Fraser River三角洲，全新世）上部4–22.7 m中密细砂（平均K*G = 214）落在砂状剪胀区，下部22.9–40 m灵敏海相黏土平均K*G = 215落在黏状剪缩灵敏区；旧金山湾Young Bay Mud平均K*G ≈ 85、Old Bay Clay约300，均与地质龄期相符；Bothkennar（英国，有机黏土）K*G约240，数据落在CC和CCS区；Holmen（挪威，松砂）K*G约155，落在砂状剪缩区；Madingley（英国，Gault黏土，白垩纪，OCR > 10）平均K*G = 360，落在黏状剪胀区但接近砂区因U2为负值，K*G接近理想土边界。

显著微结构土中：Cooper Marl（Charleston，南卡，钙质胶结黏土，Eocene–Oligocene）22–50 m平均K*G = 580，数据在Qtn–Fr图上落在过渡剪缩区而Qtn–U2图落在黏状剪缩区，高K*G和高U2指示胶结破坏后大应变剪缩；Piedmont残积土（Atlanta，佐治亚）平均K*G = 520，孔压接近−100 kPa，t50 = 20–100 s指示部分排水；洛杉矶市中心粉砂岩（Fernando组，上新世）平均K*G = 635，Qtn–Fr图落在砂状剪胀区而Qtn–U2图落在黏状剪缩区（U2 = 18–40），两图差异正表明胶结的存在；Tangier（摩洛哥）水力填筑钙质砂（碳酸盐含量75–95%）平均K*G ≈ 380，因CaCO₃颗粒高压缩性产生小Fr（< 0.3%）但高小应变刚度。作者还提出SCF = (K*G/215)^1.334估计钙质砂的等效硅砂修正系数，对Tangier数据得SCF = 2.1，与Debats等（2015）的平均值约2.0接近。

## 讨论与结论

作者总结：K*G < 330的无微结构土中，修改后的Qtn–Fr和Qtn–U2图能良好分类；K*G > 330的结构土中，分类可靠性下降，此时Qtn–U2图更能反映大应变行为。消散试验t50 > 50 s（对于1000 mm²锥，20 mm/s）指示基本不排水贯入。归一化参数对σvo和u0在软细粒土中较敏感，应警惕数据落在图表限制外（如Qtn < 1或Bq > 1.2）提示应力估计不确定。作者建议分类最好用4个测量（qc、fs、u2和Vs），以识别微结构；仅用2个测量（qc、fs）时应限于硅质、年轻、未胶结土。推荐采用SCPT的Vs数据，利用Qtn–IG图评估微结构。结论强调：地质背景始终是正确分类的起点，Qtn–Fr基本图表对年轻未胶结硅质土一般可靠，但对K*G > 330的结构土需场地或地质特定修正。

文中公式汇总：Qt = (qt – σvo)/σ'vo；Fr = [(fs/(qt – σvo)]×100%；Bq = (u2 – u0)/(qt – σvo) = ∆u/(qt – σvo)；Ic = [(3.47 – log Qt)² + (log Fr + 1.22)²]^0.5；Qtn = [(qt – σv)/pa](pa/σ'vo)^n；n = 0.381(Ic) + 0.05(σ'vo/pa) – 0.15（n ≤ 1.0）；KG = (Go/qt)(Qtn)^0.75；Go = ρ(Vs)²；IG = Go/qn；K*G = (Go/qn)(Qtn)^0.75；CD = 70 = (Qtn – 11)(1 + 0.06 Fr)¹⁷；CD(下界) = 60 = (Qtn – 9.5)(1 + 0.06 Fr)¹⁷；IB = 100(Qtn + 10)/(Qtn Fr + 70)；St = 7.1/Fr；SCF = (K*G/215)^1.334。
