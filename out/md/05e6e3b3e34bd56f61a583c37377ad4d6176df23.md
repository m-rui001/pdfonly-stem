# 四声子散射显著降低固体的本征热导率

*Four-phonon scattering significantly reduces intrinsic thermal conductivity of solids* · Tianli Feng, Lucas Lindsay, Xiulin Ruan · 2017 · DOI: https://doi.org/10.1103/physrevb.96.161201

数十年来，三声子散射过程一直被认为是决定固体热输运的主导机制，而更高阶的四声子散射的作用始终不清楚，因而被忽略。然而，近期对三声子散射的定量计算常常显著高估热导率，与实验值不符。本文表明，四声子散射在固体中普遍重要，并能弥补这一偏差。对硅和金刚石，计入四声子散射后，1,000 K 时预测热导率降低 30%，与测量值高度吻合。对于被预测为超高导热材料的闪锌矿结构 BAs（金刚石作为散热材料的竞争者），由于三声子过程的可散射相空间极为有限，四声子散射异常强：室温下预测热导率从 2,200 W/m-K 降至 1,400 W/m-K，1,000 K 时降幅达 60%。研究还发现光学声子散射率受到显著影响，这对诸如电子激发平衡中的声子瓶颈等应用很重要。鉴于四声子散射计算代价高昂，文章最后基于能量面非谐性和散射相空间，给出了如何快速判断是否需要考虑四声子散射的准则。该工作澄清了数十年来关于高阶散射重要性的基本问题，并指出了改进热电、热障涂层和辐射传热的新途径。

## 背景与问题

声子是量子化晶格振动的准粒子，通过散射事件相互作用，其中最重要的过程被称为三声子过程。近期基于密度泛函理论的热导率（κ）计算，尽管只考虑三声子相互作用的最低阶微扰本征散射，却在多种体系中与测量 κ 值高度吻合，并对热过程做出了引人注目的预测。然而，数十年来一个持续存在的根本问题是：四声子和更高阶散射的影响是什么？由于缺乏形式理论和计算能力，四声子散射在此前研究中一直被忽略。这一问题变得尤为相关，因为第一性原理方法已高估了多种材料的测量热导率。例如，一些预测在低温下与测量数据精度合理，但在更高温度下显著高估，削弱了对热障涂层和高温热电等应用的预测能力。此外，对某些技术重要材料如 c-BN 和 SnSe，即使在室温下偏差也可能相当大。作为热管理应用的例子，Lindsay 等人预测闪锌矿结构硼砷化物（BAs）在室温下热导率约为 2,200 W/m-K，高于已知最佳导热体金刚石，这可能为被动冷却和其他热管理应用开辟新机会。BAs 体系已被合成，但测量热导率仅达到约 200 W/m-K。外来缺陷和晶界是这一差异的可能原因，或者更高阶本征散射可能在决定该材料 κ 上限中变得显著。

四声子散射的预测已被追求很长时间。近期，四声子散射的形式理论已被发展。然而其中的非谐力常数来自经典力场，因此结果只是定性的，无法与实验验证。本文首次完全从第一性原理计算四声子散射率，并考察其对 BAs、Si 和金刚石热导率及光学声子寿命的影响。我们证明四声子散射阻力能显著降低它们预测的热导率和光学声子寿命，表明四声子散射在固体中的普遍影响。

## 方法与计算

本征声子散射由晶格非谐性引起。从微扰论看，最低阶非谐耦合涉及三个声子：一个声子可分裂为两个声子，或两个声子可结合产生一个新声子（图 1a）。除这些散射外，二阶非谐性产生图 1b 所示的四声子过程。每个声子模式的三声子和四声子散射率通过累加涉及该模式的所有可能散射事件概率得到。每个跃迁概率由密度泛函理论的费米黄金规则计算。计算成本非常高，但可按我们早期工作所述加以缓解。详见补充信息中的方法与计算挑战部分。

我们获得了 BAs、Si 和金刚石在 10 至 1,300 K 范围内、由 16×16×16 q 网格离散的第一布里渊区中 24,576 个（870 个不可约）声子模式各自的散射率。300 K 和 1,000 K 下散射率随声子频率变化的结果见图 2a–f，插图显示低频行为。与四声子散射可忽略的普遍观念相反，我们发现对许多频率，四声子散射与低阶三声子散射相当甚至强得多，如图中蓝色椭圆所示。

最令人惊讶的是，BAs 中的四声子散射相当强（图 2a）。这与微扰论的一般观念相悖，后者认为四声子散射强度由哈密顿量高阶项的大小驱动，而 BAs 中这些项很小。BAs 中强四声子散射的起源见图 3a。如文献 [3] 所示，三声子过程的数量部分受大的声学-光学（a-o）能隙限制，该能隙阻止两个声学声子结合成一个光学声子以及逆过程，因为两个声学声子的能量之和无法达到光学声子的能量。这与紧密聚集的声学支一起，导致 BAs 中三声子散射弱和预测的超高热导率。进一步证据可见图 2a 中约 21 THz 处，三声子散射率有一个深谷。这些声子是 Γ 点附近的光学模式，能量高、动量小，很难找到同时满足能量守恒和动量守恒的两个其他声子模式。然而，如此大的 a-o 能隙并不禁止声学与光学声子之间的四声子过程。例如，在约 21 THz 处，可能的三声子散射构型数小于 20，而四声子过程数约为 10^7~10^8。对这些四声子过程，94% 是 q+q1→q2+q3，6% 是 q→q1+q2+q3。因此，三声子图像严重高估了光学声子弛豫时间。计入四声子项后，室温下弛豫时间从 10^4 ps 降至 40 ps，见补充图 S1。由于 Γ 点附近这些光学声子对与电子和光子的相互作用（如激光加热和红外光学性质）至关重要，三声子散射预测的长寿命是误导性的，而四声子散射是关键且应被纳入。

当温度升至 1,000 K，BAs 的四声子散射变得更加重要，尤其是对更高频率的声子，如图 2b 中蓝色椭圆所示。随温度和频率的变化见图 3b 和 c，由此我们确定四声子散射的标度律 τ4^-1 ∼ T^2 ω^4。与三声子散射相比，四声子散射在更高温度和更高能量声子下更重要，因为声子布居随温度增加，相空间随声子能量（频率）增加。由于其简单性，标度律在热纳米工程中也非常重要。例如，三声子散射的幂律 τ3^-1 ∼ T ω^2 和声子-缺陷散射 τd^-1 ∼ ω^4 已被广泛用于理解先进热电材料中的实验热导率。

在另外两种无声子带隙的材料 Si 和金刚石中，四声子散射不如 BAs 中强，但肯定不可忽略。300 K 时，对大多数声学声子，τ4^-1 远低于 τ3^-1。这符合微扰论的一般观念，因为 Si 和金刚石的非谐性（哈密顿量高阶项）小。然而，蓝色椭圆标记的光学模式仍有大的四声子散射率，这可能解释为何仅考虑三声子散射计算的红外光学线宽比实验窄。当 T 升至 1,000 K，低频声子的四声子散射率仍不显著，但更高能量的纵声学（LA）模式和所有光学模式表现出大的 τ4^-1，与 τ3^-1 相当。热输运 LA 声子的大 τ4^-1 将对这些材料的热导率产生实质影响。在所有材料中，我们注意到三声子和四声子散射的低频极限都遵守由平移不变性导致的 lim_{ω→0} τ^-1 = 0 定律，表明我们四声子计算的准确性。与 BAs 相同，金刚石和硅的幂律拟合给出 τ4^-1 ∼ ω^4，见补充图 S2。

我们还通过使用混合三声子相互作用的迭代方案精确求解声子玻尔兹曼输运方程（BTE），计算了超出弛豫时间近似（RTA）的 κ。本文中，由于计算成本高，四声子散射率仅在 RTA 水平计算，并插入到由三声子过程混合决定非平衡声子分布的迭代方案中。这类似于在完整 BTE 解中采用声子-同位素和声子-边界散射项。我们将表明这种近似可能有效，因为四声子散射由 Umklapp 过程主导。在这些天然存在材料的 κ 计算中，我们还纳入了声子-同位素散射。

## 结果与讨论

天然存在材料的热导率 κ 见图 4b。对金刚石和 Si，三声子预测在低温下与测量数据吻合良好（Si < 600 K，金刚石 < 900 K），但在高温下与实验出现显著偏差。例如，1,000 K 时仅三声子散射就将金刚石和硅的 κ 分别高估 31% 和 26%（相对于实验值）。计入四声子散射后，我们发现预测热导率在整个温度范围内与测量值吻合良好。这种降低对需要低热导率的热电和热障涂层有利。对天然存在的 BAs，即使在室温下，计入四声子散射后热导率也显著降低，从 2241 W/m-K 降至 1417 W/m-K。当温度升至 1,000 K，降幅增至超过 60%。尽管如此，BAs 的室温本征热导率仍属已知材料中最高之列，远高于普通金属。此外，仅考虑三声子散射时高温下著名的温度标度 κ ∼ 1/T，在加入四声子散射后可修正为 κ ∼ 1/(AT+BT^2)。

这里我们讨论关于四声子散射过程的重要物理细节。更多计算细节见补充信息，即展宽因子、q 网格、原子间截断半径、平移不变性、力常数截断以及 Normal 和 Umklapp 过程的作用。

相空间。对特定模式，散射相空间是找到满足能量和动量守恒（或 Umklapp 过程中相差 R）的三声子或四声子过程的可能方式。四声子散射尽管在微扰论中阶数更高、每个散射构型的散射概率远低于三声子过程，却能提供显著热阻。原因在于四声子散射允许的巨大相空间。本文考察材料使用 16×16×16 q 网格时，四声子过程可能的散射构型数在 10^7–10^8 量级，比相同网格密度下三声子构型数多 4–5 个数量级。

估计四声子散射的重要性。如上所述，四声子散射在所有材料中随温度升高而日益重要；然而，仔细考察本文三种材料后，一个自然的问题是：四声子散射在其他固体中一般有多重要？与三声子散射一样，四声子散射由两个因素支配：能量面的非谐性和散射相空间。我们注意到三声子和四声子散射率的构建都不简单，各自是矩阵元、本征矢和频率结合各种声子模式的复杂相互作用。然而，基于声子散射形式理论，我们尝试估计四阶非谐性的相对重要性。Yue 等人通过评估哈密顿量中的四阶项做了一些估计。粗略地说，第 n 阶声子散射率正比于 τn^-1 ∼ |Vn|^2 · f^{n-2} / ω^{n+1}，其中 Vn 是第 n 阶跃迁矩阵元 ∼ Φn / m^{n/2}。Φn 是第 n 阶力常数，m 是平均原子质量，f 是玻色-爱因斯坦分布，高温下近似为 ∼ kB T / ħω。将频率近似为 ω ∼ √(Φ2/m)，我们得到 τn^-1 ∼ |Φn|^2 · √m / |Φ2|^{n-1/2}。因此，第 n 阶非谐性相对于三阶非谐性的重要性粗略估计为 τn^-1 / τ3^-1 ∼ |Φn/Φ3|^2 / |Φ2|^{n-3}。注意这捕捉了高阶散射随温度增加而日益重要，且只需单次计算势能的二阶、三阶和更高阶导数。

表 I 给出了本文研究材料以及低热导率闪锌矿材料 CuCl（室温约 1 W/m-K）的四阶非谐性相对强度 |Φ4/Φ3|^2 / |Φ2|。注意温度依赖性被省略。这一简化形式旨在粗略估计何时高阶散射在一种材料中比另一种更重要。如表所示，预测四阶非谐性在 CuCl 中比本文考虑的高热导率材料中显著更重要。我们此前基于原子间势的工作直接证明了四声子散射与非谐性之间的正相关。在软材料中，如热电和热障涂层应用感兴趣的材料，原子可显著偏离平衡以采样更高非谐性，其哈密顿量中的四阶项可能相当大。注意 |Φ4/Φ3|^2 / |Φ2| 在 Si 中高于金刚石；Si 的四阶散射也相对更重要。

然而，这一简单形式未考虑三声子和四声子散射过程的相空间。因此，尽管如表 I 所示预测 BAs 中四阶非谐性相对不重要，BAs 热导率仍被四声子散射阻力显著降低（图 4）。在三声子散射因色散特征（如声子带隙、声学聚集）而弱的材料中，相空间减小，我们预期四声子散射也重要，例如在 BSb 和 BeSe 中。

总之，我们严格地从完全第一性原理方法计算了四声子散射率和热阻。由于可能的散射构型数量巨大，四声子过程在决定本征声子输运中起重要作用。我们发现四声子散射在闪锌矿 BAs 中异常强，即使室温下也将其热导率从约 2,200 显著降至约 1,400 W/m-K（与先前计算相比）。室温光学声子寿命从 10^4 降至 40 ps。这些影响随温度升高而大幅增加。BAs 中如此强的四声子散射源于其声子色散特性结合基本守恒条件导致的三声子散射弱。这些条件对四声子过程的可用散射限制不那么严格。计入四声子散射后，硅和金刚石的预测热导率在高温下降低约 30%，并使预测在整个考虑温度范围内与测量数据一致。基于我们对四声子过程对热输运和光学模式寿命普遍且显著影响的发现，我们预期未来这些性质的预测将纳入这一重要散射机制，尤其是在考虑能量传递、转换和存储应用工程材料时。
