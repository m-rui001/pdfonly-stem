# 水泥混合体系中辅助胶凝材料的反应性

## 研究背景与问题

辅助胶凝材料（SCMs）是可持续低碳水泥的关键组分。水泥生产占人为CO₂排放的6–8%，其中约60%来自石灰石脱碳，40%来自燃料和电力。用SCMs部分替代CO₂密集的波特兰熟料，可在不显著牺牲强度、耐久性和成本的前提下减少30–40%的CO₂排放。然而，粉煤灰等传统副产SCMs的供应因燃煤电厂逐步淘汰而减少，亟需开发与粉煤灰、矿渣相当或更优的新型SCMs。石灰石和黏土因全球储量丰富而备受关注，石灰石与富铝硅酸盐SCM（如煅烧黏土）组合的三元体系成为研究热点。

本文综述了过去4–5年关于SCMs反应性及其对波特兰熟料水化影响的研究进展，聚焦于中性和碱性条件下SCM溶解与反应的机理描述，重点关注影响SCM反应性的物理和化学参数。

## SCM反应机理

SCMs通过两种方式影响混合水泥水化：一是物理“填充效应”，即惰性细粉也具备的作用；二是参与化学反应形成水化产物。化学反应遵循溶解-沉淀机制，涉及固体反应物、固体水化产物和孔隙溶液三个主要组分。若反应消耗Ca(OH)₂，称为“火山灰反应”；若不需Ca(OH)₂或Ca(OH)₂仅用于pH激活，则称为“水硬性”或“潜在水硬性”反应。

SCMs的火山灰和水硬性反应产生有限范围的（亚）稳定水化物。热力学模型和数据库能较准确预测水化物类型、比例及组成变化。孔隙溶液既是反应介质又是反应物，其组成反映溶解源项与沉淀汇项之间的平衡。反应发生的条件是溶液对反应物不饱和、对水化产物过饱和，反应物与产物溶解度差异越大，驱动力越大。

常见SCM反应式如下：硅质火山灰SCM（如硅灰S）生成C-S-H：

$$\mathrm{S} + 1.7\mathrm{CH} + 2.3\mathrm{H} \rightarrow \mathrm{C}_{1.7}\mathrm{SH}_4$$

铝硅酸盐SCM（如偏高岭土AS₂）在石膏存在时生成单硫铝酸盐：

$$\mathrm{AS}_2 + 6.4\mathrm{CH} + \mathrm{C}\bar{\mathrm{S}} + 13.6\mathrm{H} \rightarrow 2\mathrm{C}_{1.7}\mathrm{SH}_4 + \mathrm{C}_4\mathrm{A}\bar{\mathrm{S}}\mathrm{H}_{12}$$

碳酸钙存在时生成碳铝酸盐并析出钙矾石：

$$\mathrm{AS}_2 + 6.4\mathrm{CH} + 0.5\mathrm{C}\bar{\mathrm{C}} + 1.5\mathrm{C}\bar{\mathrm{S}} + 23.1\mathrm{H} \rightarrow 2\mathrm{C}_{1.7}\mathrm{SH}_4 + 0.5\mathrm{C}_4\mathrm{A}\bar{\mathrm{C}}\mathrm{H}_{11} + 0.5\mathrm{C}_6\mathrm{A}\bar{\mathrm{S}}_3\mathrm{H}_{32}$$

比较后两式可见，富铝SCM与石灰石联用可结合更多水进入固相，这是石灰石-粉煤灰、石灰石-矿渣、石灰石-煅烧黏土等三元体系的基础。矿渣含镁铝时还生成水滑石。作为潜在水硬性SCM，矿渣消耗较少Ca(OH)₂，可在Ca(OH)₂耗尽前达到更高反应程度。Ca(OH)₂耗尽后，pH降低、C-S-H的Ca/Si比下降，富铝SCM体系中生成钙铝黄长石（C₂ASH₈）。

限制SCM反应完全进行的机制尚未完全解决，但共识是热力学和动力学壁垒共同作用。水可用性方面，C₃S水化在70–80% RH停止，C₂S需要更高湿度。水活度也取决于溶液离子强度，pH≤14时接近1，但NaOH浓度≥2 M时水活度下降。空间可用性方面，水化产物填充孔隙使孔径细化，水化物生长受限于临界尺寸。Ostwald-Freundlich方程描述驱动力与晶体尺寸的关系：

$$\Delta G = RT\ln\left(\frac{K}{K_{sp}}\right) = \gamma_{cl}v_m\left(\frac{dA}{dV}\right)$$

Berodier和Scrivener发现矿渣/粉煤灰-石英-OPC体系中，后期SCM反应受限于缺乏充水毛细孔，临界孔径为6–8 nm。Avet和Scrivener在50%替代的OPC-煅烧黏土-石灰石体系中发现，碳铝酸盐水化物形成受限于临界孔径，此时铝更多进入C-(A)-S-H。

## 影响SCM反应性的性质

SCM性质可分为本征性质（组成、比表面积）和外部体系性质（温度、溶液组成）。

物理性质方面，细度影响反应动力学：比表面积增大提高溶解速率，并增加水化物成核位点。纳米二氧化硅和纳米氧化铝可促进早期强度，但存在分散困难和水需求增加问题。填充效应通过降低有效水灰比增加水化产物形成空间。孔隙溶液pH对SCM溶解动力学有重要影响，碱度在水化早期增加。玻璃碎屑研究表明，最细组分（0–25 μm）在pH≥12.5时铝和硅溶解显著增加，Si和Al含量与表面积近似线性关系。浮石研究表明细颗粒增强成核生长，提高早期强度但后期差异消失。单粒径SCM研究表明，SCM对强度的贡献可分为固有特性效应、颗粒细化效应和水化效应，后两者随粒径减小而增加，均与D₅₀呈指数关系。

化学参数方面，SCMs的反应组分通常为玻璃态或非晶相。粉煤灰和矿渣的主要反应相分别为铝硅酸盐和钙铝硅酸盐玻璃。玻璃网络由SiO₄和AlO₄四面体通过桥氧连接，Ca²⁺等作为电荷补偿或网络修饰离子，后者产生非桥氧（NBO）。聚合度常用(CaO+MgO)/SiO₂比或NBO/T表示，聚合度越低反应性越高。

Durdzinski等用SEM-EDS识别出粉煤灰中四种玻璃相，合成模型玻璃在NaOH（pH=13.2）和水泥浆中的溶解速率与NBO/T呈近线性增加。Aughenbaugh等发现不同粉煤灰的玻璃相组成相似，但需注意排除惰性相。Kucharczyk等用²⁷Al和²⁹Si MAS NMR研究CAS玻璃，发现矿渣和富钙粉煤灰中>90%的Al为四配位（网络形成体），反应速率随钙含量增加而提高，铝含量影响较小。提高CaO含量可增强铁硅酸盐渣和不锈钢渣的反应性，高冷却速率有利于保持高活性晶相（如β-C₂S而非γ-C₂S）。

矿物和玻璃溶解动力学方面，驱动力ΔG为溶液浓度与溶解度积之间的不平衡。过渡态理论（TST）给出线性速率方程：

$$r = k_+\Pi(a_j)^{m_j}(1-\exp(-\Delta G/RT))$$

但许多矿物呈S形溶解行为。碱性条件下速率方程为：

$$r = k_{OH}a_{OH}^m(1-\exp(-\Delta G/RT))$$

Oelkers和Schott提出多氧化物硅酸盐的通用速率方程：

$$r = k\prod_{i=1,i\neq k}^{i}\left[\frac{K_i\left(\frac{a_{H^+}^{v_i}}{a_{M_i}^{v_i}}\right)^s}{\left(1+K_i\left(\frac{a_{H^+}^{v_i}}{a_{M_i}^{v_i}}\right)^s\right)}\right]$$

温度依赖性由Arrhenius方程描述：

$$k(T) = k(T_0)e^{-(E_a/RT)}$$

硅酸盐相界面溶解活化能为50–100 kJ/mol。溶解速率随桥氧数减少而增加，相同连接度下与电荷补偿阳离子的水交换速率一致。

Snellings在pH=13下研究CAS玻璃溶解，发现BFS玻璃溶解速率最高，随Ca含量降低而降低，log溶解速率与Ca/(Al+Si)比呈线性关系。增加Al或Ca浓度降低溶解速率，Si无影响。Schöler等发现富钙渣溶解最快，硅质粉煤灰最慢，Al₂O₃增加也促进溶解，初始溶解速率与NBO/T呈线性关系。Maraghechi等测得钠钙玻璃活化能，Snellings等测得GGBFS为55 kJ/mol，粉煤灰86、钠钙玻璃88、天然火山灰95 kJ/mol。

早期溶解和表面结构方面，Newlands等发现中性pH下Ca优先释放，高pH下元素释放一致。XPS显示BFS玻璃表面形成富Si/Al层，ToF-SIMS显示Ca表面富集。提出了中性/碱性条件下玻璃溶解模型：中性pH下形成富Si改性层，Ca²⁺和铝酸盐再吸附；碱性条件下网络水解和离子交换同时进行，可能形成低Ca/Si C-(A)-S-H钝化层。Snellings通过pH滴定和zeta电位发现低pH（<9）下质子-金属交换主导，高pH下硅溶解更显著。水化物沉淀可消耗网络形成元素（Al、Si），加速溶解。

## SCM对混合水泥水化的影响

评估SCM反应性方面，R³测试在40°C下用含碱和硫酸盐的Ca(OH)₂溶液模拟混合水泥环境，通过等温量热或结合水测定跟踪反应，与28天抗压强度相关。PONKCS分析、SEM-BSE-EDS和固体NMR可用于量化非晶SCM反应程度。

早期水化方面，Berodier和Scrivener发现水化物在石英和水泥颗粒表面类似生长，颗粒间距是关键参数，加速效应主要是混合时颗粒间剪切作用。石灰石因表面有利于C-S-H成核而加速水化。Ouyang等发现石灰石表面对Ca²⁺亲和力强，促进稳定晶核形成。硅灰和偏高岭土对C₃S早期水化的影响研究表明，铝酸盐离子通过内层表面络合抑制C₃S溶解和C-S-H生长。Schöler等发现早期水化动力学主要受阿利特不饱和程度驱动，粉煤灰早期溶解增加铝酸盐浓度延缓水化，但受硫酸盐浓度影响。

后期水化方面，SCM反应程度增加使C-(A)-S-H的Ca/Si比降低、Al/Si比增加，形貌从纤维状变为箔状。热力学模型（如GEMS）可预测相组合。波特兰水泥-硅灰体系中，Ca(OH)₂耗尽后C-(A)-S-H量恒定但Ca/Si比下降。波特兰水泥-偏高岭土体系中，Ca(OH)₂耗尽后生成钙铝黄长石，²⁷Al NMR证实>15 wt%偏高岭土时出现。OPC-偏高岭土（>20 wt%）中观察到Ca(OH)₂与钙铝黄长石共存，归因于致密C-S-H基质导致的局部平衡。Zajac和Ben Haha通过粉煤灰溶解-pH关系估算反应程度，模型与XRD和抗压强度吻合。

**煅烧黏土作为SCM**
煅烧黏土因储量丰富、成本低而受关注。黏土矿物由四面体（T）和八面体（O）片层组成，分为1:1（TO）、2:1（TOT）或混合层型。最常见为高岭石（1:1）和蒙脱石（2:1）。热活化温度通常为500–800°C，低于玻璃形成温度。热处理序列为：脱水→脱羟基→层坍塌形成非晶结构→更高温度重结晶或玻璃化。

高岭石热处理生成偏高岭石（Si₂Al₂O₇），在约450–850°C稳定。DFT研究表明八个羟基氢中有一个保留以防止层完全坍塌。850–1100°C转变为莫来石和非晶二氧化硅。偏高岭土含四、五、六配位铝和多种Qⁿ(mAl)硅环境。HF溶解和NMR表明第二配位层含Al的Si位点最活泼。

2:1黏土（如蒙脱石）热处理不形成亚稳相，²⁹Si NMR显示500–1000°C连续变化，800–1000°C无序度最高，1000°C以上结晶。反应性实验显示最佳煅烧温度为750–850°C，反应程度与C-(A)-S-H的Al/Si比相关。

不同黏土矿物反应性研究表明，偏高岭土反应性最高且对煅烧温度不敏感，归因于铝酸盐和硅酸盐溶解速率较高。反应性顺序为：高岭石质黏土>Ca-蒙脱石>Na-蒙脱石>伊利石>锂皂石。天然黏土中偏高岭土含量是主要驱动因素，Avet等发现抗压强度与煅烧高岭石含量近线性增加，>40%偏高岭土时30%和50%替代的强度与纯波特兰水泥相当。

石灰石-煅烧黏土-波特兰水泥三元体系（LC³）在煅烧黏土:石灰石≈2:1、替代30–50 wt%时产生协同效应。CaCO₃与铝酸盐反应生成半碳铝酸盐和单碳铝酸盐，稳定钙矾石，降低孔隙率。最佳MK/(MK+LS)比为0.6–0.75，对应Ca(OH)₂几乎耗尽但钙铝黄长石尚未形成的状态。

**结论**
过去几年在理解SCM反应、结构和组成方面取得显著进展，特别是粉煤灰和矿渣等以玻璃相为主的SCM。钙铝硅酸盐玻璃作为模型化合物有助于揭示控制SCM反应的机制和参数。溶解实验提供了中性和碱性环境下主要元素溶解动力学及玻璃颗粒表面结构和组成的新认识。早期水化驱动力主要是pH、水活度和孔隙溶液组成，钙和铝可能抑制熟料和SCM表面活性组分的溶解。后期水化中，Ca(OH)₂、水和空间可用性对水化动力学和反应程度有决定性影响，孔隙细化和临界半径以上毛细孔的缺失影响SCM替代水平。热力学模型取得显著进展，但仍需更多关于结构、溶解和动力学的实验数据。煅烧黏土的热活化相结构和溶解性质的基础知识仍较缺乏。原子尺度模拟工具在SCM溶解和水化物生长研究中的应用尚少，预计结合先进显微分析工具将做出重要贡献。
