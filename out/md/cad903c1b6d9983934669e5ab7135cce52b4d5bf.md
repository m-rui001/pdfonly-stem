# 3D/2D 钙钛矿双层堆叠的确定性制备：兼具耐久性与高效率的太阳能电池

**英文原题：** Deterministic fabrication of 3D/2D perovskite bilayer stacks for durable and efficient solar cells · **年份：** 2022 · **DOI：** https://doi.org/10.1126/science.abq7652

本文报道了一种基于溶剂介电常数（εr）和 Gutmann 供体数（DN）的溶剂设计原则，用于在 3D 钙钛矿薄膜上溶液法生长相纯的 2D 钙钛矿双层结构。该方法避免了溶剂对底层 3D 钙钛矿的溶解破坏，实现了对 2D 层厚度、相纯度和能带结构的精确控制。所制备的 3D/PP-2D 双层太阳能电池获得了 24.5% 的光电转换效率（PCE）和 1.2 V 的开路电压（VOC），并在 ISOS-L-1 协议下表现出 T99 > 2000 小时的运行稳定性，表明双层结构同时继承了 2D 钙钛矿的固有耐久性和 3D 钙钛矿的高效率。

## 溶剂设计原则

溶液法构建 3D/2D 钙钛矿异质结的长期挑战在于加工溶剂会破坏底层 3D 钙钛矿。作者提出，溶剂能否选择性溶解 2D 钙钛矿而不破坏 3D 钙钛矿，取决于两个关键参数：介电常数（εr）和 Gutmann 供体数（DN）。介电常数决定溶剂通过屏蔽离子间库仑吸引来溶解离子化合物的能力；而 Gutmann 供体数描述溶剂的 Lewis 碱性，反映溶剂与阳离子（高 DN 时）或前驱体之间（低 DN 时）配位化合物形成的程度。在含有 MAI、FAI 和 PbI2 的前驱体溶液中，高 DN 溶剂会与 Pb2+ 强烈配位，抑制碘铅配合物（如 [PbI6-x(solvent)x]-(4-x)）的形成。

实验结果显示，极性非质子溶剂（如 DMF、DMSO，εr > 30，DN > 18）完全溶解 3D 和 2D 钙钛矿；而乙腈（MeCN）、四亚甲基砜（TMS）、碳酸丙烯酯（PC）、碳酸乙烯酯（EC）等溶剂虽然介电常数 > 30，但因 DN 值较低（5 < DN < 18 kcal/mol）无法溶解 3D 钙钛矿，却能完全溶解 2D 钙钛矿粉末。对照实验进一步验证了选择性：高 DN 低介电常数的四氢呋喃（DN=20 kcal/mol，εr=7.6）和低 DN 高介电常数的硝基甲烷（NME，DN=2.7 kcal/mol，εr=35.9）均不能溶解 2D 钙钛矿。因此，满足 εr > 30 且 5 < DN < 18 kcal/mol 的溶剂可用于选择性构建 3D/2D 双层结构。

在选定的溶剂中，测试了 RP 相（BA2MAn-1PbnI3n+1，n=1-4）、DJ 相（(4AMP)MAPb2I7）和 ACI 相（(GA)MA2Pb2I7）2D 钙钛矿的溶解度。由于极性高，PC 对 2D RP 相的溶解能力优于 TMS 和 MeCN。RP 相 2D 钙钛矿的溶解度随 n 值增大而降低，从 n=1 的大于 100 mg/ml 降至 n=4 的 30-40 mg/ml，这与无机层分数增加有关。n=2 的 ACI 和 DJ 相溶解度分别为 20-40 mg/ml 和 10-25 mg/ml。综合考虑，MeCN 因沸点低（≈82°C）适用于低温加工，被选为主要制备溶剂，采用旋涂、滴铸、刮涂或狭缝涂布等方法进行制备。

## 双层结构制备与物相表征

在 3D 钙钛矿 Cs5(MA0.10FA0.90)95Pb(I0.90Br0.10)3 上旋涂含 2D 钙钛矿种子溶液的 MeCN 分散液，经 80°C 退火 5 分钟制备双层结构。通过调控浓度和沉积工艺，2D 层厚度可从亚 10 nm 调至亚微米尺度。XRD、吸收光谱和稳态光致发光（PL）表征表明（图 2A-C），2D 层具有高相纯度：吸收光谱呈现出从 2.4 eV（n=1）到 1.9 eV（n=4）的尖锐激子峰，与不同 n 值对应；PL 光谱未观察到底层 3D 钙钛矿带隙变化，说明 2D 层未破坏 3D 结构。共聚焦 PL 成像（图 2D）显示 20 μm × 20 μm 范围内 2D（n=2, 2.15 eV）和 3D（1.6 eV）发射均匀，证实双层堆叠的空间均匀性。该制备方法同样适用于纯 FAPbI3 和 MAPbI3 3D 钙钛矿。

## 界面表征

ToF-SIMS 深度剖析显示（图 3A-B），引入 BA2MAPb2I7 后，BA+（C4H12N+）离子在 50 nm 厚度内均匀分布后急剧下降，拟合得到的界面过渡区宽度为 20 nm。GIWAXS 角度依赖测量（图 3C-D）显示表面存在水平取向的 BA2MAPb2I7 2D 钙钛矿（入射角 ≈0.08°），底层为 3D 钙钛矿（≈0.5°）。依据计算 X 射线穿透深度曲线（临界角 αc = 0.181°，图 3E），在入射角 0.2° 处可分辨 3D/2D 界面；(020) 峰（2D 特征）和 (111)/(001) 峰（3D 特征）的积分面积变化确认 2D 层厚度为 50-60 nm。值得注意的是，n=3（BA2MA2Pb3I10）2D 钙钛矿呈现混合取向，这种织构对高效电荷传输是必要的。截面暗场 HRTEM（图 3G）进一步验证了 3D/2D 界面锐利度为 20 nm，与 ToF-SIMS 测得的控制 3D 薄膜粗糙度相符。

## 器件性能与稳定性

基于第一性原理计算并与光电子产额光谱和吸收测量相互印证，建立了 3D 与不同 n 值 2D 钙钛矿的能级图（图 4A）：n=3 的 2D 钙钛矿与 3D 形成 II 型能带排列，价带近完美对齐，有利于空穴提取而阻挡电子，是理想的空穴传输层；n=1 和 n=2 则形成 I 型排列，对载流子提取构成势垒。

在 n-i-p 结构（FTO|SnO2|3D|PP-2D(n=3)/spiro-OMeTAD|Au）中，2D 层厚度从 0 增加至 50 nm 时，VOC 从 1.09 V 升至 1.2 V，FF 从 0.80 增至 0.84，JSC 从 23.54 mA/cm² 增至 24.34 mA/cm²，在 50 nm 时达到峰值 PCE 24.5%，且无迟滞。继续增加厚度则 PCE 下降，归因于多晶 2D 钙钛矿（n=3，混合取向）的扩散长度 <100 nm 限制了载流子传输。在 p-i-n 结构（ITO|PTAA|3D|PP-2D(n=3)|C60|BCP|Cu）中，仅 5 nm 厚的 2D 层有利于性能提升，更厚则显著降低，这与能带图中 p-i-n 几何对电子收集的大势垒一致。

光学模拟显示 2D 层增强了双层堆叠的光生载流子产生，使 JSC 比 3D 控制器件增加 1.5 mA/cm²，与 EQE 测量一致。自洽输运模拟预测 2D 层减少了 3D/HTL 界面的非辐射复合。表面光电压（SKPM）测量显示 SPV 随 2D 层厚度增加而增大，表明准费米能级分离增强；稳态 PL 和 TRPL 显示载流子寿命在 2D 层厚度达 50 nm 时最长，更厚则下降。这些结果共同解释了 3D/PP-2D 器件中 JSC、VOC 和 FF 的同步提升。

在 ISOS-L-1 协议（环境空气中、1 个太阳连续照射、55°C、环氧封装、最大功率点跟踪）下，图 4E 中使用的控制 3D、3D|2D 钝化、3D|PP-2D 和纯 2D 器件的初始 PCE 分别为 21%、22.93%、23.75% 和 16.3%。3D/PP-2D 双层器件在 2000 小时内无退化（T99 > 2000 小时）；控制 3D 器件损失 25% 初始 PCE；2D 钝化的 3D 器件在 1000 小时后损失 10%；纯 2D 钙钛矿控制器件为 T97 > 1500 小时。这表明 3D/PP-2D 双层结构在不牺牲效率的前提下继承了 2D 钙钛矿的固有稳定性。
