# 受体激酶FER是一种受RALF调控的支架蛋白控制植物免疫信号传导

*原题：The receptor kinase FER is a RALF-regulated scaffold controlling plant immune signaling*


Martin Stegmann, Jacqueline Monaghan, Elwira Smakowska-Luzan, Hanna Rovenich, Anita Lehner, Nicholas Holton, Youssef Belkhadir, Cyril Zipfel · 2017 · DOI: https://doi.org/10.1126/science.aal2541

本文主张：拟南芥 SITE-1 PROTEASE（S1P）切割内源 RAPID ALKALINIZATION FACTOR（RALF）前体肽以抑制植物免疫；该抑制由 malectin-like receptor kinase FERONIA（FER）介导，FER 作为受 RALF 调控的支架，促进免疫受体激酶 EFR 和 FLS2 与其共受体 BAK1 的配体诱导复合物形成，从而启动免疫信号。

植物免疫模式识别受体（PRRs）常为受体激酶。拟南芥受体激酶 FLS2 和 EFR 分别结合细菌 flagellin（或表位 flg22）和 EF-Tu（或表位 elf18/elf24），并与共受体 BAK1 形成配体诱导复合物。为解析 PRR 介导免疫信号的负调控，作者筛选在免疫缺陷背景 bak1-5 中恢复免疫应答的 modifier of bak1-5（mob）突变体，并报道了 MOB6 的特征。bak1-5 在 flg22 或 elf18 处理下 ROS 产生受损；作者基于该应答的恢复鉴定到隐性突变体 bak1-5 mob6。通过将 bak1-5 mob6 与 bak1-5 回交后的 F2 分离群体混池测序，并结合 bak1-5 mob6 与 Col-0 杂交 F2 群体的表型和遗传分析，定位到 At5g19660 编码 subtilase S1P/SBT6.1 的纯合错义突变（P612S）。等位性测试和反式互补实验确认 mob6 表型由 S1P 突变引起，遂将 mob6 更名为 s1p-6。

作者进一步表征 S1P 突变等位基因对免疫信号的影响。s1p-3 和 s1p-6 单突变体在 elf18、flg22 和 chitin 处理下产生更多 ROS，elf18 处理后免疫标记基因 FRK1 和 PHI1 表达升高，且对 hypovirulent 细菌 Pseudomonas syringae pv. tomato（Pto）DC3000 COR− 更抗性。因此 S1P 是免疫的负调控因子。与其人类直系同源物相似，拟南芥 subtilase S1P 加工具有经典切割位点 RxxL/RxLx 的底物。内源肽 RAPID ALKALINISATION FACTOR 23（RALF23；At3g16570）是拟南芥中已确立的 S1P 底物，也是 flg22 调控转录网络的主要枢纽。与 RALF23 在免疫中的潜在作用一致，elf18 处理或接种 III 型分泌缺陷菌株 Pto DC3000 hrcC− 迅速增加前体肽 PRORALF23 的加工，且该加工依赖 S1P。

RALF23 处理导致 elf18 ROS 的剂量依赖性抑制（IC50 ~200 nM），并诱导对 Pto DC3000 的抗性。此外，RALF23 过表达抑制 elf18 触发的 ROS，并增加对 Pto DC3000 COR− 和真菌 Plectosphaerella cucumerina 的敏感性。相反，RALF23 缺失导致 elf18 触发的 ROS 增加和对 Pto DC3000 COR− 的抗性。RALF23 同样抑制 flg22 触发的 ROS。RALF23 处理还抑制 s1p-6 突变体中升高的 elf18 诱导 ROS，提示 S1P 的负调控功能通过加工 RALF23 或相关肽执行。例如，密切相关的 RALF33（At4g15800）肽也能抑制 elf18 诱导的 ROS。作者由此得出结论：RALF23（及 RALF33）负调控免疫。

拟南芥基因组编码约 35 个 RALF 肽，其中仅 11 个（包括 RALF23 和 RALF33）具有 S1P 切割位点。共处理 RALF34（含预测的 S1P 切割位点）对 elf18 诱导 ROS 的抑制程度与 RALF23 和 RALF33 相同，而 RALF32（缺乏预测的 S1P 切割位点）则无此效果，提示被 S1P 切割的 RALF 抑制免疫。RALF23、RALF33 以及更趋异的 RALF32 均触发幼苗生长抑制，类似 RALF1；但 RALF32 不影响 elf18 触发的 ROS。此前测试的所有 RALF 肽均诱导碱化，提示免疫抑制并非 RALF 的普遍特性，且独立于碱化活性；这与 RALF 肽生物测定在缓冲条件下进行一致。

拟南芥 malectin-like 受体激酶 FERONIA（FER；At3g51550）近期被鉴定为 RALF1 的受体。RALF1、RALF23 和 RALF33 密切相关，并与 FER 有重叠的基因表达模式。fer-2 和 fer-4 突变体对 RALF23 或 RALF33 肽抑制 elf18 诱导 ROS 的效果不敏感，而 fer-4/FER-GFP 株系中该表型被互补。此外，fer-2 中 RALF23 过表达对 ROS 无影响。RALF23、RALF33 和 RALF32 触发的生长抑制对 FER 的遗传依赖性提示 FER 可能结合其他 RALF 肽。生物素化 RALF23 结合重组 FER 胞外域（ectoFER），但不结合无关的 EFR 受体胞外域（ectoEFR）。类似地，昆虫细胞表达的 ectoFER 结合生物素-RALF23 但不结合生物素-elf24，通过微量热泳动和等温滴定量热法揭示 Kd 值分别约为 300 nM 和 600–900 nM，与其他配体-受体激酶对的报道值以及 RALF23 介导抑制 elf18 触发 ROS 的 IC50 一致。因此，除 RALF1 外，FER 也是 RALF23 的受体。

flg22 处理后 FER 富集于去垢剂抗性膜。fer-2 和 fer-4 突变体对 elf18、flg22 和 chitin 低敏感，且对 Pto DC3000 COR− 更敏感，表明 FER 也能正调控免疫。FER 与 FLS2 和 BAK1 均弱结合，其中与后者的结合在 flg22 处理后强烈增强。flg22 诱导的 FLS2-BAK1 复合物形成在 fer-4 中减少，在 fer-4/FER-GFP 中恢复。共处理 RALF23 减少配体诱导的 FLS2/EFR-BAK1 复合物形成。RALF23 过表达对 flg22 诱导的 FLS2-BAK1 复合物形成有类似影响。RALF23 或 FER 缺失不影响 FLS2、EFR 或 BAK1 的积累。因此，FLS2/EFR 与其共受体 BAK1 之间的配体诱导复合物形成由 FER 促进、被 RALF23 抑制。

数据提示 FER 作为支架调控免疫受体复合物形成。FER 可能驻留于质膜微区，作为预形成信号“平台”的一部分与受体和共受体一起存在。FER 介导的调控是否与其他 FLS2/EFR-BAK1 复合物形成调控因子（如 BIR2 和 IOS1）交叉，将是未来有趣的研究课题。三分之二的 RALF 蛋白缺乏预测的 S1P 切割位点且没有前肽区域。处理其中一种 RALF17 诱导 ROS 产生，并与 elf18 叠加作用。RALF17 预处理也足以诱导对 Pto DC3000 的抗性。由于 RALF17 诱导的 ROS 产生依赖 FER，该活性并非由实验室使用的合成肽（如 flg22、elf18）可能污染引起。

PRORALF23 在激发子感知后数分钟内被 S1P 加工，提示存在负反馈机制以抑制 FER 的支架功能并减弱免疫信号。真菌病原体分泌与 RALF23 同源的肽；这些真菌 RALF 直系同源物可能通过抑制活性受体复合物的形成来抑制免疫。FER 已成为从受精到抑制细胞伸长和生长等多种生物过程的调控因子。许多过程涉及受体激酶和共受体，提示 FER 可能在其他受体激酶复合物中具有类似的支架功能。FER 和 RALF 基因不同但重叠的表达模式提示，多种 FER-RALF 模块可能在生长、发育或环境感知中调控多样的受体激酶复合物。
