# Privateer：碳水化合物结构构象验证软件

*Privateer: software for the conformational validation of carbohydrate structures* · 2015 · https://doi.org/10.1038/nsmb.3115

碳水化合物在细胞生物学中日益重要，但晶体学精修中糖类结构的质量普遍较差，大量错误结构存在于PDB中。尽管过去十年中出现了如 pdbcare 等命名验证工具，在低于 1.6 Å 分辨率下不恰当的精修协议仍可能将正确糖分子扭曲为极不可能的环构象，甚至引入化学错误。高能构象在自然界很少见，在 N-聚糖中甚至不可能，除非有清晰电子密度支持，否则应视为异常。为此我们开发了 Privateer 软件包，用于检测和预防环状碳水化合物结构的构象异常。软件能识别错误的区域化学和立体化学以及不可能的构象，生成可视化检查清单以便在实空间中快速修正，并确保在后续重建和精修中考虑构象偏好。

## 方法：数据库与构象参考

Privateer 基于 PDB Chemical Component Dictionary（CCD）手工整理了一份受支持单糖数据库。CCD 条目含有由 PDB 在每次新沉积时用 Corina 或 Omega 计算的能量最小化构象坐标。对每种受支持糖，数据库存储由 Cremer-Pople 算法确定的构象，以及立体化学和几何信息，作为验证参考。此外，吡喃糖的 puckering 振幅与环己烷构象自由能面的从头算 metadynamics 模拟结果进行了比较。软件报告对 omit mFo-DFc 电子密度的实空间相关系数作为拟合质量指标，并自动导出偏差最小化图系数，可用于评估糖的鉴定。Privateer 通过 Python 或 Scheme 脚本接口将结果馈入 Coot，自动加载模型和地图，视觉标记问题。

## 验证与修正策略

在较高分辨率（<1.6 Å）下，大多数构象异常通常从一开始就建模错误，可能需要重建（图 1 上方面板）。在较低分辨率下，即使输入模型正确，高能构象也可能因精修参数化不足而出现；只要引入足够限制来平衡参数与观测比，即可在实空间和倒易空间精修中纠正。常用的谐波扭转限制虽然能够施加构象偏好，但同样能被多种构象（如椅式和船式）满足。为强制单一构象，Privateer 生成 CIF 库文件，其中包含直接由最小能量构象计算得到的环键单周期扭转限制。这些文件利用 CCP4SRS 框架生成，兼容所有主流精修软件。此外，Privateer 生成的关键字文件可在 Refmac5 中为扭曲糖开启扭转限制，从而便捷地整合到 PDB_REDO 等再精修流程中。图 1 展示了两个实例：上方面板中，PDB 3QVP 的 MAN 616（链 A）在 1.1 Å 分辨率数据下，因被建模为 β 连接而非期望的 α 连接，被精修软件扭曲为 1 S5 构象，需要重建后才能精修至最小能量构象 4C1；下方面板中，PDB 3D7D 的 NAG 1757（链 A）在部分密度中被 Refmac5 精修至 2,5 B 构象，由于该构象最小化了键长、键角和谐波扭转的偏差，仅限制这些参数无法纠正，而应用 Privateer 产生的单周期扭转限制后得到了期望的 4C1 构象。这两例均表明，在密度较差时，高能构象没有密度支持，应使用期望的最小能量构象。

## 实现与可用性

Privateer 目前由 CCP4 分发。即将推出的 CCP4 7.0 将提供图形用户界面，完全自动化验证、修正和再精修流程，并提供交互式 HTML5/JavaScript 图形报告。本文应视为 Privateer 的主要引用文献。
