# 陆地生物圈是温室气体的净源

**原文题目**: The terrestrial biosphere as a net source of greenhouse gases to the atmosphere (2016) · DOI: https://doi.org/10.1038/nature16946

本研究基于28项自下而上（BU）研究和13项自上而下（TD）大气反演研究，综合核算了1981–2010年间陆地生物圈因人类活动引起的CO₂、CH₄和N₂O通量及其对气候系统的净影响。核心主张是：2001–2010年间，生物源CH₄和N₂O的累计增温效应约为全球陆地CO₂汇冷却效应的两倍，导致三种温室气体对行星能量收支的净累积影响为正（即增温），最佳估计（以GWP100计）为TD方法3.9±3.8 Pg CO₂当量/年、BU方法5.4±4.8 Pg CO₂当量/年。因此，减少农业排放（尤其在东南亚）可能有助于减缓气候变化。

## 方法：双约束核算框架

研究将陆地生物源温室气体通量定义为源于植物、动物和微生物群落的通量，其变化由自然和人为扰动共同驱动。CO₂通量包括人类活动的直接和间接效应（如土地利用、气候变暖、大气CO₂升高、氮沉降），但排除地质过程、化石燃料燃烧和水泥生产的排放。CH₄通量涵盖自然湿地、水稻田、生物质燃烧、粪便管理、反刍动物、白蚁、垃圾填埋和废弃物，以及土壤CH₄吸收。N₂O通量包括农业生态系统（施肥土壤、粪便管理、人类污水、间接排放）、自然生态系统和生物质燃烧的排放。

采用双重约束方法：BU方法包括清单、局部通量测量的统计外推和过程模型模拟；TD方法为大气反演。对每个气体，分别计算十年平均通量及其标准差（标准差为各研究标准差的平方和开根号）。人类活动造成的通量通过从当代估计中扣除工业化前排放获得：CH₄扣除125±14 Tg C yr⁻¹，N₂O扣除7.4±1.3 Tg N yr⁻¹。CO₂通量则调整了河流输运（0.45 Pg C yr⁻¹）和泥炭地排水排放。GWP换算采用IPCC AR5的100年GWP（CH₄为28，N₂O为265）和20年GWP（CH₄为84，N₂O为264）。净生物源温室气体平衡的计算公式为：GHG = F_CO2-C × (44/12) + F_CH4-C × (16/12) × GWP_CH4 + F_N2O-N × (44/28) × GWP_N2O，其中F为年通量（Pg C yr⁻¹或Pg N yr⁻¹）。

## 2000年代全球生物源温室气体收支

2001–2010年（“2000年代”），全球陆地生物源CH₄排放的TD估计为325±39 Tg C yr⁻¹，BU估计为326±43 Tg C yr⁻¹，二者非常接近。自然湿地是最大排放源，占总排放的40%–50%；水稻田约10%；反刍动物约20%；垃圾填埋和废弃物约14%；生物质燃烧约4%–5%；粪便管理约2%；白蚁、野生动物等约6%–10%。全球土壤CH₄汇抵消了约10%的生物源CH₄排放，但该通量约束较差。

全球生物源N₂O排放的TD估计为12.6±0.7 Tg N yr⁻¹，BU估计为15.2±1.0 Tg N yr⁻¹。自然生态系统贡献约55%–60%，农业土壤约25%–30%，生物质燃烧约5%，间接排放约5%，粪便管理约2%，人类污水约2%。

全球陆地CO₂汇在2000年代为TD估计−1.6±0.9 Pg C yr⁻¹，BU估计−1.5±1.2 Pg C yr⁻¹，与近期估计一致。扣除工业化前排放后，人类活动引起的生物源CH₄和N₂O的增温能力（以GWP100计）相当于当前全球陆地CO₂汇的1.7倍（TD）和2.0倍（BU）。因此，三种温室气体对行星能量收支的净累积影响为正，最佳估计为3.9±3.8 Pg CO₂当量/年（TD）和5.4±4.8 Pg CO₂当量/年（BU）。

若改用GWP20指标，2000年代人类活动引起的生物源CH₄排放的辐射强迫是陆地CO₂汇的3.8（TD）或4.2（BU）倍（符号相反），远大于GWP100下的作用（Table 1）。因此，削减CH₄排放是短期内快速降低温室气体辐射强迫的有效途径。

仅考虑农业和废弃物排放（水稻田、粪便管理、反刍动物、垃圾填埋、废弃物，以及作物种植、人类污水和间接排放的N₂O），其累计辐射强迫在2000年代为BU估计7.9±0.5 Pg CO₂当量/年、TD估计8.2±1.0 Pg CO₂当量/年，分别抵消人类活动引起的陆地CO₂汇的1.4倍和1.5倍。这表明农业是造成这种“双重抵消”的最大贡献者。

## 三个十年的变化趋势与区域差异

1980年代至2000年代，人类活动引起的生物源温室气体净源呈下降趋势，速率为2.0 Pg CO₂当量/年每十年（P<0.05），主要原因是CO₂汇增加（TD为2.2、BU为2.0 Pg CO₂当量/年每十年，P<0.05），这由大气CO₂浓度升高、森林恢复和氮沉降共同驱动。热带毁林排放呈下降或稳定趋势，但卫星观测显示巴西毁林减少被其他热带国家增加所抵消。全球总生物源CH₄排放从1980到2010年无显著趋势，但2007年后排放增加导致大气CH₄持续上升。BU估计显示人类活动引起的N₂O排放自1980年以来以0.25 Pg CO₂当量/年每十年的速率增加（P<0.05），主要源于氮沉降、氮肥使用和气候变暖；TD估计在1995–2008年也有类似趋势。

区域上，东南亚（Southern Asia）是人类活动引起的CO₂、CH₄和N₂O通量净增温效应最大的区域，因为其CH₄和N₂O排放的100年累积效应超过陆地CO₂汇。东南亚拥有全球约90%的水稻田和超过60%的氮肥消费，其CH₄排放的64%–81%和N₂O排放的36%–52%来自农业和废弃物部门。非洲被估计为小CO₂汇（BU）或CO₂中性（TD），但计入CH₄和N₂O后呈轻微增温。南美洲为中性或小汇，因为其大部分当前CH₄和N₂O排放在工业化前就存在。北美洲和北亚的CO₂吸收几乎抵消或超过CH₄和N₂O排放，起到减缓气候变暖的作用。欧洲的陆地生态系统为中性角色。

区域尺度上，TD和BU估计的差异大于全球尺度。例如，北美洲的CO₂汇（TD: −0.37±0.22 Pg C yr⁻¹；BU: −0.75±1.87 Pg C yr⁻¹），TD估计北美洲净温室气体平衡为−2.35±6.87 Pg CO₂当量/年（大标准差），BU估计为−0.38±0.93 Pg CO₂当量/年。东南亚的TD估计净源为6.3±3.7 Pg CO₂当量/年，BU为4.4±1.2 Pg CO₂当量/年。TD估计中东南亚的高辐射强迫部分源于TransCom反演估计的净CO₂源（0.36 Pg C yr⁻¹，标准差0.99）。BU估计可能低估了热带地区干扰导致的CO₂排放，如泥炭火灾和排水的泥炭地分解。非洲的TD估计净辐射强迫为1.20±3.05 Pg CO₂当量/年，BU为0.34±1.42 Pg CO₂当量/年。

## 不确定性来源与对策启示

TD方法在区域源归因上存在大不确定性，且依赖BU估计作为先验，尤其在热带观测稀少地区。BU方法受限于对微生物和地下过程的理解不足，以及缺乏空间显式和时序的驱动数据。人类活动引起的CH₄和N₂O排放的不确定性大于总排放，因为叠加了工业化前排放估计的误差。湿地面积数据、稻田管理、自然土壤N₂O排放等均是主要不确定性来源。研究强调在气候影响评估和减缓政策中必须同时考虑三种主要温室气体，并警惕减排措施的潜在抵消效应，例如土壤固碳可能增加N₂O排放，稻田排水减少CH₄但增加CO₂和N₂O，泥炭地火抑制和复湿增加CH₄等。未来生物圈是源还是汇取决于土地利用集约化路径和陆地CO₂汇的演变；若CO₂汇继续增加，总体平衡可能逆转，但CO₂汇的未来演变本身不确定。研究结论是：采用最佳管理实践减少受人类影响的陆地生态系统的温室气体排放，可能逆转生物圈当前的增温作用。
