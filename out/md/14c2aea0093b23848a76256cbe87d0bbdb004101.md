# 草原生产力受多种营养元素共同限制
*Grassland productivity limited by multiple nutrients, 2015, https://doi.org/10.1038/nplants.2015.80*

本文报告了Nutrient Network（NutNet）在全球五大洲42个草地开展的一项标准化全因子施肥实验，核心主张是：草地地上净初级生产力（ANPP）并非只受氮（N）限制，而是经常受N、磷（P）以及钾加微量元素（K+µ）的共同限制；限制性营养素的组合在全球范围存在广泛变异，且K和微量元素的限制作用比以往公认的更常见；同时，有约三分之一的站点未表现出本研究测试营养素的限制，提示这些地点可能受其他因子控制。

## 局限认知与全球实验的设立

此前人们对陆地生态系统生产力的认识以单一氮限制为主，但Elser等人对1400个N、P施肥研究的meta分析表明，N和P常常协同限制生产力，即共同施加时效应超过二者单独效应之和。然而，对于N和P之外的其他营养元素（如钾、微量元素）在自然群落中的全球性限制作用，仍缺乏认识；草地约占陆地净初级生产力的三分之一，而这一问题在草地中尤为突出。人类活动使活性N产量超过全部自然陆地来源，加速N沉降，可能进一步加剧P、K或微量元素的限制。K在植物组织中含量高，其吸收与其他元素相关，但草地系统中K限制的研究明显滞后于农业生态系统。先前研究也因施肥剂量、方法不统一及缺少全因子设计，难以确证多种营养元素限制的存在。本研究通过NutNet网络，在位于五大洲、跨越约25°绝对纬度（实际纬度54° N至37° S）、海拔50–3500 m、年均降水252–1898 mm、年均温0.3–22.1 °C的42个草地站点上，统一施加N、P、K+µ的2×2×2全因子处理（8个处理组合，含对照；每站点多为3个区组，范围2–6），每种处理设在5 m × 5 m的重复样方内；K+µ中的微量元素（含Ca、Mg、S、B、Cu、Fe、Mn、Mo、Zn）只在第一年随K添加以避免毒害。ANPP通过每年高峰生物量刈割、60 °C烘干称重估算，每样方取两个0.1 m²样方；效应量采用对数响应比（LRR）度量。这一标准化设计克服了此前meta分析中施肥率和方法不一、且缺乏全因子处理的主要局限。

## 全球尺度的限制频率与形式

在42个站点中，营养限制影响了31个站点的ANPP；24个站点出现N、P、K+µ的成对组合共限制。全球平均来看，N和P联合处理使ANPP较对照平均增加40%（LRR = 0.34），显著高于N单独的18%（LRR = 0.16）和P单独的9%（LRR = 0.09；p = 0.03），为N和P的协同共限制提供了明确证据。站点层面，约60%的站点（25个）出现某种形式的NP共限制，平均增值67%（LRR = 0.51），分布于全部五个大陆；其中13个站点为协同共限制，12个为亚加性共限制。这一结果与长期以来的“N是草地主要限制元素”的认知相悖，凸显了P的重要角色。

K+µ在全球平均层面未显示单独或组合限制效应（p > 0.32），但站点层面频繁存在：K+µ单独限制见于3个站点，NK+µ共限制见于18个站点，两者平均增值均为48%（LRR = 0.39）；PK+µ共限制见于9个站点，平均增值52%（LRR = 0.42），其幅度已接近N单独（57%）或P单独（54%）限制的站点平均值。涉及K+µ的单独或多种限制总共出现在24个站点，同样遍布五大洲。这可能是迄今对草地ANPP受K+µ限制的最广评估，提示K限制（可能受第一年微量元素添加影响）发生频率高于先前认识。

不过，仍有15个站点未发现多种营养限制的证据，其中12个站点同样没有单一营养限制。站点层面的单一营养限制幅度彼此正相关（R²介于0.08–0.15），营养对限制与第三种元素的限制幅度也正相关（R²介于0.07–0.21），说明存在共同的站点属性可预测限制幅度。文中将检验这些属性的分析推迟到方法部分之后，而本段的统计模型已明确使用了嵌套于站点、年份及站点×年份的线性混合模型。

## 限制模式的空间、气候与时间预测

在可供检验的定性预测因子（大陆、火烧、放牧、既往耕作、优势土壤质地）中，未发现营养限制的显著差异。对运行时间最长的19个站点（其站点平均限制与站点平均气候、土壤属性对应最佳）做定量回归分析：N限制随站点年均温（MAT）降低而增强（R² = 0.40，p = 0.002），并在温带纬度（约45°）达到峰值（R² = 0.38，p = 0.009）；MAT随纬度升高而降低（R² = 0.66，p < 0.0001），故N限制集中在较冷的温带纬度，与先前理论预测一致。其他单一或组合营养限制与土壤质地组分、处理前土壤养分、pH或气候变量均无显著相关（p > 0.05）。

营养限制的幅度随时间增大。为排除样方间空间异质性，以各处理样方处理前（第0年）ANPP为基准重新计算LRR；对37个在第1–3年无缺失数据的站点，所有处理中ANPP响应逐年增加，且含N处理每年增幅显著大于P、K+µ和PK+µ处理（p < 0.005）。这意味着图1A中N的全球平均效应大于P或K+µ，部分原因是P和K+µ的效应出现更晚、增幅更小；因此，草地对N以外营养元素的限制可能需要更长时间才能完全显现，本研究给出的全球平均限制估计是保守的，未来可能需向上修正。

## 讨论与方法

多营养元素限制，特别是协同共限制，使人为营养输入（如N沉降）对草地及其他生态系统的后果更难预测：协同限制可能在初期限制单一营养输入的效应，但当第二个限制元素随后输入时，生态系统响应可能快于预期。若只考虑共限制中的一种营养元素，就可能对生物多样性和生态系统服务的未来响应得出错误结论。

统计方法与效应量计算：用SAS/STAT v9.2拟合线性混合模型，检验各站点间营养主效应与交互效应及其随年份的变化：ln(ANPP)ijkl = µ + nutrientsi + nutrients(site)ij + nutrients(year)ik + nutrients(site × year)ijk + eijkl，其中nutrients指N、P、K的8种因子组合，年份不作重复测量处理。效应量按两种方式计算：处理相对同区组对照的LRR = ln[ANPP_trt/ANPP_ctrl]，以及相对自身处理前ANPP的LRR = ln[ANPP_trt(year X)/ANPP_trt(year 0)]以分离时间信号。站点LRR的显著性以阈值LRR = (1/7) × (LRRN + LRRP + LRRK + … + LRRNPK)/pooled SD，并与p = 0.05对应的临界Z值（1.65）比较。位点变量预测采用线性回归，仅在p < 0.05时报告，并按残差评估拟合多项式曲线。
