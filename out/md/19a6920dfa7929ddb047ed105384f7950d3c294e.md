# CasADi：非线性优化与最优控制的软件框架

*CasADi: a software framework for nonlinear optimization and optimal control* · Andersson, Gillis, Horn, Rawlings, Diehl · 2018 · DOI: https://doi.org/10.1007/s12532-018-0139-4

CasADi 是一个面向数值优化的开源软件框架，其定位比 AMPL、GAMS、JuMP、Pyomo 等代数建模语言更灵活，但也更底层，要求用户理解建模过程中构造的表达式图。它尤其关注受微分方程约束的问题，即最优控制问题。CasADi 用自包含的 C++ 编写，但最方便的使用方式是通过 Python、MATLAB 或 Octave 的完整接口。自 2009 年末诞生以来，它已被用于学术教学以及过程控制、机器人、航空航天等多个领域的应用。本文对该框架做了一次最新的、可读性强的介绍，涵盖其七年来经历的大量设计改进。

## 符号框架与自动微分

CasADi 的核心是一个符号框架，允许用户构造表达式，并用这些表达式定义可自动微分的函数。这些通用表达式本身不涉及优化，类似于 MATLAB Symbolic Toolbox 或 Python SymPy 中的表达式。表达式创建后，既可以用自动微分高效地获得导数表达式，也可以在 CasADi 的虚拟机中高效求值，或生成自包含的 C 代码。

CasADi 采用 MATLAB 风格的“一切皆矩阵”语法：标量视为 1×1 矩阵，向量视为 n×1 矩阵，所有矩阵都是稀疏的，以压缩列格式存储。这种单一稀疏数据类型使工具更易学习和维护；由于线性代数运算通常只在构造符号表达式时调用一次，而非数值求值，因此把标量当作 1×1 稀疏矩阵的额外开销可以忽略。例如，创建两个符号原语 $x\in\mathbb{R}^{2}$ 和 $A\in\mathbb{R}^{2\times 2}$，再构造 $e:=A\sin(x)$，输出可解释为两个共享子表达式 $\@1:=\sin(x_{0})$ 和 $\@2:=\sin(x_{1})$，随后是结果列向量的表达式。表达式允许包含共享子表达式，这是解决大规模问题以及实现自动微分的关键。

CasADi 有两种表达式类型。标量表达式类型 SX 中，每个非零元素由一系列标量值操作定义；表达式存储为有向无环图（DAG），节点或原子操作可以是符号原语、常数、一元操作（如 sin）或二元操作（如 *、+）。这种图表示设计用于以极低开销进行数值求值，每个操作也有可用其他原子操作高效表达的链式法则。矩阵表达式类型 MX 中，每个操作是矩阵操作；例如 $A+B$（A、B 为 n×m 矩阵）在 MX 中是一个加法操作，而用 SX 则可能多达 mn 个标量加法。MX 操作一般可有多个矩阵值输入并返回多个矩阵值输出。实现两种表达式类型并都暴露给用户，是一种设计折中：既要在 ODE 右端项等对开销极敏感的场景中高效工作，又要能表示直接多重打靶离散化所产生的、包含嵌入式 ODE 积分器的非常一般的 NLP 符号表达式。MX 的原子操作选择使前向或反向自动微分都能用同一组操作高效表达，并考虑 MX 虚拟机支持原地操作；因此矩阵乘累加 $\operatorname{mac}(X_{1},X_{2},X_{3}):=X_{3}+X_{1}X_{2}$ 被选为原子操作，而非标准矩阵乘法，实际执行的是 $X_{3}:=X_{3}+X_{1}X_{2}$。Table 1 列出了 MX 表达式图最重要的原子操作及其在自动微分下的相互依赖关系；例如对取矩阵元素操作（表中操作 9）做反向模式 AD，会得到给矩阵元素赋值的操作（操作 10）。赋值操作分两步：先把现有矩阵复制到新变量，再实际赋值（或可选地加法）；复制操作通常在虚拟机中被消除。某些操作如二元操作 $A+B$ 假定参数具有相同稀疏模式，否则 CasADi 在构造时插入“投影”节点。函数调用节点是一种特殊原子操作，由运行时创建的函数对象的调用组成；同一函数对象可有多次调用，从而保持表达式图较小。

符号表达式可用于定义函数对象，即运行时创建、行为类似常规函数的类实例。函数对象除支持数值求值外，还支持符号求值、C 代码生成以及导数计算。创建时提供显示名和输入输出表达式列表，可有任意数量的输入输出，每个都是稀疏矩阵；若某输入含结构零，则构造的函数被理解为不依赖该矩阵的对应部分。创建函数对象本质上是对表达式图做拓扑排序，把 DAG 变成可求值算法。与 ADOL-C、CppAD 等传统 AD 工具不同，表达式创建顺序（追踪步骤）与排序后算法中的出现顺序无关；CasADi 用深度优先搜索对 DAG 节点做拓扑排序。给定排序后的操作序列，CasADi 为每种图表示实现一个基于寄存器的虚拟机（VM）。每个操作的输入输出从工作向量中分配一个元素（SX VM）或一个区间（MX VM），这与 AMPL Solver Library 等基于栈的 VM 不同。为限制工作向量大小，会分析每个操作的活跃变量范围，然后按后进先出方式复用工作向量元素或区间。尽可能原地执行操作，例如给矩阵左上角元素赋值的操作通常简化为元素赋值 $X_{1}(1,1):=x_{2}$，前提是 $X_{1}$ 之后不再需要。由于 MX 表达式图可包含函数对象调用，因此可定义嵌套函数对象；把多次使用的子表达式封装为独立函数对象可使表达式图保持较小，并影响自动微分时的内存使用。CasADi 中由 Function 类表示的函数对象不必由符号表达式定义；ODE/DAE 积分器、非线性方程组求解器和 NLP 求解器就是不由符号表达式显式定义的函数对象例子，其中许多（但并非全部）也可自动微分。

CasADi 的 VM 设计用于高速低开销，例如数值求值期间避免内存分配。在频繁快速原型设计和多次设计迭代的框架中，快速 VM 不仅对数值求值重要，对符号处理也重要，后者可能占总求解时间的很大部分。另一种求值方式是生成函数对象的 C 代码。用合适编译器标志编译后，生成代码可比 CasADi 的 VM 快得多。生成代码是自包含 C，无动态内存分配，适合部署在嵌入式系统；可链接为动态库、通过生成的头文件静态/动态链接、通过生成的 main 入口从操作系统命令行调用，或通过生成的 mexFunction 入口从 MATLAB/Octave 调用。生成 C 代码可用于即时编译，既可用系统编译器，也可通过 LLVM 编译器框架及其 C/C++ 前端 Clang 的接口；后者适用于所有平台并随 CasADi 分发，用户无需二进制兼容的系统编译器。

自动微分（AD）是高效计算以算法表示的函数导数的技术。对 $y=f(x)$（x、y 为向量值），前向模式可精确计算 Jacobian 乘向量积 $\hat{y}:=\frac{\partial f}{\partial x}\hat{x}$，计算成本与求值原函数 $f(x)$ 相当。该定义自然扩展到矩阵值函数 $Y=F(X)$，只需定义 $x:=\operatorname{vec}(X)$、$y:=\operatorname{vec}(Y)$，其中 $\operatorname{vec}(\cdot)$ 表示把矩阵各列垂直堆叠；也自然推广到多个矩阵值输入输出的情况，即 CasADi 中函数的一般情形。反向模式则精确计算 Jacobian 转置乘向量积 $\bar{x}:=\left(\frac{\partial f}{\partial x}\right)^{\mathrm{T}}\bar{y}$，计算成本也与求值原函数相当；与前向模式不同，反向模式一般有更大但常可避免的内存开销。该定义同样自然扩展到多矩阵值输入输出。任何 AD 实现都把计算分解为具有已知（最好显式）链式法则的原子操作序列。例如矩阵乘法 $Y=X_{1}X_{2}$ 的前向模式 AD 规则为 $\hat{Y}=\hat{X}_{1}X_{2}+X_{1}\hat{X}_{2}$，反向模式规则为 $\bar{X}_{1}=\bar{Y}X_{2}^{\mathrm{T}};\quad\bar{X}_{2}=X_{1}^{\mathrm{T}}\bar{Y}$。前向和反向模式提供两种高效精确计算方向导数的方式；高效计算完整 Jacobian（可能大而稀疏）则困难得多，大规模问题通常需要某种回退到上述前向/反向模式的启发式。高阶导数可作为特例处理，或如本文所做，递归应用 AD 算法；标量值函数的 Hessian 就计算为梯度的 Jacobian，最好利用 Hessian 的对称性。CasADi 用源代码变换方法实现 AD：请求导数时生成使用相同图表示的新符号表达式，可计算方向导数以及大而稀疏的 Jacobian 和 Hessian 的可微表达式。

对由符号表达式定义的函数对象，CasADi 通过分别向前和向后传播符号种子来实现前向和反向模式 AD，得到包含原函数表达式图节点引用的新符号表达式。遇到函数调用节点时，会生成新函数对象来计算方向导数；生成的导数函数对象会被缓存以限制内存使用。函数类如何计算方向导数因类而异；例如积分器节点通常通过给 ODE/DAE 积分增广灵敏度方程来生成方向导数函数。若符号表达式节点数很大，反向模式导数求值可能内存开销大，因为中间结果必须保存在内存中并按逆序访问。CasADi 用户负责把大表达式分解为较小表达式的层次结构，每个封装在独立函数对象中，以避免内存爆炸。选择合适的函数对象层次等价于 AD 术语中的检查点策略，代价是反向模式 AD 浮点运算次数适度增加。

计算完整 Jacobian 和 Hessian 时，CasADi 用图着色方法生成大而稀疏的完整 Jacobian 和 Hessian 表达式。其思想是用一组 Jacobian 乘向量积（即方向导数）重建 Jacobian；用贪心图着色算法寻找比简单使用单位向量（即 $\nu_{i}$ 为单位矩阵第 i 列）更少的向量集。CasADi 用启发式构造 Jacobian 和 Hessian 表达式：当先验知道所得 Jacobian 对称时（特别是构造 Hessian 时），使用利用对称性的贪心、距离-2、星形着色算法；对非对称 Jacobian，则分别按列（对应前向模式 AD）和按行（对应反向模式 AD）尝试贪心、距离-2、单向算法。根据 Jacobian 的行列数，先尝试其中一种，若第二种算法被判定需要更多颜色（即更多方向导数）则提前中断。引入因子 $\alpha$（默认 2）以考虑反向模式 AD 扫描通常比前向模式慢。着色算法与最大优先预排序步骤一起使用。

Jacobian 稀疏模式计算是上述图着色方法的前提。对一般表达式获得该模式并非易事，且往往是 Jacobian 构造中最昂贵的步骤。CasADi 使用位向量方法，本质是用单个比特作为数据类型实现前向或反向模式 AD，指示 Jacobian 乘向量积的某分量是否结构为零。位向量方法可用无符号整数数据类型的位运算高效实现；CasADi 使用 64 位 unsigned long long，意味着一次稀疏传播扫描最多可计算 64 行或列。对 CasADi 中遇到的大而稀疏 Jacobian 和 Hessian（行列数可达数百万），执行数万次稀疏传播扫描来确定稀疏模式可能极其昂贵。若对非零元素位置一无所知，已有 Griewank 和 Mitev 提出的概率方法；但对 CasADi 中典型（模拟和优化中）的 Jacobian，非零元素不太可能出现在随机位置，更典型的稀疏模式是有大片区域没有一个非零元素。为利用这种块稀疏结构，CasADi 实现基于图着色的分层稀疏模式计算算法，在计算逐渐更精细的稀疏模式与前述相同图着色算法之间交替。第一步把 Jacobian 的行和列分成 64 个大小相近的组，执行稀疏模式传播算法（前向或反向）得到粗稀疏模式；对 Figure 1 的模式，这会得到块对角或块三对角稀疏模式，取决于块如何选择，两种情况都适合图着色。经过利用对称性或非对称性的图着色后，对更细的稀疏模式重复该过程，粗模式中每种不同颜色用一次稀疏传播扫描。如此对逐渐更细的稀疏模式重复，直到获得实际稀疏模式。例如，假设 Jacobian 维度为 100,000×100,000，具有（先验未知的）非对称三对角稀疏模式。所提传播算法先做一次扫描，得到块三对角模式，块大小不超过 ceil(100,000/64)=1,563。三对角模式无论维度如何都可用 3 种颜色着色，即列可分为 3 组。对每种颜色做一次扫描（共 3 次）找到更细稀疏模式，它也是三对角；此时块不超过 ceil(1,563/64)=25。再次执行图着色算法，再次得到 3 种颜色。最后对每种颜色做一次扫描，得到真实稀疏模式。该例中稀疏模式用 7 次扫描恢复，而朴素算法需要 ceil(100,000/64)=1,563 次扫描（每次计算 64 行或列）。若非零元素随机散布，该分层算法效率不高，CasADi 假定用户在构造大规模 NLP 等时考虑到这一点。

CasADi 用户常问如何处理含 if 语句、for 循环和 while 循环等流控制的表达式。含流控制的表达式在许多应用中自然出现，例如不同值范围由不同方程支配的物理模型；能对此类模型计算至少几乎处处准确的导数，对实际数值优化至关重要。CasADi 选择通过实现 Haskell 等函数式编程语言的概念来支持流控制。条件表达式（包括 switch 和 if 语句）可用专门的 Switch 函数对象类表达；该类由一组对应不同情况以及默认情况的函数对象定义，所有函数对象具有相同输入输出签名。由于 CasADi 通过生成方向导数表达式来计算函数对象导数，上述类的前向和反向模式导数规则可定义为由相应导数函数定义的新条件函数对象。注意对第一个参数（c）的导数几乎处处为零。Switch 构造的一个重要特例是 if-then-else 操作，此时 N=1。另一个来自函数式编程且易于微分概念是 map，即用不同参数多次求值一个函数，可串行或并行执行。CasADi 的 Map 函数对象类允许用户构造 map；该函数对象接受所有输入的水平拼接，返回所有输出的水平拼接。

## 隐式定义的可微函数

优化问题可能包含隐式定义的量。一个重要例子（也是最初编写 CasADi 的动机之一）是直接多重打靶法，其中 NLP 包含嵌入式微分方程初值问题求解器；另一个例子是含代数环的动态系统，可通过嵌入求根求解器使其显式。以下讨论如何把某些隐式定义的函数嵌入符号表达式，同时自动高效地生成其导数和稀疏信息。

线性方程组 $y=X_{2}^{-1}x_{1}$ 的解具有前向和反向模式 AD 规则：$\hat{y}=X_{2}^{-1}(\hat{x_{1}}-\hat{X_{2}}y);\quad\bar{x}_{1}=X_{2}^{-\mathrm{T}}\bar{y};\quad\bar{X}_{2}=-\bar{x}_{1}y^{\mathrm{T}}$。除矩阵乘法等标准操作外，方向导数可用与非微分表达式相同的线性系统做线性求解来表达；反向模式情形需要转置矩阵的线性求解。CasADi 通过线性求解器抽象基类支持这种形式的线性方程组，该基类是一个能分解和求解稠密或稀疏线性方程组的 oracle 类。求解步骤支持可选转置，以满足反向模式 AD 的需要。线性求解器类是 CasADi 中的插件类，把实际分解和求解留给派生类（通常是第三方线性求解器的接口）。线性求解器实例通过专门的线性求解节点嵌入 CasADi 的 MX 表达式图，该节点类似于 2.3 节更通用的函数调用节点。线性求解节点实现上述导数 AD 规则，使用 MX 的水平拆分和拼接节点，以便对多个方向导数（即多个右端项）复用同一分解。线性求解节点的稀疏模式传播实现方式是：先对行和列做块三角重排序，暴露元素间的单向和双向依赖；重排序对每个稀疏模式只计算一次并缓存。写作时 CasADi 中的线性求解器插件（可能施加对称性或正定性等额外限制）包括 CSparse（稀疏 LU、稀疏 QR 和稀疏 Cholesky 分解）、MA27（frontal 方法）和 LAPACK（稠密 LU 和稠密 QR 分解）。

更一般的隐式定义函数是求根问题的解：$g(y,x)=0\Leftrightarrow y=f(x)$。若满足正则性条件，特别是 Jacobian $\frac{\partial g}{\partial y}$ 存在且可逆，则问题适定，其 Jacobian 由隐函数定理给出：$\frac{\partial f}{\partial x}=-\left(\frac{\partial g}{\partial y}\right)^{-1}\frac{\partial g}{\partial x}$，由此可得前向和反向 AD 传播规则：$\hat{y}=-\left(\frac{\partial g}{\partial y}\right)^{-1}\frac{\partial g}{\partial x}\hat{x};\quad\bar{x}=-\left(\frac{\partial g}{\partial x}\right)^{\mathrm{T}}\left(\frac{\partial g}{\partial y}\right)^{-\mathrm{T}}\bar{y}$。前向模式下，计算隐式定义函数 f(x) 的方向导数归结为计算残差函数 g(y,x) 的前向模式方向导数再做线性求解；反向模式下，计算涉及转置系统的线性求解再做残差函数的反向模式方向导数。CasADi 通过所谓 rootfinder 函数对象支持上述内容，使用 (3) 的推广，包含多个矩阵值输入参数和一组辅助输出，其中 $x_{0}$ 作为 $y_{0}$ 的初始猜测引入；注意对 $x_{0}$ 的导数几乎处处为零。与线性求解器一样，求根器用插件设计实现：基类定义导数计算和稀疏模式传播规则，实际求解非线性方程组委托给派生类（通常是第三方工具的接口）。CasADi 中的求根对象可被任意次微分，因为其前向和反向模式方向导数都可用（任意可微的）CasADi 构造表达，即残差函数的方向导数和 3.1 节处理的线性求解器操作。线性求解器通常与非线性方程组牛顿法中使用的线性求解器相同；默认使用 CSparse 插件，但可通过向 rootfinder 构造函数传选项更改。

某些最优控制方法（包括直接多重打靶和直接单打靶）会产生需要求解 ODE 或 DAE 初值问题（IVP）的优化问题表述。由于积分器调用出现在 NLP 的约束和/或目标函数中，需要计算一阶、最好还有二阶导数信息。前述 CasADi 构造可用于定义显式或隐式固定步长积分格式。例如，Runge-Kutta 4（RK4）格式可用 CasADi 的 MX 类型在不到 10 行代码中实现，导数可自动生成到任意阶；类似地，隐式固定步长格式（如配点法）可用 3.2 节所述的 CasADi 求根功能实现。更高级的积分格式，如变阶和/或自适应步长的后向差分公式（BDF）方法，无法用这种方法处理。与固定步长积分格式相比，自适应格式通常以相同精度用更少步数，且用户无需选择合适步长。CasADi 的积分器功能使用户能把 ODE 或 DAE 初值问题求解器嵌入，并用 SUNDIALS 套件等最先进代码精确计算任意阶导数。CasADi 的积分器对象求解如下形式的问题：$f:\mathbb{R}^{n_{x}}\times\mathbb{R}^{n_{z}}\times\mathbb{R}^{n_{u}}\times\mathbb{R}^{n_{r}}\times\mathbb{R}^{n_{s}}\times\mathbb{R}^{n_{v}}\rightarrow\mathbb{R}^{n_{x}}\times\mathbb{R}^{n_{z}}\times\mathbb{R}^{n_{q}}\times\mathbb{R}^{n_{r}}\times\mathbb{R}^{n_{s}}\times\mathbb{R}^{n_{p}}$，$(x_{0},z_{0},u,r_{T},s_{T},v)\mapsto(x(T),z(T),q(T),r(0),s(0),p(0))$，约束为 $\dot{x}(t)=\phi(x(t),z(t),u),\ x(0)=x_{0}$；$0=\theta(x(t),z(t),u),\ z_{0}$ 为 $z(0)$ 的初始猜测；$\dot{q}(t)=\psi(x(t),z(t),u),\ q(0)=0$；$-\dot{r}(t)=\phi^{*}(x(t),z(t),u,r(t),s(t),v),\ r(T)=r_{T}$；$0=\theta^{*}(x(t),z(t),u,r(t),s(t),v),\ s_{T}$ 为 $s(T)$ 的初始猜测；$-\dot{p}(t)=\psi^{*}(x(t),z(t),u,r(t),s(t),v),\ p(T)=0$。该问题由两个半显式 DAE 组成，分别带初始和终端约束，都支持求积分；第二个 DAE 与第一个 DAE 的解轨迹耦合。额外要求 $\theta^{*}(x,z,u,r,s,v)$、$\phi^{*}(x,z,u,r,s,v)$ 和 $\psi^{*}(x,z,u,r,s,v)$ 对 r、s、v 仿射。包含 z(0) 和 s(T) 的初始猜测是为了效率、鲁棒性和确保解唯一性。该积分器表述在优化和灵敏度分析中有两大优势：其一，足够一般，能处理大多数工业相关模拟问题，求积分功能允许用求积公式高效计算目标函数中的积分项；其二，可以证明该问题的前向和反向模式方向导数都可通过求解结构完全相同的问题高效计算。通过反复微分，可用前向和伴随灵敏度分析的适当组合计算任意阶导数；特别地，可做前向-伴随灵敏度分析以高效计算 Hessian。这种变分灵敏度分析方法的一个潜在缺点是，在基于梯度的优化代码中使用时，由于时间离散化差异，计算导数可能与未微分函数求值不一致。与线性求解器和求根求解器一样，积分器在 CasADi 中用插件设计实现：基类实现微分和稀疏模式传播规则，派生类（可以是第三方工具接口）执行实际求解。CasADi 中的积分器插件包括 SUNDIALS 套件的 IDAS 和 CVODES、固定步长 RK4 代码，以及实现 Legendre 或 Radau 配点的隐式 Runge-Kutta 代码。

## 优化

与常规代数建模语言一样，CasADi 把建模支持与数学优化支持结合起来。支持两类优化问题：非线性规划（NLP）和锥优化问题，后者包括线性规划（LP）和二次规划（QP）。实际求解通常在派生类中进行，可能使用随 CasADi 分发的工具，也可能是第三方求解器的接口。CasADi 的作用是提取结构信息、生成所需导数信息，并为所有求解器提供公共接口。

CasADi 对非线性规划（NLP）使用如下表述：$\mathrm{minimize}_{x,p}\ f(x,p)$，约束为 $\underline{x}\leq x\leq\bar{x},\quad p=\bar{p},\quad\underline{g}\leq g(x,p)\leq\bar{g}$。这是参数化 NLP，目标函数 $f(x,p)$ 和约束函数 $g(x,p)$ 依赖决策变量 x 和已知参数 p。对等式约束，变量界 $[\underline{x},\overline{x}]$ 或约束界 $[\underline{g},\overline{g}]$ 相等。求解 (7) 得到原始解 $(x,p)$ 和对偶解 $(\lambda_{x},\lambda_{p},\lambda_{g})$，其中 Lagrange 乘子与如下 Lagrangian 函数定义一致：$\mathcal{L}(x,p,\lambda_{x},\lambda_{p},\lambda_{g}):=f(x,p)+\lambda_{x}^{\mathrm{T}}x+\lambda_{p}^{\mathrm{T}}p+\lambda_{g}^{\mathrm{T}}g(x,p)$。该表述丢弃所有不依赖 x 或 p 的项，并对不等式约束使用相同乘子（但符号不同）：$\lambda_{\bar{x}}(x-\bar{x})+\lambda_{\underline{x}}(\underline{x}-x)=\underbrace{(\lambda_{\bar{x}}-\lambda_{\underline{x}})}_{:=\lambda_{x}}^{\mathrm{T}}x\underbrace{-\lambda_{\bar{x}}^{\mathrm{T}}\bar{x}+\lambda_{\underline{x}}^{\mathrm{T}}\underline{x}}_{\mathrm{ignored}}$，对 $g(x,p)$ 同理。注意 $\lambda_{\overline{x}}(i)$ 和 $\lambda_{\underline{x}}(i)$ 不能同时为正，且被丢弃的项不出现在 (7) 的 KKT 条件中。该 NLP 表述中，严格正乘子表示对应上界活跃，反之亦然；此外 $\lambda_{p}$ 是目标对参数向量 p 的参数灵敏度。Table 2 列出了写作时可用的 NLP 求解器插件，包括通常随 CasADi 分发的开源求解器和需要单独安装的商业求解器。该表粗略区分适合非常大但非常稀疏的 NLP（如直接配点产生）的求解器，和适合大而结构化 NLP（如直接多重打靶产生）的求解器。插件 'sqpmethod' 对应“vanilla”SQP 方法，主要作为打算开发自己求解器代码的用户的样板代码。部分求解器支持混合整数非线性规划（MINLP），其中一部分决策变量被限制取整数值。

当目标函数 $f(x,p)$ 对 x 二次、约束函数 $g(x,p)$ 对 x 线性时，(7) 可写成如下二次规划（QP）：$\underset{x}{\mathrm{minimize}}\quad\frac{1}{2}x^{\mathrm{T}}Hx+g^{\mathrm{T}}x$，约束为 $\underline{x}\leq x\leq\bar{x},\quad\underline{a}\leq Ax\leq\bar{a}$。CasADi 支持求解表述为 (7) 或 (9) 的 QP。前者情形用 AD 把问题重述为 (9) 形式，自动识别稀疏矩阵 H 和 A 以及向量 g、$\underline{a}$ 和 $\overline{a}$。与 NLP 求解器一样，优化问题求解在 CasADi 的锥求解器插件之一中进行，见 Table 3。某些插件对 (9) 施加额外限制：线性规划求解器要求 H 项为零，大多数接口的 QP 求解器要求 H 半正定。部分求解器支持混合整数表述。注意混合整数二次规划（MIQP）是 QP 的超集，QP 是 LP 的超集。CasADi 未来版本可能允许更一般的锥约束，如 SOCP 和 SDP。

由最优控制问题转录产生的 NLP 和 QP 通常稀疏或块稀疏。此处的稀疏 QP 指矩阵（即 (9) 中的 A 和 H）每行或每列非零元素足够少，可由通用稀疏线性代数例程高效处理。对稀疏 NLP，同样适用于 KKT 条件线性化产生的矩阵，即 (7) 和 (8) 中的 $\frac{\partial g}{\partial x}$ 和 $\nabla_{x}^{2}\mathcal{L}$。直接配点型 OCP 转录通常产生稀疏 NLP 或 QP，前提是 ODE 右端函数（或 DAE 残差函数）的 Jacobian 足够稀疏。已有若干工具可高效处理这些问题，见 Table 2 和 Table 3；这些求解器一般依赖稀疏直接线性代数例程，例如来自 HSL Library 的例程。另一方面，直接多重打靶型转录通常产生具有稠密子块的 NLP 或 QP，因而整体呈块稀疏模式，非零元素太多，通用稀疏线性代数例程难以高效处理。已知 condensing 与 qpOASES 等稠密求解器结合对某些结构化 QP 效果良好，特别是时间范围短且控制维数相对状态维数小时。其他 QP 可用 FORCES、qpDUNES 和 HPMPC 等工具高效求解。lifted Newton 方法把 condensing 方法推广到 NLP 和非线性求根问题。写作时 CasADi 支持一个结构化 QP 求解器 HPMPC，以及两个结构化 NLP 求解器 Scpgen 和 blockSQP。Scpgen 是用 CasADi 的 AD 框架实现的 lifted Newton 方法；blockSQP 以修改形式并入 CasADi，可处理 Hessian 矩阵块对角的 NLP。

## 教程示例与应用

以下通过一系列复杂度递增的教程示例展示 CasADi 语法和使用范式。前两个例子介绍 CasADi 的优化建模方法，它不同于 AMPL、GAMS、JuMP 或 Pyomo 等常规代数建模语言。5.3 节演示自动 ODE/DAE 灵敏度分析，5.4 节结合前面例子引入的工具实现直接多重打靶法。使用对应 CasADi 3.1 的语法，MATLAB/Octave 和 Python 并排展示。

第一个例子是无约束优化：求 Rosenbrock 香蕉谷函数 $\underset{x,y}{\mathrm{minimize}}\quad x^{2}+100(y-(1-x)^{2})^{2}$ 的最小值。通过观察可知其唯一解为 (0,1)。用 CasADi 表述和求解分三部分：首先构造问题的符号表示（MATLAB/Octave struct 或 Python dict），字段命名与 (7) 一致；变量 z 是中间表达式，更复杂模型会包含大量此类表达式。其次创建求解器实例，此处用 IPOPT；该步骤调用 AD 框架生成一组求解器特定的数值求值函数，此处对应代价函数、其梯度和 Hessian。最后数值求值求解器实例以获得最优解，传入初始猜测 (2.5,3.0)，其他输入保持默认值，例如 x 的界为 $\underline{x}=-\infty$、$\overline{x}=\infty$。上述脚本在 26 次迭代后收敛到最优解，MacBook Pro 上总求解时间约 0.02 s。

第二个例子把 (10) 重述为约束优化问题，引入对应上述 z 的决策变量：$\mathrm{minimize}_{x,y,z}\ x^{2}+100z^{2}$，约束为 $z+(1-x)^{2}-y=0$。用 CasADi 表述和求解时，通过把 g 的上界和下界设为 0 施加等式约束，并用 (2.5,3.0,0.75) 作为初始值，与无约束表述的初始猜测一致。上述脚本在 10 次迭代后收敛到最优解，耗时约 0.01 s。注意把优化问题提升到更高维数使 IPOPT 的 Newton 型方法局部收敛更快；对结构复杂的非线性问题常可观察到这种行为，这也是直接多重打靶法的优势之一。

第三个例子转向使用 3.3 节引入的 CasADi 积分器对象进行模拟和灵敏度分析。考虑对应 Van der Pol 振子的 ODE 初值问题：$\dot{x}_{1}=(1-x_{2}^{2})x_{1}-x_{2}+p,\ x_{1}(0)=0$；$\dot{x}_{2}=x_{1},\ x_{2}(0)=1$。固定 p=0.1，求 $x_{\mathrm{f}}:=x(1)$。与上述优化例子一样，求解分三部分：构造问题的符号表示、创建求解器实例、求值求解器实例以获得解。脚本中使用 SUNDIALS 套件的 CVODES 求解初值问题，它实现变步长、变阶后向差分公式（BDF）方法。由于上述脚本中的 F 是可微 CasADi 函数，可自动生成任意阶导数信息。例如，x(1) 对 x(0) 的 Jacobian 可如下计算：创建 Jacobian 函数 D=F.factory('D',{'x0','p'},{'jac:xf:x0'})，然后做灵敏度分析。自动灵敏度分析常在使用基于梯度的优化求解器时被间接调用，如下一例所示。

第四个例子结合 5.2 节的非线性规划例子和 5.3 节的可嵌入积分器，实现 Bock 和 Plitt 的直接多重打靶法。考虑一个简单 OCP，使用与 (12) 相同的 IVP，但重述为 DAE，并把 p 替换为时变控制 u：$\underset{x(\cdot),z(\cdot),u(\cdot)}{\mathrm{minimize}}\quad\int_{0}^{T}(x_{1}(t)^{2}+x_{2}(t)^{2}+u(t)^{2})dt$，约束为 $\dot{x}_{1}(t)=z(t)x_{1}(t)-x_{2}(t)+u(t)$；$\dot{x}_{2}(t)=x_{1}(t)$；$0=x_{2}(t)^{2}+z(t)-1$；$-1.0\leq u(t)\leq 1.0,\quad x_{1}(t)\geq-0.25$，$t\in[0,T]$；$x_{1}(0)=0,\quad x_{2}(0)=1$。其中 $x(\cdot)\in\mathbb{R}^{2}$ 是（微分）状态，$z(\cdot)\in\mathbb{R}$ 是代数变量，$u(\cdot)\in\mathbb{R}$ 是控制。令 T=10。目标是把 OCP (15) 转录为 (7) 形式的问题。直接方法的第一步是控制轨迹参数化；为简单起见，假设均匀间隔的分段常数控制轨迹：$u(t):=u_{k}\quad\mathrm{for}\ t\in[t_{k},t_{k+1}),\quad k=0,\dots,N-1\quad\mathrm{with}\ t_{k}:=kT/N$。控制在一个区间上固定后，可用积分器把问题从连续时间重述为离散时间，做法如 5.3 节。由于现在有 DAE，引入代数变量 z 和相应代数方程 g，并使用 IDAS 而非 CVODES；还引入求积分以计算对代价函数的贡献。下一步构造 NLP 的符号表示，使用形式 $\mathrm{minimize}\ J(w)$，约束为 $G(w)=0,\ \underline{w}\leq w\leq\overline{w}$。为此从空 NLP 开始，添加对应初始条件的决策变量；在 for 循环中，为每个控制区间和每个区间末状态引入决策变量，调用积分器，累加目标，并添加连续性约束。得到 (16) 的符号表达式后，可用 CasADi 的 blockSQP 分支求解该块结构 NLP，如 5.2 节。更多 CasADi 用法示例可在 CasADi 示例集合中找到，包括其他 OCP 方法，如直接单打靶、直接配点，以及两种间接方法和一种动态规划方法用于比较。

自 2011 年首次发布以来，CasADi 已被用于研究生最优控制课程教学、求解科学与工程优化问题，以及实现新算法和软件。截至 2017 年初，应用研究概览如下。在能源研究中，应用包括化石燃料的开采和运输、power-to-gas 系统、联合循环和蒸汽发电厂控制、太阳能热发电厂、经典风力涡轮机的生产模型和控制、机载风能系统的设计与控制、MEMS 能量采集器、地热热泵设计、建筑热控制、电网、电网平衡以及能源市场价格套利。在汽车工业中，应用包括传动系统的设计与运行、电力系统、内燃机控制、自动驾驶汽车研究、交通控制以及驾驶模拟器运行。在过程工业中，应用包括（生物）化学反应器的控制、最优实验设计和参数估计。在机器人研究中，应用包括农业机器人控制、用 UAV 对冰山进行遥感、机器人时间最优控制、人机交互的运动模板、含接触机器人系统的运动规划，以及复杂机器人的多目标控制。其他各类应用包括系统生物学估计、生物力学、身体过程最优控制、信号处理和机器学习。

上述大多数应用涉及系统设计、参数估计、模型预测控制（MPC）或移动 horizon 估计（MHE）表述。对其中一些问题，主要挑战在于优化问题的非标准表述。一些应用超越经典分类：dual control 结合控制与学习，最优轨迹与参考跟踪器的协同设计，多目标设计，在系统状态空间不同部分使用不同转录方法。关于鲁棒性，表述包括使用场景树、椭球计算、样条松弛、使用线性化的随机控制、使用 sigma 点以及使用多项式混沌展开。在 MPC 研究中，表述包括多级迭代、无偏设计、基于 Lyapunov 的 MPC、多目标 MPC、分布式 MPC、时间最优路径跟踪和 tube following。其他表述包括混合 OCP、处理含不变量的系统，以及用于 OCP 的改进 Gauss-Newton 方法。依赖 CasADi 进行自动微分和优化的软件包包括 JModelica.org 模拟与优化包、用于构建建筑热模型的 Greybox 工具、用于高效测试和实现鲁棒非线性 MPC 的 do-mpc 环境、用于非线性 MPC 的 mpc-tools-casadi、用于参数估计和最优实验设计的 casiopeia 工具箱、用于液压网络控制的 RTC-Tools 2 包、用于存在移动障碍物时实时运动规划的 omgtools 包、用于多目标最优控制的 Pomodoro 工具箱、用于鲁棒最优控制的样条工具箱，以及一个 MATLAB 最优控制工具箱。

自 2016 年初 CasADi 3.0 发布以来，其范围和语法可视为成熟，预计不再有重大非向后兼容变更。当前开发重点是通过解决速度和内存瓶颈使现有功能更高效，并添加新功能。一个特别关注的领域是混合整数最优控制问题（MIOCP）。这类问题在工程领域自然出现，例如 MPC 表述中的离散执行器。写作时 CasADi 已支持混合整数 QP 和 NLP 问题，如第 4 节所述，但 MIOCP 在很大程度上尚未探索。另一项进行中的开发是实现 NLP 的自动灵敏度分析。假设最优 NLP 解满足 [48] 等所述的正则性准则，NLP 求解器对象的方向导数保证存在，并可用从表达式图提取的信息计算。参数灵敏度信息在一系列应用中有用，包括参数估计中的协方差估计。
