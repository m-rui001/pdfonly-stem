# 细胞毒性淋巴细胞如何杀死癌细胞？

**How Do Cytotoxic Lymphocytes Kill Cancer Cells?** · 2015 · DOI: https://doi.org/10.1158/1078-0432.ccr-15-0685

本文综述细胞毒性淋巴细胞（cytotoxic lymphocytes, CL）——主要是细胞毒性 T 细胞（Tc）和自然杀伤（NK）细胞——在肿瘤免疫监视与免疫治疗中杀伤癌细胞的效应分子机制。作者的核心主张是：CL 通过颗粒胞吐（perforin 与 granzymes）和死亡配体/死亡受体系统两条基本途径杀伤靶细胞，但具体由哪些分子执行杀伤，在免疫监视与免疫治疗中并不总是一致；凋亡并非 CL 杀伤癌细胞的唯一或必需方式，非凋亡性细胞死亡、部分 granzyme 的炎症效应以及死亡配体的促增殖效应都可能影响肿瘤结局。

## 两条基本效应途径

免疫监视与免疫治疗的最终目标是清除癌细胞，CL 是这一过程的主要执行者；巨噬细胞、肥大细胞、树突状细胞等也可能杀伤转化细胞，但其具体作用与所用分子尚不清楚。Tc 与 NK 细胞虽经不同受体激活，却使用相同的基本机制：一是颗粒胞吐，即 perforin（PRF1）与 granzymes（GZM）；二是死亡配体/死亡受体系统。两条途径均在靶细胞内触发程序性事件，多数情况下导致凋亡。因此通常假定靶向 CL 的疗法会激活这些途径杀死癌细胞。但作者指出，从分子层面细看，在免疫监视与免疫治疗中真正执行癌细胞死亡的分子并不清楚，二者有时可能不同（见 Table 1）。更重要的是，当凋亡被病原体来源或内源性胞内抑制物（如 IAPs 或 Bcl-2 家族成员）阻断时，CL 仍能杀死癌细胞，说明凋亡并非 CL 杀伤的必需条件。这些问题之所以重要，是因为免疫系统对死亡细胞的后续反应很大程度上取决于细胞死亡方式，即死亡是否具有免疫原性。

经 TCR 或杀伤激活受体（KAR）刺激后，CL 激活效应机制，包括表达和释放 FasL（Fas ligand）与 TRAIL（TNF-related apoptosis inducing ligand）等死亡配体，以及颗粒胞吐。颗粒胞吐途径通过预先形成的特化胞质颗粒向 CL 与靶细胞接触部位（免疫突触）定向动员并释放内容物，快速执行。穿孔蛋白 perforin（PRF1）和丝氨酸蛋白酶家族 granzymes（GZM）是细胞溶解颗粒的主要成分。GZMA 与 GZMB 在过去数十年最受关注，但人类共有 5 种、小鼠共有 10 种 GZM，另有其他颗粒相关分子如人类特有的 granulysin，它们在肿瘤免疫与免疫治疗中的生物学功能尚未阐明。

多数情况下 PRF1 作为 GZM 进入靶细胞胞质的载体，其机制似乎依赖其在膜上成孔的能力。但这一控制癌细胞清除的关键步骤仍存激烈争论，直到近年才开始澄清。目前认为，正如近 30 年前所提出，PRF1 在质膜上成孔以使 GZM 进入靶细胞胞质，但孔的性质尚不清楚。替代模型（受体或网格蛋白介导的 GZM 内吞，以及共内吞的 PRF1 使 GZM 从内体释放）是否在依赖靶细胞的某些情况下运作，仍属未知。此外，在使用敏感靶细胞或 GZM 不表达/被抑制的特定情形下，PRF1 本身可能通过诱导细胞裂解杀死靶细胞；支持该假说的实验显示，瞬时转染 PRF1 cDNA 的大鼠嗜碱性白血病细胞可裂解 Jurkat 细胞。癌细胞质膜脂质组成的变化可能影响其对 PRF1 的反应（作为 GZM 递送者或裂解剂），从而调节细胞对 CL 与免疫治疗的敏感性。GZM 一旦释放到胞质，即通过切割控制细胞死亡与存活的关键胞内底物来执行靶细胞死亡；其底物还包括对病毒复制至关重要的病毒与细胞蛋白，以及控制血管完整性、炎症和皮肤衰老的细胞外基质蛋白，但后者不在本文讨论范围。哪些 GZM 激活细胞死亡、死亡细胞有何特征，目前才刚开始在生理模型中阐明。

## 免疫监视与免疫治疗中“谁执行什么”

在癌症免疫监视方面，多数小鼠体内模型证据表明 PRF1 是 NK 与 Tc 细胞控制移植同基因肿瘤及化学致癌的关键因子，也适用于控制癌症转移。PRF1 缺陷小鼠的 Tc 与 NK 细胞在快速有效诱导多数靶细胞死亡方面存在严重缺陷。PRF1 介导的细胞死亡在自发癌症发展中的作用已明确，对血液系统肿瘤尤为相关：PRF1 敲除小鼠发生自发 B 淋巴瘤；PRF1 缺陷还增强 Abl-1、Bcl-2 或 MIh1 等多种蛋白的致癌潜能。人类 PRF1 缺陷似乎易患多种淋巴瘤和白血病。其他肿瘤方面，PRF1 缺陷加速 Her-2/neu 驱动的乳腺癌发生及肿瘤分级进展。

GZM 在免疫监视中的作用则不清楚、尚无共识。有报道 GZMA 与 GZMB 缺陷小鼠对 NK 敏感植入癌细胞系更易感；相反，也有报道这些 GZM 缺陷小鼠控制植入肿瘤及化学诱导肉瘤的效率与野生型相同。需注意，在某些模型中 GzmB 缺陷消除了 CD4 T 调节细胞功能，增强 CL 的抗肿瘤反应，可能掩盖 CL 相关 GzmB 的抗肿瘤潜能。这些分歧尚未澄清，有观点认为其他 GZM 可能补偿 GZMA 与 GZMB 的缺失，而 PRF1 缺陷会使所有 GZM 的抗肿瘤功能失活。然而 GZMM 缺陷并不增加对植入同基因癌细胞系（含淋巴瘤和黑色素瘤）的易感性；GZMK 缺陷小鼠表型未知，但因其体外细胞毒性极低，预期肿瘤易感性不增加。在 GZM 缺失时，PRF1 本身可能如补体膜攻击复合物那样通过诱导细胞裂解清除癌细胞。

某些情况下，PRF1 缺陷 CL 诱导的细胞死亡可在较长孵育时间后于对 FasL 敏感的特定肿瘤细胞类型中恢复，提示该死亡配体也可能在体内参与肿瘤免疫监视。近期研究显示 Tc 细胞利用 FasL 在 RAG1 缺陷小鼠中清除移植的 B 细胞淋巴瘤，印证了此前使用 Fas（lpr）或 FasL（gld）自然突变动物的发现。与此一致，人类淋巴增殖性疾病中 Fas 突变与 B、T 淋巴瘤发生率升高相关；但此情况下淋巴瘤发生可能与活化诱导的细胞死亡缺陷有关，而非 FasL 介导的免疫监视。值得注意的是，尚未报道人类 FasL 突变有类似发生率。

另一主要死亡配体 TRAIL 最初被描述为能在多种癌细胞中诱导凋亡而保护正常细胞的细胞因子，但其主要作用似乎是调节免疫反应。内源性 TRAIL 在肿瘤免疫监视中的作用尚未完全清楚。少数研究明确显示 NK 细胞能用 TRAIL 杀死癌细胞；TRAIL 似乎是肝脏而非脾脏 NK 细胞用于阻止肿瘤转移的机制。TRAIL 或 TRAIL-R 缺陷小鼠对某些移植肿瘤及化学致癌更易感。TRAIL 与 TRAIL-R 缺陷动物早年不自发肿瘤，但年老 TRAIL 缺陷小鼠自发淋巴瘤易感性略增，且在至少缺失一个 p53 等位基因时更明显；但其他组发现无 p53 时 TRAIL-R 缺陷小鼠自发肿瘤不增加。尽管如此，TRAIL 的主要作用似乎与控制肿瘤转移有关：最初用移植同基因细胞系显示，后在化学诱导癌后自发转移的更生理模型中得到确认。与 PRF1 和 Fas 不同，尚未描述 TRAIL 或 TRAIL-R 的人类突变与癌症易感性升高相关。

在癌症免疫治疗方面，PRF1 与 GZM 的参与研究不深，结果也不清晰。强免疫显性 Tc 细胞表位——淋巴细胞性脉络丛脑膜炎病毒（LCMV）肽 gp33——被广泛用作模型肿瘤抗原来分析激活病毒特异性 Tc 细胞反应对癌细胞的清除。使用该模型，作者发现预防和清除多种来源的同基因移植癌细胞系依赖 PRF1 的存在，且不受 FasL 缺陷影响（手稿准备中）。多项工作试图揭示 PRF1 与死亡配体在临床免疫调节剂（如免疫刺激抗体或细胞因子）清除癌细胞中的作用，但结果因所用肿瘤模型不同而难以解读。

如 Table 1 所示，抗 CD73、抗 CTLA-4、抗 PD-1 单克隆抗体（mAb）或其组合介导的结肠、前列腺和乳腺癌细胞系体内清除不受 PRF1 缺失影响。相反，BRAF 抑制剂与激动性抗 CD137 抗体组合在黑色素瘤中的抗肿瘤效应显著依赖 PRF1，而非 FasL 或 TRAIL。作者近期发现抗 CD137 介导的 EL4 淋巴瘤小鼠清除同时依赖 PRF1 和 FasL。mAb 介导肿瘤控制中 PRF1 的贡献是由癌细胞类型还是刺激类型决定，尚需更多实验证据。

细胞因子治疗方面，多数研究集中于主要激活 NK/NKT 细胞反应的细胞因子。IL-12 或 IL-15 对黑色素瘤和肉瘤小鼠细胞系的清除依赖 PRF1 表达；IL-12 控制黑色素瘤转移也需 PRF1。相反，PRF1 缺陷不影响 IL-12 和 αGalCer（alpha-galactosylceramide）在 RENCA 肾癌模型中控制肝转移，此情况下转移被抗 TRAIL 治疗抑制。另一研究确认 PRF1 缺陷不影响 αGalCer 在 B16 黑色素瘤模型中的抗转移活性。最后，IL-12 对小鼠黑色素瘤的抗肿瘤效应依赖 PRF1；同一研究显示 IL-18 活性依赖 FasL 而不依赖 PRF1。如前所述，IL-12 在癌症免疫治疗中的效应似乎依赖模型。

另一治疗途径是过继细胞转移（ACT），即向癌症患者输注具有直接抗癌活性的细胞。部分工作分析了 ACT 中参与癌症清除的 CL 效应分子。发现 PRF1 缺陷小鼠的 Tc 或 NK 细胞在 B16 黑色素瘤模型中控制肺转移的效率与野生型相同。近期 Phil Darcy 组显示，过继 NK 细胞转移中抑制移植肉瘤细胞系生长需要 PRF1、GZMB 和 GZMM；此外，转移 NK 细胞的抗肿瘤功能需要 TRAIL，而 GZMA 缺失不影响肿瘤生长。GZMA 在该模型中缺乏抗肿瘤活性，可能由近期质疑该 GZM 及其他 GZM 细胞毒潜能的发现解释。

从这些研究可得出一个结论：在某些癌症类型中，参与免疫监视的细胞死亡执行者可能与免疫治疗激活的不同。比较相似肿瘤模型中的免疫监视与免疫治疗研究（Table 1）强烈支持该假说。例如：GZMB 缺陷小鼠对 MCA 诱导肉瘤比野生型更易感，但在过继 NK 细胞转移中控制植入肉瘤时受损；PRF1 缺陷小鼠对癌基因驱动或植入乳腺癌比野生型更易感，但在 mAb 治疗中控制植入乳腺癌细胞无问题；PRF1 缺陷增加 RENCA 肾癌模型中肝和肺转移易感性，但不影响 IL12/αGalCer 或过继 Tc 细胞治疗中的转移控制；PRF1 缺陷增加对植入前列腺癌细胞系 RM1 的易感性，但该缺陷对 mAb 介导的该细胞系控制无影响。免疫监视与/或免疫治疗中参与癌细胞清除的分子差异，可能与 CL 识别刺激的强度有关。

## 颗粒胞吐激活的凋亡与非凋亡途径

通常认为 PRF1 与 GZM 协同作用的最终后果是诱导凋亡。但这一主要来自体外模型（使用纯化 GZM 并以多种试剂递送）的过度概括结论可能不成立。近期证据表明，并非所有 GZM 都具有细胞毒潜能，CL 激活的细胞死亡机制也并非总是凋亡。首先，PRF1 本身在上述情形下可能裂解特定靶细胞；该效应仅在使用转染 PRF1 cDNA 的大鼠嗜碱性白血病细胞作为效应细胞、Jurkat 细胞为靶细胞时显示，尚需用 CL 确认。这种裂解活性取决于效应细胞递送的 PRF1 量、靶细胞膜的敏感性及/或靶细胞修复 PRF1 孔的能力。

在此背景下，GZMA 与 GZMB 双敲除小鼠的抗原特异性 Tc 和 NK 细胞在体外仍对肿瘤靶细胞具有一定诱导死亡能力，在体内腹腔杀伤中亦然，但水平低于野生型 CL。然而这类细胞死亡无明确凋亡特征，表现为膜通透化而无 caspase 激活。值得注意的是，随后显示在 GZMA 与 GZMB 缺失下被清除的细胞不显示对 DC 的“吃我”信号，且因死亡肿瘤细胞吞噬减少而不诱导抗原交叉呈递。支持该发现的是，作者发现 Tc 细胞攻击时，死亡细胞质膜上免疫原性钙网蛋白暴露需要 GZMB。

多种 GZM（包括人和小鼠 GZMA、GZMB、GZMK、GZMM 以及人 GZMH 或小鼠 GZMC）已被证明用纯化分子可在体外诱导细胞死亡。除 GZMB 明确激活涉及 caspase 及 Bcl-2 家族调控的线粒体固有途径的凋亡外，纯化 GZM 激活的细胞死亡分子机制并非凋亡，且常相互矛盾，本文不重点讨论。此外，这些 GZM 由 CL 递送时是否确实诱导细胞死亡尚不清楚：GZMM 或 GZMA 敲除小鼠的 CL 杀伤多数靶细胞无缺陷。近期多个独立组结合纯化分子与 CL 数据表明，人 GZMA 的细胞毒潜能极低甚至没有。小鼠中 GZMA 可在特定癌细胞系中诱导细胞死亡，机制需要完整的肌动蛋白骨架；该过程不具备凋亡全部特征，被命名为 athetosis。

多项使用完整 CL 的实验证据显示 GZMB 诱导靶细胞凋亡。GZMB 簇缺陷小鼠的 CL 无法诱导快速寡核小体 DNA 片段化及无膜通透性时的 PS 转位。GZMB 对 CL 介导的 caspase-3 和 Bid 激活以及肿瘤细胞中特定胞内底物（如 tubulin、Mcl-1 或 Bcl-X^L）的降解至关重要，且此时质膜仍完整。值得注意的是，GZMB 激活的细胞死亡机制可能依赖物种及细胞转化类型。人类中，GZMB 被阻断的细胞因子激活人 NK 细胞的细胞毒性大幅降低，证实 GZMB 是 CL 中主要的细胞死亡诱导者。为确认 GZMB 诱导的细胞死亡在 Tc 细胞介导的癌症免疫治疗中重要，作者采用 LCMV gp33 抗原模型，发现 Tc 细胞需要 GZMB 介导的细胞死亡来预防长期肿瘤发生（手稿准备中）。

然而，CL 经 GZMB 诱导的细胞死亡并非总是凋亡。当使用凋亡途径被阻断的靶细胞时尤为明显。发现 Tc 细胞使用 PRF1 和 GZMB 杀死固有线粒体途径和 caspase 均被阻断的细胞，凸显免疫治疗对常规治疗无反应癌细胞的潜在益处。作者近期在人类中确认，表达 GZMB 的同种异体激活 NK 细胞可清除因 p53 突变、Bcl-X_L 过表达甚至 caspase 抑制剂存在而凋亡被阻断的血液系统癌细胞。但此情形下死亡细胞表型非凋亡，PS 转位不先于膜通透性。这类细胞死亡的特征及其对免疫系统的后果正在探索中。总之，GZMB 缺失时或凋亡被阻断的靶细胞中，CL 诱导的细胞死亡可能不足以放大抗肿瘤免疫反应并建立防止未来肿瘤复发的抗肿瘤记忆。

关于其他细胞死亡方式，如上所述多项实验证据表明颗粒胞吐可诱导非凋亡性细胞死亡。目前尚不清楚焦亡、坏死性凋亡或自噬等其他死亡/存活机制是否调控 CL 执行的细胞死亡。近年发现 GZMA、GZMK 和 GZMM 等部分 GZM 具有炎症潜能，可以 caspase-1 依赖方式调控巨噬细胞产生 IL-1β、TNF-α 和 IL-6。GZMA 缺陷小鼠能抵抗脓毒症，同时不损害 Tc 细胞介导的感染巨噬细胞清除等其他保护功能。但此条件下 caspase-1 激活不导致巨噬细胞死亡，与细菌感染诱导的焦亡不同。

## 死亡配体与结语

已知死亡受体连接导致 caspase 依赖的凋亡。但在 caspase 抑制剂存在下，细胞死亡机制从凋亡转向坏死性凋亡。死亡受体诱导坏死性凋亡的分子机制涉及激酶 RIP1 和 RIP3，近期已被描述。对死亡受体诱导凋亡耐药的肿瘤细胞可能转向坏死性凋亡，这会影响免疫原性、后续免疫监视机制的作用以及免疫治疗。另一方面，TRAIL 不仅能诱导凋亡和/或坏死性凋亡，还能通过激活 NF-κB、PKB/Akt 和 MAPK 途径引发促炎反应。肿瘤细胞可利用这一点促进自身增殖、迁移和侵袭。事实上，在胰腺腺癌异种移植模型中，肿瘤细胞利用 TRAIL 促进肝转移发展。类似地，FasL 也增强凋亡抵抗癌细胞的运动性和侵袭性。更近期显示，通过 TRAIL 受体的信号可被肿瘤细胞用于促进 KRAS 驱动的肿瘤发生。

结语：CL（Tc 和 NK 细胞）是癌症免疫监视和免疫治疗中执行转化细胞死亡的主要效应细胞。但实验证据提示，免疫监视涉及的分子机制并不总与免疫治疗相同。PRF1 和 GZMB 是 CL 杀死癌细胞最有效的途径，可克服包括 p53 缺失/突变、Bcl-2 家族成员过表达或下调以及 caspase 抑制在内的抗凋亡突变。因此在这些情况下，凋亡并非 CL 介导靶细胞杀伤所必需。值得注意的是，在 GZMB 缺失（如基因突变或内源性抑制物表达）时，PRF1 本身可在敏感靶细胞中诱导细胞裂解。相反，TRAIL 似乎参与转移控制，FasL 在某些情况下可补偿 PRF1 缺陷。最初认为 CL 的主要效应途径 PRF1/GZMs 和死亡配体仅通过诱导转化细胞凋亡起作用。近期实验证据表明，在 CL 与肿瘤细胞相互作用中，非凋亡性细胞死亡途径、部分 granzyme 和死亡配体诱导的炎症以及死亡配体的促增殖效应，可能出乎意料地促进癌症进展而非控制。更好地理解 CL 在免疫治疗中实际如何杀死癌细胞，将有助于预测患者反应并选择最佳方案，获得能有效杀死肿瘤细胞而不诱导其他不良效应的激活 CL。

**Figure 1** 展示 CL 主要效应机制的激活：Tc 细胞激活是抗原特异性过程，需 TCR-CD3 复合物与 MHC I 类分子结合的加工肿瘤抗原肽相互作用及共刺激信号（CD8 和 CD28）；NK 细胞激活依赖肿瘤细胞提供的激活与抑制受体平衡。两者共享颗粒胞吐和死亡配体/死亡受体系统。CL 激活后，微管组织中心（MTOC）迅速将预形成分泌颗粒运向突触前膜，颗粒在免疫突触处与质膜融合释放内容物（perforin 和 granzymes）导致肿瘤清除。控制胞内运输、颗粒融合与释放的蛋白缺陷在不同层面影响胞吐，降低 CL 杀伤靶细胞能力。死亡配体/死亡受体介导凋亡中，CL 再激活后预形成 FasL 和 TRAIL 表达于 CL 表面，或在多囊体（MVB）与细胞接触区融合后作为外泌体膜结合死亡配体释放；再激活也诱导 FasL 和 TRAIL 从头合成，形成新的死亡配体相关外泌体并增加表面表达。FasL 和 TRAIL 与各自死亡受体相互作用杀死敏感肿瘤细胞。这些效应机制可被多种免疫调节 mAb 调控：mAb 可结合 NK 细胞 Fc 受体实现抗体依赖细胞毒性（ADCC）；阻断 CTLA-4 和 PD-1 的 mAb 分别阻止 CL 从这些分子接收的抑制或细胞死亡信号；激动性抗 CD137 等共刺激分子 mAb 增强 CL 抗肿瘤细胞毒活性。

**Figure 2** 展示 CL 对肿瘤细胞的效应机制：perforin 递送的胞内 granzyme B 可通过不同途径诱导细胞死亡。Granzyme B 可直接切割激活效应 caspase-3 和 -7；也切割促凋亡 Bcl-2 家族蛋白 Bid 生成 tBid，进而激活 Bak/Bax 在线粒体外膜寡聚化，使细胞色素 C（cyt C）释放。胞质中 cyt C、Apaf-1 和 procaspase-9 形成凋亡体激活 caspase-9。同时 Smac/DIABLO 释放阻止 XIAP 抑制功能，允许 caspase 激活。Granzyme B 还可通过诱导促凋亡 Bcl-2 家族蛋白 Bim 从与抗凋亡蛋白 Mcl-1 和 Bcl-X^L 的结合中释放来激活线粒体途径。Granzyme A 以 caspase-1 依赖机制调控促炎细胞因子（IL-1β）产生，炎症小体平台的贡献被提示但未证实。体外纯化蛋白实验中，granzyme A 还能切割 NADH dehydrogenase ubiquinone iron-sulfur protein 3（NDUFS3），诱导线粒体去极化（↓ΔΨM）和活性氧（ROS）产生；ROS 诱导 DNA 损伤及后续 DNA 修复机制激活，包括 SET 复合物从内质网（ER）转位至核。核内 granzyme A 切割 SET、pp32 和 Ape1 等 SET 复合蛋白，释放核酸酶 NM23H1，进而诱导 DNA 损伤触发细胞死亡。纯化 granzymes C、F、H、K 和 M 在 perforin 存在下可通过激活不同胞内途径诱导细胞死亡，但该能力的生理相关性受质疑。此外，granzymes K 和 M 也能调控促炎细胞因子产生。CL 诱导肿瘤细胞死亡会诱导磷脂酰丝氨酸转位、钙网蛋白及可能其他危险信号如 ATP，这些事件是免疫系统针对死亡肿瘤细胞适当激活所必需。死亡配体方面，FasL 和 TRAIL 结合各自死亡受体（FasL 结合 Fas，TRAIL 结合 TRAIL R1/2），促进受体寡聚化；寡聚化死亡受体通过死亡域同型相互作用招募衔接蛋白 FADD；FADD 的死亡效应域结合 procaspase-8 使其反式激活。活性 caspase-8 根据细胞类型触发两条凋亡途径：切割 procaspase-3 降解不同底物导致凋亡，也切割 BH3-only 促凋亡蛋白 Bid 生成 tBid 激活线粒体凋亡途径。死亡受体途径凋亡可在不同层面被抑制：c-FLIP 可与 caspase-8 竞争结合 FADD 抑制 caspase-8 激活。某些 caspase-8 失活情况下，TRAIL-Rs 及可能 Fas 连接可招募 RIP1 和 RIP3 形成坏死体，磷酸化 MLKL 促其寡聚化；MLKL 插入并通透化质膜导致坏死性细胞死亡。最后，凋亡被阻断时 TRAIL 也可触发增殖和存活信号：TRAIL-Rs 结合 TRAIL 后招募 RIP，形成含 TRAF2 和 TRADD 的次级复合物；RIP1 可促进转录因子 NF-κB 及 MAPK 和 Akt 激酶激活，促进存活信号。
