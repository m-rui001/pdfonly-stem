# WhatsHap：面向未来测序读长的加权单倍型组装

**原文：** WhatsHap: Weighted Haplotype Assembly for Future-Generation Sequencing Reads · 2015 · https://doi.org/10.1089/cmb.2014.0157

WhatsHap 是首个在 SNP 数量上以线性运行时间求解加权最小错误校正（wMEC）问题的最优算法，采用固定参数可跟踪（FPT）设计，参数为覆盖度。实验表明，覆盖度 10–15× 足以可靠地完成长读段单倍型定相，即使测序错误率显著升高（如 5%），其 switch 和 flip 错误率仍优于当前主流的统计定相方法。

## 1. 背景与问题定义

人类基因组是二倍体，每条常染色体有两个拷贝，杂合 SNP 需被分配到两个拷贝上，这一过程称为定相，所得 SNP 列表即为单倍型。现有方法分两类：一类基于基因型输入，采用统计模型整合参考 panel（如隐变量模型、MCMC），是当前的主流；另一类直接利用测序读段进行单倍型组装，遵循简约原则，目标是以最少的错误校正或读段剔除将读段分配到两个单倍型。其中最小错误校正（MEC）问题受到最多关注：给定矩阵 F，元素取 {0,1,-}，'-' 表示空洞（hole），要求通过翻转最少条目使矩阵无冲突（即存在两个单倍型 h1,h2，使得每一行至少与其中一个不冲突）。加权版本 wMEC 为每个非空洞条目赋予非负权重 w(i,j)，目标为最小化翻转总权重——当权重取 phred 对数似然时，最优解对应最大似然分群。MEC 是 NP 难的（即使片段无间隔也如此）。已有方法包括启发式（Panconesi 和 Sozio 2004；Levy 等 2007；HapCUT 等）、整数线性规划（ILP，Fouilhoux 和 Mahjoub 2012；Chen 等 2013）、精确动态规划（He 等 2010 依赖最长读长，指数级；Deng 等 2013 依赖最大覆盖度）。wMEC 最早由 Greenberg 等 2004 提出，Zhao 等 2005 给出特例启发式并显示加权优于非加权。这些方法的共同缺陷是：要么依赖变体沙漠（variant deserts）进行分解，要么无法处理长读段与高错误率的组合。WhatsHap 则针对未来长读段（数千至数万碱基）且错误率升高的情况，首次实现线性时间求解 wMEC。

## 2. 动态规划算法

WhatsHap 采用精确的动态规划。定义片段 i 在左端非空洞条目到右端非空洞条目之间的所有列均为“活跃”。令 F(j) 为 SNP 位置 j 的活跃片段集合，F 为全部片段。目标为找到 F 的一个二划分 (R,S)，使校正代价最小。对每个位置 j，定义 W0(j,R) 为将 R 中所有片段在 j 位置设为 0 所需翻转权重之和，W1 类似（即 W0(j,R)=∑_{i∈R, F(i,j)=1} w(i,j)，W1(j,R)=∑_{i∈R, F(i,j)=0} w(i,j)）。列 j 的贡献为 ΔC(j,(R,S)) = min{ W0(j,R), W1(j,R) } + min{ W0(j,S), W1(j,S) }；若强制所有 SNP 杂合，则改为 min{ W0(j,R)+W1(j,S), W1(j,R)+W0(j,S) }。

DP 表 C(j,B) 表示所有满足前 j 列无冲突且扩展 B 的划分的最小代价，其中 B 为 F(j) 的二划分。初始化时 C(1,·)=ΔC(1,·)。递推式为：C(j+1,(R,S)) = ΔC(j+1,(R,S)) + min_{B∈B(F(j)|(R_{j+1}, S_{j+1}))} C(j,B)，其中 R_{j+1}=R∩(F(j)∩F(j+1))，并预先投影列 C̄(j,B') = min_{B0∈B(F(j)|B')} C(j,B0) 以加速。由于对称性只需存储半数的 2^{|F(j)|-1} 个二分划；用 Gray 码枚举所有划分，每次只移动一个片段，可在常数时间更新 W 值。算法复杂度为 O(2^{k-1} m)，其中 k 为最大覆盖度，m 为 SNP 数，与读长无关。回溯时存储最右列和辅助表 D(j,B)，空间 O(2^{k-1}m)。最终从最优二分划 Rj*,Sj* 推出单倍型：h1(j)=0 若 W0(j,Rj*)<W1(j,Rj*)，否则 1；h2 同理。

## 3. 实验结果

由于目前尚无真实长读段数据，作者采用模拟：以 Levy 等（2007）报道的 J. Craig Venter 基因组全部变体（SNP、缺失、插入、倒位）重建二倍体人类基因组（参考为 hg18），利用 SimSeq 按 HiSeq/MiSeq 错误谱生成 2×100 bp 和 2×250 bp 双端读段（内部片段长度分别 100/250 bp），另模拟 1,000/5,000/10,000/50,000 bp 的长读段，均匀错误率 1% 或 5%。所有数据平均覆盖 30×，用 BWA MEM 比对到人类基因组，仅使用真杂合 SNP 位置，提取覆盖至少两个 SNP 的读段，再修剪至目标覆盖 5×、10×、15×。权重取 phred 刻度，即权重 X 对应错误概率 10^{-X/10}。

**与现有方法比较（单位权重、all-het 假设）**：在 Venter 基因组 1 号染色体上，与 He 等（2010）、Deng 等（2013）和 Chen 等（2013 ILP）对比。He 的方法在 5 小时时限内几乎无法完成任何实例；Deng 的 DP 在低覆盖时略快，但在 15× 时 WhatsHap 显著更快（如 2×100 HiSeq 覆盖 15× 时，WhatsHap 62.6 秒 vs Deng 377.8 秒；长读段 1×1000 时 WhatsHap 192.6 秒 vs Deng 3701.5 秒）。复杂度上 WhatsHap 为 O(n2^k)，而 Deng 为 O(nk2^k)，节省因子 k 得益于 Gray 码工程实现。ILP 方法运行时间很长（数百秒以上），但不受覆盖度影响，归因于其预处理（如去重）仅适用于非加权情况。

**定相准确性**：将无法定相位置定义为未覆盖 SNP 数加上不连续间隙数（breaks）。误差分为三类：翻转错误（孤立位点翻转）、交换错误（连续两个 SNP 相位颠倒）和歧义错误（翻转 0/1 不改变 wMEC 得分，随机定相，预期一半出错）。图 2（按正文描述）显示：当前代短读段（HiSeq/MiSeq）有大量无法定相位置（如 2×100 HiSeq 覆盖 5× 时约 48994 个无法定相位置，而长读段 1×5000 仅约 12693 个），长读段使无法定相位置大幅减少；相位错误率仅 0.1–0.25%，而统计定相方法通常至少 1%（参见 O'Connell 等 2014）。覆盖度超过 10–15× 后错误率不再显著改善，因此 10–15× 已足够。

**权重的好处**：表 2 对比加权与非加权（uw/w）在覆盖 15× 下的误差。所有数据集中，加权情况的歧义位置数更少（如 1×50000 (1%) 的歧义位置从 51 降至 6），尽管 flip/switch 误差略有增加（如 1×50000 (1%) 从 27+30 增至 30+123），但按歧义位置一半计为误差，总体相对减少近 10%（计算：原误差 (27+30+51/2)/(27+30+51) 与加权后 (30+123+6/2)/(30+123+6) 比较）。该优势在所有数据集普遍存在，尤其对长读段和高错误率（5%）情形。

## 4. 结论与展望

WhatsHap 是首个精确求解 wMEC 且运行时间线性于 SNP 数的方法，特别适合长读段与高错误率组合。局限在于覆盖度上限（标准工作站可处理 20×，更高覆盖需剪枝或分治启发式）。未来工作包括：分治并合并超读段、集成统计定相结果实现混合方法、将单倍型从 SNP 扩展到非 SNP 变异，以及利用线性时间特性进行“从头”单倍型构建（由于 SNP 约占 5% 位点，平均运行 10 分钟，全基因组约 3 小时），可用于 SNP 发现。
