# 用于多视图立体重建的大规模数据集

**英文原题**：Large-Scale Data for Multiple-View Stereopsis (2016, DOI: https://doi.org/10.1007/s11263-016-0902-9)

本文提出了一套面向多视图立体（MVS）评估的大规模数据集，包含80个不同场景，每个场景由49或64个精确相机位拍摄，并配有结构光参考扫描，所有图像在7种光照条件下获取。作者扩展了Middlebury评估协议，以处理复杂几何场景中的遮挡与缺失数据，并将其应用于三种代表性MVS算法（Tola等、Furukawa等、Campbell等），揭示出精度与完整性之间的权衡，同时发现网格化和缺少纹理是当前MVS的主要瓶颈。该数据集与评估框架已免费公开，为MVS研究提供了统计上可靠的基准。

## 引言与相关工作

已有的MVS基准（如Middlebury的两场景数据集和Strecha等的六场景数据集）虽然推动了技术发展，但规模较小，限制了结论的泛化。本文通过构建80个场景的数据集（比现有规模大近一个量级）来解决这一问题，旨在回答“何种场景特征导致MVS失败”而非仅比较算法优劣。相关工作分为点云方法和体积方法；本文聚焦于点云方法，并识别出特征扩展（如Fur）和深度图融合（如Cam、Tol）两种范式，但强调实验目的并非直接比较算法，而是揭示场景类型对性能的影响。

## 数据采集与组成

数据集在受控环境中使用六轴工业机器人搭载相机与结构光扫描仪采集。图像分辨率为1200×1600像素（8位RGB），光圈小、景深足够。场景类别包括16个模型房屋、7个建筑材质、11个杂货、6个水果蔬菜和7个毛绒玩具，并刻意覆盖几何复杂度、高光反射和纹理缺失等变化，但未包含极薄结构以免参考数据不准确。59个场景使用49个相机位（半径50厘米球面），21个场景额外增加15个位置（半径65厘米），以支持尺度变化研究。

参考扫描采用二进制灰度编码的结构光，平均每个场景含1340万个点，但存在自遮挡和曝光不足导致的不完整。为了评估精度，使用一个保龄球作为已知几何物体，测得球心位置的标准差为0.17毫米，表面点标准差为0.14毫米（约0.6像素）。机器人重复定位精度很高，采集期间10次校准的平均标准差为0.0552毫米，重投影误差仅0.067像素。光照变化通过天花板上的16个LED实现，每个相机位拍摄7种光照模式（其中一种为全亮的漫射模拟），以模拟不同时刻的光照条件。

## 评估协议

协议以Middlebury为基础，但引入关键修改。精度定义为MVS点到参考点的距离，完整性定义为参考点到MVS点的距离；两者均以去除20毫米以上离群值后的均值和中位数表征。由于复杂几何场景存在自遮挡，参考扫描有孔洞，故放弃Middlebury的孔洞填充法，而是显式计算一个体素大小为1毫米³的观测掩码：从每个结构光点沿相机光线传播，并将点后10毫米范围内的体素标记为已观测。掩码用于忽略不可观测区域的精度和完整性计算。

针对点云采样密度不均匀的问题，采用随机降采样至间距不小于0.2毫米（该值约为扫描精度的保守估计），以等价地对待所有表面区域。对降采样影响的验证显示，均值差异为0.0631毫米、中位数差异为0.0301毫米，远小于算法间的性能差异。网格化表面通过均匀采样三角形并降采样至同样密度来评估。最终协议包括四个步骤：降采样、计算完整性分布、在掩码内计算精度分布、去除离群值后取均值与中位数。对0.2毫米阈值、20毫米离群值阈值和10毫米射线扩展长度分别进行±10%的敏感性分析，均值影响约百分之一毫米，表明协议对参数不敏感。

## 实验与结论

使用Campbell等（Cam）、Furukawa等（Fur）和Tola等（Tol）的原始实现，未调节参数，但统一使用泊松重建（深度11，去除深度小于8的区域）生成三角网格。两个实验：80场景的满光照全量评估和10场景的随机光照方向变化评估。统计分析采用方差分析（ANOVA），模型为：

$$y_{ijk} = \mu + a_i + s_j + m_k + as_{ij} + am_{ik} + sm_{jk} + \epsilon_{ijk}$$

（全量实验）以及

$$y_{ijn} = \mu + a_i + s_j + l_n + as_{ij} + al_{in} + sl_{jn} + \epsilon_{ijn}$$

（光照实验），其中性能为精度/完整性的均值或中位数。全量结果（表3）显示：Tol精度最高（均值0.408毫米）但完整性最低（均值1.040毫米）；Cam完整性最高（均值0.551毫米）但精度最低（均值1.082毫米）；Fur居中（0.952毫米和0.772毫米）。网格化显著影响精度（使用网格时均值0.562毫米，未使用为1.066毫米），但完整性几乎不变（0.829对0.746毫米），且网格化对Tol的完整性略降、对Fur和Cam的精度有损害。所有主效应与交叉效应均在p<0.001显著，证明数据集规模足以支撑统计推断。

场景类别分析显示，模型房屋和建筑材质最易恢复，而杂货等无纹理高光物体较难。三种方法在不同场景上的性能高度相关（相关系数矩阵：Tol-Fur 0.8333，Tol-Cam 0.6011，Fur-Cam 0.7764），且无聚类趋势，说明场景特征对各算法的影响一致。光照变化实验中，随机组合各视角的不同光照图像后重建，精度几乎不变（均值0.576毫米对0.576毫米），完整性仅轻微下降（均值0.735毫米对0.832毫米，p<0.001）。作者猜想这是因为MVS方法基于多视图匹配的鲁棒聚合，只要对每部分表面存在少数匹配良好的图像对，结果就不会严重退化。

点云与网格的对比表明，点云重建整体优于网格，因为泊松重建的平滑先验在简单几何（如平坦或球形表面）上有助于填补无纹理孔洞，但会破坏细节并可能产生幻影表面。例如，模型房屋上的精细天线（约1毫米粗）在点云中被还原，但网格化后丢失。结论指出，当前MVS的两大瓶颈是缺少纹理和网格化步骤，而高光与光照变化的影响低于预期。未来工作拟通过单原子表面属性的数据集进一步分离影响。
