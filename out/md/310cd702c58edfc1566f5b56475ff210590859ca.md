# 全球陆地生态系统氮与磷限制的空间格局

**Global patterns of terrestrial nitrogen and phosphorus limitation** · 2020 · DOI: https://doi.org/10.1038/s41561-019-0530-4

本研究基于全球171个样点优势物种的叶片氮、磷再吸收效率比值（NREdom/PREdom），构建了首个全球陆地氮（N）与磷（P）限制格局图，并用106个N限制和53个P限制的施肥实验站点数据验证了预测。作者估计，在排除农田、城市和冰川区域后，全球自然陆地面积中约18%受N单独显著限制，43%相对受P限制，其余39%可能受N与P共同限制或受任一养分弱限制。这一工作为检验养分限制提供了新框架，也为植被和地球系统模型约束陆地碳汇预测提供了N、P限制基准。

## 背景与指标构建

陆地植物初级生产力普遍受必需养分（尤其是N和P）限制。基岩风化假说预测，从地质年轻的高纬度生态系统到热带森林，P限制逐渐增强，因为后者几乎没有可风化的岩石P；而生物固氮和N矿化则呈现相反的纬度趋势，导致N限制向极地方向增强。火干扰通常挥发更多N而非P，可能加剧易火生物群区（如北方森林）的N限制；人为N沉降会增加热点区域的P限制；升高的CO2和变暖导致的生长季延长也可能加剧陆地生态系统的养分限制。以往推断养分限制的方法各有局限：施肥实验虽可直接检验限制，但全球整合分析发现的纬度趋势不一致；叶片N:P比阈值（如14:1与16:1，或10:1与20:1）存在较大不确定性。叶片N再吸收效率（NRE）和P再吸收效率（PRE）分别随N、P有效性降低而升高，反映了植物体内养分循环与根系吸收之间的权衡。Han等（2013）提出用NRE与PRE之差指示木本植物的N、P限制，但未发现显著纬度和气候趋势；Reed等（2012）发现NRE/PRE比值随纬度升高而增加，并随年均温（MAT）和年降水量（MAP）降低而增加，但两者均基于单个物种，不一定代表生态系统层面的限制。

基于化学计量内稳性理论和利比希最小因子定律，作者定义了用植物叶片NRE和PRE估计生态系统尺度N、P相对限制的指标。叶片养分需求由内部再吸收养分和外部环境获取养分共同满足。为维持成熟叶片功能，N与P的需求比应相对稳定，即叶片再吸收的N与P之比（NRE/PRE）应等于成熟叶片的N:P质量比（Eq. 3: NRE/PRE > 成熟叶片N:P质量比）。整理后可得：当NRE/PRE > 1（或其自然对数值> 0）时，N相对P更限制；当NRE/PRE < 1（或其自然对数值< 0）时，P相对N更限制。一个初步检验是：共生固氮植物被认为相对更受P限制，其NRE/PRE应低于1。数据库中37种固氮植物的ln(NRE/PRE)平均值为-0.30 ± 0.05，显著低于0（p < 0.001），支持了该指标的有效性。在生态系统尺度上，理论上应用所有物种的叶片质量加权平均NRE与PRE之比来指示N、P限制，但由于物种叶片质量数据常与NRE、PRE同时报告的很少，作者采用优势物种的站点平均NREdom与PREdom之比作为近似指标。后续验证表明，基于NREdom/PREdom诊断的限制养分与NuLi数据库中田间施肥实验结果吻合良好。

## 全球数据与模型预测

作者构建了陆地植物成对N、P再吸收效率数据库（PRENP, 版本1.0），仅纳入同时测定NRE和PRE的研究，共含925条观测、585个物种、135篇文献，其中171个站点有优势物种数据（627条观测、377个优势种）。数据来源为Web of Science、Google Scholar和中国知网，检索关键词为“nitrogen resorption”和“phosphorus resorption”；为避免人为干扰干扰自然养分限制信号，排除了集约管理生态系统（如农林复合系统、施肥人工林、播种草地、农田、城市森林）的数据。此外，基于84篇文献中的施肥实验，编制了田间诊断养分限制数据库（NuLi, 版本1.0），包含N限制站点106个、P限制站点53个。

NREdom/PREdom呈对数正态分布（Shapiro-Wilk检验，W=0.99, p=0.11），全球几何均值为0.90（中位数0.90），其中NREdom几何均值55%（中位数57%），PREdom几何均值61%（中位数63%）。NREdom与PREdom的最大值（第95-100百分位，分别为81-86%和80-87%）相近，说明生态系统尺度上N和P的最大再吸收效率相似。

为预测全球N、P限制格局，作者考虑了11个潜在预测因子：气候变量（MAT、MAP、温度季节性、降水季节性）、土壤肥力变量（N沉降、土壤黏粒含量、土壤pH、阳离子交换量CEC）和植被特征变量（植被类型、总初级生产力GPP、归一化植被指数NDVI）。基于校正Akaike信息准则（AICc）的模型选择显示，最优模型包含MAT、MAP、温度季节性、降水季节性、土壤黏粒含量、MAT与MAP的交互项以及植被类型（即木本生态系统与草地之间），偏差解释率为54%。模型选择依据预测因子的相对重要性（基于Akaike权重和），剔除了土壤pH、CEC、NDVI、GPP和N沉降。诊断检验表明线性模型满足同方差性、多元正态性、残差独立性且不存在明显多重共线性。

在气候因子中，偏回归分析显示ln(NREdom/PREdom)随MAT升高（p < 0.001）、温度季节性增大（p < 0.001）和MAP升高（p < 0.001）显著下降，但随降水季节性增大而显著上升（p < 0.001）。NREdom/PREdom随MAT和MAP的变化主要归因于NREdom的显著下降，这可能是由于P有效性主要由成土母质决定，而N有效性主要由依赖气候的生物固氮和矿化决定。MAT与MAP存在显著交互作用（p < 0.01），可能部分因为温度通过促进蒸发而抵消额外降水的作用。土壤黏粒含量升高时NREdom/PREdom显著下降（p < 0.001），因为高黏粒土壤通常风化强烈、P有效性偏低。草地比木本生态系统有显著更低的NREdom/PREdom（p < 0.001），表明草地中植物对P的保存更为重要。受气候、土壤和植被变量驱动，NREdom/PREdom随纬度升高显著增加（p < 0.001），其中NREdom的纬度趋势强于PREdom。作者同时用全部11个预测因子训练了随机森林模型，但交叉验证R²显示线性模型用更少预测因子即获得更优统计表现，因此最终用线性模型在全球1×1 km分辨率上进行预测（图3a）。

## 全球格局与验证

预测结果显示出强烈的纬度格局，并与田间N、P限制实验结果（NuLi数据库）吻合较好：在ln(NREdom/PREdom)绝对值大于0.16（模型残差标准误为0.16）的统计有效范围内，模型对N限制的诊断成功率为83%（38/46），对P限制的成功率为83%（25/30）。低纬度的一些高海拔区域（如青藏高原、安第斯山脉、南非高原）出现向N限制的转变，可能归因于海拔下降引起的温度降低及土壤和植被变化。

排除农田、城市和冰川区域后，模型估计18%的自然陆地面积显著受N限制（ln(NREdom/PREdom) > 0.16），43%受P限制（ln(NREdom/PREdom) < -0.16），39%无法诊断（ln(NREdom/PREdom)介于-0.16与0.16之间，可能指示N、P共限制或任一养分弱限制）。按生物群区汇总：N限制主要见于北方森林、苔原、温带针叶林和高山草地与灌木地；P限制更常见于热带和亚热带森林、温带阔叶和混交林、荒漠、地中海生物群区以及热带、亚热带和温带的草地、稀树草原和灌木地。

作者指出，以往针对单个物种的研究提供了重要但不完整的生态系统尺度养分限制信息，本文基于站点尺度NREdom/PREdom的方法可部分克服这一挑战。由于方法不确定性，部分自然生态系统未被确定限制养分；未来研究若能获取按物种叶片质量或丰度加权的生态系统平均NRE/PRE数据，并同时开展施肥实验对照，将有助于提高诊断精度。N和P以外的养分（如钾、钙及其他微量元素）也可限制陆地产量，但不太可能在全局尺度上成为限制因子。作者强调，该地图的稳健性来自基于经验数据模型选择确定的驱动变量，并与田间实验结果一致。模型提供的是静态的全球N、P限制格局，但许多因子可能重组这一格局：人为N沉降可将部分地区从N限制转变为P限制；CO2富集可能通过增加生物量中的养分积累而加剧养分限制；气候变暖可能通过促进中高纬度固氮和N矿化而改善N有效性。该工作提供的全球N、P限制数据有望帮助植被模型和地球系统模型约束N沉降、CO2升高和气候变化情景下的陆地碳循环预测。

## 方法与补充说明

养分再吸收效率（NuR, %）定义为衰老期间基于质量的养分净回收比例，即 NuR = (1 − 衰老叶养分含量/成熟绿叶养分含量) × 100（Eq. 5）。若原始研究采用基于浓度的再吸收效率，则使用质量损失校正因子（MLCF）转换为基于质量的数值（Eq. 7），MLCF对不同植物功能型取值分别为：常绿阔叶0.780，落叶阔叶0.784，针叶树0.745，草本0.640，禾草类0.713。统计分析中，若一个站点报告了多种优势种，则NREdom和PREdom分别取平均值；若同一站点多年观测，也跨年取均值；木本生态系统仅使用冠层优势种数据。所有预测变量均进行零中心化处理（原始值减去均值）以降低多重共线性，相应均值：MAT 12.39°C，MAP 1196 mm，温度季节性665.55，降水季节性58.53，土壤黏粒21.46%，土壤pH 6.22，CEC 19.52 mmol kg⁻¹，N沉降9.88 kg N ha⁻¹ yr⁻¹，GPP 0.11 kg C m⁻² yr⁻¹，NDVI 0.56。诊断分析显示模型残差无显著空间自相关（Moran's I = 0.034, 期望值-0.006, p=0.196），混合效应模型检验未发现年份或研究者随机效应破坏线性模型稳健性。数据可用性声明指出所有支持数据存放在figshare（https://doi.org/10.6084/m9.figshare.10735652.v1），代码可联系通讯作者获取。
