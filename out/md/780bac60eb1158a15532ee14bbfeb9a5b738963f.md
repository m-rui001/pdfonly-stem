# 基于 DREAM 软件包的马尔可夫链蒙特卡洛模拟：理论、概念与 MATLAB 实现

Jasper A. Vrugt，2015，DOI: 10.1016/j.envsoft.2015.08.013

## 引言与贝叶斯推断框架

本文旨在综述马尔可夫链蒙特卡洛（MCMC）模拟的基本理论，并介绍由 Vrugt 等人（2008a, 2009a）开发的 DiffeRential Evolution Adaptive Metropolis（DREAM）算法的 MATLAB 工具箱。该工具箱为科学家和工程师提供了一套完整的选项和工具，用于求解涉及双峰性、高维性、摘要统计量、有界参数空间、动态模拟模型、形式/非形式似然函数（GLUE）、诊断模型评估、数据同化、贝叶斯模型平均、分布式计算以及信息/非信息先验分布等后验采样问题。DREAM 工具箱支持并行计算，并包含采样链轨迹的收敛分析和结果后处理工具。七个不同的案例研究展示了该 MATLAB 工具箱的主要能力和功能。

贝叶斯推断在科学与工程中广泛应用，用于将地球系统模型与数据调和，包括空间预测（插值）、时间预测（预报）、观测与确定性/随机模型输出的同化，以及模型参数的推断。贝叶斯定理指出，假设 H 的后验概率 $p(H|\tilde{\mathbf{Y}})$ 正比于该假设的先验概率 $p(H)$ 与给定新观测 $\tilde{\mathbf{Y}}$ 下同一假设的似然 $L(H|\tilde{\mathbf{Y}})$ 的乘积，即 $p(H|\tilde{\mathbf{Y}}) \propto p(H)L(H|\tilde{\mathbf{Y}})$。在科学与工程中，H 通常构成某个数值模型 $\mathcal{F}(\mathbf{x})$，它以代数方程和微分方程概括了关于目标系统的所有知识，而未知参数值 $\mathbf{x}$ 则通过数据 $\tilde{\mathbf{Y}}$ 进行推断。然而，对于复杂系统模型，后验分布往往是高维且解析不可处理的，需要采样方法来近似目标分布。

若 $\tilde{\mathbf{Y}}={\tilde{y}_1,\dots,\tilde{y}_n}$ 表示在时刻 t = {1,...,n} 的离散测量向量，概括了某环境系统 $\mathfrak{J}$ 对强迫变量 $\mathbf{U}={\mathbf{u}_1,\dots,\mathbf{u}_n}$ 的响应，则观测数据与物理系统的联系为 $\tilde{\mathbf{Y}} \leftarrow \Im(\mathbf{x}^*) + \varepsilon$，其中 $\mathbf{x}^* = {x_1^*,\dots,x_d^*}$ 是未知参数，$\boldsymbol{\varepsilon}={\varepsilon_1,\dots,\varepsilon_n}$ 是 n 维测量误差向量。当物理过程的假设或模拟器 $\mathbf{Y} \leftarrow \mathcal{F}(\mathbf{x}^*,\tilde{\mathbf{u}},\tilde{\psi}_0)$ 可用时，数据可建模为 $\tilde{\mathbf{Y}} \leftarrow \mathcal{F}(\mathbf{x}^*,\tilde{\mathbf{U}},\tilde{\psi}_0) + \mathbf{E}$，其中 $\tilde{\psi}_0 \in \Psi \in \mathbb{R}^{\tau}$ 表示 $\tau$ 个初始状态，$\mathbf{E}={e_1,\dots,e_n}$ 包括观测误差（强迫和输出数据）以及由于模拟器 $\mathcal{F}(\cdot)$ 可能与真实系统 $\mathfrak{J}(\mathbf{x}^*)$ 存在系统性差异而产生的误差。后者可能源于数值误差（求解器和离散化不充分）以及模型公式化和/或参数化不当。

采用贝叶斯形式，模型参数的后验分布可通过将模型的时空行为以观测系统响应的测量为条件来推导：$p(\mathbf{x}|\tilde{\mathbf{Y}}) = \frac{p(\mathbf{x})p(\tilde{\mathbf{Y}}|\mathbf{x})}{p(\tilde{\mathbf{Y}})}$，其中 $p(\mathbf{x})$ 和 $p(\mathbf{x}|\tilde{\mathbf{Y}})$ 分别表示先验和后验参数分布，$L(\mathbf{x}|\tilde{\mathbf{Y}}) \equiv p(\tilde{\mathbf{Y}}|\mathbf{x})$ 表示似然函数。证据 $p(\tilde{\mathbf{Y}})$ 作为归一化常数（标量），使后验分布积分为 1：$p(\tilde{\mathbf{Y}}) = \int_{\mathcal{X}} p(\mathbf{x})p(\tilde{\mathbf{Y}}|\mathbf{x})\mathrm{d}\mathbf{x} = \int_{\mathcal{X}} p(\mathbf{x},\tilde{\mathbf{Y}})\mathrm{d}\mathbf{x}$，在参数空间 $\mathbf{x} \in \chi \in \mathbb{R}^d$ 上积分。实践中，$p(\tilde{\mathbf{Y}})$ 不需要用于后验估计，因为所有关于 $p(\mathbf{x}|\tilde{\mathbf{Y}})$ 的统计推断都可以从非归一化密度 $p(\mathbf{x}|\tilde{\mathbf{Y}}) \propto p(\mathbf{x})L(\mathbf{x}|\tilde{\mathbf{Y}})$ 得出。

如果暂时假设先验分布 $p(\mathbf{x})$ 定义良好，那么主要问题在于似然函数 $L(\mathbf{x}|\tilde{\mathbf{Y}})$ 的定义，该函数用于概括模型模拟与相应观测之间的距离。如果误差残差假设为不相关，则 n 维误差残差向量的似然可写为 $L(\mathbf{x}|\tilde{\mathbf{Y}}) = f_{\tilde{y}_1}(y_1(\mathbf{x})) \times f_{\tilde{y}_2}(y_2(\mathbf{x})) \times \dots \times f_{\tilde{y}_n}(y_n(\mathbf{x})) = \prod_{t=1}^n f_{\tilde{y}_t}(y_t(\mathbf{x}))$，其中 $f_a(b)$ 表示 a 在 b 处的概率密度函数。如果进一步假设误差残差服从正态分布 $e_t(\mathbf{x}) \overset{D}{\sim} \mathcal{N}(0,\widehat{\sigma}_t^2)$，则方程变为 $L(\mathbf{x}|\tilde{\mathbf{Y}},\widehat{\sigma}^2) = \prod_{t=1}^n \frac{1}{\sqrt{2\pi\widehat{\sigma}_t^2}} \exp\left[-\frac{1}{2}\left(\frac{\tilde{y}_t - y_t(\mathbf{x})}{\widehat{\sigma}_t}\right)^2\right]$，其中 $\widehat{\sigma}={\widehat{\sigma}_1,\dots,\widehat{\sigma}_n}$ 是观测测量误差标准差的 n 维向量。该公式允许同方差（常数方差）和异方差测量误差（方差依赖于数据幅度）。出于数值稳定性和代数简洁性，通常使用对数似然 $\mathcal{L}(\mathbf{x}|\tilde{\mathbf{Y}},\hat{\boldsymbol{\sigma}}^2) = -\frac{n}{2}\log(2\pi) - \sum_{t=1}^n{\log(\hat{\sigma}_t)} - \frac{1}{2}\sum_{t=1}^n\left(\frac{\tilde{y}_t - y_t(\mathbf{x})}{\hat{\sigma}_t}\right)^2$。

如果误差残差 $\mathbf{E}(\mathbf{x})=\tilde{\mathbf{Y}}-\mathbf{Y}(\mathbf{x})={e_1(\mathbf{x}),\dots,e_n(\mathbf{x})}$ 表现出时间（或空间）相关性，则可以在推导对数似然函数时显式考虑。例如，假设误差残差服从 AR(1) 过程 $e_t(\mathbf{x}) = c + \phi e_{t-1}(\mathbf{x}) + \eta_t$，其中 $\eta_t \overset{D}{\sim} \mathcal{N}(0,\widehat{\sigma}_t^2)$，期望 $\mathbb{E}[e_t(\mathbf{x})]=c/(1-\phi)$，方差 $\operatorname{Var}[e_t(\mathbf{x})]=\widehat{\sigma}^2/(1-\phi^2)$。这导致以下对数似然公式：$\mathcal{L}(\mathbf{x}|\tilde{\mathbf{Y}},c,\phi,\widehat{\sigma}^2) = -\frac{n}{2}\log(2\pi) - \frac{1}{2}\log[\widehat{\sigma}_1^2/(1-\phi^2)] - \frac{(e_1(\mathbf{x})-[c/(1-\phi)])^2}{2\widehat{\sigma}_1^2/(1-\phi^2)} - \sum_{t=2}^n{\log(\widehat{\sigma}_t)} - \frac{1}{2}\sum_{t=2}^n\left(\frac{(e_t(\mathbf{x})-c-\phi e_{t-1}(\mathbf{x}))}{\widehat{\sigma}_t}\right)^2$，其中 $|\phi|<1$ 表示一阶自回归系数。如果假设 c 为零（无长期趋势），则方程经重新排列后简化为 $\mathcal{L}(\mathbf{x}|\tilde{\mathbf{Y}},\phi,\hat{\sigma}^2) = -\frac{n}{2}\log(2\pi) + \frac{1}{2}\log(1-\phi^2) - \frac{1}{2}(1-\phi^2)\widehat{\sigma}_1^{-2}e_1(\mathbf{x})^2 - \sum_{t=2}^n{\log(\widehat{\sigma}_t)} - \frac{1}{2}\sum_{t=2}^n\left(\frac{(e_t(\mathbf{x})-\phi e_{t-1}(\mathbf{x}))}{\widehat{\sigma}_t}\right)^2$，且冗余变量 ${\phi,\hat{\sigma}}$ 与模型参数 x 一起使用观测数据 $\tilde{\mathbf{Y}}$ 进行推断。

该方程假设误差残差先验服从平稳 AR(1) 过程，这一假设对实际研究可能不太现实。因此，多位作者提出了替代的似然函数公式，以扩展到误差残差非高斯、具有不同峰度和偏度的情况（Schoups and Vrugt, 2010; Smith et al., 2010; Evin et al., 2013; Scharnagl et al., 2015）。潜变量也可用于增强似然函数，更好地考虑强迫数据和模型结构误差（Kavetski et al., 2006a; Vrugt et al., 2008a; Renard et al., 2011）。对于具有生成性（负）反馈的系统，初始状态误差无害，因为其影响随时间迅速减弱。因此可以利用预热期来消除建模结果（和误差残差）对状态值初始化的敏感性。

一旦定义了先验分布和似然函数，贝叶斯分析剩下的就是概括后验分布，例如通过均值、协方差或单个参数和/或冗余变量的百分位数。然而，大多数动态系统模型高度非线性，这项任务无法通过解析方法或解析近似完成。从经典一阶近似构建的置信区间只能提供后验分布的近似估计。此外，目标被假设为多元高斯（$\ell^2$ 范数型似然函数），这是一个限制性假设。因此，我求助于蒙特卡洛（MC）模拟方法来生成后验分布的样本。

研究现象、通过实验和数据收集获取新信息、并通过贝叶斯分析完善现有理论和知识的过程与科学方法有许多共同要素。这个框架如图 2 所示，被地球科学的许多分支采用，旨在阐明支配自然世界的规律。

在之前的一篇论文中，我们介绍了 DiffeRential Evolution Adaptive Metropolis (DREAM) 算法（Vrugt et al., 2008a, 2009a）。这种多链马尔可夫链蒙特卡洛（MCMC）模拟算法在通往目标分布的过程中自动调整提议分布的尺度和方向，并在复杂、高维和多模态目标分布上表现出优异的采样效率。DREAM 是 Shuffled Complex Evolution Metropolis（Vrugt et al., 2003）算法的改编，具有保持细致平衡和遍历性的优势。基准实验表明，DREAM 优于其他自适应 MCMC 采样方法，在高维搜索/变量空间中甚至比常用优化算法提供更好的解。

短短几年内，DREAM 算法已在众多不同领域得到广泛应用，包括大气化学、生物地球科学、生物学、化学、生态水文学、生态学、经济学和定量金融、流行病学、地球物理学、地质统计学、水文地球物理学、水文地质学、水文学、物理学、心理学、土壤水文学和交通工程等。许多出版物使用了 DREAM 的 MATLAB 工具箱，该工具箱由本文作者开发和编写，并与世界各地的许多人共享。然而，DREAM 工具箱从未通过软件出版物正式发布，记录如何使用该代码进行贝叶斯推断和后验探索。

本文综述了马尔可夫链蒙特卡洛（MCMC）模拟的基本理论，提供了一些常用后验采样方法的 MATLAB 脚本，并介绍了 DREAM 算法的 MATLAB 工具箱。该 MATLAB 工具箱为科学家和工程师提供了一套全面的能力，用于将 DREAM 算法应用于贝叶斯推断和后验探索。DREAM 工具箱实现了多核计算（如果用户需要），并包含采样链轨迹的收敛分析和结果后处理工具。还描述了工具箱的最新扩展，包括（除其他外）内置功能，支持使用非形式似然函数（Beven and Binley, 1992; Beven and Freer, 2001）、摘要统计量（Gupta et al., 2008）、近似贝叶斯计算（Nott et al., 2012; Sadegh and Vrugt, 2013, 2014）、诊断模型评估（Vrugt and Sadegh, 2013）以及可接受性 limits 框架（Beven, 2006; Beven and Binley, 2014）。这些发展部分是对使用系统行为摘要统计量的模型诊断新兴范式的回应。最近的工作表明，这种方法比传统的基于残差的范式能更好地指导模型故障及相关问题（Sadegh et al., 2015b; Vrugt, submitted for publication）。DREAM 工具箱的主要能力通过七个不同的案例研究展示，涉及（例如）双峰性、高维性、摘要统计量、有界参数空间、动态模拟模型、形式/非形式似然函数、诊断模型评估、数据同化、贝叶斯模型平均、分布式计算、信息/非信息先验分布以及可接受性 limits。这些示例研究易于运行和修改，可作为其他推断问题的模板。

本文遵循同一期刊上其他人关于在高层次统计语言（如 R）以及通用语言（如 Fortran）中实现 DREAM 的论文。其他未发布的 DREAM 版本包括 C 和 Python 代码。这些不同的代码让潜在用户可以选择他们偏好的语言，但这些翻译基于作者几年前提供的源代码，与本文描述的 MATLAB 包相比功能有限。本代码与其早期版本的不同之处在于它包含了一套新选项和新方法学发展（Vrugt and Sadegh, 2013; Sadegh and Vrugt, 2014; Vrugt, 2015a, submitted for publication）。

## 后验探索与 MCMC 方法

贝叶斯推断的一个关键任务是概括后验分布。当这项任务无法通过解析方法或解析近似完成时，可以使用蒙特卡洛模拟方法从后验分布生成样本。然后从样本中获得所需的后验分布概括。后验分布，也称为目标分布或极限分布，通常是高维的。已经开发了大量迭代方法从后验分布生成样本。所有这些方法都以某种方式依赖于蒙特卡洛模拟。

蒙特卡洛方法是一类广泛的计算算法，使用重复随机采样来近似某些多元概率分布。最简单的蒙特卡洛方法涉及对先验分布的随机采样。这种方法效率相当低，可以用一个简单例子说明。考虑一个单位半径的圆，位于大小 $\mathbf{x} \in [-2,2]^2$ 的正方形中。圆（后验分布）面积为 $\pi$，占先验分布的 $\pi/16 \approx 0.196$。现在可以使用蒙特卡洛模拟来估计 $\pi$ 的值。从先验分布中随机采样 N=10,000 个 $\mathbf{x}$ 值。落在圆内的 M 个 $\mathbf{x}$ 样本是后验解，用加号表示；落在圆外的样本被拒绝，用点表示。$\pi$ 的值可以用 $\pi \approx 16M/N$ 估计，在此数值实验中 N=10,000 个样本得到 3.0912。

目标分布在本例中相对容易采样。然而，如果先验分布的超立方体大得多，均匀随机采样将不会特别有效。事实上，随机样本 x 落在单位圆内的概率随着先验分布大小的增加而迅速（二次方）减小。如果考虑更高维的样本，则拒绝采样将很快需要数百万个蒙特卡洛样本才能合理地描绘后验分布并获得准确的 $\pi$ 值。此外，在本例中圆内的所有解具有相等的密度。如果不是这种情况，则需要许多接受的样本才能紧密近似后验分布内概率质量的分布。事实上，依赖于均匀采样（如拒绝采样）的方法（如广义似然不确定性估计 GLUE）如果目标分布有些复杂和/或仅构成先验分布的相对较小部分，则可能产生可疑的结果（Vrugt, 2015a）。总之，标准蒙特卡洛模拟方法对于除非常低维问题外的任何问题在计算上都是低效的。

因此，我求助于马尔可夫链蒙特卡洛模拟来探索后验目标分布。MCMC 模拟的基础是一条马尔可夫链，它在搜索空间中生成随机游走，并连续访问具有来自平稳分布 $\overline{\pi}(\cdot)$ 的稳定频率的解。为了探索目标分布 $\overline{\pi}(\cdot)$，MCMC 算法从马尔可夫链的当前状态 $\mathbf{x}_{t-1}$ 生成试验移动到新状态 $\mathbf{x}_{\mathrm{p}}$。最早的 MCMC 方法是 Metropolis 等人（1953）引入的随机游走 Metropolis（RWM）算法。该方案构造为在链的每一步保持关于 $\overline{\pi}(\cdot)$ 的细致平衡。如果 $p(\mathbf{x}_{t-1})$（$p(\mathbf{x}_{\mathrm{p}})$）表示系统处于状态 $\mathbf{x}_{t-1}$（$\mathbf{x}_{\mathrm{p}}$）的概率，$q(\mathbf{x}_{t-1}\rightarrow\mathbf{x}_{\mathrm{p}})$（$q(\mathbf{x}_{\mathrm{p}}\rightarrow\mathbf{x}_{t-1})$）是执行从 $\mathbf{x}_{t-1}$ 到 $\mathbf{x}_{\mathrm{p}}$（$\mathbf{x}_{\mathrm{p}}$ 到 $\mathbf{x}_{t-1}$）试验移动的条件概率，则接受从 $\mathbf{x}_{t-1}$ 到 $\mathbf{x}_{\mathrm{p}}$ 试验移动的概率 $p_{\mathrm{acc}}(\mathbf{x}_{t-1}\rightarrow\mathbf{x}_{\mathrm{p}})$ 与 $p_{\mathrm{acc}}(\mathbf{x}_{\mathrm{p}}\rightarrow\mathbf{x}_{t-1})$ 的关系为 $p(\mathbf{x}_{t-1})q(\mathbf{x}_{t-1}\rightarrow\mathbf{x}_{\mathrm{p}})p_{\mathrm{acc}}(\mathbf{x}_{t-1}\rightarrow\mathbf{x}_{\mathrm{p}}) = p(\mathbf{x}_{\mathrm{p}})q(\mathbf{x}_{\mathrm{p}}\rightarrow\mathbf{x}_{t-1})p_{\mathrm{acc}}(\mathbf{x}_{\mathrm{p}}\rightarrow\mathbf{x}_{t-1})$。如果使用对称跳跃分布，即 $q(\mathbf{x}_{t-1}\rightarrow\mathbf{x}_{\mathrm{p}})=q(\mathbf{x}_{\mathrm{p}}\rightarrow\mathbf{x}_{t-1})$，则 $\frac{p_{\mathrm{acc}}(\mathbf{x}_{t-1}\rightarrow\mathbf{x}_{\mathrm{p}})}{p_{\mathrm{acc}}(\mathbf{x}_{\mathrm{p}}\rightarrow\mathbf{x}_{t-1})} = \frac{p(\mathbf{x}_{\mathrm{p}})}{p(\mathbf{x}_{t-1})}$，Metropolis 等人（1953）做出以下选择：$p_{\mathrm{acc}}(\mathbf{x}_{t-1}\rightarrow\mathbf{x}_{\mathrm{p}}) = \min\left[1,\frac{p(\mathbf{x}_{\mathrm{p}})}{p(\mathbf{x}_{t-1})}\right]$，以确定是否接受试验移动。该选择规则已成为许多现有 MCMC 算法的基本构建块。Hastings（1970）将方程扩展到非对称跳跃分布的一般情况：$p_{\mathrm{acc}}(\mathbf{x}_{t-1}\rightarrow\mathbf{x}_{\mathrm{p}}) = \min\left[1,\frac{p(\mathbf{x}_{\mathrm{p}})q(\mathbf{x}_{\mathrm{p}}\rightarrow\mathbf{x}_{t-1})}{p(\mathbf{x}_{t-1})q(\mathbf{x}_{t-1}\rightarrow\mathbf{x}_{\mathrm{p}})}\right]$，其中前向（$\mathbf{x}_{t-1}$ 到 $\mathbf{x}_{\mathrm{p}}$）和后向（$\mathbf{x}_{\mathrm{p}}$ 到 $\mathbf{x}_{t-1}$）跳跃概率不相等，$q(\mathbf{x}_{t-1}\rightarrow\mathbf{x}_{\mathrm{p}}) \neq q(\mathbf{x}_{\mathrm{p}}\rightarrow\mathbf{x}_{t-1})$。这种推广称为 Metropolis-Hastings（MH）算法，显著拓宽了可用于后验推断的提议分布类型。

RWM 算法的核心可以用几行代码编写（见算法 1），只需要一个跳跃分布、一个生成均匀随机数的函数和一个计算每个提议概率密度的函数。注意，暂时我方便地假设使用非信息先验分布。这将 Metropolis 接受概率简化为提议密度与链当前状态密度的比值。信息先验分布的使用将在稍后阶段考虑。

算法 1 给出了 RWM 算法的 MATLAB 函数脚本。基于输入参数 prior、pdf、T 和 d，RWM 算法创建马尔可夫链 x 和相应的密度 p_x。prior() 是一个匿名函数，从 d 元先验分布中抽取 N 个样本，生成马尔可夫链的初始状态。pdf() 是另一个匿名函数，计算给定参数值向量 x 的目标分布密度。输入参数 T 和 d 分别表示马尔可夫链的样本数和参数空间的维数。MATLAB 内置函数用下划线突出显示。函数句柄 q(C,d) 用于从 d 元正态分布 mvnrnd() 中抽取样本，均值为零，协方差矩阵为 C。rand 从开区间 (0,1) 上的标准均匀分布中抽取一个值，min() 返回两个不同标量中的最小值，zeros() 创建零向量（矩阵），eye() 计算 $d \times d$ 单位矩阵，sqrt() 计算平方根，nan() 用非数填充向量（矩阵）的每个条目。

用文字描述，假设点 ${\mathbf{x}_0,\dots,\mathbf{x}_{t-1}}$ 已经被采样，则 RWM 算法如下进行。首先，从依赖于当前位置 $\mathbf{x}_{t-1}$ 且对称的提议分布 $q$ 中采样候选点 $\mathbf{x}_{\mathrm{p}}$，$q(\mathbf{x}_{t-1},\mathbf{x}_{\mathrm{p}}) = q(\mathbf{x}_{\mathrm{p}},\mathbf{x}_{t-1})$。然后，使用 Metropolis 接受概率（方程 (14)）接受或拒绝候选点。最后，如果提议被接受，链移动到 $\mathbf{x}_{\mathrm{p}}$，否则链停留在当前位置 $\mathbf{x}_{t-1}$。重复这三个步骤产生一条马尔可夫链，在某些正则条件下，该链具有唯一的平稳分布，后验概率密度函数为 $\overline{\pi}(\cdot)$。在实践中，这意味着如果观察 $\mathbf{x}$ 的值足够远离任意初始值，即在预热期之后，链的连续生成状态将根据 $\overline{\pi}(\cdot)$ 分布，即 $\mathbf{x}$ 的后验概率分布。预热期是必要的，以允许链探索搜索空间并达到其平稳状态。

也许并不意外，RWM 算法的双变量样本很好地近似了目标分布。23% 的接受率略低于理论上认为的最优值，但肯定高于从蒙特卡洛模拟得出的值。后验均值和协方差与目标分布的值非常一致（未显示）。这个简单例子只是展示了 RWM 近似后验目标分布的能力。RWM 的相对易实现性和理论基础使其在贝叶斯推断中得到广泛应用。然而，RWM 算法的效率取决于用于在马尔可夫链中创建试验移动（转移）的提议分布 $q(\cdot)$ 的选择。当提议分布太宽时，太多候选点被拒绝，因此链混合效率不高，只能缓慢收敛到目标分布。另一方面，当提议分布太窄时，几乎所有候选点都被接受，但移动距离太小，采样器需要大量更新才能收敛到目标分布。因此，提议分布的选择至关重要，决定了 MCMC 模拟在许多研究领域的实际适用性（Owen and Tribble, 2005）。

在过去十年中，已经提出了多种不同方法来提高 MCMC 模拟的效率并增强原始 RWM 和 MH 算法。这些方法可以分为单链方法和多链方法。最常见的自适应单链方法是自适应提议（AP）（Haario et al., 1999）、自适应 Metropolis（AM）（Haario et al., 2001）和延迟拒绝自适应 Metropolis（DRAM）算法（Haario et al., 2006）。这些方法使用单条轨迹，并连续使用链的接受样本自适应高斯提议分布 $q_t(\mathbf{x}_{t-1},\cdot)=\mathcal{N}_d(\mathbf{x}_{t-1},s_d\Sigma)$ 的协方差 $\Sigma$，$\Sigma=\operatorname{cov}(\mathbf{x}_0,\dots,\mathbf{x}_{t-1})+\varphi\mathbf{I}_d$。变量 $s_d$ 表示仅依赖于问题维数 d 的缩放因子（标量），$\mathbf{I}_d$ 表示 d 维单位矩阵，$\varphi=10^{-6}$ 是防止样本协方差矩阵奇异的小标量。作为基本选择，缩放因子选为 $s_d=2.38^2/d$，这对于高斯目标分布和提议分布是最优的（Gelman et al., 1996; Roberts et al., 1997），并且对于 d=1 应给出接近 0.44 的接受率，d=5 为 0.28，大 d 为 0.23。AM 算法的 MATLAB 代码见算法 2。

对 x 的单点更新（Haario et al., 2005）可以提高 AM 在高维问题（大 d）中的效率。此外，对于水文模型的层次贝叶斯推断的特殊情况，Kuczera 等人（2010）提出在经典单块 Metropolis 运行之前，使用有限内存多块预采样步骤来调整 $\Sigma$。另一种可行的自适应策略是保持协方差矩阵固定（单位矩阵），并在预热期间更新缩放因子 $s_d$，直到达到所需的接受率。这种方法与 AM 算法有些不同，但易于实现（见算法 3）。

特定缩放因子（也称为跳跃率）自适应方案在实践中是否有效取决于目标分布的性质。因此需要进行一些调整才能获得足够的结果。实践经验表明，协方差矩阵自适应（AM）优于缩放因子自适应。使用 AM 算法创建的提议将更快地表现为目标分布。

使用具有自适应协方差矩阵或跳跃率的多元正态提议分布对于高斯形目标分布效果良好，但对于具有长尾、可能无限一阶和二阶矩的多模态分布不能正确收敛（如本节所示）。经验进一步表明，单链方法无法有效穿越具有多个不同吸引区域和众多局部最优的复杂多维参数空间。使用过于分散的提议分布可以帮助避免过早收敛，但代价是非常低的接受率。对于单链，也特别难以判断何时达到收敛。即使是最强大的诊断方法，比较链的前半部分和后半部分的样本矩，也不能保证目标分布已被采样。事实上，链的两部分的样本矩可能相同，但链卡在后验曲面的局部最优处，或始终只穿越目标分布的一部分（Gelman and Shirley, 2009）。实际上，单链方法遭受许多与局部优化器类似的问题，不能保证在追求目标分布的过程中充分探索了整个参数空间。

多链方法使用不同的并行轨迹来探索后验目标分布。使用多条链有几个理想的优势，特别是在处理涉及长尾、相关参数、多模态和众多局部最优的复杂后验分布时（Gilks et al., 1994; Liu et al., 2000; ter Braak, 2006; ter Braak and Vrugt, 2008; Vrugt et al., 2009a; Radu et al., 2009）。使用多条链提供了对过早收敛的稳健保护，并开辟了使用广泛的统计措施来测试是否达到极限分布收敛的可能性（Gelman and Rubin, 1992）。一种在水文学中得到广泛应用的流行多链方法是 Shuffled Complex Evolution Metropolis 算法（SCEM-UA, Vrugt et al., 2003）。尽管 SCEM-UA 的提议自适应违反了马尔可夫性质，但在各种多元目标分布上的数值基准实验表明，该方法是有效的且接近精确。在大多数合理情况应用中，SCEM-UA 的极限分布与真实目标分布之间的差异可以忽略不计。如果协方差矩阵的多链自适应仅限于预热期，则 SCEM-UA 方法可以成为精确采样器。以类似于 AP（Haario et al., 1999）和 AM 算法的方式，该方法然后为标准 Metropolis 算法推导出有效的高斯提议分布。然而，本文不考虑 SCEM-UA 算法。

ter Braak（2006）提出了一种简单的自适应 RWM 算法，称为差分进化马尔可夫链（DE-MC）。DE-MC 使用差分进化作为种群进化的遗传算法，并使用 Metropolis 选择规则来决定候选点是否应替换其父代。在 DE-MC 中，N 条不同的马尔可夫链同时并行运行。如果单条链的状态由 d 维向量 $\mathbf{x}$ 给出，则在每一代 $t-1$，DE-MC 中的 N 条链定义一个种群 $\mathbf{X}$，对应于一个 $N \times d$ 矩阵，每条链为一行。然后，多元提议 $\mathbf{X}_{\mathrm{p}}$ 从链的集合 $\mathbf{X}={\mathbf{x}_{t-1}^1,\dots,\mathbf{x}_{t-1}^N}$ 中使用差分进化（Storn and Price, 1997; Price et al., 2005）动态生成：$\mathbf{X}_{\mathrm{p}}^i = \gamma_d(\mathbf{X}^a - \mathbf{X}^b) + \zeta_d, \quad a \neq b \neq i$，其中 $\gamma$ 表示跳跃率，a 和 b 是从 ${1,\dots,i-1,i+1,\dots,N}$ 中无放回抽取的整数值，$\zeta \sim^D \mathcal{N}_d(0,c_*)$ 是从标准偏差很小的正态分布中抽取的，例如 $c_* = 10^{-6}$。通过以 Metropolis 概率 $p_{\mathrm{acc}}(\mathbf{X}^i \rightarrow \mathbf{X}_{\mathrm{p}}^i) = \min[1,p(\mathbf{X}_{\mathrm{p}}^i)/p(\mathbf{X}^i)]$ 接受每个提议，获得一条马尔可夫链，其平稳或极限分布是后验分布。证明见 ter Braak and Vrugt（2008）。因此，如果 $p_{\mathrm{acc}}(\mathbf{X}^i \rightarrow \mathbf{X}_{\mathrm{p}}^i)$ 大于从 $\mathcal{U}(0,1)$ 抽取的某个均匀标签，则接受候选点，第 i 条链移动到新位置，即 $\mathbf{x}_t^i=\mathbf{X}_{\mathrm{p}}^i$，否则 $\mathbf{x}_t^i=\mathbf{x}_{t-1}^i$。

由于 N 条链的联合 pdf 分解为 $\overline{\pi}(\mathbf{x}^1|\cdot) \times \dots \times \overline{\pi}(\mathbf{x}^N|\cdot)$，在 DE-MC 变得独立于其初始值之后的任何一代，各链的状态 $\mathbf{x}^1 \dots \mathbf{x}^N$ 是独立的。在此预热期之后，DE-MC 运行的收敛可以用 Gelman and Rubin（1992）的 $\widehat{R}$ 统计量监测。如果初始种群从先验分布中抽取，则 DE-MC 将该样本转换为后验种群。根据 RWM 中 $s_d$ 的指导，$\gamma=2.38/2d$ 是最优选择。有 10% 的概率 $\gamma=1$，或 $p_{(\gamma=1)}=0.1$，以允许模式跳跃（ter Braak, 2006; ter Braak and Vrugt, 2008; Vrugt et al., 2008a, 2009a），这是 DE-MC 的一个显著优势，稍后将展示。如果后验分布由不连通的模式组成，中间是低概率区域，则基于协方差的 MCMC 方法将缓慢收敛，因为概率区域之间的转移将很少。

DE-MC 方法可以用大约 20 行 MATLAB 代码编写（算法 4），并解决了 RWM 中的一个重要实际问题，即选择合适的跳跃分布尺度和方向。早期方法如（并行）自适应方向采样（Gilks et al., 1994; Roberts and Gilks, 1994; Gilks and Roberts, 1996）解决了方向问题但没有解决尺度问题。

基于用户定义的输入参数 prior、pdf、N、T 和 d，de_mc 返回后验分布的样本。prior 是一个匿名函数，从 d 元先验分布中抽取 N 个样本，类似地 pdf 是一个函数句柄，计算提议（候选点）的后验密度。

为了展示 DE-MC 相对于单链方法的优势，请考虑图 5，它展示了 AM（左图）和 DE-MC（右图）导出的后验样本直方图，针对一个简单的单变量目标分布，该分布由两个正态分布的混合组成：$p(x) = \frac{1}{6}\psi(-8,1) + \frac{5}{6}\psi(10,1)$，其中 $\psi(a,b)$ 表示均值为 a、标准差为 b 的正态分布的概率密度函数（pdf）。目标分布用实黑线显示，在 MATLAB 语言中等价于 $\mathrm{pdf} = @(\mathrm{x})1/6*\mathrm{normpdf}(\mathrm{x},-8,1) + 5/6*\mathrm{normpdf}(\mathrm{x},10,1)$。马尔可夫链的初始状态从 $\mathcal{U}[-20,20]$ 采样，使用 $\mathrm{prior} = @(\mathrm{N},\mathrm{d})\mathrm{unifrnd}(-20,20,\mathrm{N},\mathrm{d})$。

AM 算法产生了双峰目标分布的虚假近似。提议分布的方差（宽度）不足以使链充分探索目标分布的两个模式。这个问题的一个简单补救方法是增加单变量正态提议分布的（默认）初始方差。这将允许 AM 采样器采取更大的步骤并直接在两个模式之间跳跃，但代价是接受率和搜索效率的急剧下降。事实上，除了偶尔成功的跳跃外，许多其他提议将超出目标分布，获得几乎为零的密度，因此被拒绝。

这个相当简单的单变量例子说明了 RWM 的困境，即如何确定提议分布的合适尺度和方向。幸运的是，DE-MC 算法导出的后验样本直方图完美匹配混合分布。周期性使用 $\gamma=1$ 使 DE-MC 的 N=10 条不同马尔可夫链能够直接在两个不连通的后验模式之间转移，并快速收敛到精确目标分布。DE-MC 链的初始状态应分布在参数空间上，以便找到两个模式。此外，使用 N 条轨迹允许对收敛进行更稳健的评估。

在之前的工作（Vrugt et al., 2008a, 2009a）中，我们已经表明，通过使用自适应随机子空间采样、多链对生成提议以及显式考虑异常轨迹，DE-MC 的效率可以提高，有时是显著提高。这种方法称为 DiffeRential Evolution Adaptive Metropolis (DREAM)，保持细致平衡和遍历性，并在涉及非线性、高维性和多模态的广泛问题上表现出优异的性能。在这些和其他论文中，基准实验表明 DREAM 优于其他自适应 MCMC 采样方法，在高维搜索/变量空间中甚至比常用优化算法提供更好的解。

DREAM 算法源于 DE-MC，但使用子空间采样和异常链校正来加速向目标分布的收敛。子空间采样在 DREAM 中实现为每次生成提议时仅更新 x 的随机选择维度。如果 A 是原始参数空间 $\mathbb{R}^{d^*} \subseteq \mathbb{R}^d$ 的 $d^*$ 维子集，则第 i 条链在迭代 $t={2,\dots,T}$ 的跳跃 $\mathbf{dX}^i$ 从链的集合 $\mathbf{X}={\mathbf{x}_{t-1}^1,\dots,\mathbf{x}_{t-1}^N}$ 中使用差分进化计算：$\mathbf{dX}_{\mathrm{A}}^i = \zeta_{d^*} + (1_{d^*}+\lambda_{d^*})\gamma_{(\delta,d^*)}\sum_{j=1}^{\delta}(\mathbf{X}_{\mathrm{A}}^{\mathbf{a}_j} - \mathbf{X}_{\mathrm{A}}^{\mathbf{b}_j})$，$\mathbf{dX}_{\neq \mathrm{A}}^i = 0$，其中 $\gamma = \frac{2.38}{\sqrt{2\delta d^*}}$ 是跳跃率，$\delta$ 表示用于生成跳跃的链对数，a 和 b 是由 $\delta$ 个整数组成的向量，从 ${1,\dots,i-1,i+1,\dots,N}$ 中无放回抽取。$\delta=3$ 的默认值在实践中导致三分之一的提议用 $\delta=1$ 创建，另外三分之一用 $\delta=2$，剩余三分之一用 $\delta=3$。$\lambda$ 和 $\zeta$ 的值分别独立地从 $\mathcal{U}_{d^*}(-c,c)$ 和 $\mathcal{N}_{d^*}(0,c_*)$ 中采样，即多元均匀和正态分布，通常 $c=0.1$，$c_*$ 相对于目标分布宽度较小，例如 $c_*=10^{-6}$。与 DE-MC 相比，$p_{(\gamma=1)}=0.2$ 以增强目标分布不连通模式之间的跳跃概率。第 i 条链在迭代 t 的候选点变为 $\mathbf{X}_{\mathrm{p}}^i = \mathbf{X}^i + \mathbf{dX}^i$，并使用方程 (19) 的 Metropolis 比率确定是否接受该提议。如果 $p_{\mathrm{acc}}(\mathbf{X}^i \rightarrow \mathbf{X}_{\mathrm{p}}^i) \geq \mathcal{U}(0,1)$，则接受候选点，第 i 条链移动到新位置，即 $\mathbf{x}_t^i=\mathbf{x}_{\mathrm{p}}^i$，否则 $\mathbf{x}_t^i=\mathbf{x}_{t-1}^i$。对于高斯和 Student 目标分布，$\gamma$ 的默认方程应导致最优接受率接近 0.44（d=1）、0.28（d=5）和 0.23（大 d）（关于这些参考接受率的警告，请参阅 Roberts and Casella (2004) 第 7.84 节）。
