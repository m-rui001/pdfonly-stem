# 多因素进化：迈向进化多任务

本文提出进化多任务这一新范式，并给出多因子优化（MFO）的形式化定义与多因子进化算法（MFEA）。其核心主张是：传统进化算法虽具种群搜索的隐并行性，却始终只求解单一优化问题；若让多个任务共同影响同一进化种群，则可在任务间实现遗传物质的隐式迁移，从而加速复杂函数的收敛并缩短一批任务的完工时间。方法灵感来自多因子遗传的生物—文化模型，即子代的复杂发育性状受遗传与文化因素交互影响；在计算上，每个优化任务被视为影响种群进化的一个额外“因子”，由此形成 K-因子问题。

## 从单目标、多目标到多因子优化

进化算法基于自然选择或适者生存的达尔文原则，从个体种群出发，经类似有性繁殖与变异的操作产生子代，并保留使个体更适应给定“环境”（即目标函数景观）的遗传物质。既有问题一般分为单目标优化（SOO，搜索空间每点映射为标量目标值）与多目标优化（MOO，每点映射为向量目标函数）。本文引入第三类问题——多因子优化（MFO）。MFO 的特征是多个任务对应的多个搜索空间同时存在，各任务可有各自独特的函数景观，且任务之间可以相互依赖也可以彼此独立。命名源于每个任务都为单一种群的进化贡献一个独特因子。例如，在同一个进化求解器中同时处理作业车间调度（生产优化）与车辆路径（物流优化），即属 MFO。

MFO 不要求任务间存在严格约束关系；本文的讨论聚焦于任务间无先验依赖知识的情形，即传统上被独立看待的多个优化问题。因此 MFO 的目的不是在各目标函数间寻找最优折衷，而是借助种群搜索的隐并行性，同时且充分地优化每个任务。形式化地，设同时执行 K 个任务，不失一般性均设为最小化问题；第 j 个任务记为 T_j，其搜索空间为 X_j，目标函数为 f_j : X_j → ℝ，并可能受若干等式/不等式约束。MFO 的目标是求 {x_1, x_2, …, x_{K−1}, x_K} = argmin{f_1(x), f_2(x), …, f_{K−1}(x), f_K(x)}，其中 x_j 是 X_j 中的可行解。每个 f_j 被视为影响单一种群进化的额外因子，故该复合问题称为 K-因子问题。

为在多任务环境中比较种群成员，个体 p_i（i ∈ {1,2,…,|P|}）被编码在涵盖 X_1, X_2, …, X_K 的统一搜索空间中，并可解码为各任务特定的解表示，记为 {x_1^i, x_2^i, …, x_K^i}。定义 1（因子代价）：对任务 T_j，个体 p_i 的因子代价为 Ψ_j^i = λ·δ_j^i + f_j^i，其中 λ 是很大的惩罚乘子，f_j^i 与 δ_j^i 分别是 p_i 对 T_j 的目标值与总约束违反量；若 p_i 对 T_j 可行（约束违反为零），则 Ψ_j^i = f_j^i。定义 2（因子排名）：r_j^i 是 p_i 在按 Ψ_j 升序排列的种群列表中的序号；若 Ψ_j^a = Ψ_j^b，则随机打破平局，并称二者为 j-对应体。定义 3（标量适应度）：个体 p_i 的因子排名列表 {r_1^i, r_2^i, …, r_K^i} 按其所有任务中的最好排名归约为标量适应度 φ_i = 1 / min_{j ∈ {1,…,K}} {r_j^i}。定义 4（技能因子）：τ_i = argmin_j {r_j^i}，j ∈ {1,2,…,K}，即个体最擅长的那个任务。据此，若 φ_a > φ_b，则称 p_a 在多因子意义上支配 p_b，记为 p_a >> p_b；若两个个体技能因子相同（τ_a = τ_b = j）且互为 j-对应体，则称其为强对应体。该比较过程依赖种群（因子排名、标量适应度与技能因子均取决于其他个体表现），但可保证：若个体 p* 映射到任一任务的全局最优，则对所有 i ∈ {1,2,…,|P|} 有 φ* ≥ φ_i。定义 5（多因子最优性）：个体 p* 的目标值列表为 {f_1*, f_2*, …, f_K*}，当且仅当存在 j ∈ {1,2,…,K} 使得对所有可行 x_j ∈ X_j 有 f_j* ≤ f_j(x_j) 时，称其在多因子意义上最优。

MFO 与 MOO 存在根本区别：MFO 旨在利用种群搜索的隐并行性挖掘任务间潜在遗传互补性，而 MOEA 旨在解决同一任务内相互竞争目标间的冲突。Pareto 最优性概念在 MFO 中并不存在，因为多因子最优性不依赖于在不同目标间寻找良好折衷，而依赖于至少找到一个构成目标函数的全局最优。以假设的 2-因子问题目标空间为例：按 MOEA 的非支配排序，{p_2, p_3, p_4, p_5} 属于第一非支配前沿，{p_1, p_6} 属于第二非支配前沿，前者彼此不可比且总优于后者；但按第 II 节定义，p_1 与 p_2（以及 p_5 与 p_6）被称为强对应体，且 {p_1, p_2, p_5, p_6} >> {p_3, p_4}，即 {p_1, p_2, p_5, p_6} 在多因子意义上彼此不可比且总优于 {p_3, p_4}。可见 MOO 与 MFO 对个体相对表现的判断出现分歧。

## MFEA：统一表示、选型交配与选择性模仿

MFEA 受多因子遗传的生物—文化模型启发，基于基因与模因（genes and memes）从亲代向子代的传递，属于模因计算范畴。文化效应通过多因子遗传的两个协同特征引入：选型交配（assortative mating）与垂直文化传递（vertical cultural transmission）。算法 1 给出 MFEA 基本结构：生成初始种群存入 current-pop (P)；对多任务环境中每个优化任务评估每个个体；计算每个个体的技能因子 τ；当未满足停止条件时循环——(i) 对 current-pop 施加遗传算子生成 offspring-pop (C)（见算法 2）；(ii) 仅对选定优化任务评估 offspring-pop 中的个体（见算法 3）；(iii) 将 offspring-pop 与 current-pop 拼接为 intermediate-pop (P ∪ C)；(iv) 更新 intermediate-pop 中每个个体的标量适应度 φ 与技能因子 τ；(v) 从 intermediate-pop 中选择最适应个体组成下一代 current-pop (P)。

种群初始化时，设第 j 个任务维度为 D_j，定义统一搜索空间维度 D_multitask = max_j {D_j}。每个个体被赋予一个含 D_multitask 个随机变量（均位于固定范围 [0,1]）的向量，构成其染色体；统一搜索空间第 i 维由随机键 y_i 表示，固定范围即统一空间的箱式约束。处理任务 T_j 时只取染色体的前 D_j 个随机键。采用该编码而非将各任务变量拼接成 D_1 + D_2 + … + D_K 的巨型染色体，原因有二：实践上可规避多个多维搜索空间任务同时求解时的维数灾难；理论上，不同优化任务对应的图式（遗传积木）被包含在统一遗传物质池中并由进化算法并行处理，从而促进有用遗传物质在任务间被发现与隐式迁移；且单个个体可继承对应多个任务的遗传积木，使多因子遗传的类比更有意义。

遗传机制方面，MFEA 的关键特征是：两个随机选出的亲代候选体须满足一定条件才能交叉。其原则是非随机或选型交配，即个体偏好与同一文化背景者交配；MFEA 将技能因子 τ 视为个体文化偏置的计算表示。因此，若两个随机选出的亲代候选体技能因子相同，可自由交叉；若技能因子不同，则仅按规定的随机交配概率（rmp）发生交叉，否则执行变异。算法 2（选型交配）：从 current-pop 随机选两个亲代候选体 p_a 与 p_b；生成 0 到 1 之间的随机数 rand；若 (τ_a = τ_b) 或 (rand < rmp)，则 p_a 与 p_b 交叉产生两个子代 c_a 与 c_b；否则 p_a 轻微变异产生子代 c_a，p_b 轻微变异产生子代 c_b。评估个体对任务 T_j 时，首先将其随机键解码为该任务的有意义输入。对连续优化，若实际问题第 i 个变量 x_i 限定在 [L_i, U_i]，对应随机键取值为 y_i，则映射为 x_i = L_i + (U_i − L_i)·y_i。对离散优化，染色体解码方案通常依赖具体问题，第 VI 节给出若干组合问题的示例。

选择性评估方面，rmp 用于平衡搜索空间的开发与探索：rmp 接近 0 意味着只允许文化上相似的个体交叉，此时以文化内交配为主，加上技能因子不同时变异产生的小遗传变异，便于扫描搜索空间的受限区域，但解有陷入局部最优的倾向；rmp 接近 1 时跨文化交配增加，可增强对整个搜索空间的探索，有助于逃离局部最优；而仅在同一文化背景个体间交配可能导致来自其他文化背景的优良多样遗传物质丢失。因此 rmp 须在“彻底扫描较小区域”与“探索整个空间”之间取得良好平衡。选择交叉与变异算子时须注意：即使底层优化问题是离散的，随机键始终被解释为连续变量，这鼓励使用现有实数编码遗传算子或设计新算子以更好地导航 MFO 的复合景观。

算法 3（通过选择性模仿实现垂直文化传递）：子代 c 可能有两个亲代（p_a 与 p_b）或单个亲代（p_a 或 p_b）。若 c 有两个亲代，生成 0 到 1 之间的随机数 rand；若 rand < 0.5，则 c 模仿 p_a，仅对任务 τ_a（p_a 的技能因子）评估；否则 c 模仿 p_b，仅对任务 τ_b 评估。若 c 只有单个亲代，则 c 模仿该亲代，仅对该亲代技能因子对应的任务评估。c 在所有未评估任务上的因子代价被人为设为 ∞（一个非常大的数）。这一设计源于观察：MFEA 中生成的个体不太可能在所有任务上都表现优异，因此理想情况下只对最可能表现好的选定任务评估。其模因概念来源是垂直文化传递——在生物遗传之外并行运作，使子代表型直接受亲代表型影响；计算类比即允许子代模仿任一亲代的技能因子（文化性状），称为选择性模仿。由此，子代不再对每个任务评估，而只评估一个任务。对 K-因子问题，函数评估次数相比对全部任务评估几乎减少为原来的 1/K。选择操作采用精英策略，确保最优个体跨代存活，识别最优个体时使用第 II 节的多任务比较技术。

MFEA 的显著特征可总结为：标准进化算法通常生成大量候选解，但都未必胜任当前任务；而在多任务环境中，随机生成或经遗传修饰的个体至少胜任一个任务的概率直觉上更高。MFEA 据此将种群有效划分为不同技能组，每组擅长不同任务；更重要的是，某一组内产生的遗传物质可能对另一任务也有用，从而跨任务遗传迁移有望发现原本难以找到的全局最优。MFEA 中遗传物质的迁移通过允许不同技能组以受控方式交流（偶发染色体交叉）实现，具体由两个组件协同完成：rmp 允许技能因子不同的个体以一定概率交配，从而为子代创造多元文化培育环境；生成的子代可随机选择亲代技能因子进行模仿（算法 3）。过度交流会破坏聚焦搜索，但禁止交流同样不可取，因为会限制探索与整个种群提供的隐并行能力。

## 多任务之利：连续优化实验

理论上，多任务在多个作业同时提出时具有吸引力，例如云服务提供商同时面对多个客户的服务需求，关注点包括最小化完工时间（makespan，完成所有作业所需时间）与提供高质量解。实验选取三个连续优化基准函数：a) Sphere 函数 ∑_{i=1}^{D} x_i^2；b) Ackley 函数 20 + e − 20 exp(−0.2 √(1/D ∑_{i=1}^{D} z_i^2)) − exp(1/D ∑_{i=1}^{D} cos(2π z_i))，z = M_A × (x − O_A)；c) Rastrigin 函数 ∑_{i=1}^{D} (z_i^2 − 10 cos(2π z_i) + 10)，z = M_R × (x − O_R)。其中 M_A 与 M_R 是随机生成的旋转矩阵，O_A 与 O_R 是相应函数的全局最优。所选问题复杂度不均：凸的 Sphere 函数最简单，多峰的 Rastrigin 函数优化难度显著更大，这为展示“较简单问题中产生的遗传物质可用于辅助复杂函数优化”提供了理想平台。

第一组实验考察全局最优相交的情形，通过设 O_A = O_R = 0（原点）并为三个函数采用同质搜索空间实现；后者通过所有实验每一维搜索空间范围取 [−50, 50] 满足，从而确保确实存在可从一问题迁移到另一问题的有用遗传物质。实验考虑 20 维与 30 维变体，简记为问题维度加函数名首字母：20S、30S、20A、30A、20R、30R；若同时求解 20S 与 20A，则复合 2-因子问题记为 (20S, 20A)，最终函数值也以 (·,·) 形式给出；若仅以 SOO 形式求解单个问题如 20R，则记为 (20R, none)。为展示复杂函数（如 30R 或 30A）的优化如何受益于多任务环境中的其他任务，构造两个问题集族：F1: {(30R, none), (30R, 30S), (30R, 30A), (30R, 20S)} 与 F2: {(30A, none), (30A, 30S), (30A, 30R), (30A, 20S), (30A, 20R)}。MFEA 使用模拟二进制交叉（SBX）与高斯变异。所有结果均为每个问题集 30 次独立运行的汇总，实验设置一致：每次运行种群 100 个个体，最多进化 500 代，或直到解收敛到构成任务的全局最优。为获得高质量解，MFEA 中每个个体经历学习步骤；对连续问题，个体学习通过 BFGS 拟牛顿法进行，遵循拉马克主义原则；生成的子代仅针对其模仿的技能因子进行局部改进。所有实验中 rmp 设为 0.3，以允许充分的跨文化交流。

由图 2a 可见，含多任务的实例收敛速率显著改善。不出所料，(30R, 30S) 的曲线在最初几代内收敛，原因是 Sphere 函数在搜索过程中几乎瞬时被优化，从而产生有助于优化 Rastrigin 函数的精炼遗传物质。(30R, 30A) 曲线也快速收敛，类似解释成立：尽管 Ackley 函数是多峰的，但其局部最优较浅，常被认为优化难度较低，因此在 (30R, 30A) 中 Ackley 函数趋于较快收敛，进而为 Rastrigin 函数提供高质量遗传物质。而在 (30R, 20S) 中，优化 Sphere 函数所创造的遗传物质仅构成 Rastrigin 函数所需的三分之二，故收敛速率受限；但 (30R, 20S) 的收敛曲线仍显示，Sphere 函数提供的部分信息帮助其整体表现超过 (30R, none)。墙钟时间改善的进一步证据见表 I。图 2b 的收敛趋势与图 2a 定性特征相似；值得注意的是，将 Ackley 函数与 Rastrigin 函数配对反而加速了 Ackley 函数的收敛，比较 (30A, none) 与 (30A, 30R) 曲线即可见。这很有趣，因为 Rastrigin 函数已知更难优化，本应拖慢收敛；相反，MFEA 中遗传交换的机制对两个任务都有助益。推测进化种群同时成功利用了两种函数的景观，从而高效绕过障碍、更快收敛。

表 I 报告了本节所有数值实验的平均函数值与归一化墙钟时间（以 (30R, none) 的墙钟时间为基准归一化）。除改善的收敛特性外，表 I 还显示多任务在最小化一批优化任务完工时间方面的潜在收益。例如，比较 (30R, none) 与 (30A, none) 的墙钟时间同 (30R, 30A) 的墙钟时间，发现多任务相对 SOO 至少节省 70%。这主要因为任务 30R 与 30A 在 MFO 中组合时能快速收敛到相交的全局最优；相反，以 SOO 形式单独求解时，在 500 代的预算内很少收敛。第二个贡献因素是 MFEA 的选择性模仿策略：多任务环境中的个体只选择一个任务评估，因此对 (30R, 30A) 这样的 2-因子问题，总函数评估次数相比串行求解 (30R, none) 与 (30A, none) 大幅减少。因此，比较 (30A, none) 与 (30A, 30S)、(30A, 20S) 或 (30A, 20R) 的结果可见，多任务处理一批优化任务的时间可能少于单独处理该批中最昂贵单个任务的时间。

第二组实验研究构成任务函数最优存在不同程度分离的情形，考虑 (30R, 30A) 复合测试问题，O_R = 0（原点），O_A 按如下方式偏移：a) 小分离（SS）：O_A 每个元素在 0 到 2 之间随机偏移；b) 中分离（MS）：每个元素在 2 到 5 之间随机偏移；c) 大分离（LS）：每个元素在 5 到 10 之间随机偏移。两个多峰函数对应的搜索空间设为异质：Ackley 函数变量范围 [−32, 32]，Rastrigin 函数变量范围 [−5, 5]。注意大分离情形（LS）下，偏移 Ackley 函数的最优位于 Rastrigin 函数变量边界之外。实验保持 MFEA 算法规格与上一小节相同。由图 4 的收敛趋势可见，无论构成函数最优间分离程度如何，进化多任务相比单独以 SOO 求解 Ackley（或 Rastrigin）函数都持续带来显著性能改善。但细看可见，多任务的有效性随最优分离增大而缓慢降低（见图 4a 与 4b 中 SS、MS、LS 的收敛趋势）。对此的解释是：最优分离增大削弱了两个任务间的遗传互补性；尽管如此，MFEA 仍利用了偏移函数间继续存在的潜在协同，其性能在大分离时逐渐接近 SOO（见图 4a 的 LS）。这一观察为第 IV-E 节（斜体部分）关于 MFEA 有效将种群划分为不同技能组的主张提供了间接证据；当构成任务的最优彼此相距较远时，该特征尤为关键。受控跨文化交配带来的增强探索，即使在任务间无明显遗传互补来源时也有助于优化。

本节结果凸显将多任务概念引入进化优化的三大理论激励：a) 在存在遗传互补性时，从简单任务到复杂任务的隐式遗传迁移可导致复杂优化任务快速收敛；b) 两个复杂任务间的遗传交换促进同时利用两个函数景观，从而高效避开障碍、更快收敛；c) 垂直文化传递这一自然现象在多因子框架中被利用，可潜在地减少一批优化问题的墙钟时间。

## 跨域扩展：离散问题、异步任务与结论

为最终实现跨域多任务，本节将 MFEA 推广到离散优化问题，讨论聚焦组合优化。此类问题有多种形式，通常需要彼此不同的遗传表示，对 MFEA 的通用性构成严峻挑战。组合问题通常由有限基态 S = {1,2,3,…,n} 定义，产生由可行解集合 X ⊆ 2^S 构成的离散搜索空间，每个解映射为实函数值 f: 2^S → ℝ。本文选取以下著名组合优化问题作演示：a) 0/1 单背包与多背包问题；b) 二次分配问题；c) 带容量车辆路径问题。

单背包与多背包问题（KP 与 MKP）：KP 要求从 n 个物品（第 i 个物品重量 w_i、利润 q_i，i ∈ {1,2,…,n}）中选取子集装入容量 W 的背包，使利润最大。更一般的 MKP 含 m 个容量分别为 W_1, W_2, …, W_m 的背包与 n 个物品；第 i 个物品考虑装入第 k 个背包时重量为 w_ik；MKP 还要求物品要么放入所有背包，要么都不放。经典进化算法通常用二进制变量向量 x = (x_1, x_2, …, x_n) 表示解，x_i = 1 表示第 i 个物品放入背包，0 表示不放。一种简单随机键到二进制变量的推导是：若随机键 y_i ≥ 0.5 则 x_i = 1，否则 x_i = 0；但实验发现该技术通常导致 MFEA 性能不佳。本文改为将个体（随机键向量 (y_1, y_2, …, y_n)）视为可在 0 到 1 实数线段上自由移动的 n 个基因集合，每个基因对应唯一物品；基因的自由移动意味着其位置可通过实数编码算子操纵，符合 MFEA 需要。二进制变量由此图景推导：基因集合形成两个簇；本研究用单链接（single-linkage）算法识别簇；根据背包容量选择其中一个簇，其所有物品暂定装入背包，另一簇物品全部排除。若所选簇物品总重量违反容量约束，则采用 Dantzig 贪心近似算法，按效率（利润与重量之比）递增顺序考虑删除物品；修复以鲍德温学习（Baldwinian learning）的精神进行。

二次分配问题（QAP）：QAP 旨在将 n 个设施分配到 n 个位置（每位置一个），使二次目标函数最小。随机键可按已有方式直接解码：第 i 个随机键视为第 i 个设施的标签；将随机键升序排序，再按排序列表中的位置将设施分配到位置。例如 3 个位置 {1,2,3} 与 3 个设施随机键 (0.7, 0.1, 0.3)，则设施 2 分配到位置 1，设施 3 到位置 2，设施 1 到位置 3。局部搜索使用 2-交换启发式改进候选分配；由于变化可通过交换设施的随机键标签重新并入染色体，QAP 中的学习以拉马克主义精神进行。

带容量车辆路径问题（CVRP）：CVRP 定义在图 G(V, E) 上，V 为节点集，E 为弧集；一个节点表示车辆仓库，其余表示有特定需求的客户。求解 CVRP 是为车队寻找行程安排，使服务所有客户的成本最小，成本一般由车辆总行驶距离给出；须确保单个车辆服务的客户总需求不超过其容量；此外常存在客户指定硬时间窗的额外约束。进化算法研究者提出多种 CVRP 遗传表示方案，包括变长染色体方案、巨型巡回方案（将所有客户排列为无行程分隔符的 TSP 路线）等。CVRP 也可构想多种随机键解码过程；本研究将第 i 个随机键标记第 i 个客户，随后像 QAP 那样将随机键升序排序得到 TSP 路线，再基于已有分割过程将 TSP 路线划分为各车辆行程（细节从略）；最后个体以拉马克学习精神经历一组简单局部搜索移动以改进解质量。

跨域随机键解码示例：为总结上述跨域解码过程，给出一个同时执行三个不同优化任务的示例：a) 含五个决策变量、每个限定在 [0, 5] 的连续问题；b) 含 10 个物品的 KP；c) 含 10 个设施（与 10 个位置）的 QAP。该 3-因子问题的 D_multitask = max{5,10,10} = 10，故随机生成十维染色体 y：(0.79, 0.31, 0.53, 0.17, 0.60, 0.26, 0.65, 0.69, 0.75, 0.45)。对连续问题，取 y 的前五个随机键并从 [0,1] 线性映射到 [0,5]。对 KP，将随机键连同对应基因索引绘于实数线上，用单链接算法分为两簇：第一簇含基因 {4,6,2}，第二簇含基因 {10,3,5,7,8,9,1}；按 KP 解码过程，物品 {4,6,2} 暂定装入背包，另一簇物品排除，即 KP 的领域特定染色体表示为 (0101010000)，该解码过程称为二值聚类。对 QAP，基因索引沿实数线出现的顺序规定设施分配到位置的次序，给定 y 的领域特定表示为 (4,6,2,10,3,5,7,8,9,1)。随机键表示方案的一个有趣特征是，对 QAP 与 CVRP 这类排序问题，它能在实数编码交叉与变异操作下确保子代可行性；这与此类问题的领域特定表示形成对比，后者需要专门设计的遗传算子来确保子代可行性。

数值实验与讨论部分的目标有二。第 VII-A 节考虑四组性质各异的 MFO 示例，以更全面理解 MFEA 性能，特别是面向可能同时接收多客户多样作业的云软件服务；实验由离散与连续优化的流行基准实例组合而成，并声明构成任务间不存在可辨遗传互补性的先验知识，以模拟云服务器面对多个特性未知作业的真实情形。第 VII-B 节简要讨论并非所有待解任务都在同一时刻到达的情形，即新任务可在处理另一任务的中间阶段呈现给求解器，从而带来动态性；其动机来自云客户在空间与时间上天然分布的观察，并将展示 MFO 在此类情形下的显著含义：当前任务的遗传物质可用于启动中间呈现任务的优化过程。

MFEA 在多种复合问题集上测试，每个含三个任务，大致分三类：Set 1 由排序问题（QAP 与 CVRP）组成，解码时须排序随机键；Set 2 的任务类似，其随机键解码过程要求对基因进行二值聚类；Set 3 与 Set 4 是真正的跨域多任务示例，组合了排序、二值聚类与连续优化实例。每个集合是 3-因子优化环境，三个构成任务取自各自领域的流行基准实例（详见表 II）。KP 与 MKP 本质是最大化问题，因此在作为全局最小化器的 MFEA 中取其目标函数值的负值。KP 与 MKP 实例随机生成；KP 实例的最优解通过动态规划获得，MKP 的最优解不可得。KP 实例生成过程：w_i = uniformly random [1,10]，q_i = w_i + 5；平均背包容量 W = 1/2 ∑_{i=1}^{n} w_i。MKP 类似，但考虑五个背包：w_ik = uniformly random [1,10]，q_i = mean_k (w_ik) + 5；第 k 个背包容量 W_k = 1/2 ∑_{i=1}^{n} w_ik。评判 MFEA 输出质量与鲁棒性的参数包括：平均（Avg）——MFEA 所有运行的平均函数值；变异系数（CV）——标准差与平均函数值之比；平均差距（AG）——平均值与最优值之差，以最优值的百分比表示；最佳发现（BF）——MFEA 所有运行中达到的最佳函数值；差距（Gap）——最佳发现与最优值之差，以最优值的百分比表示。

所有后续实验中，100 个个体进化 500 代，即停止准则设为完成约 50,000 次任务评估，其中单次“任务评估”调用包含个体经历的拉马克/鲍德温学习步骤。MFO 与 SOO 模拟使用相同染色体表示方案与遗传算子：SBX（交叉）与高斯变异用于导航连续化搜索空间，MFEA 中 rmp 设为 0.3。收敛趋势中，任务 T_j（j ∈ {1,2,3}）的目标函数值先归一化为 f̃_j = (f_j − f_j^min)/(f_j^max − f_j^min)，其中 f_j^min 与 f_j^max 是 T_j 在所有测试运行（含 MFO 与 SOO）中发现的最小与最大函数值；随后归一化值在集合三个任务上平均：f̃ = (f̃_1 + f̃_2 + f̃_3)/3；最后 f̃ 在 30 次独立运行上再平均。

Set 1（排序问题）的收敛趋势显示，MFO 模拟曲线超过平均 SOO 性能，整体收敛特性更好；由于 SOO 与 MFO 使用相同编码方案与遗传算子，改善可完全归因于进化多任务范式提供的隐式遗传迁移对多个函数景观的利用。解质量方面，MFEA 表现稳定：可靠输出两个 QAP 实例（T_1, T_3）的最优解；对 CVRP 实例平均达到距最优（或已知最好解）1.1783% 的小差距。Set 2（二值聚类问题）含一个大规模 MKP 实例（T_1，1000 个物品）与两个相对较小实例（T_2, T_3，各 100 个物品）；收敛趋势再次证明进化多任务相比串行 SOO 的有效性；最终结果显示小 KP 实例（T_3）的最优解在 MFEA 每次运行中都稳定达到。Set 3 与 Set 4 含排序、二值聚类与连续优化实例，构成真正跨域多任务环境；相比串行 SOO 的优越收敛趋势凸显 MFO 在此类设置中的效力。Set 3 最终结果显示 MFEA 成功收敛到三个问题变体（Rastrigin 函数、QAP、KP）各自的最优，为 MFEA 在多样多任务环境下的鲁棒性提供有力证据，鼓励其作为云基计算智能工具的潜在应用。Set 4 结果显示 MFEA 能找到大规模 KP 实例（T_1：1000 个物品）的最优解，同时确保 CVRP 与连续优化任务的高质量解；Ackley 函数（T_3）的全局最优经常达到；CVRP 实例（T_2）的平均差距也较小。

为更好理解 MFO 带来的性能改善，图 12 描绘跨域多任务示例（Set 3 与 Set 4）中每个单独任务的收敛趋势；MFO 中某任务的曲线通过在任务标签后加星号标注，例如 T_2 的曲线标为 MFO (T_1, T_2*, T_3)。由图 12a（Set 3）可见 MFO 中每个构成任务的收敛速率都被加速；组合实例（T_2 与 T_3）的加速较不明显，而连续优化问题（T_1：Rastrigin 函数）尤为显著。图 12b（Set 4）可得类似推断，Ackley 函数（T_3）的优化受益最大；另一方面，图 12b 也显示相比 SOO，大规模 KP 实例（T_1）的收敛略有受阻。这一观察引出结论：进化多任务未必保证每个任务性能都改善，因为并非所有遗传迁移都有用；换言之，某些任务受多任务中隐式遗传迁移正面影响，某些其他任务可能受负面影响。但实践中，由于预期任务间遗传互补性先验知识很少，让进化在存在潜在互补性时自主利用，而无需显式识别并向 MFEA 注入领域知识，是合理的；结果还表明，在许多跨域 MFO 问题中，正迁移显著超过负迁移。

MFO 的额外优势是最小化一批优化问题的完工时间。对 Set 1 至 Set 4 的实验表明，MFEA 在单机上达到的完工时间常可少于将任务分布到多台机器执行 SOO 求解器时的完工时间；这一性能提升仅通过释放进化搜索固有的并行性即可获得。图 13 比较 MFEA（停止准则为 50,000 次任务评估）与串行 SOO（每任务相同停止准则）在 Set 1 至 Set 4 上的总墙钟时间。注意 MFEA 执行的总任务评估次数并不按处理任务数成比例缩放；由于选择性模仿策略（规定多任务环境中个体只选择一个任务评估），MFEA 同时优化一批任务所需总时间明显少于 SOO 求解器仅花在单个最昂贵任务上的时间。因此，若假设 SOO 求解器并行部署在多台机器上，最昂贵任务会成为瓶颈，阻碍整批任务的完工时间；故认为 MFO 可达到的完工时间可能少于多个 SOO 求解器并行运行（每个求解器执行一个任务）时的完工时间。

异步优化任务方面，作业最优调度是云服务提供商的严峻挑战，短时间内可收到多用户多个作业。本小节简要考虑新优化任务在另一任务处理中间阶段呈现给 MFO 求解器的情形，特别希望表明隐式遗传迁移的机制在此类动态设置中对改善性能极为宝贵。为此设想一个带容量车辆路径示例：同一城市内不同物流服务商客户地理分布相似，此时预期最优车辆路线存在结构相似性，可从一问题正向迁移到另一问题；为便于阐述，假设各物流公司以相当快的接续速度向 MFO 求解器提交各自的车辆路径问题。为设计上述情形的计算类比，考虑 Solomon 基准集中三个带时间窗约束的 CVRP 实例（c101、c102、c103）；这些样本实例的有趣特征是客户在二维欧氏空间中分布相似，但客户指定的时间窗约束不同。通过假设进化过程从单独求解实例 c101 开始，人为创建动态环境；后续实例 c102（或 c103）在中间阶段呈现给求解器。注意由于所有实例属于 CVRP 领域，此处 MFO 求解器采用领域特定表示方案。隐式遗传迁移利用解相似性的优势在图 14 中清晰展示：优化 c101 中间阶段创建的基因池被正向迁移到后续任务，从而相比独立 SOO 求解器，为 c102 与 c103 实例的进化搜索过程提供了显著推动。

结论与未来研究方向：本文引入多因子优化（MFO）作为进化计算的新范式。传统基于种群的进化算法一次只求解一个问题，而适当利用其隐并行性可产生有效多任务引擎，同时求解多个问题；“多因子”一词正源于每个额外任务都为进化贡献一个额外因子。为实现高效进化多任务，基于多因子遗传的生物—文化概念提出新的多因子进化算法（MFEA）。该算法具有统一染色体表示方案，被证明是处理跨域多任务问题的关键要素；统一搜索空间意味着不同任务对应的积木包含在统一遗传物质池中，特别使 MFEA 能利用任务间潜在遗传互补性，从而高效地发现并隐式迁移有用遗传物质。多项数值实验测试了所提算法的效力，实验可分为连续问题、离散优化以及连续与离散优化混合；结果表明进化多任务在加速复杂优化函数收敛与最小化一批优化任务完工时间方面提供了有前景的结果。对跨域多任务中单个任务收敛特性的深入分析显示，某些任务受隐式遗传迁移正面影响，也可能存在某些任务受负面影响；但多数情况下正迁移超过负迁移，从而在跨所有任务平均性能时带来改善的收敛趋势。

尽管结果令人鼓舞，须记住本文只是这一尚未探索研究方向的第一步，未来需要对范式的若干实践与理论方面进行严格研究。例如，离散优化领域仍有大量文献有待处理；MFEA 当前方法尚未针对可扩展性进行充分测试，而后者预期是进化多任务的关键问题，尤其从云计算角度看，待处理任务数可能增长极快；搜索统一搜索空间的个体种群因此必须被智能操纵，以尽可能高效地容纳大量多样化的传入任务。最后，提请注意迄今所作的假设：待并行求解的任务间不存在任何关系先验知识。MFEA 的效力已在传统上被独立看待的不同问题多任务求解中得到展示；但值得强调，MFO 的适用性不限于此类场景。单个复杂问题常由若干相互依赖的子问题或组件构成，MFO 可设想用于同时求解这些组件；另一例子是问题受优先级约束，即某些任务必须利用某些其他任务的结果。显然，能处理此类挑战的改进 MFO 求解器将在众多实际应用中具有重要价值。
