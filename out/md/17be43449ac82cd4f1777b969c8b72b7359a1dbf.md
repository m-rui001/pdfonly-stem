# 基于多智能体强化学习的数据驱动家庭能量管理方法

原文：A Multi-Agent Reinforcement Learning-Based Data-Driven Method for Home Energy Management（2020）DOI: https://doi.org/10.1109/tsg.2020.2971427

本文提出一种基于多智能体强化学习（RL）与数据驱动方法的家庭能量管理（HEM）框架，旨在实现高效的家居需求响应（DR）。作者将小时级能量消耗调度问题建模为有限马尔可夫决策过程（FMDP），基于极端学习机（ELM）训练的神经网络滚动预测电价与光伏出力，再由多智能体Q学习算法为各类家电与电动车（EV）给出调度决策，目标是最小化电费与DR引起的不满意度。仿真结果验证了该方法在降低用电成本和提升计算效率方面的有效性。

## 引言与问题动机

现有HEM研究多采用集中式优化，通常假设不确定性预测完全准确，这一假设在现实中不成立；同时，许多工作只针对单一类型负荷（如家电或EV），且较少在决策中集成屋顶光伏。强化学习（RL）无需初始环境信息、可离线训练在线执行，并具有较高的计算效率，因此近年来被用于能量管理。但现有RL方法仍存在上述不足。本文的贡献有三：一是提出一种基于ELM和Q学习的无模型可自适应HEM方法；二是用数据驱动方式克服未来不确定性（电价和光伏预测误差）；三是针对非可移、功率可移、时间可移和EV充电四类负荷，开发多智能体Q学习算法，以完全分布式方式获得最优调度。

## 问题建模与多智能体框架

系统包含四类智能体：非可移负荷（如冰箱、报警系统）、功率可移负荷（空调、加热、照明）、时间可移负荷（洗衣机、洗碗机）和EV。每个时隙为小时级，智能体观察状态并选择动作。FMDP由五元组(𝑺,𝑨,𝑹,𝛾,𝜃)描述，其中𝑺为状态集、𝑨为有限动作集、𝑹为奖励集、𝛾为折扣率、𝜃为学习率。状态定义为当前及未来电价和光伏出力的向量：$s_t = \{(\lambda_t^G, \lambda_{t+1}^G, \ldots, \lambda_T^G), (E_t^{PV}, E_{t+1}^{PV}, \ldots, E_T^{PV})\}$。非可移负荷只能“on”；功率可移负荷可选离散功率等级；时间可移负荷可选择“on/off”；EV只考虑充电，不放电，以避免缩短电池寿命。

各智能体奖励如下：非可移负荷奖励$r_{it}^{NS} = -\lambda_t^G [P_{it}^{d,NS} - E_t^{PVs}]^+$（$i \in \Omega^{NS}$）；功率可移负荷奖励$r_{jt}^{PS} = -\lambda_t^G [P_{jt}^{d,PS} - E_{jt}^{PVs}]^+ - \alpha_j^{PS}(P_{j,max}^{d,PS} - P_{jt}^{d,PS})^2$；时间可移负荷奖励$r_{mt}^{TS} = -\lambda_t^G [u_{mt} P_{mt}^{d,TS} - E_{mt}^{PVs}]^+ - \alpha_m^{TS}(t_m^s - t_m^{ini})^2$；EV奖励$r_{nt}^{EV} = -\lambda_t^G P_{nt}^{d,EV} - \alpha_n^{EV}(P_{n,max}^{d,EV} - P_{nt}^{d,EV})^2$。其中$[\cdot]^+ = \max(\cdot,0)$，$\alpha$为不满意度系数，二次项表示降低功率或等待带来的不适。总奖励$R$由式(5)给出（见原文）。动作值函数$Q^\pi(s,a) = \mathbb{E}_\pi[\sum_{k=0}^{K} \gamma^k r_{t+1} | s_t = s, a_t = a]$，目标是最优策略$\pi^*$最大化累计折扣奖励。

## 数据驱动求解方法

所提方法由两部分构成：ELM训练的神经网络用于预测未来24小时电价和光伏出力；多智能体Q学习算法用于决策。ELM具有随机输入权重和快速学习的特点，以过去24小时数据为输入，输出未来24小时预测值。Q学习通过Bellman方程$Q^{\pi*}(s_t,a_t) = r(s_t,a_t) + \gamma \max Q(s_{t+1},a_{t+1})$迭代更新Q值：$Q(s_t,a_t) \leftarrow Q(s_t,a_t) + \theta [ r(s_t,a_t) + \gamma \max Q(s_{t+1},a_{t+1}) - Q(s_t,a_t) ]$，其中$\theta \in [0,1]$为学习率。训练采用$\varepsilon$-greedy策略平衡探索与利用，每幕终止条件为$|Q^{(\sigma)} - Q^{(\sigma-1)}| \le \tau$。算法流程见原文Algorithm 1-3。仿真中，折扣率$\gamma=0.9$，学习率$\theta=0.1$，$\varepsilon=0.1$。

## 仿真验证与结论

使用PJM 2017年1月1日至2018年12月31日共730天的真实电价和光伏数据训练网络。电价预测网络为24-40-24三层结构，光伏预测网络为24-20-24结构，训练幕数50,000。预测精度：光伏输出MAPE为8.82%，电价MAPE为9.34%。为分析预测误差影响，设置案例1-3（MAPE分别为：案例1：4.41%/4.67%；案例2：8.82%/9.34%；案例3：17.64%/18.68%），结果显示预测越精确，Q学习得到的运行成本越接近完美预测下的最优解。

多智能体Q学习算法方面，表IV展示了不同状态-动作对数量下的计算时间：$3.6\times10^2$对用时1.315秒，$3.6\times10^3$对用时2.067秒，$3.6\times10^4$对用时7.385秒，$3.6\times10^5$对用时317.992秒。增加动作空间（功率等级细分）使搜索更耗时，但精度提升有限，且实际家电难以精确控制，因此采用小规模状态-动作对更合理。图7显示各功率可移智能体Q值最终收敛到最大值；图8显示电价上升时能耗下降，高电价时最低。对不同不满意度系数$\alpha$的测试（图9）表明，$\alpha$越大能耗越高，存在节省电费与降低不满意的权衡。对比有/无DR（图10和表V）：有DR时总电费为4.057美元，无DR为7.329美元，其中AC1从1.378降至0.836，EV从1.262降至0.399，多个负荷显著降低。

与遗传算法（GA）基准比较：GA求解混合整数非线性规划（最小化式(1)-(4)），本文方法在训练初期表现较差，但随迭代次数增加逐渐优于GA；平均计算1000次，GA为46.296秒，本文Q学习法仅1.107秒。结论总结：基于ELM预测网络和多智能体Q学习，所提方法能有效降低电费并提高计算效率；未来将考虑储能和更精确的预测模型。
