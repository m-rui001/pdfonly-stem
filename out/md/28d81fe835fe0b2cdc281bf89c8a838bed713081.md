# 基于多智能体系统的微电网与微电网集群分布式协调控制与优化综述

*MAS-Based Distributed Coordinated Control and Optimization in Microgrid and Microgrid Clusters: A Comprehensive Overview* · 2017 · DOI: 10.1109/TPEL.2017.2761438

本文系统综述了多智能体系统（MAS）在微电网（MG）与微电网集群（MGC）中分布式协调控制与优化的研究进展。作者指出，高渗透分布式可再生能源要求微电网具备灵活的控制策略，而MAS凭借其自治性、通信与协调能力，在功率/能量平衡、电压/频率稳定和经济运行方面具有优势；但分布式电源的复杂组合也增加了系统控制难度。论文梳理了拓扑模型与数学模型（加权图模型、非合作博弈模型、遗传算法、粒子群优化等）并比较其优缺点，系统回顾了共识协议，综述了固定与随机通信延迟的补偿方法，并总结了切换拓扑建模以及MGC能量协调与经济调度方法，最后展望了未来方向。

## 一、微电网与微电网集群的层次控制框架

微电网中电力电子变换器具有小惯性、快响应、低过流能力等特点，其运行需在并网与孤岛两种模式间切换并保持供需平衡。经典层次控制包含初级、次级和三级控制。初级控制采用P/Q下垂法：

(1) ωMG =ω * − m ⋅ ( P − P* )
(2) EMG =E * − n ⋅ (Q − Q* )

其中ωMG和EMG为输出频率和电压幅值参考，ω*和E*为参考值，P和Q为有功和无功功率，m和n为下垂系数。初级控制负责本地功率、电压和电流调节及多DG间的功率分配。次级控制用于消除初级控制产生的频率和电压偏差，可采用集中式或分散式方式，其补偿器表达式为：

(3) δω =k pω (ωMG − ωMG ) + kiω ∫ (ωMG − ωMG )dt + Δωs
(4) δ E =k pE ( EMG − EMG ) + kiE ∫ (EMG − EMG )dt

其中kpω、kiω、kpE、kiE为控制参数，Δωs为同步项（并网时为零），δω和δE为补偿器处理后的误差信号。集中式次级控制过度依赖MGCC，且需双向通信，存在延迟和故障风险；分散式控制不依赖MGCC，具有更高容错性和即插即用能力，但每个DG需测量PCC处电压和频率，大容量MG需高带宽双向链路，且频率为全局信号，同时调节可能影响稳定性。三级控制根据经济调度规则优化运行，并网时可通过调整MG内部电压频率控制功率流，其控制律为：

(5) ωMG =k pP ( PG* − PG ) + kiP ∫ (PG* − PG )dt
(6) EMG =k pQ (QG* − QG ) + kiQ ∫ (QG* − QG )dt

层次控制可在不同时间尺度上同时实现电气控制、电能质量调节和经济运行，但传统集中式层次控制难以满足高智能、强扩展、高冗余和电压频率功率的可靠调节需求。因此，MAS被引入。MAS将复杂大系统划分为多个自治子系统（agent），agent具备反应性、预动性和社会性。文献中已有多种MAS应用于MG，如分散次级控制、异构储能功率共享、频率控制等。一个典型的MAS框架中，各电气设备对应一个agent（如电池储能、燃气轮机、风力机、负载），由MGCC协调，并遵循合同网协议。agent的两级控制中，上层控制（ULC）根据局部信息更新和最优增量成本发现，更新规则如下：

(7) ri [t + 1] = ∑ dij rj [t ] + ε ⋅ PD,i [t ]
(8) PD,i [t + 1] = ∑ dij PD' , j [t ]

其中ri[t]为组件i的增量成本，ε为步长，PD,i[t]为供需失配局部估计，dij为通信系数。随后通过(9)(10)更新功率和失配估计：

(9) Pi [t + 1] = ( ri [t + 1] − bi ) / ai
(10) PD' ,i [t ] = PD,i [t ] + ( Pi [t + 1] − Pi [t ] )

其中ai、bi为燃料成本系数。初始化由(11)(12)给出：ri[0]=aiPi[0]+bi，PD,i[0]=Pi[0]。下层控制则实现功率参考跟踪。

## 二、分布式多智能体系统的建模与共识控制

由于MAS中分布式电源组合复杂，需设计合适的拓扑与数学模型以优化配置和控制策略。图模型是广泛采用的拓扑建模方法。加权图模型中，节点xi代表DGi，边表示交互，阻抗Zij等。图模型结构简单、冗余度高、易扩展，但鲁棒性受图结构影响较大。非合作博弈模型可用于MGC协调运行，使各agent达到最优平衡状态，但不适用于大规模动态博弈仿真。遗传算法能够提高预测精度和收敛速度，且可扩展、并行，但参数依赖经验，动态响应慢，计算负担高。PSO算法结构简单、计算快，能有效提升MG频率电压和调度方案，但不擅长离散优化且易陷入局部最优。表I总结了这些方法的优缺点：图拓扑模型简单冗余高但鲁棒性受图影响；非合作动态博弈模型可达最优平衡但算法复杂耗时；遗传算法预测精度高收敛快可扩展但参数依赖经验响应慢；PSO简单快速经济调度好但无法处理离散优化。总体而言，图模型属拓扑模型，其余为数学模型；遗传算法适合离散问题，PSO规则更简单，非合作博弈用于多MG交互。

共识协议是MAS中agent之间交互的规则。共识问题包括平均共识、最大/最小共识等。文献提出了多种协议。例如，带通信延迟的线性共识协议：

(13) ui (k ) = K ∑ aij ( x j (k − τ (k )) − xi (k − τ (k )))

其中ui(k)和xi(k)为协议和状态，K为反馈增益，τ(k)为时变延迟。定义代价函数JC=JCx+JCu，其中JCx和JCu分别表示共识调节性能和控制能量消耗，Qx和Qu为对称正定矩阵。加权共识协议利用边介数中心性提高鲁棒性，如式(17)(18)。此外，模型预测控制可加速动态共识，分布式动态共识协议估计平均电压，如式(19)：viavg(t) = ∑ aij (vjavg(t) − viavg(t)) + vi(t)。还有群共识、H∞群共识等。对于MG/MGC，动态共识协议能保证电压频率稳定，改善功率调节和电能质量。

## 三、通信延迟补偿与切换拓扑

通信延迟在MG中不可避免，分为固定延迟（发送处理、接收处理、传输延迟）和随机延迟（等待延迟）。固定延迟补偿方法包括神经网络预测控制、加权平均预测控制、多定时器同步方案、增益调度等。增益调度中，若第(k−N−1)个采样有效，则执行器输入为：

(20) u (k ) = uc (k − N − 1) = − Lq x(k − N − 1)

其中Lq为状态反馈增益。该法可通过QoS监控调整参数，补偿延迟。随机延迟补偿方法包括GPC、NPC、MPC、史密斯预测器、H∞控制、滑模控制等。MPC中，解耦后二次控制特征方程为：

(21) 1+e− sτ Gp Gc H = 0

其中H为PLL传递函数。史密斯预测器的传递函数为：

(22) Y ( s) / R ( s ) = GC ( s )GP ( s )e − t1s / [ 1 + GC ( s)Gˆ P ( s) − GC ( s)Gˆ P ( s)e − tm s + GC ( s)GP ( s)e − t p s ]

其中GˆP为无延迟名义模型，t1为指令延迟，t2反馈延迟，tp=t1+t2。表II比较了各种补偿策略的优缺点：GPC鲁棒但计算量大；NPC无需数学建模但未考虑实际因素；MPC可减少数据丢失但算法复杂；史密斯预测器响应快但存在模型不确定性和外部扰动；神经网络预测可线性化但不处理随机延迟；加权平均预测提高收敛但不处理随机延迟；增益调度可降低成本但不处理随机延迟；H∞可处理固定和随机延迟但计算量大、算法复杂；滑模控制实现简单、鲁棒但存在抖振；多定时器同步可降低成本和增强鲁棒但不处理随机延迟。

切换拓扑方面，MG/MGC中DG或MG的插拔会改变系统结构，需研究切换拓扑对一致性的影响。图理论用于表示通信拓扑，邻接矩阵的变化反映插入、切除和模式转换。图8展示了正常加权图、边消失、节点失效、节点增加四种情形。当DG渗透率增加导致拓扑变化时，仍需保证MGC稳定性。目前对时变通信拓扑的研究尚不成熟，需进一步研究。

## 四、基于MAS的MGC能量协调、经济调度与未来趋势

对于MGC，层次结构常用于协调多个DG及与主网的功率分配。已有许多MAS能量管理策略，如分层框架包含物理层、资源agent层、反应层和协调层。当MOA检测到功率缺额时，激活本地agent；若本地无法平衡，则MMA协调邻居进行动态谈判，最终达成能量交易协议。优化目标为最小化总能量成本：

(23) Ctotal = CPV + CMT + Cgrid

其中CPV、CMT、Cgrid分别为光伏、微型燃气轮机和电网购电成本，各自表达式为(24)-(26)，约束条件为功率平衡(27)和传输线功率限制(28)。市场出清价格λ由总成本和总功率计算(29)。MAS的层次结构具有局部错误隔离、易扩展、延迟影响、减少主控依赖等特点。未来研究方向包括：通信延迟影响（降低成本和增加延迟裕度）、切换拓扑建模（图理论）、能量管理与经济调度（考虑多MG交互和系统多目标多时间尺度特性）。结论总结了全文。
