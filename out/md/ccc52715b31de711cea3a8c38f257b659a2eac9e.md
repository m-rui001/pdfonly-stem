# 基于堆叠GRU-RNN的智能电网可再生能源与电力负荷预测

A Stacked GRU-RNN-Based Approach for Predicting Renewable Energy and Electricity Load for Smart Grid Operation · 2021 · https://doi.org/10.1109/tii.2021.3056867

本文提出一种改进的堆叠门控循环单元-循环神经网络（GRU-RNN）方法，用于智能电网中可再生能源（RE）发电量与电力负荷的预测，可同时处理单变量和多变量场景。首先根据相关性分析选取敏感监测参数作为输入；其次构建采用简化门控结构的堆叠GRU-RNN，并设计结合AdaGrad与可调节动量的训练算法以增强训练效率与鲁棒性；最后通过两个实验——德国风电功率预测（多变量）和西班牙电力负荷预测（单变量）——验证了该方法在准确性和鲁棒性上优于多种现有机器学习与深度学习方法。

## 引言与相关工作

智能电网利用信息通信技术实现电力生产、分配和消费的监测与优化，能源生产与负荷预测对电网调度与安全运行至关重要。可再生能源的大规模接入带来了显著不确定性：2019年欧洲风电累计容量达205 GW，太阳能达131.9 GW，约占EU-28用电量的18%；德国和西班牙可再生能源净发电占比分别超过46%和49%。用户行为多样化和智能设备、电动汽车的接入也加剧了负荷波动。预测可分为短、中、长期，服务于不同管理目标。数据驱动方法分为统计方法（如ARMA、卡尔曼滤波、马尔可夫链）和机器学习方法（如SVM、随机森林、模糊逻辑）。深度学习因能自动提取非线性特征而表现更好，但前馈网络和CNN未利用时间相关性。RNN具有自反馈连接，适合时间序列，但存在梯度消失问题；LSTM-RNN通过门控机制缓解了该问题，GRU-RNN进一步简化结构，但计算成本仍较高。本文针对这些问题提出改进方案，主要贡献包括：提出基于改进堆叠GRU-RNN的预测框架；采用简化的GRU结构减少参数并降低复杂度；训练算法加入可调节动量与自适应学习率；方法适用于多变量和单变量场景。

## 改进的堆叠GRU-RNN方法

经典LSTM-RNN由输入门、遗忘门、输出门和记忆单元组成，其操作如公式(1)-(8)所示（提取文本中公式编号因跨页排列有误）。经典GRU仅含重置门和更新门，其更新过程为：z_t = σ(V_{xz} x_t + U_{hz} h_{t-1} + b_z)，r_t = σ(V_{xr} x_t + U_{hr} h_{t-1} + b_r)，c_t = φ(V_{xc} x_t + U_{hc}(r_t ⊙ h_{t-1}) + b_c)，h_t = (1 - z_t) h_{t-1} + z_t c_t，分别对应公式(9)-(12)（编号顺序在原文中可能错乱）。为减少参数，本文采用门控变体：每个门仅由前一隐藏状态和偏置计算，即z_t = σ(U_{hz} h_{t-1} + b_z)，r_t = σ(U_{hr} h_{t-1} + b_r)，候选状态c_t = φ(V_{xc} x_t + U_{hc}(r_t ⊙ h_{t-1}) + b_c)，隐藏输出h_t同前。通过堆叠多个GRU层并在顶部加入回归层（ŷ_t = σ(U_{yh} h_t + b_y)）构成预测模型。

训练算法方面，以均方误差E = (1/(2T)) Σ_{t=1}^T (y_t - ŷ_t)^2为损失，传统SGD更新θ_{q+1} = θ_q - η·(∂E/∂θ_q) + β·(θ_q - θ_{q-1})。本文提出自适应学习率和动量：θ_{q+1} = θ_q - η_q·(∂E_q/∂θ_q) + β_q·(θ_q - θ_{q-1})，其中η_q = η_0 / sqrt(Σ_{i=1}^q g_i^2 + λ)，β_q = e^{-κ - g_q}，g_q = ∂E_q/∂θ_q，λ为小正数（默认1e8），κ为初始动量系数。流程步骤为：收集历史时间序列数据；根据相关性分析选择敏感参数；划分训练和测试集；构建堆叠GRU-RNN并训练；用测试集验证。

## 实验验证

实验一：风电功率预测。数据为德国2016年每小时风电实际发电量及256个位置的天气数据，每天有6144（256×24）个数据点，全年共8784（24×366）小时数据。对256个位置取平均后，计算各监测参数与实际发电量的相关系数，V1（2米高风速）、V2（10米高风速）、V_50m（50米高风速）的相关系数分别为0.8773、0.9131、0.9503，明显高于其余八个参数，故选为输入。输入和输出均归一化到[0,1]。评价指标采用RMSE和MAE。训练样本5000个，测试样本3784个。与浅层模型LSSVR、ELM、WNN和深度模型改进SAE（结构3-10-7-1）、改进DBN（结构3-12-9-1）比较，经网格搜索确定超参数，本文方法结构为3-15-10-1，初始学习率0.0009，动量系数初始0.01，迭代150次。重复十次取平均，本文方法的RMSE=0.0526、MAE=0.0393，均小于其他五种方法（LSSVR: 0.1104/0.0816，WNN: 0.1033/0.0616，ELM: 0.1109/0.0767，SAE: 0.0779/0.0561，DBN: 0.0839/0.0662），但运行时间32.54秒，长于其他方法（10.51、16.28、2.04、27.57、29.89秒）。误差统计显示，本文方法在±0.02、±0.05、±0.10范围内的误差个数分别为1326、2715、3524，均高于其他方法。进一步与层次GRU、SAE-LSTM、基本堆叠RNN比较，本文方法RMSE/MAE仍最优（0.0526/0.0393 vs 0.0689/0.0482、0.0662/0.0467、0.0838/0.0637），运行时间最短（32.54s vs 44.79、47.82、53.37s）。

实验二：电力负荷预测。数据为西班牙2015年1月1日至2018年12月31日的小时负荷（共1461天，少数缺测）。选择两个时段：第649天至第748天（100天）和第749天至第948天（200天）。第一个时段用前99天（2376点）训练，后1天（24点）预测；第二个时段用前197天训练，后3天（72点）预测。考虑到相同小时的日相关性和周模式，使用24个堆叠GRU-RNN分别对每个小时建模，回归步长设为7。数据样本格式为{x_t^{(H)}, x_{t+1}^{(H)}, ..., x_{t+7}^{(H)}} → {x_{t+8}^{(H)}}。预测结果（图13、14）显示，本文方法的RMSE和MAE显著低于其他四种深度学习方法：第一时段RMSE=507.2、MAE=351.1，第二时段RMSE=484.2、MAE=327.8；而对比方法（方法5-8）的RMSE在848.2~1618.8之间。结果验证了方法在不同长度和季节时段下的准确性，且更多训练样本可略微提升精度。

## 结论

本文提出了一种基于改进堆叠GRU-RNN的可再生能源和电力负荷预测方法。通过相关性分析选择敏感输入参数，简化GRU结构降低模型复杂度，结合AdaGrad与可调节动量改进训练算法，使模型能够准确建立监测参数与发电量或负荷之间的映射，并适用于多变量和单变量场景。在德国风电和西班牙负荷数据上的实验表明，该方法的预测精度优于现有浅层和深度学习方法，且运行时间低于其他RNN变体。局限性包括：部分超参数依赖经验确定，训练时间仍长于浅层模型，且需要较长的训练样本。未来工作包括改进训练策略、探索更多监测参数、多能预测及极端情况下的负荷异常检测。
