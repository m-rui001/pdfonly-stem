# 处理木质纤维素生物质热解热重分析数据以进行等转化率动力学分析：玉米秸秆案例研究

*Processing thermogravimetric analysis data for isoconversional kinetic analysis of lignocellulosic biomass pyrolysis: Case study of corn stalk*, 2017, https://doi.org/10.1016/j.rser.2017.09.113

本文主张，利用热重分析（TGA）数据对木质纤维素生物质热解进行等转化率动力学分析时，采用Friedman微分等转化率法可以最有效地获得随转化率变化的有效活化能，但必须对原始TGA数据进行系统预处理——包括去除误差数据点、脱除脱水段、数值微分、平滑噪声和插值——才能得到可靠结果。作者以玉米秸秆为案例，完整演示了该流程，并指出所得有效活化能从148到473 kJ·mol⁻¹（转化率0.05–0.85）的显著变化源于木质纤维素各组分的多重分解机制。

## 一、引言与实验基础

木质纤维素生物质可通过燃烧、气化、热解等转化途径生产可再生能源与化学品，其中热解一般在300–600°C无氧条件下进行，产品分布受原料、温度、加热速率等影响。热解反应器的设计需要流体力学、传热传质及动力学参数，而TGA是获取动力学实验数据最常用的工具。文献计量显示，2000年以来基于TGA的木质纤维素热解动力学研究持续增长。动力学方法分模型拟合法和等转化率法；模型拟合法常因转换函数的选择而得到差异极大的动力学参数，等转化率法则能避免这一缺陷。Friedman方法是其中最常用的一种，因为它线性、准确，且不限于线性升温程序，但对数据噪声敏感，需借助平滑技术。本文旨在系统梳理从原始TGA数据到有效活化能的完整处理链条，并以玉米秸秆为对象展开案例分析。

TGA测量样品在受控温度和气氛下的质量变化，常与红外（IR）、质谱（MS）或GC/MS联用分析逸出气体。热解动力学测定需在惰性气氛（如N₂）下进行，升温程序可选等温、线性或阶跃线性，其中线性程序最常用，加热速率通常取0.1–100 K min⁻¹，过高会引起传质干扰。实验所用仪器为PerkinElmer Pyris 1 TGA，氮气气氛，加热速率为2.5、5、10、20、40 K min⁻¹。玉米秸秆样品的工业分析和元素分析结果见原文图4。线性升温公式为：
```
T = Ti + β t    (1)
```
（原文中此公式以乱码形式出现，变量T、Ti、t、β分别代表温度、起始温度、时间和升温速率。）

## 二、TGA数据预处理与转化率计算

原始TGA数据中由于系统误差可能存在少量违背质量单调递减趋势的“误差”数据点，需在进一步处理前去除。作者编写了程序，按顺序遍历数据点，仅保留质量严格下降的点，流程图见图5。随后应去除脱水阶段，因为水蒸发机制与生物聚合物分解不同。若不去除，会导致动力学模型预测偏差。脱水阶段终点T₀的确定可简单地取固定温度（如150°C），但更准确的是遵循ASTM E1131标准，取TGA曲线第一质量平台的中心点。基于处理后的TGA曲线，转化率定义为：
```
α(T) = (m0 - m(T)) / (m0 - mf)   (2)
```
（原文提取为乱码，但变量m0、m(T)、mf分别在T₀、温度T和最终温度时的质量；当T从T₀升至Tf，α从0增至1。）

微分转化率dα/dT能揭示重叠分解反应细节，也是Friedman方法所需。通常用有限差分法进行数值微分：中间点用中心差分，首尾点分别用向前和向后差分，计算公式如式(3)所示（原文乱码，但逻辑明确）。微分后的曲线噪声很大，需平滑处理。平滑方法分参数拟合（如logistic、Weibull、Fraser-Suzuki函数）和非参数拟合（如移动平均、Savitzky-Golay、LOWESS）。参数拟合可能扭曲动力学特征，非参数法中LOWESS通过对每个数据点邻域进行二次多项式加权回归给出平滑值，比等权方法更合理。平滑程度由参数sp控制，sp过小平滑不足，过大则过度平滑。作者采用校正Akaike信息准则（AICc）自动确定最优sp，公式为：
```
AICc = log(RSS/n) + 2·(δ1/δ2)·(n+ν)/(δ1/δ2-2)   (4)
```
（原文公式乱码，n为数据点数，RSS为残差平方和，δ1、δ2、ν为涉及平滑矩阵L的迹。）对玉米秸秆2.5 K min⁻¹数据，sp在0.01–0.1范围内以0.01步长扫描，最优sp=0.04。

## 三、Friedman等转化率分析与动力学验证

为应用Friedman方法，需从平滑后的α–T和dα/dT–T曲线中插值得到给定转化率α下的Tα和(dα/dT)α。常用三次样条插值，因其能保证节点间连续。本文取α=0.05:0.05:0.85。等转化率方法的基本假设是：反应速率在给定转化率下仅为温度的函数，且转化函数和动力学参数与升温速率无关。线性升温下固态反应速率方程为：
```
β·(dα/dT) = A·exp(-E/RT)·f(α)   (5)
```
取对数得：
```
ln[β(dα/dT)] = ln[A f(α)] - E/(RT)   (6)
```
对特定α和不同升温速率i，有：
```
ln[βi(dα/dT)α,i] = ln[Aα f(α)] - Eα/(RTα,i)   (7)
```
因此，用ln[βi(dα/dT)α,i]对-1/(RTα,i)作图，斜率为-Eα，截距为ln[Aα f(α)]。注意实际绘图采用-1000/(RTα,i)以便Eα直接以kJ mol⁻¹读出。玉米秸秆五种升温速率下的平滑β(dα/dT)–T曲线均出现一个峰及左侧肩峰，峰温和峰值随升温速率升高而增大（表2：峰温从592.0增至645.8 K，峰值从4.717×10⁻⁴增至7.693×10⁻³ s⁻¹）。Friedman等转化率图显示，大多数转化率下线性关系极好（R²>0.99），但α=0.85时R²仅为0.8998，这归因于高转化率处不同升温速率实验差异很小，导致误差增大。由此得到Eα和ln[Aα f(α)]随α的变化（图17）：Eα从α=0.05时的148 kJ mol⁻¹缓慢升至α=0.65时的186 kJ mol⁻¹，随后急剧升至α=0.85时的473 kJ mol⁻¹。类似趋势在芒草酸水解残渣、烟草废料、桉木等热解中也有报道。

由于Friedman方法同时给出Eα和ln[Aα f(α)]，可重建热解动力学过程。由式(5)可导得：
```
dT/dα = β·exp(Eα/(RT) - ln[Aα f(α)])   (8)
```
用经典四阶Runge-Kutta法对给定β和α求解该常微分方程，得到温度预测值。原文图18将五种升温速率下的实验曲线与基于Eα和ln[Aα f(α)]的模拟曲线对比，模拟与实验吻合良好，证明所得动力学参数有效。文中还强调，仅给出平均活化能没有意义，木质纤维素生物质的热解是由纤维素、半纤维素和木质素等多个子过程叠加而成，有效活化能是这些子过程活化能的集体表征，因此随转化率显著变化是合理现象。

## 四、结论

本文系统总结了从TGA原始数据到Friedman等转化率动力学参数的完整流程：去除误差点、去除脱水阶段、转化为α–T数据、数值微分、平滑、插值、等转化率计算、动力学重建及实验验证。玉米秸秆案例中，Eα在α=0.05–0.65范围内从148缓慢增至186 kJ mol⁻¹，在0.65–0.85范围内陡增至473 kJ mol⁻¹，这一变化反映了木质纤维素组分分解动力学的差异性。该通用流程同样适用于煤、聚合物、油页岩等固体燃料的TGA动力学分析。
