# 单层III族单硫族化物的结构与电子性质

**Structural and electronic properties of monolayer group III monochalcogenides** · 2017 · DOI: https://doi.org/10.1103/physrevb.95.115409

本文通过第一性原理计算，系统考察了16种可能的二维六角结构III-VI族二元单层MX（M = B, Al, Ga, In；X = O, S, Se, Te）的结构、力学与电子性质，发现它们全部热力学稳定，均为间接带隙半导体，带隙覆盖深紫外到近红外光谱范围；其面内刚度最高可媲美石墨烯，而弯曲刚度比石墨烯高一个数量级。文中特别指出氧化物（MO）因氧的高电负性而具有与众不同的电子结构，且带边色散与原子间成键性质均与组成元素的电负性相关。

## 引言与方法

石墨烯的诸多优异性能激发了对其衍生物及其他二维半导体的研究，已有多种MX体系（如InSe、GaS、GaSe、GaTe等）被实验制备，并展现出光电探测、光催化等应用潜力。然而，以往研究仅集中于Ga、In与S、Se、Te的组合，MO体系尚未被系统考察。本文则涵盖所有M与X的组合，旨在通过系统比较揭示性质随组成元素（尤其是电负性χ）的变化规律。

计算采用基于密度泛函理论（DFT）的投影缀加波（PAW）方法，交换关联泛函为GGA-PBE；平面波截断能从230 eV（InTe）到520 eV（MO）不等；布里渊区采用16×16×1的Monkhorst-Pack k点网格；电子与离子步的收敛标准分别为10⁻⁵ eV和10⁻⁴ eV；真空层至少12 Å以避免层间相互作用。全部计算使用VASP软件包。Bader方法用于分析原子有效电荷；对部分体系还采用HSE06混合泛函获得修正后的带隙值。声子谱通过小位移法计算，力常数矩阵在6×6×1超胞中构建，使用PHON软件处理。内聚能定义为

$$E_C = [(N_M E_M + N_X E_X) - E_{MX}] / (N_M + N_X),$$

其中E_MX为体系总能量，E_M和E_X分别为M和X原子的单原子能量，N_M和N_X为单胞中M和X的原子数。

## 结构与稳定性

模型体系按照已实验合成的GaSe和GaS的几何结构构建。所有16种MX化合物都形成六角蜂窝结构，单胞含有四个原子，以X-M-M-X的堆叠顺序构成四个子层，属于D_3h空间群。若切断其中的共价M-M键，可得到与翘曲III-V族单层相同的两层几何；但实验数据表明MX体系以“双层”几何生长。计算得到的结构参数列于表I，与已有理论结果吻合。键长d_MX随周期和族向下移动而增大，与原子半径趋势一致；晶格常数a随d_MX成比例变化。M-M键长d_MM只随M原子下移而增大，不依赖X种类。键角θ随X原子周期增大而减小，对M元素依赖较弱。单层厚度h与d_MX和d_MM均相关。

内聚能E_C随d_MX的增大而减小，即键越短结合越强。从最稳定的BO（6.65 eV/原子）到最不稳定的InTe（2.77 eV/原子），价电子离核越远，结构a越大。将氧化物与其体相对应物比较：体相Al₂O₃的内聚能为6.47 eV/原子，高于本文AlO的5.74 eV/原子；但与从体相切割出的Al终止（5.49 eV/原子）和O终止（4.93 eV/原子）表面相比，AlO在X-M-M-X几何中更稳定，支持了氧化物在该结构中的稳定性。文中承认表面重构可能降低能量，但未在本文研究范围内。

由于X比M电负性更强，X从M吸引电子到成键区域；Δχ增大时，更多电子在键上积累，键间排斥使键角增大。这解释了氧化物θ≈107°而其他体系约100°的现象。图1(c)显示电荷转移Δρ与Δχ的关系，氧化物与硫化物、硒化物、碲化物明显不同，这与IV-VI族[19]和II-VI族单层的趋势类似。

声子谱分析显示所有16种结构在整个布里渊区都具有正频率平方，即全部动力学稳定。每个单层有3支声学支（面内纵波LA、横波TA和面外声学支ZA）和9支光学支；LA和TA色散线性，ZA为二次色散，其曲率用于计算弯曲刚度。D_3h对称性在Γ点产生非简并和双重简并模式。光学谱可由六个特征本征模式描述：最低能量的光学模属E''表示，上下MX对在面内反向运动；此模式与声学模共存，可能导致强声光散射和低热导率。随后是A''₁模式，上下MX对在面外反向运动。当M和X质量变大时A''₁模与其他模分离；M为B或X为O时与之混杂。在BO中A''₁模几乎接触光学模上端。更高的光学模由六个带组成，Γ点上有两个非简并模（A'₁和A''₂）和两个双重简并模（E'和E''）。在氧化物中，E'和E''模在Γ点能量相近，而在InTe中则分离明显。将M从In换成B（保持Te），E'和E''模间的能隙闭合并在Γ点交换位置。A'₁模中M原子的本征矢量幅度显著大于X原子，其比值与原子质量比成正比：BO、BS、BSe和BTe的A'₁模本征矢量比为2.1、5.2、10.2和16.2。

## 力学性质

为研究力学性质，在扶手椅方向（x）和锯齿方向（y）施加高达1%的压缩和拉伸应变，弛豫后拟合到二次多项式：

$$E_T(ε_x, ε_y) = b_1 ε_x^2 + b_2 ε_y^2 + b_3 ε_x ε_y + E_0,$$

其中E_0为平衡单胞能量，ε为应变，b为能量量纲参数。计算发现b₁ = b₂，说明面内弹性响应各向同性，这是三角对称性的结果。面内刚度C和泊松比ν由下式得到：

$$C = [2b_1 - (b_3)^2 / 2b_1] / A_0,$$

$$ν = b_3 / 2b_1,$$

其中A₀为零应变单胞面积。方法可靠性由石墨烯验证（C = 341 J/m²，实验值340±50 J/m²）。MX化合物的C随元素下移而减小：最高为BO的350 J/m²，可比甚至略高于石墨烯；最低为InTe的39 J/m²，与磷烯相当（C_x = 26 J/m², C_y = 88 J/m²）。C与a相关：晶格常数越小，面内刚度越大。泊松比ν对给定M元素，从O到Te几乎单调减小。

弯曲刚度D由ZA模二次色散的曲率导出，采用Lifshitz公式：

$$ω = \sqrt{D/ρ_{2D}} \, q^2,$$

其中ρ_2D为二维质量密度。先验证石墨烯D = 1.5 eV与文献相符；MX体系中BO的D最高，约30 eV，比石墨烯高一个数量级，表明BO抵抗面外变形能力远强于石墨烯。其他MX结构的D也远高于石墨烯，这归因于X-M-M-X“双层”几何中垂直于表面的共价M-M键。

## 电子结构

氧化物MO的电子带结构用PBE和HSE06计算（图3）。所有MO都是间接带隙半导体。带隙值：BO为4.71 eV（HSE为6.24 eV），AlO为1.30 eV（HSE为1.94 eV），GaO为1.54 eV（HSE为2.62 eV），InO为0.45 eV（HSE为1.21 eV）。HSE修正只提高带隙、使导带上移，不改变色散形态。带图按χ(M)递减排列（B为2.04、Ga为1.81、In为1.78、Al为1.61）。价带顶的K点态在BO中能量显著低于Γ点态；GaO和InO中Γ点态略低；AlO中Γ点态显著低于K点。这可用部分电荷密度理解：K点态在M原子间呈σ成键特征，Γ点态在O原子周围呈π特征；当M的χ更高时，K点态能量更低。BO的价带顶偏离布里渊区中心，形成双峰结构，对应墨西哥帽色散，导致环形价带边缘和2D态密度中的1/√E奇异性。

对非氧化物MX（图4），PBE与HSE结果一致，只给PBE。所有MX单层均为间接带隙半导体。体相GaS、GaSe、InSe也是间接带隙（2.59、2.07、1.35 eV）。带隙范围在BO（6.24 eV）和InO（1.21 eV）之间。蓝色线标示的态类似于氧化物的孤立价带边：其Γ点态比K点低，但除AlO外不会低于K点，因为O的χ（3.44）远高于其他硫族元素（Te为2.10）。Δχ减小时，蓝色线下移。BTe是唯一χ(X)高于χ(M)的结构，其价带顶不由蓝色线决定，电荷密度集中在B和Te原子之间形成成键。墨西哥帽色散在BS、AlS、AlSe、AlTe以及GaS、GaSe、GaTe、InS、InSe、InTe中均存在，但在BO中最为突出。

总之，所有16种MX单层都热稳定，为间接带隙半导体，带隙从1.21 eV（InO）到6.24 eV（BO），覆盖深紫外到近红外。面内刚度最高可与石墨烯相比，弯曲刚度（尤其是氧化物）可比石墨烯高一个数量级。BO、BS、AlS、AlSe、AlTe在价带顶具有墨西哥帽色散。这些性质使它们成为纳米电子学应用的潜在候选材料。
