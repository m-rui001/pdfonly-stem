# 全球海洋碳汇的年代际变化与趋势

**Decadal variations and trends of the global ocean carbon sink** · 2016 · https://doi.org/10.1002/2015gb005359

本研究基于观测重建的全球表层海水二氧化碳分压（pCO₂）地图，将神经网络插值方法的时间覆盖范围从1998–2011年扩展至1982–2011年，用以评估全球海洋碳汇的年代际变化与趋势。分析表明，全球海洋碳汇在长期增强趋势上叠加了强烈的年代际波动：1990年代碳汇持续减弱，至2000年前后达到最低值约−0.8 ± 0.5 Pg C yr⁻¹，此后显著增强，2011年达到约−2.3 ± 0.6 Pg C yr⁻¹。这些年代际变化主要来自副极地与极地海域（南北半球中高纬度），而热带区域主要贡献年际变化。温度驱动的溶解度变化只能解释部分波动，尤其在中纬度；更高纬度的大多数变化则源于大气强迫引起的溶解无机碳与碱度变化的非热力效应，其空间模态类似于南北半球环状模。与全球碳计划（GCP）相比，1982–2011年累积人为CO₂吸收量减少约7.5 ± 5.5 Pg C，相应增强了陆地碳汇的估算。

## 数据与方法：SOM-FFN重建与气海通量计算

研究使用Surface Ocean CO₂ Atlas第2版（SOCATv2）的网格化pCO₂数据，通过自组织映射-前馈神经网络（SOM-FFN）方法，在1°×1°空间分辨率和月时间分辨率上重建全球表层pCO₂。该方法分两步：首先利用海表温度、盐度、混合层深度和Takahashi等（2009）的pCO₂气候态将全球海洋划分为16个生物地球化学省；其次在每个省内建立环境驱动因子（SST、盐度、大气CO₂干空气混合比xCO₂、混合层深度、卫星叶绿素）与观测pCO₂的非线性关系，再结合驱动因子重建时空演化。为扩展至1982年，部分输入数据采用气候态替代（如叶绿素、混合层深度、EN4盐度），并做了敏感性测试，表明在数据稀疏年代重建的差异不超过1990年以来的不确定性。重建的pCO₂场经过三维平均滤波去除高频噪声。气海CO₂通量采用标准批量参数化公式：

FCO₂ = k_w · S_CO₂ · (1 − f_ice) · (pCO₂ − pCO₂_atm)   （式1）

其中k_w为气体传输速率（按Wanninkhof 1992的二次风速依赖，并以全球平均传输速率16 cm h⁻¹调整为Sweeney等2007的¹⁴C约束），S_CO₂为CO₂溶解度（Weiss 1974），pCO₂_atm由GLOBALVIEW-CO₂干空气混合比经水汽校正得到，f_ice为海冰覆盖率。通量按无冰面积尺度化。北极区域补充常值吸收−0.12 ± 0.06 Pg C yr⁻¹；沿海区域未独立校正以避免双重计算。不确定性整合了网格化误差、SOM-FFN与网格观测的均方根误差、以及多种参数化方案（Wanninkhof 1992、Wanninkhof-McGillis 1999、Nightingale等2000）带来的系统性差异。评估表明，重建值与SOCATv2观测之间几乎零偏差，均方根误差小于20 μatm；与未参与训练的LDEOv2013数据库对比，全区平均差异在±3 μatm以内（1982–1986年除外）。但长期站点（BATS、Hydrostation S、HOT）对比显示，重建的季节振幅、年际变率和趋势略有低估。方法比较研究中SOM-FFN在年际变率重建上名列前茅，但数据稀疏区年际变率偏低；在年代际尺度上与其他方法一致，适合揭示年代际变化。

## 通量变化与时空模态：从全球到区域

全球积分通量显示，1980年代平均吸收约−1.4 ± 0.4 Pg C yr⁻¹，1990年代逐渐减弱至1999年约−0.8 ± 0.5 Pg C yr⁻¹，此后加速增强，2011年达−2.3 ± 0.6 Pg C yr⁻¹。与仅由大气CO₂增长驱动的预期趋势（由NCAR CCSM模型hindcast缩放得到）相比，1997–2002年的低吸收期显著偏离。分解到海盆：南方海洋（35°S以南）的演变形态与全球大致同步，贡献了2002年后全球吸收增加的约50%；大西洋也呈类似模式（1990年代减弱、2000年后加速）；太平洋整体对年代际趋势贡献较小，但主导年际变率；印度洋在1998年前较平稳，之后略有增加。

纬向平均通量的Hovmöller图（图2、3）显示：太平洋赤道带呈现ENSO驱动的年际信号；北太平洋50°N–60°N存在1980年代异常吸收、1990年代异常排放、2000年代后期恢复吸收；2002年后太平洋出现近乎全盆地的异常吸收，但被赤道强异常排放抵消，故太平洋整体年代际趋势不强。大西洋赤道区变幅小，但整个盆地呈现2000年后转强吸收的趋势；印度洋变化最弱；南方海洋在40°S–65°S表现出最强的年代际振荡（1980年代末–1990年代初异常吸收，1990年代末–2000年代初异常排放，之后再度增强）。值得注意，2000年后强源与强汇同时增强，表明气海CO₂交换强度整体增大。

对去季节性、去趋势后的ΔpCO₂（海洋与大气pCO₂之差）进行EOF分解，前两个模态共解释53%方差：EOF1（34%）为年代际模态，空间上几乎全球正异常（除热带中太平洋负异常），最强中心位于北大西洋与北太平洋高纬、东赤道太平洋和南极周边；其主成分（PC1）在1990年代末前上升（碳汇减弱），随后骤降（碳汇增强）。EOF2（19%）为ENSO相关年际模态，空间上热带太平洋呈典型ENSO型（El Niño时负异常），其主成分与MEI相关系数0.62（表1）。EOF1与任何气候指数（MEI、PDO、AMO、SAM、NAM）的相关均不显著（最高为NAM 0.33），表明该年代际模态并非单一经典环状模的直接反映。

## 驱动机制：热力与非热力成分的补偿及大气环流联系

将EOF模态分解为热力部分和非热力部分（ΔpCO₂_EOF = ΔpCO₂_thermal + ΔpCO₂_nonthermal）。热力部分由温度敏感性0.0423·<pCO₂>·SST_EOF计算（式3），非热力部分为残差，主要反映DIC、碱度和盐度变化，其中盐度直接贡献很小。分析表明两模态中热力与非热力成分大体反向补偿，这与季节尺度上的典型行为一致。

对EOF2（ENSO模态），东赤道太平洋的El Niño正热力信号被更强的非热力负信号掩盖——后者源于上升流减少导致的DIC供给下降，总体上形成净的负ΔpCO₂。回归至海平面气压、风场等，显示典型的ENSO遥相关型：西太平洋低压东移、赤道西风异常、副极地北太平洋低压增强。浮力强迫的变化对上升流的影响远小于直接风应力。

对EOF1（年代际模态），北半球副极地环流区以正非热力异常为主，副热带以正热力异常为主，二者叠加形成中高纬度几乎匀一的正常ΔpCO₂。海平面气压回归显示中纬度40°N附近气压梯度增强、风应力增强，而副热带风减弱，这种经向结构有些类似北半球环状模（NAM/北极涛动），但中心位置偏太平洋且范围更宽。解析上，高纬冷SST和强风使混合层加深，将富DIC水携带至表层并加重光限制，产生正非热力异常且超过冷却的负热力异常；副热带则相反，暖异常使混合层变浅，非热力负异常但弱于热力正异常。热带太平洋，EOF1调制ENSO的类型——正相位时使El Niño中心西移（偏Modoki型）。南半球副极地也出现与北半球类似的非热力正异常被热力负异常部分补偿的模式，并联系到南方环状模（SAM）；但整体上EOF1与SAM和NAM的相关都很低，可能因为该模态同时拟合两个环状模，且受1997/1998年中心型El Niño扰动。作者强调这些机制是相关性的推断，无法区分因果，且30年长度对充分评估年代际变化仍偏短。但值得注意的是，碳汇的演变与全球平均表面气温的“高温停滞”期存在时间上的类似，可能与太平洋和北大西洋多年代际模态的协同变化相关。

## 全球碳预算影响与结论

将本文当代净通量加上河流输入（约0.45 Pg C yr⁻¹）得到人为CO₂吸收量，进而计算剩余陆地汇。与GCP 2015预算对比：GCP给出的1982–2011年累积海洋人为CO₂吸收为64.6 ± 2.7 Pg C，本文为57.1 ± 2.8 Pg C，差值7.5 ± 5.5 Pg C；相应地，陆地生物圈需要额外吸收约7.5 ± 8.8 Pg C（相当于每年约0.25 Pg C更强），但该差异因综合不确定性而不显著。这一结果意味着，当考虑观测重建的强年代际变化时，海洋累积吸收量显著小于基于模式（低估变率）的预算推算。

总结：本文扩展的SOM-FFN重建表明，全球海洋碳汇在1980年代停滞、1990年代减弱、2000年后强力反弹，其主导模态EOF1代表了副极地/副热带海区对大气环流年代际重组的响应，与NAM/SAM有某种相似但有差异；年际变率由热带太平洋ENSO主导（EOF2）。这些发现说明海洋碳汇对气候变化的敏感性可能高于以往认知，对2°C目标下排放路径的制定具有潜在影响。未来需要提高年际变率重建精度、定量化驱动机制，以及区分外强迫与内部变率的方法。
