# 石墨烯负载单原子催化剂用于析氢反应的理论设计与实验验证

**Rational Design of Graphene-Supported Single Atom Catalysts for Hydrogen Evolution Reaction** · 2019 · https://doi.org/10.1002/aenm.201803689

本研究通过密度泛函理论（DFT）计算与电化学实验相结合，系统考察了负载于氮掺杂石墨烯上一系列过渡金属单原子催化剂（SACs）的析氢反应（HER）活性，提出活性起源于金属价层dₘ²轨道及其与氢形成的反键态能级位置，并据此建立了活性—电子结构线性关联。理论预测Co-SAC具有最佳活性（ΔGₔ* = 0.13 eV），实验合成Co、Ni、W三种SACs后，以XANES、EXAFS、STEM等手段确证其M-N₄C₄结构，电化学测试表明Co-SAC的HER性能显著优于Ni-SAC和W-SAC，与理论趋势一致。

## 1. 引言与背景

全球变暖与化石燃料耗竭推动了对清洁能源技术的需求，氢气因其高能量密度和可再生性被视为理想能源载体，而电解水制氢中的HER反应需要高效催化剂来克服较高过电位（η）。铂是目前最有效的HER催化剂，但高昂成本和稀缺性限制了其大规模应用，因此需开发基于非贵金属（如Co、Ni、Mo、Fe及其衍生物）的高效、稳定电催化剂。单原子催化剂（SACs）因具有单一活性位点、100%原子利用率及独特的电子结构（不饱和配位、量子尺寸效应、强金属—载体相互作用）而受到关注，但载体通常存在导电性差或稳定性不足的问题。石墨烯因比表面积大、导电性高、化学稳定好而成为理想载体，氮掺杂进一步通过氮的孤对电子与过渡金属空d轨道成键增强金属分散性并抑制团聚。尽管已有多种过渡金属SACs被用于ORR、OER、HER、CO₂还原等，但其活性起源仍不明确，催化剂的电子结构与活性之间缺乏系统关联。本文旨在通过DFT计算和实验验证，揭示SACs在HER中的活性来源，并提出理性的设计原则。

## 2. 理论预测与活性起源

HER涉及Volmer反应（H⁺ + e⁻ + * → H*）、Tafel反应（2H* → H₂ + 2*）或Heyrovsky反应（H⁺ + e⁻ + H* → H₂ + *），催化剂对氢的吸附自由能ΔGₔ*是决定反应速率的关键参数。根据Sabatier原理，ΔGₔ*接近零时HER活性最优。作者首先构建了包含多种可能非金属活性位点（graphitic-N、graphitic-C、pyridinic-N、terminal pyridinic-N、pyrrolic-N、N-oxide）的N掺杂石墨烯模型，计算各非金属位点的ΔGₔ*，结果显示这些位点活性均较差：N-oxide（-0.51 eV）、pyrrolic N（0.52 eV）、pyridinic N/M-N（0.89 eV）、terminal graphitic N（1.01 eV）、graphitic C（1.69 eV）、graphitic N（1.89 eV）。随后以金属原子与四个氮配位构成M-N₄C₄模型，计算18种过渡金属SACs的ΔGₔ*，发现仅Co、Cr、Fe、Rh、V等少数金属具有较好活性（ΔGₔ*在-0.20至0.30 eV之间），其中Co-SAC的ΔGₔ* = 0.13 eV最接近零。而Pd-SAC（1.86 eV）和Ni-SAC（1.62 eV）因氢吸附过弱活性低，Re、Mo、Ti、W、Ta等金属则因氢吸附过强（ΔGₔ*分别为-0.92、-0.93、-0.94、-1.44、-1.64 eV）也不理想。由于金属活性位点位于石墨烯基面而非边缘，作者提出HER按Volmer-Heyrovsky机理进行。

为了阐明活性来源，作者基于d带理论分析了SACs的电子结构。总态密度和投影态密度计算表明，金属的dₘ²价轨道（自旋向上和向下）是唯一与氢发生杂化的活性轨道，杂化后形成成键态（σ）和反键态（σ*）。将这三种轨道能级（Eₚ、Eσ、Eσ*）与ΔGₔ*关联，发现Eσ*与ΔGₔ*呈最佳线性关系：Eσ*能级越高且占据数越低，氢吸附越强（ΔGₔ*越负）；反之反键态填充程度升高则活性降低。当Eₚ靠近费米能级时，反键态部分填充，对应理想吸附强度（ΔGₔ*≈0），Co-SAC正是这种情况。此外，Bader电荷分析表明电荷转移量也与ΔGₔ*存在线性趋势：Ta-SAC向氢转移0.84 e⁻/H原子（ΔGₔ*=-1.64 eV），Pd-SAC仅转移0.10 e⁻/H原子（ΔGₔ*=1.86 eV），Cr-SAC转移0.42 e⁻/H原子（ΔGₔ*=0.28 eV），理想电荷转移量约为0.35 e⁻/H原子对应ΔGₔ*=0 eV。这些结果揭示了SACs HER活性源于金属dₘ²轨道与氢轨道的杂化，反键态能级和占据状态是核心描述符。

## 3. 实验合成、表征与电化学验证

基于理论预测，作者以氧化石墨烯（GO）、丙烯酰胺和金属氯化盐为前驱体合成了Co-SAC、Ni-SAC和W-SAC，并制备无金属的氮掺杂石墨烯（NG）作为对照。XPS表征显示样品中金属含量极低，金属以混合价态存在；N 1s谱可解卷积出pyridinic N（398.0 eV）、Co-N（398.6 eV）、pyrrolic N（400.5 eV）、graphitic N（401.1 eV）和N-oxide（404.2 eV）等位点，与理论模型一致。XANES和EXAFS分析表明，金属的配位环境与体相金属及其氧化物显著不同：Co-SAC的EXAFS主峰位于1.43 Å（对应Co-N键），区别于Co-O（1.63 Å）和Co-Co（2.1、2.7 Å）；Ni-SAC和W-SAC分别显示1.44 Å和1.45 Å的Ni-N、W-N峰，均不同于各自的金属—金属或金属—氧峰。理论模拟的XANES谱（使用FDMNES）与实验谱吻合，进一步验证了M-N₄C₄结构模型。ADF-STEM图像显示孤立金属原子均匀分布在石墨烯表面，原子间距约2–3 Å，EELS进一步确认了单原子存在。

电化学测试在0.5 M H₂SO₄中进行（三电极体系，催化剂载量0.2 mg cm⁻²，iR补偿）。线性扫描伏安曲线表明Co-SAC的HER活性明显优于Ni-SAC、W-SAC和NG：达到10 mA cm⁻²电流密度所需过电位分别为230、530、590和630 mV（vs RHE），与理论ΔGₔ*趋势一致。Tafel斜率方面，Co-SAC（99 mV dec⁻¹）小于W-SAC（122 mV dec⁻¹）、Ni-SAC（167 mV dec⁻¹）和NG（169 mV dec⁻¹），且Co-SAC具有更高交换电流密度（3.88 × 10⁻² mA cm⁻²）。循环伏安1000圈后Co-SAC性能衰减可忽略，表明其具有良好的长期稳定性。实验结果为理论预测提供了直接验证。

## 4. 结论与计算方法

本文通过DFT计算与实验结合，确立了SACs的HER活性与电子结构间的关联：金属价层dₘ²轨道及其反键态Eσ*的能级位置决定氢吸附强度，Eσ*越高（填充越少）吸附越强，反之越弱；Co-SAC因dₘ²轨道靠近费米能级、反键态部分填充，获得接近零的ΔGₔ*和最优活性。这一“活性—电子结构”线性关系可指导SACs的理性设计。合成的Co、Ni、W三种SACs均以M-N₄C₄形式均匀分散，电化学测试确认Co-SAC活性最高，与理论预测一致。

计算方法：采用自旋极化DFT，投影缀加波（PAW）方法，PBE交换关联泛函，平面波截断能500 eV，能量收敛标准10⁻⁶ eV，原子力小于0.01 eV Å⁻¹，Gaussian展宽0.05 eV。结构弛豫和能量计算使用9×9×1的K点，电子结构计算使用45×45×1。模型为4×4石墨烯超胞（26个C原子），在碳双空位处嵌入一个金属原子并与4个N配位，晶格常数优化为2.46×2.46 Å，层间距20 Å。氢吸附能按公式ΔE_ad = E(SACs-H*) − E(SACs) − 1/2 E(H₂)计算（原文公式排版有歧义，见疑点），吉布斯自由能修正为ΔGₔ* = ΔE_ad + 0.24 eV（已包含零点能和熵贡献）。Bader电荷分析采用Henkelman组的方法。XAS实验在APS 20-BM-B和9-BM-B线站完成，XANES理论谱用FDMNES计算。AFD-STEM使用Nion Ultra STEM 200（60 kV，汇聚半角30 mrad，ADF收集半角50–210 mrad）。电化学测试使用CHI 760C工作站，参比电极为饱和Ag/AgCl，对电极为铂丝，工作电极为玻碳电极（载量0.2 mg cm⁻²），扫描速率10 mV s⁻¹，稳定性测试在0–0.6 V（vs Ag/AgCl）循环。
