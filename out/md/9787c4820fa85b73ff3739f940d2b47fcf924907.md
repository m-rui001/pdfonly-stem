# 注视线索效应（Gaze-Cueing Effect）的元分析：眼睛注视如何引导视觉注意

**Visual attentional orienting by eye gaze: A meta-analytic review of the gaze-cueing effect** · 2021 · https://doi.org/10.1037/bul0000353

本文报告了首项对注视线索效应（gaze-cueing effect）文献的元分析整合，汇总了来自137个独立样本、共423个效应量、4,239名健康成人参与者的数据。核心主张是：他人眼睛注视方向可靠地引导观察者的空间注意，这一效应在各任务特征和线索特征水平上均稳定存在（总体效应量 grm = 0.26），但效应量大小受到先前直视线索、线索-目标刺激间隔（SOA）、任务类型以及线索面部表情的显著调节，而线索是否在目标出现后仍停留在屏幕上以及线索面孔类型（示意性面孔、计算机生成面孔或真实面孔照片）没有可靠的调节作用。这些发现被置于社会注意系统的理论框架中讨论。

## 背景与理论问题

由于人类无法同时将有限视觉信息全部处理到意识层面，选择性视觉注意是必要的认知机制。理想的自适应注意机制会利用环境中的信息性线索将注意引向潜在重要位置。注意线索范式（cueing paradigm）已经证明，人们倾向于对被线索有效提示（cued）而非无效提示（miscued）的外周目标反应更快。他人的方向性注视就是这样一种被广泛关注的线索：在社交互动中，他人注视的方向具有高度信息性，已被提出有助于乃至服务于一系列高级人类行为，包括社会认知、协调行动和语言习得。健康成人一致表现出的注视线索效应是指：观察者对出现在注视方向一致位置（线索有效）的目标反应快于出现在注视方向相反位置（线索无效）的目标。虽然这一效应被视为稳健，但具体的任务特征和线索特征如何调节该效应，因缺乏系统研究或研究结果混乱而不清楚。这种不确定性既阻碍了理论进展——例如，情绪表情对注视线索效应的影响在不同范式间难以统一解释——也妨碍了研究者在方法学上进行明智的设计选择。

四个关键任务参数在不同注视线索任务间变化显著：是否呈现先前直视线索（prior direct gaze）、注视线索的偏移时机（gaze cue offset timing）、线索与目标之间的刺激间隔（SOA）、以及任务类型。关于先前直视线索，部分任务在每次方向性注视线索前呈现同一面孔的直视预线索，另一些则没有；虽然直视在更广泛的社会注意文献中被证明是强大的调节变量（如Senju和Johnson的“快速通道调节模型”提出直视会增强社会知觉和认知过程），但直接操纵先前直视线索的既有研究很少，且结果不一。关于线索偏移时机，有些任务中方向性注视线索在目标出现后仍留在屏幕上，有些则在目标出现同时或之前消失；由于突现和突隐刺激都能捕获注意，线索提前消失可能将注意从注视位置拉回中央注视点，从而干扰注视线索效应的形成。关于SOA，不同研究从14 ms到2,500 ms不等；注视线索效应随SOA变化的时程被认为可以说明该效应是自动的还是意志性的——若注视线索效应与外围线索效应（后者被认为是自动的）具有相同的行为和神经时程，则应同样被视为自动的。外围线索效应在约200 ms出现、600 ms衰减，约800 ms时出现反转（即返回抑制，IOR）；而注视线索效应是否遵循同样时程尚不清楚。关于任务类型，检测任务（只需判断目标出现）的工作记忆负荷最小，定位任务（需判断目标位置）居中，分类任务（需判断目标类别）最大；Posner曾提出任务难度增加会通过“零和”现象削弱自动注意线索效应——任务实施所需资源会侵占注意定向资源。

三个关键线索特征同样在不同研究间差异显著：面孔类型（示意性线条面孔、计算机生成面孔、真实面孔图像——其生态效度依次递增）、表情是情绪性的还是中性的、以及情绪表情的具体类型。面孔类型这一变量在既有注视线索文献中被惊人地忽视；虽然早期研究（Hietanen & Leppänen, 2003）发现示意性面孔比真实面孔产生更大的注视线索效应，但该发现尚未被重复。关于情绪表情，理论上有充分理由预测表情类型可能调节注视线索效应：跟随不同表情的注视具有不同的适应价值——跟随恐惧注视可能获知威胁，跟随快乐注视可能获知食物，跟随厌恶注视可能避开有害物，跟随悲伤注视可能发现需要帮助的同类；从进化角度看，不同目的所需的注意定向速度也应不同（潜在威胁需要最快响应）。但单项研究结果混杂：部分研究发现恐惧面孔比快乐或中性面孔产生更强的注视线索效应，也有研究发现快乐面孔产生弱于中性面孔的效应，还有研究未发现任何表情调节作用。

基于上述研究空白，本元分析预先注册了所有调节变量分析：检验总体注视线索效应是否存在，并评估先前直视线索、线索偏移时机、SOA（连续和分类两种方式）、任务类型、面孔类型、中性与情绪表情、以及具体情绪表情的调节作用。预设假设包括：总体效应为正；SOA在早期（≤200 ms）、短期（201–400 ms）、中期（401–600 ms）、长期（601–800 ms）均产生效应且短期效应最大，延长（>800 ms）时效应可能消失甚至反转（基于IOR的可能性）；情绪表情比中性表情产生更大线索效应；威胁相关表情（恐惧或愤怒）比其他表情产生更大线索效应。对面孔类型不作方向性预测，但计划在不同SOA水平上探索性比较示意图与真实面孔的差异。

## 方法

筛选标准如下：排除非英文论文、不报告实验独有数据的论文、以及不含健康成人（17岁及以上）人类被试样本的论文；同一数据集在多个实验中报告时取参与者人数最多的实验，人数相同时取最先发表的实验；具有特定亚临床特征作为临床群体代理的样本被视为非健康成人而排除；排除儿童研究，因为目的是评估任务和线索特征调节效应而非发展轨迹或个体差异。纳入条件包括：注视线索任务通过电脑直接或镜像呈现；每名被试接受相等数量的有效和无效线索试验；无任何并发任务；每次只呈现一个注视线索刺激，且必须是面部或双眼的图像、系列图像或视频（双眼同时左视或右视），嵌入正面朝向的示意性人类面孔、计算机生成人类面孔、类人机器人或真实人类面孔中；线索须在中央呈现且未被以干扰人类眼睛识别的方式操纵（如操纵白色巩膜与深色瞳孔/虹膜的比例）；目标须在中央外周呈现且只出现在有效和无效位置；反应必须通过按键手动完成。若存在被试与线索或目标刺激之间的操纵性/有意义先前关系则排除；若存在某任务参数与线索有效性系统性共变的情况，或所有作者一致认为方法学严重损害范式效度，也予以排除。数据要求：效应量计算所需的最小数据——有效与无效试验的条件均值和标准差——必须报告或可获取；对2005年后发表的缺失数据研究，联系通讯作者请求数据。

检索策略为多步骤：2020年4月在Web of Science、PsycINFO、PUBMED、Scopus和ProQuest Dissertations and Theses Global中进行标题和摘要检索，检索词组合为“social”与“gaz*”及“cue*”、“cuing”、“follow*”、“direction*”、“perce*”或“orient*”；排除标题或摘要含“ophthalmol*”的引文（因眼科文献中“注视定向”指完全不同的事物）；限制英文且1990年后发表。辅以对Dalmaso等人（2020）和Frischen等人（2007）两篇综述的系统向后和向前引文检索。共获得10,549条引文（另有5条在数据请求邮件过程中发现），去重后剩5,632条待筛选。摘要筛选由第一和第二作者独立进行，若两人均建议排除则排除，均建议纳入则送全文评审，意见分歧时讨论至共识，无法决定时咨询最后作者——始终偏向谨慎纳入。5,632条摘要中5,315条在摘要阶段被排除，317篇全文进入资格评审；12篇因无法获得全文或非英文而无法评审，15篇为软件未检测到的人工重复。最终75篇论文或论文中报告了至少一个符合条件的注视线索效应。

数据提取由第一作者完成，提取每个效应量对应的任务和线索特征（是否使用直视预线索、线索是否与目标同时呈现在屏幕上、SOA毫秒数、任务类型、面孔类型、真实面孔的线索表情）、样本平均年龄和女性人数。效应量计算需要有效和无效试验的反应时均值、标准差和事后数据缩减样本量，以及可用时提取两种试验反应时之间的皮尔逊相关系数。最初计划每样本仅提取一个聚合效应量，后改为多层级元分析；第三作者独立编码了最初112个样本中30%的随机子集（当时SOA和具体情绪表情尚未作为调节变量编码故未双重编码），各变量编码百分比一致性在94.1%–100%之间，平均98.5%，Cohen's κ在.90–1之间，平均.97，表明编码系统高度可靠。

所有效果量采用Hedges's grm——重复测量标准化均数差（Lakens, 2013推荐）。效应量计算公式为正数表示线索有效比线索无效反应更快（见原文公式1和公式2）。由于有效-无效相关r仅62个效应量可用，通过三水平元分析对62个可用的皮尔逊相关进行元分析估计（r = .92, 95% CI [.90, .94]），用该点估计值r = .920169进行均值插补。主分析使用R包“metafor”中的rma.mv函数进行三水平随机效应元分析，建模三个层面的变异：抽样变异（水平1，参与者变异）、样本内变异（水平2，共享同一样本的效果集变异）、样本间变异（水平3，汇集样本效应间的变异）。为处理相关抽样方差，使用R包“clubSandwich”对所有模型进行稳健方差估计。调节变量分析用metafor进行；因Knapp-Hartung校正尚不支持多层级模型，改用t分布替代默认z分布。配对事后比较用clubSandwich的稳健方差估计和小样本校正（“Naive-Fp”方法）。对于需要多个调节变量同时控制的模型，SOA作为连续变量进入，表情未纳入（因其只能针对真实面孔线索的效应子集编码，纳入会损失大量功效）。连续SOA分析中SOA进行均值中心化。研究报告了多个SOA但仅提供跨SOA合并效应量时未排除：不能进入SOA调节分析，但可进入总体效应及其他调节变量分析。表情分析仅使用真实面孔线索且表情为中性或六种基本情绪表情（快乐、悲伤、愤怒、惊讶、恐惧、厌恶，Ekman & Friesen, 1971）的满强度表达。

## 结果

总体上，423个效应量来自137个样本、4,239名参与者；39个效应量来自未发表研究；发表年份1998–2020年（M = 2011, Median = 2013）。在报告了性别的107个样本中（3,429名参与者），2,163人（63.08%）为女性。三水平元分析合并全部423个效应量发现：总体注视线索效应显著为正，grm = 0.26, SE = 0.02, t(134) = 14.40, p < .001, 95% CI [0.22, 0.29]。显著异质性被检出，Q(422) = 3316.71, p < .001；总方差中90.25%归因于异质性，其中样本内占18.82%，样本间占71.43%——大量样本间异质性为检验任务和线索特征的调节作用提供了良好基础。标准化残差法（阈值±2.24）未检出统计离群值。

**先前直视线索**：可编码421个效应量（k = 136, N = 4,218），有/无直视预线索条件下注视线索效应均显著为正。作为调节变量显著，F(1, 419) = 9.88, p = .002，有直视预线索时效应更大（grm = 0.31 vs. 0.17）。在多调节变量模型（控制线索偏移时机、SOA、任务类型、面孔类型）中仍显著，t(346) = 3.43, p < .001。

**线索偏移时机**：可编码400个效应量（k = 130, N = 3,978），两组均显著为正但差异不显著，F(1, 398) = 2.44, p = .119。线索提前消失的效应量与留在屏幕上的效应量无可靠差别。

**SOA**：378个效应量（k = 120, N = 3,792）的SOA范围为14–2,500 ms。连续变量分析显示SOA显著负向调节效应量，F(1, 376) = 17.11, p < .001；多调节变量模型中仍显著，t(346) = 4.44, p < .001。连续SOA右偏（偏度 = 1.75, 均值 = 412.59, 中位数 = 300.00）。SOA分为五类（≤200早期；201–400短期；401–600中期；601–800长期；>800延长），总体调节显著，F(4, 373) = 10.31, p < .001；延长SOA组效应显著小于所有其他组，Fs(1, 115) > 12.45, ps < .001；早期SOA组效应显著大于短期、中期和长期组，Fs(1, 115) > 31.43, ps < .001——但效应量差异较小。移除延长SOA后连续SOA效应消失，F(1, 341) = 0.56, p = .456，表明SOA影响主要来自延长SOA组。二次项检验：含SOA²的模型整体显著，F(2, 375) = 10.19, p < .001，但线性模型的AIC和BIC（−246.67/−230.95）优于二次模型（−246.00/−226.37），故保留线性项。

**任务类型**：423个效应量均可编码，调节效应显著，F(2, 420) = 11.23, p < .001。检测任务grm = 0.20，定位任务grm = 0.34，分类任务grm = 0.17。配对比较：定位大于检测，F(1, 134) = 13.77, p < .001；检测大于分类，F(1, 134) = 14.59, p < .001；定位与分类差异不显著，F(1, 134) = 0.08, p = .777。多调节变量模型（控制先前直视线索、线索偏移时机、SOA、面孔类型）中任务类型仍显著，F(2, 346) = 10.48, p < .001；定位仍大于检测，t(346) = 2.33, p = .020；检测仍大于分类，t(346) = 2.04, p = .042。

**面孔类型**：417个效应量（k = 135, N = 4,139），三类面孔（示意性、计算机生成、真实照片）效应均显著为正。总体调节效应不显著，F(2, 414) = 2.81, p = .062。按预注册直接比较示意性与真实面孔：真实面孔产生更大效应，F(1, 362) = 5.16, p = .024，但在多调节变量模型中不保留（t(346) = 0.37, p = .708）。按SOA分层比较：仅中期SOA组出现显著差异，F(1, 78) = 4.36, p = .040，但加入其他调节变量后不保留（t(74) = 0.56, p = .578），且考虑到p值接近.05和多重比较，不视为有意义的发现。

**面部表情**：229个效应量（k = 68, N = 2,178）使用真实面孔且表情为中性或基本情绪。中性 vs. 情绪表情的比较：情绪表情产生显著更大的效应，F(1, 227) = 11.12, p < .001；多调节变量模型（控制先前直视、线索偏移、SOA、任务类型）中仍保留，t(182) = 3.12, p = .002。具体情绪表情类型（快乐、愤怒、厌恶、恐惧）作为调节变量显著，F(3, 117) = 5.02, p = .003。配对比较显示恐惧面孔效应显著大于快乐面孔，F(1, 30) = 9.67, p = .004。愤怒（k = 4, ES = 9）和厌恶（k = 2, ES = 3）样本量过小且不均匀，未进行其他配对比较（恐惧59个、快乐50个效应量）。多调节变量模型控制其他变量后，恐惧仍大于快乐，t(86) = 2.85, p = .006。

**发表偏倚分析**：纳入未发表效应量以降低偏倚风险。发表状态不显著调节效应量，F(1, 421) = 1.03, p = .310；多变量建模中所有显著调节变量在控制发表状态后仍被保留。Rodgers和Pustejovsky（2021）回归方法（Egger sandwich检验和Egger MLMA检验分别使用robumeta和metafor包）均未检测到显著的效应量分布不对称（稳健方差估计法：β = 1.25, SE = 1.04, p = .117；多层级元分析方法：β = 1.71, SE = 0.67, p = .118），未发现选择报告/小样本效应的证据。

## 讨论

整体而言，注视线索效应在几乎每个任务和线索特征的每个水平上都成立（除可能统计功效不足的厌恶表情分析外），为将眼神注视视为强大且有影响力的视觉社会信号的理论模型，以及方向性注视能引起反射性注意转移的观点提供了迄今最有力的支持。

**先前直视线索的调节作用是核心发现**。有直接注视预线索时效应更大，这一模式与眼注视促进后续注视跟随的近期研究一致（如Kompatsiari等人用机器人头部/注视线索发现仅在有目光接触条件时出现线索效应；Dalmaso等人发现直接注视在混合试验条件下增强眼动注视跟随效应）。不过本结果不同于Dalmaso等人主张的语境显著性必要条件——本元分析比较的研究要么有要么没有直视预线索，效应仍然成立。该发现支持Senju和Johnson（2009）的快速通道调节模型（观察目光接触通过加速皮层下加工产生“眼注视效应”）；但Xu等人（2018）发现视觉意识可能必要（阈上而非阈下呈现的直视才增强效应），与快速通道模型不完全一致。机制上，可能的解释是直视预线索标志着后续注视转移具有社会意图，值得跟随（与Jording等人2019的观点一致，也与Gobel等人2015关于注视既指向他物也指向他人的双重功能观点一致）；另一种替代解释是直视预线索通过创造生物运动的错觉来逼近真实注视转移。未来研究需要直接检验这些机制在神经层面的表达。

**线索偏移时机**不产生可靠调节作用。线索在目标出现前/同时消失还是留在屏幕上看不到显著差异。可解释为：一旦注视线索效应已建立，观察者不需要注视停留在目标位置来维持注意；其他通常能捕获注意的线索（突隐事件）此时效力降低。这在实际应用层面有积极含义——在教学中或干预中引导他人注意时无需持续保持注视方向。

**SOA时程**：效应在800 ms内保持相同幅度，超过800 ms后减弱但仍存在。这不同于典型的外周线索效应——后者约800 ms就出现IOR。结合<200 ms SOA时效应已稳定出现，说明注视线索效应的时程是延长而非平移的。效应在早期SOA略大但幅度差异很小。这一延长时程支持注视线索效应是一类特殊的注意效应——可能在进化上较晚出现且服务于独特社会功能。不过需谨慎：有研究报告长SOA（2,400 ms）时出现反向注视线索效应（IOR），但那些研究因方法不符合纳入标准而未能贡献于本元分析。

**任务类型**产生可靠调节但模式与任务难度假设不符。定位任务（中等难度）产生了最大效应而非难度最高的分类任务最小。任务难度无法轻易解释这一模式；但分类效应确实小于检测效应，这部分可能与任务需求有关。两种可能的解释被提出：线索相关性解释——在定位任务中方向性注视线索与任务目标相关，更难以被抑制（确定物体位置时先看别人看的地方是合理搜索策略）；空间一致性（Simon）解释——定位任务的水平反应键映射使线索方向与反应键空间位置产生一致或不一致效应。两种解释可通过操纵反应键映射来区分——几乎所有既有定位任务都使用水平映射。值得注意的是，若空间兼容效应确实在某些情况下驱动了有效与无效试验的反应时差异，则可能意味着“注意转移并非注视线索效应的必要条件”——这挑战了该效应作为纯粹注意现象的传统解读。

**面孔类型**不产生可靠调节。总体三类面孔无差异，示意图与真实面孔的直接比较虽在单变量模型中显著（真实更大），但在多变量模型中不保留；SOA分层比较仅在中期SOA出现不稳健的差异。Hietanen和Leppänen（2003）关于示意图产生更大效应的发现未得到支持。这为注视线索效应在不同刺激生态效度间等价出现提供了有力证据；但超出实验室范畴的更高生态效度（如与真人交互）仍待检验。

**面部表情**：情绪表情比中性表情产生更大线索效应，恐惧比快乐更大。前者与“人们有动机理解他人的认知和情感状态，因此更可能追随带有情绪表情的注视”一致；后者与威胁相关刺激产生更大注意效应（生存价值驱动）一致。愤怒表情效应显著但估计可能功效不足，厌恶表情效应不显著——两者的效应量估计均不精确。未来需研究更广泛的基本情绪和复杂自我意识情绪（如尴尬、羞愧），以及情绪真实性（genuineness）等特征。

**方法学建议**：线索偏移时机和面孔类型可相对自由变动而不影响效应量。SOA在200–800 ms范围内可灵活选择；研究者可根据对其他变量的预期选择SOA。但对以下变量的选择需谨慎：先前直视线索增强效应；定位任务比检测任务、检测比分类产生更大效应；情绪优于中性、恐惧优于快乐表情。若研究目的是测试被试是否能忽略注视线索，检测或分类任务更合适；若要检验临床群体中注视线索效应是否消失，定位任务作为更灵敏的试金石更佳。

**局限性**：第一，初级研究极少报告参与者/样本多样性信息（性别、年龄、种族），无法确认调节效应是否普遍适用于所有健康成人，未来需开放个体层面数据。第二，许多未编码的参数（如分心刺激、注意检查试验、更复杂目标刺激、试验间隔等）可能影响效应量。第三，调节发现需在设计充分且功效充足的初级研究中重复——本元分析所基于的初级研究本身并非旨在评估这些变量。第四，调节效应的评估在总体水平进行，具体个体差异变量（性别、年龄、种族/民族）可能进一步调节这些效应，但数据不足以支持这些分析。

**结论**：眼神注视方向作为线索可靠地引导空间视觉注意——对线索有效位置目标的响应快于线索无效位置。某些任务特征（先前直视、SOA、任务类型、线索表情）会增减效应的绝对量，但没有任何变量消除这一效应。这些发现为“他人方向性注视是社会注意中引导视觉注意转移的重要线索”提供了有力证据。
