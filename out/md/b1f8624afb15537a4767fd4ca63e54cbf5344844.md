# 5G 安全与隐私技术综述：潜在解决方案、最新进展与未来方向

**原文：** A Survey on Security and Privacy of 5G Technologies: Potential Solutions, Recent Advancements, and Future Directions (2019) · DOI: https://doi.org/10.1109/comst.2019.2933899

本文主张：5G 安全与隐私问题不能沿用前几代移动网络的静态安全模型，而必须围绕网络软硬化（SDN、NFV、MEC、云、网络切片）、物理层安全、隐私保护、安全监控管理以及标准化和项目实践来构建一个互补的安全框架。作者声称这是首篇同时覆盖 SDN、NFV、MEC、云和网络切片等全部关键 5G 软硬化技术的安全与隐私综述，其目标是揭示这些技术在安全上的相互依赖关系，并给出开放挑战与未来方向。

## 一、5G 安全需求的形成与演进

论文从移动网络代际演进梳理威胁景观：1G 无加密、易被无线电扫描截获并克隆 MIN/ESN；2G 引入 SIM 卡和共享密钥认证，但 A5/1、A5/2 流密码可被密文攻击实时破解，SMS 在漫游时暴露；3G 修复了伪基站和短密钥问题，采用五类安全架构（网络接入、网络域、用户域、应用域、可视性与可配置性），但仍受虚假基站、中间人、拒绝服务等攻击；4G 采用全 IP 架构和 256 位密钥、EEA/EIA 算法、AKA 认证，但 IP 连接暴露了 IP 欺骗、TCP SYN DoS、用户 ID 盗窃等攻击。

5G 面临三个主要安全来源：前几代遗留威胁仍适用；用户数量激增、设备异构、物联网和关键任务应用引入新威胁；SDN、NFV、MEC、网络切片等软硬化技术本身引入全新挑战。作者将传统 CIA（机密性、完整性、可用性）扩展为五个参数，加入集中化安全策略（Centralized security policy）和可见性（Visibility）。5G 完整性保护扩展到用户平面（4G 仅保护 NAS/AS），5G NR 在 PDCP 层加密，使用 NEA 算法（沿用 4G 的 SNOW3G/AES/null 但改名）。可用性目标通过 eMBB 和 uRLLC 分别达到 95% 和 99.99%（依据 Larsen 等）。针对 5G-AKA，作者列举了若干安全分析结果：形式化分析发现 5G-AKA 缺少若干安全目标；Koutsos 指出除 IMSI-catcher 外多数攻击仍适用；Braeken 等提出用随机数实现后妥协安全和前向安全的新协议；另有多篇关于垂直切换认证、组播认证、D2D 匿名认证等协议。

## 二、网络软硬化关键技术的安全挑战

**SDN/SDMN**：SDN 将控制与数据平面分离，集中控制器成为攻击靶点。数据通道、交换机、控制器、应用平面、管理站等各平面均有对应威胁向量（如伪造流表、TCAM 过载、SDN 扫描、东/西向接口攻击）。核心网控制流量缺乏 IP 层安全，依赖 TLS/SSL 但有已知 IP 漏洞，作者主张用 IPSec 补充。多控制器场景下 ICC（控制器间通信）通道若被攻破，整个系统沦陷。

**NFV**：NFV 将网络功能从专用硬件解耦为虚拟化软件，但引入从 MANO 到 VNF、VM、hypervisor、物理硬件的多层次攻击面，包括恶意配置、DNS 放大、日志过载、VM 逃逸、迁移攻击、侧信道、资源争用等。作者综述了基于 Intel SGX 隔离 NFV 状态、扩展 NFV 编排器管理安全、NSFV 概念、安全策略框架等方法。

**MEC 与云**：边缘设备比核心网更易受物理攻击，计费和数据路由依赖边缘组件，核心网只能通过轮询追踪。相关方案包括零水印和视觉密码保护人脸图像、D2D 位置共享框架、VEC 的分布式信誉系统 DREAMS、模糊粗糙集安全服务选择等。云侧提出 LDSS-CP-ABE、混沌模糊搜索、KP-TSABE 数据自销毁、Smart-Frame 智能电网框架等。

**网络切片**：切片共享物理资源，但需隔离。主要威胁包括切片间通信攻击、冒充切片管理器、策略不一致、DoS、侧信道（因共享硬件泄露密码信息）、超管攻击和隐私泄露。建议包括切片间互相认证、资源封顶和 ring-fencing、VM 强隔离、避免不同敏感级别共宿、在 UE 和网络中建立安全密封等。

## 三、物理层安全（PLS）

物理层安全是 5G 安全的重要组成部分，主要靠信道编码、波束赋形、人工噪声（AN）、协作干扰（CJ）和资源分配实现保密。3GPP 确定 Polar 码和 LDPC 码为候选信道编码。

在 OFDMA 与 NOMA 方面，作者列举了多种基于资源分配和功率分配的方案，例如：在 OFDMA 下行用联合子载波和功率分配提升最大最小公平保密率；用干扰者功率提升保密率；在 SWIPT 网络中优化功率分割和子载波分配；在 CRN 中考虑鲁棒遍历资源分配（SRERA）和跨层调度。NOMA 方面，常用保护区域、保密区域或排除区域来保护合法用户；通过生成 AN 干扰窃听者 SIC；利用随机几何分析大规模网络；用受信任中继优化保密率区域；功率域 NOMA（PD-NOMA）中联合优化功率、解码顺序和传输速率。

UAV 安全：UAV 因 LOS 链路易被窃听、干扰和欺骗。方案包括 IDS（自适应规格 IDS、分层检测）、PASER 路由协议、轨迹与功率联合优化（平均最坏情况保密率、SEEM 问题）、博弈论功率分配、MA-DAA 认证、GLLR 欺骗检测、EEG 生物认证、协作干扰等。

mmWave：结合 MIMO 的保密波束赋形、混合预编码、时间调制方向调制（DM）、FTR 衰落模型（推导严格正保密容量概率、平均保密容量和保密中断概率）等。作者指出低发射功率配合低频段 mmWave、高发射功率配合高频段可获得更好保密性能。

massive MIMO：δ-共轭波束赋形可提供信息论安全；训练阶段干扰下最大保密自由度为零，因此需要密码学补充。AN 方案基于 Wishart 特征值编码，另有 BDMA 鲁棒 AN 波束赋形、模式选择、中继选择和功率分配、基于 GEO-STBC 的密钥共享、混沌天线索引调制加密（CATMCPR）等。

其他物理层问题：FDA 波束赋形解耦相关信道；多符号混淆保护被动窃听和包注入；WFRFT 用户协作；认知无线电中次用户干扰改善主用户安全；WBAN 中的多跳拓扑博弈（MTFG）；RF 能量采集中 SWIPT 的 harvest-and-jam 协议等。

## 四、安全监控管理、隐私、标准化与未来方向

**监控管理**：传统监控系统依赖专用硬件、缺少集中控制、难以扩展。作者总结软件定义监控（SDM）架构，将 SDN 控制器和 NFV 虚拟化引入监控，解决部署难、自动化差、资源利用率低、供应商锁定和高 CAPEX/OPEX 问题。机器学习被用于异常检测（如深度模型对 Flooding、Impersonation、Injection 攻击的检测准确率达 99.9%）。未来需解决虚拟实体监控、多域拓扑统一视图、信息提取、可扩展性、异构性和动态性等问题。

**隐私**：从用户角度分为数据隐私、位置隐私和身份隐私。数据隐私风险源于服务商未经许可存储分享个人数据（如智能电表可暴露家庭状况）；位置隐私因 LBS 被持续跟踪；身份隐私有 IMSI 捕获和身份盗窃风险。5G 隐私问题还包括端到端数据隐私、共享环境数据所有权丢失、不同信任目标、跨境数据流和第三方问题。作者引用云计算的监管目标（单一市场推广、数据可移植性、全球市场规则、数据责任与可问责性）并建议推广到 5G。隐私机制包括匿名性、不可链接性、不可检测性、不可观察性和假名性。

**标准化**：3GPP Release 15 定义了 5G 第一阶段安全框架，引入 AUSF、ARPF、SAF 等实体。ITU-T SG17 关注量子计算威胁；IETF 的 HIP、IPWAVE、ACE 等工作组可应用于 5G；ETSI 发布了 ABE 规范（TS 103 458、TS 103 532）和 NFV 安全指南；IEEE P1912 针对消费无线设备隐私；oneM2M 提供 M2M 安全；5G PPP 安全工作组识别身份盗窃等风险；NGMN 发布安全建议包；NIST 云安全参考架构。作者认为目前尚无统一 5G 安全标准，需要全球协作。

**项目**：列举了 5G PPP、5G-ENSURE、NSF 资助项目（SaTC、IIS、NeTS）、STEAM、ANASTACIA、5G!Pagoda、5G-MiEdge、5G Champion、IRACON、RECORDIS 等项目及其技术贡献（涉及 MEC、IoT、SDN、NFV、切片、mmWave、NOMA、massive MIMO 等）。

**未来方向**：作者给出了多方面的开放挑战：访问控制需解决在线服务器依赖和权限撤销；SDN 需研究安全策略的跨控制器同步和东/西向接口保护；NFV 可结合 ML 实现自主安全、VNF 镜像签名和区块链远程证明；网络切片可分配独立的安全切片承载认证与安全策略；监控需支持虚拟实体；隐私需从数据起源嵌入，采用 Privacy-by-Design；物理层可结合密码学与 ML；量子安全用于密钥分配；上下文感知安全、AI 安全、安全编排自动化、区块链（防漫游欺诈）、Security-by-Design、Security-as-a-Service 等均为有前景的方向。最后结论重申本文综合了 5G 安全模型、威胁景观、关键安全域、软硬化技术、PLS、监控、隐私和标准化等内容。
