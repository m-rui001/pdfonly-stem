# SnSe中轨道驱动的巨声子非谐性

*Orbitally driven giant phonon anharmonicity in SnSe*（2015，https://doi.org/10.1038/nphys3492）

本文通过非弹性中子散射（INS）测量与第一性原理模拟，揭示了SnSe超低热导率的微观起源。实验直接观测到与结构相变相关的软光学声子模，并证明巨声子非谐性来源于电子结构的不稳定性：Se的共振p键网络与Sn的立体化学活性5s孤对电子耦合，产生了类似铁电体的晶格不稳定性，导致强烈的声子散射和温度依赖的力常数。这一机制为理解超低热导率及设计热电材料提供了微观图像。

## 1. 背景与实验方法

热电材料需同时实现低晶格热导率和高电导率。SnSe此前被报道在特定晶向上具有创纪录的热电优值zT>2，其室温晶格热导率κlat<1 W·m⁻¹·K⁻¹，且κlat随温度下降，表明强非谐性是重要散射机制，但其电子起源和主要参与的声子模此前未知。本文对SnSe单晶（采用改进Bridgman法合成，纯度99.999%，质量约8克）进行了系统的INS测量，使用Spallation Neutron Source的CNCS谱仪，入射能量Ei=12 meV，在100、300、486和648 K温度下映射了约50个布里渊区的四维散射函数S(Q,E)，并沿特定Q方向切片。此外，在High Flux Isotope Reactor的HB-3三轴谱仪上测量了300–850 K的定Q谱（Ef=14.7 meV）。第一性原理计算使用VASP，采用LDA和GGA交换关联泛函，声子计算使用Phonopy，三阶力常数计算使用ShengBTE和Phonopy。LDA声子色散与INS实验符合更好，因此主要用于后续分析。

晶体结构方面，SnSe在T<810 K时为Pnma相，高于转变温度时转变为Cmcm相。两相通过冷却时的“手风琴式”畸变相联系，Sn配位多面体发生畸变，沿c方向形成波纹状双层。晶格参数和键长随温度连续变化，表明相变为二级相变，主要序参量为Sn沿c方向的运动。温度依赖的INS测量直接表明，Pnma→Cmcm转变源于布里渊区中心Ag对称软模的凝聚。

## 2. 声子色散的强各向异性与温度软化

测量结果显示，沿Γ-X方向传播、c偏振的横声学（TAc）和横光学（TOc）声子比沿Γ-Y方向更软。在100 K时，沿Γ-X方向TA模显著软化，并在X点出现能带折叠，形成两套重叠的“拱形”声学支，TOc在Γ点的能量仅约4 meV。而在Γ-Y方向，TOc支向上陡峭分散，形成鞍点。这一各向异性与κlat在a轴（跨层方向）更低的事实一致，计算将其归因于层间弱键合（图1中的d4,d5键）。

温度依赖的测量揭示了强烈的软化现象：沿Γ-X方向，TAc和TOc分支在648 K时整体软化约20%（TOc从4.5 meV降至3.6 meV），而沿Γ-Y方向TAc仅软化约10%。HB-3的三轴谱数据显示，TOc(Γ)模式在500–750 K之间剧烈软化，接近相变时（775–825 K）完全阻尼，进入Cmcm相后略有硬化（825、850 K）。这种温度依赖是软模不稳定性的典型特征，且模拟确认该模具有Ag对称性。声子线宽随温度增宽，表明声子寿命缩短，非谐散射增强。

表I列出了六个低能TO模式在不同温度下的能量和线宽（已扣除仪器分辨率），显示从100 K到648 K普遍软化和增宽。表II给出声学声子群速度：从100到648 K，Γ-Y方向TAa速度平均下降11%，Γ-Z方向下降9%，[100]方向LA下降14%，[010]方向LA下降11%。实验群速度的显著温度依赖反映了力常数的强温度依赖性。仅考虑群速度软化（不考虑散射率增加）即可在300–700 K间使κlat抑制超过20%。

## 3. 非谐性的微观起源：三阶力常数与电子结构

非谐性通过势能的Taylor展开量化：

$$V = V_0 + \frac{1}{2!}\sum_{i\alpha,j\beta}\Phi_{i\alpha,j\beta} u_{i\alpha} u_{j\beta} + \frac{1}{3!}\sum_{i\alpha,j\beta,k\gamma}\Psi_{i\alpha,j\beta,k\gamma} u_{i\alpha} u_{j\beta} u_{k\gamma} + \cdots, \tag{1}$$

其中$u_{i\alpha}$是原子i在方向α的位移，$\Psi_{i\alpha,j\beta,k\gamma}$为三阶非谐力常数。在弛豫时间近似下，晶格热导率为

$$\kappa_{lat} = \frac{1}{V}\sum_{\mathbf{q}s} c_{\mathbf{q}s} v_{\mathbf{q}s}^2 \tau_{\mathbf{q}s}, \tag{2}$$

其中$c_{\mathbf{q}s}$、$v_{\mathbf{q}s}$和$\tau_{\mathbf{q}s}$分别为声子的比热、群速度和散射率。散射率由三阶力常数矩阵元决定：

$$\frac{1}{\tau_{\mathbf{q}s}} = 2\Gamma_{\mathbf{q}s} = \frac{18\pi}{\hbar^2}\sum_{\mathbf{q}',\mathbf{q}'',s',s''}|V(\mathbf{q},\mathbf{q}',\mathbf{q}'',s,s',s'')|^2 \{ (n' + n'' + 1)\delta(\omega + \omega' - \omega'') + (n' - n'')\,[\delta(\omega - \omega' - \omega'') - \delta(\omega - \omega' + \omega'')] \}, \tag{3}$$

其中$n = n(\omega, T) \propto T$为玻色占据，矩阵元包含三阶力常数$
Psi$、极化矢量、原子质量以及动量守恒的Δ因子。计算基于DFT的三阶力常数，系统找出最大的非退化三重态，其中涉及Sn沿c方向和Se在配位壳内的运动，最大键长d0≈6 Å。这些三重态数量众多，其力常数特别大，使得式(4)中的$|V|^2$增大，从而抑制热导率（图4-a中在d0处κlat出现陡降），并显著增大最低TOc模（Γ点）的Grüneisen参数（图4-b）。

冻结声子势的计算显示，TOc(Γ)的势能曲线强烈偏离抛物线，在能量-位移图中不对称（图4-d），表明非线性恢复力。这种不对称性与电子结构变化相关：沿着该振动模式畸变时，态密度（DOS）的变化也不对称。当畸变使d2缩短、d3伸长时（即Pnma相沿c的畸变方向），DOS显著变化，特别是价带顶附近的Sn 5s峰展宽；相反方向的畸变则对DOS影响很小。实空间电子密度显示每个Sn原子周围有孤立的孤对电子瓣，指向层间，且该孤对在Pnma和Cmcm相中均存在。计算得到异常大的介电常数和Born有效电荷：Pnma相介电常数为(23.3, 31.1, 27.0)，Sn的Born有效电荷为(4.04, 4.90, 4.20)，Se为(-4.04, -4.90, -4.20)，约为常规离子电荷的两倍；Cmcm相更大（介电常数(23.7, 58.6, 39.4)，Sn为(3.70, 6.20, 6.03)）。这些结果揭示了电子云的高极化率和长程力常数，特别是沿[011]方向（即Sn-Se d2键方向）的长程相互作用。结合Se p态形成的宽共振能带（约6 eV宽）及其与Sn s态和Sn p态的杂化，作者将软模和Sn离位归因于共振p键和Sn孤对电子的共同作用。三阶力常数中最大的三重态畸变模式与Cmcm→Pnma的结构演化一致，说明非谐键合直接参与了结构相变。

值得注意的是，文中还指出，温度依赖的色散意味着三声子散射相空间也随温度改变，可能部分抵消热占据效应对散射率的影响。实验中观测到的群速度软化可通过对力常数进行温度重整化（包括非谐效应和热膨胀）来模拟，拟合得到的有效力常数表明d2和d3键的力常数随温度显著变化，与键长变化趋势一致。

## 4. 结论与启示

综合INS实验和第一性原理计算，SnSe中的声子具有强各向异性和巨非谐性，源自Se共振p键和Sn立体化学活性孤对电子驱动的软模晶格不稳定性。超低热导率的各向异性由层状结构和强非谐声子共同决定。作者指出，虽然结构相变可能影响热电器件寿命，但二级软模相变（尤其是发生在高温时）可能缓解这一担忧。该工作为寻找具有高温软模晶格不稳定性的高效热电材料提供了新思路，并凸显了层状过渡金属硫属化合物在强各向异性热管理中的潜力。
