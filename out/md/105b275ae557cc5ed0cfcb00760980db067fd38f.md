# 整合证据：大气 CO₂ 升高驱动的陆地碳汇

*Integrating the evidence for a terrestrial carbon sink caused by increasing atmospheric CO₂* · 2020 · DOI: 10.1111/nph.16866

本文是一篇 Tansley 综述，围绕“CO₂ 施肥假说”系统整合了理论、控制实验（eCO₂）与历史观测（iCO₂）等多学科证据。核心主张是：多种独立证据支持大气 CO₂ 升高确实驱动了正的陆地碳汇，但碳汇的幅度仍不确定，且其他全球变化因子（氮沉降、土地利用、气候波动等）与 iCO₂ 的作用相互混杂，难以单独归因。作者以相对化的 β 因子统一衡量各变量的 CO₂ 响应，并将证据按光合生产（GPP）、生物量生产（BP）、植被死亡率、土壤有机质分解速率和生态系统碳储量五个过程组织起来。

## 引言

自工业革命以来，大气 CO₂ 浓度已由约 277 ppm 升至 411 ppm（1760–2019 年，增幅 48%），相当于向大气增加了 277 Pg C 的碳；而人为碳排放总量为 645 Pg C。全球碳核算表明，陆地生态系统目前吸收了人为排放的 33±9%（2009–2018 年），构成一个重要的“自然”碳汇，减缓了气候变化速率。过程模型通常将这一碳汇主要归因于 iCO₂，但存在很大不确定性。CO₂ 施肥假说（Box 1）认为，植物对大气 CO₂ 升高的响应会增加陆地生态系统碳储量，从而对大气 CO₂ 增长形成负反馈。该假说成立需要 ΔNEP = ΔCeco = ΔCveg + ΔCsoil 为正，其中碳储量变化遵循 dC/dt = I − kC（植被与土壤分别由 BP、死亡率与分解速率控制）。为便于跨量纲比较，作者采用相对化 β 因子：β = ln(ye/ya) / ln(CO₂,e/CO₂,a)，其中 β=1 表示变量与 CO₂ 成正比。直接实验得到的响应记作 βdir，历史观测（受多因子混杂）得到的表观响应记作 βapp。

## 理论与机制

光合作用理论预测，当 CO₂ 限制光合时，eCO₂ 增加叶尺度净碳同化（Anet），历史时期（约 280–400 ppm）的理论 βdir,hist 为 0.86；同时 eCO₂ 抑制光呼吸，使光限制光合的响应为 0.31。冠层尺度因光饱和叶比例变化，Anet 的 βdir,hist 约为 0.60±0.3，未来（400–550 ppm）降至 0.46±0.2。C4 植物因碳浓缩机制，Anet 在约 200 ppm 以上不再直接响应 CO₂。优化理论预测胞内 CO₂ 与气孔导度之比（即 iWUE）随 [CO₂] 近似成比例增加（βdir ≈ 1），而气孔导度 gs 的 β 等于 iWUE 的 β 减去 Anet 的 β，因此 gs 在历史上约为 −0.53±0.2，未来更负（−0.62±0.1）。

生物量生产受源—库共同控制：当 BP 受碳源限制时，eCO₂ 可增加 BP；但当受养分（氮、磷）或温度、水分等库限制时，响应有限。增加养分获取（细根、菌根、固氮）或改变化学计量比可支撑 BP，但也可能引发渐进性氮限制。碳分配去向决定植被碳停留时间：木材等长寿命组织更有利于碳积累，而叶片和细根周转快，主要增加凋落物输入。死亡率方面，eCO₂ 可能通过缓解水力胁迫或碳饥饿降低死亡率，也可能因加速生长、增大树体而增加大径级树木的死亡风险；净效应方向不明。土壤有机质分解方面，eCO₂ 增加根系分泌物和凋落物，可通过激发效应加速分解，但矿物结合态有机质的形成和土壤结构变化又可能减缓分解；分解加速会释放养分，反馈影响植物生长。一个单库碳模型假定 BP 的 β 等于 GPP 的 β、停留时间 β 为 0，得到碳储量 βdir 的历史值约为 0.5–0.6；实际 β 与这些基准值的偏差可指示正负反馈的强度。

## 证据整合

**光合作用与 GPP**：直接实验（FACE，11 个站点、45 个物种）显示 eCO₂ 增加叶水平光饱和光合，βdir = 0.73±0.2，其中 C3 为 0.79±0.2，C4 为 0.27±0.2；同时最大羧化能力（Vcmax）发生下调（βdir = −0.38±0.1），但对多年森林实验的净刺激影响很小。间接证据方面，冰芯 OCS、O₂ 同位素、葡萄糖异位体、卫星蒸散和涡度相关等均显示历史 GPP 增加，βapp 在 0.95–1.6 之间；其中涡度相关的 βapp 最高（1.6±0.9），归因于 iCO₂ 的部分约 1.2±0.6。14 种基于卫星 fAPAR 的 GPP 估算方法给出的 iCO₂ 敏感性范围很宽（βdir 从 −0.39±0.34 到 1.6±1，均值 0.52±0.3）。

**水分利用效率与气孔导度**：实验证据（4 站点、7 物种）显示 eCO₂ 增加 iWUE 的 βdir = 1.2±0.4；树轮 δ¹³C 也显示历史 iWUE 升高，βapp 多在 1 左右（如北方裸子植物 1.2–1.5、热带森林 1.0、多种森林 1.19）。大气 δ¹³C 反演给出 βapp = 0.94±0.2。涡度相关估算的‘内在’WUE 增幅很大（βapp = 4.72，后修正为 2.5），但与理论值存在差异。气孔导度在 FACE 实验中平均下降 βdir,fut = −0.60±0.2，但不同功能型间差异大；蒸腾响应对大多数站点不显著，仅在 ORNL 看到明显下降。卫星估算的 WUE 变化相互矛盾（βapp = −0.49 和 0.28），且时间序列短（13 年），可信度低。

**生物量生产**：四个早演替温带森林 FACE 实验在最初数年 BP 增加 βdir,fut = 0.56±0.2，十年平均为 0.49±0.3；但三个晚演替（约百年林龄）森林无显著响应（βdir,fut 范围 −0.30 至 0.55）。草地合成（19 站点）显示叶和茎 BP 增加 βdir,fut = 0.17±0.07，细根生物量增加（森林 βdir,fut = 0.92，草地 0.18）。树轮研究大多未显示木材 BP 的稳定增加（如热带 12 物种无趋势、北方森林有增有减、跨生物区系 βapp = 0.23–0.45），但也有个别研究显示与树龄相关的正响应（如密苏里栎和松，幼龄 βapp = 3.3，50 龄降为 1.1）。森林清查数据一致显示木材碳储量净增：亚马逊 βapp = 1.2±0.6，非洲 βapp = 0.69±0.63，全球 βapp = 0.94±1.1。BP 对养分的依赖明显：缺氮或缺磷的晚演替系统无 BP 响应，而早演替系统的增加主要靠增加氮获取而非改变化学计量；渐进性氮限制的直接实验证据仅有两个（ORNL 和 Biocon）。在低 LAI 生态系统中 eCO₂ 可能增加 LAI，但高 LAI 系统通常不增加；卫星显示全球“变绿”趋势，模型归因主要指向 iCO₂，但在热带雨林推断的 LAI 增加与实验和资源投资理论不符。

**植被死亡率**：温室实验未发现 eCO₂ 对干旱或高温存活率的改善；野外直接证据很少。在 Rhinelander FACE 的 11 年中，eCO₂ 降低了自我稀疏速率（相同茎密度下基面积更高），但多数清查网络显示死亡率上升，如亚马逊 biomass mortality βapp = 2.4、美国西部树茎死亡率 βapp = 6.2±3、加拿大 6.1；但这些趋势通常归因于干旱、病虫害等，不能归因于 iCO₂。生长—死亡关系存在种间和种内权衡，但也有例外，因此死亡率对 iCO₂ 的响应方向尚不清楚。

**有机质分解**：元分析（53 个实验）显示 eCO₂ 增加凋落物产量（βdir,fut = 0.4±0.1）和 SOM 分解速率（βdir,fut = 0.34±0.2），但激发效应在田间难以检测；生态系统尺度的结果不一致（如 ORNL 非显著增加，瑞士成熟林微生物量增加但土壤呼吸不变，EucFACE 在 +30 ppm 时呼吸增加但继续加 120 ppm 无额外效应）。历史时期土壤呼吸有增加趋势（βapp = 0.22 或 0.58±1），但不能排除温度贡献。eCO₂ 通过提高根系分泌物、菌根活动等增加分解，但化学计量比改变（细根 C:N 增加，βdir,fut = 0.13）可能降低分解性。菌根类型（ECM vs AM）影响分解与氮获取的耦合。

**生态系统碳储量**：直接实验方面，四个长期 FACE 实验十年的 Cveg 增量 βdir,fut = 0.60±0.4；CO₂ 温泉附近的成年树基面积增加 βdir,fut = 0.23–0.39；但 EucFACE 四年无 Cveg 增加（磷限制）。元分析（138 实验）预测全球 Cveg 增加 βdir,fut = 0.22±0.1。Csoil 的响应混合：所有实验平均 βdir,fut = 0.039±0.03，但无氮添加的 ≥2 年田间实验平均为 0.0054±0.03（不显著）；个别站点（ORNL、荒漠）有积累，而灌丛橡树无变化。间接证据：大气反演给出全球 NBP 约 1.9–2.3 Pg C yr⁻¹ 并呈正趋势（βapp = 9.8–19），区域上北方中高纬为汇、热带为源；碳预算给出‘自然’ NBP 3.6±1.0 Pg C yr⁻¹（2009–2018），对应 βapp 在植被碳（假设全在植被）0.93–1.4 或生态系统碳 0.18–0.29。森林清查显示 Cveg 增加：泛热带 βapp = 0.30–0.77，美国东部 βapp = 2.9±1.5，全球 βapp = 0.82±0.5；Pan 等（2011）的全球综合给出 Cveg βapp = 1.9、Csoil βapp = 0.31。涡度相关 NEP 的 βapp 高达 4.3±2。

## 综合与结论

综合各证据线，作者给出置信度评估：GPP 在历史时期增加有高置信度，iCO₂ 为主要驱动也有高置信度，但 GPP 增幅的绝对值只有中等置信度（βapp 均值约 1.2，各估计间相差约 1.7 倍），且观测到的 GPP 增幅（βdir,hist ≈ 1.2）约为理论冠层响应（0.60）的两倍，说明 iCO₂ 并非唯一驱动。iWUE 增加有高置信度，其幅度与理论相符（中等置信度），但历史 WUE 增幅的估计差异大（βapp 0.85–3.9），卫星估算可信度低。BP 方面，历史清查显示木材 BP 增加（βapp 约 1）为中等置信度，但幅度低置信度；eCO₂ 能刺激 BP（βdir,fut 约 0.5）为高置信度，且受养分限制减弱为高置信度，但清查响应高于实验值，可能受额外因素驱动。死亡率增加有高置信度但幅度低置信度，iCO₂ 对死亡率的影响方向未知。SOM 分解速率在历史时期可能增加（低置信度），eCO₂ 确实增加分解速率（中等置信度）但幅度低置信度。生态系统碳储量增加有高置信度，但‘自然’碳库的 βapp 范围很大（0.18–1.0），对幅度的置信度低；eCO₂ 实验的 Cveg 响应（0.22–0.39）低于清查推断（0.3–2），部分差异可由实验时间尺度和初始状态解释。整体上，CO₂ 施肥假说得到支持，但碳汇的大小及其未来演变高度不确定。

作者强调，iCO₂ 归因的最大挑战是历史趋势与多种因子相关，简单回归只能说明相关；过程模型需要更好地表征光合适应、营养获取、死亡率、土壤分解、植被结构与土地利用等机制，并与实验和长期观测深度整合。未来应优先研究：GPP 增加的水分耦合机制、树轮与清查数据的分歧来源、中晚演替和热带等代表性不足生态系统的 eCO₂ 实验、死亡率对 iCO₂ 的响应、深层土壤碳动态，以及将土地利用、农业和‘自然’通量统一核算。

结论是：有中到高置信度认为 GPP、iWUE、BP 和死亡率在历史时期均增加，但幅度和 iCO₂ 归因的置信度普遍较低。基于理论预测的 GPP 响应减弱、养分限制加剧、死亡率上升以及温度相关负效应，未来由 iCO₂ 驱动的陆地碳汇很可能衰减，从而加速气候变化。
