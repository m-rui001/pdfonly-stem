# 解读铕(III)光谱

K. Binnemans, *Coordination Chemistry Reviews* 295, 1–45 (2015). DOI: https://doi.org/10.1016/j.ccr.2015.02.015

本文是一篇关于三价铕离子（Eu³⁺）光谱学的系统性综述。其核心主张是：Eu³⁺因其独特的电子构型——基态 ⁷F₀ 和最重要的发光激发态 ⁵D₀ 均为非简并态——而成为研究镧系离子配位环境与点群对称性的理想光谱探针。作者旨在为镧系配位化学领域的新研究者提供一份扎实的入门指南，阐明如何从吸收、发光和激发光谱中提取最大量的结构信息，并避免常见的光谱解读陷阱。全文围绕能级结构、f-f 跃迁强度（包括 Judd-Ofelt 理论）、激发态衰减动力学以及 Eu³⁺ 作为结构探针的应用展开。

## 能级结构与光谱基础

Eu³⁺ 的电子构型为 [Xe]4f⁶，其 4f 壳层被 5s² 和 5p⁶ 外层屏蔽。六个 4f 电子在七个 4f 轨道中的排列方式总数为 3003，即该构型的简并度，由二项式系数 $\binom{14}{n}$ 给出（n=6）。电子间排斥、自旋-轨道耦合、晶体场效应和塞曼效应依次部分或完全解除这一简并。引入电子间排斥后，[Xe]4f⁶ 构型由 119 个 $^{2S+1}L(\tau)$ 项表征，项间距约为 10000 cm⁻¹。自旋-轨道耦合将项分裂为 295 个 $^{2S+1}L_J$ 能级，分裂量级约为 1000 cm⁻¹。晶体场效应进一步解除 2J+1 简并，产生晶体场能级（Stark 能级），分裂量级为几百 cm⁻¹ 或更小。在正交或更低对称性中，所有简并完全解除。洪特规则解释了 ⁷F₀ 为基态：4f⁶ 壳层少于半满，基态具有最低的 J 值。自由离子能级可通过有效算符哈密顿量 $H = H_{free\ ion} + H_{crystal\ field}$ 的对角化获得。自由离子哈密顿量包含电子排斥参数 $F^k$、自旋-轨道耦合常数 $\zeta_{4f}$、Trees 组态相互作用参数 $(\alpha, \beta, \gamma)$、三体组态相互作用参数 $T^i$ 以及磁相互作用参数 $M^l$ 和 $P^k$。Görller-Walrand 和 Binnemans 报道了一套平均自由离子参数（Table 2），并据此计算了 0 至 40000 cm⁻¹ 范围内的自由离子能级（Table 3）。晶体场哈密顿量按 Wybourne 形式写为 $H_{crystal\ field} = \sum_i \sum_k \sum_q B_q^k C_q^k(i)$，其中 $B_q^k$ 为晶体场参数，其数量由 Eu³⁺ 位点的点群对称性决定。例如，$O_h$ 对称性仅需 2 个参数，而 $C_1$ 对称性需要 27 个。晶体场扰动导致 $^{2S+1}L_J$ 项分裂为若干晶体场能级，分裂模式取决于对称性类别而非具体点群（Table 4）。

## 发光光谱与跃迁特性

发光光谱通过固定激发波长、扫描检测波长来记录。Eu³⁺ 化合物的发光主要源于 ⁵D₀ → ⁷F_J (J=0-6) 跃迁。Table 5 总结了这些跃迁的偶极特性、波长范围和相对强度。其中，⁵D₀ → ⁷F₁ 为磁偶极（MD）跃迁，强度基本不依赖环境，常被用作强度校准参考；⁵D₀ → ⁷F₂ 为超灵敏的电偶极（ED）跃迁，其强度对环境极为敏感；⁵D₀ → ⁷F₀ 跃迁在标准 Judd-Ofelt 理论中是严格禁戒的，其出现是选择定则破缺的典型例子，通常归因于 J-混合或低能电荷转移态的混合。该跃迁仅在 $C_{nv}$、$C_n$ 或 $C_s$ 对称性下可观测，其线宽极窄（例如在 EuCl₃·6H₂O 中 4.2 K 时半高全宽约 0.12 cm⁻¹），可用于识别非等价位点或溶液中不同物种的数量。⁵D₀ → ⁷F₁ 跃迁直接反映 ⁷F₁ 能级的晶体场分裂，其总分裂范围从立方 elpasolite 的 0 cm⁻¹ 到羟基磷灰石的 887 cm⁻¹ 不等。⁵D₀ → ⁷F₂ 跃迁的强度与 Judd-Ofelt 强度参数 $\Omega_2$ 成正比，其与 ⁵D₀ → ⁷F₁ 的强度比 R 常被用作位点不对称性的量度，但作者强调 R 值受配位多面体形状和配体性质（如极化率）影响，不能简单视为对称性的唯一指标。⁵D₀ → ⁷F₃ 跃迁通常很弱，其强度是强 J-混合和强晶体场扰动的标志。⁵D₀ → ⁷F₄ 跃迁的解读需谨慎，因其位于光电倍增管灵敏度较低的区域，必须进行光谱校正。在 $D_{4d}$ 对称性中，该跃迁常占主导。⁵D₀ → ⁷F₅ 和 ⁷F₆ 跃迁通常因探测器限制和强度低而难以观测。来自更高激发态（⁵D₁, ⁵D₂, ⁵D₃）的发射在某些无机基质中可见，但会与 ⁵D₀ 发射重叠，可通过时间门控光谱或选择性激发进行区分。

## 吸收光谱、激发光谱与其他技术

吸收光谱中，对点群对称性测定最相关的跃迁（如 ⁵D₀←⁷F₀, ⁵D₁←⁷F₁ 等）摩尔吸光系数 ε 小于 1 L mol⁻¹ cm⁻¹，需使用高掺杂晶体或长光程浓溶液。室温下可观测到来自 ⁷F₁ 和 ⁷F₂ 激发态的“热”带，其布居数由玻尔兹曼分布 $X_A(T)$ 决定。冷却至 77 K 可消除热带，简化光谱。⁷F 基态内的跃迁（如 ⁷F₆←⁷F₀）仅在低声子能量基质中可观测，且是吸收光谱中最强的跃迁。⁵D₀←⁷F₀ 跃迁可用于识别非等价位点，例如在 EDTA 溶液中观测到两条相差 14 cm⁻¹ 的谱线，归因于配位水分子数不同的两种配合物。⁵D₁←⁷F₁ 和 ⁵D₂←⁷F₀ 是超灵敏跃迁，其强度随配体环境剧烈变化。⁵L₆←⁷F₀ 是紫外-可见吸收光谱中最强的跃迁，常用于直接激发 Eu³⁺。电荷转移（CT）带对应于配体到金属的电子转移，其能量强烈依赖于配体性质，遵循 Jørgensen 公式 $E_{CT} = 30000[\chi_{opt}(X) - \chi_{uncorr}(M)]$。低能 CT 态会猝灭发光，但也可作为敏化发光的“天线”。激发光谱通过监测发光强度随激发波长的变化来记录，可用于确定最佳激发波长、探测高能级以及识别溶液中不同物种。其他技术如双光子吸收（TPA）、塞曼光谱和磁圆二色性（MCD）可提供互补信息。MCD 对 Eu³⁺ 尤为有效，其 ⁵D₂←⁷F₀ 跃迁的 A 项符号取决于位点对称性。

## Eu³⁺ 作为探针、Judd-Ofelt 理论与激发态动力学

Eu³⁺ 作为光谱探针的优势在于其非简并的基态和发光态、低的 J 值、有限的 J-混合以及窄线宽。通过计数 ⁵D₀ → ⁷F_J 跃迁的晶体场分量数目，并与 Table 8 等表格对比，可推断点群对称性。然而，实践中常因晶体场分裂小导致谱线重叠而难以唯一确定。Judd-Ofelt 理论通过三个唯象参数 $\Omega_\lambda$ (λ=2,4,6) 描述电偶极跃迁强度。对于 Eu³⁺，$\Omega_2$ 可由 ⁵D₂←⁷F₀ 跃迁的偶极强度确定，$\Omega_4$ 和 $\Omega_6$ 分别由 ⁵D₄←⁷F₀ 和 ⁵L₆←⁷F₀ 跃迁确定。这些参数可用于计算辐射跃迁概率、分支比和辐射寿命 $\tau_{rad}$。超灵敏跃迁的强度主要由 $\Omega_2$ 参数描述，其机理涉及配体极化（动态耦合模型）和电荷转移态的混合。激发态动力学方面，寿命 $\tau$ 是辐射和非辐射衰减概率的总和。非辐射衰减主要通过多声子弛豫和离子间能量传递（如交叉弛豫）进行。观测寿命 $\tau_{obs}$ 与辐射寿命 $\tau_{rad}$ 结合可计算量子产率。通过测量 Eu³⁺ 在 H₂O 和 D₂O 中的寿命差，可利用 Horrocks-Sudnick 公式 $q = 1.05[1/\tau_{H2O} - 1/\tau_{D2O}]$ 及其修正形式（如 Supkowski-Horrocks 公式）确定水合数 q。

**结论**
Eu³⁺ 离子因其特殊的电子构型而成为独特的光谱探针。其光谱的精细结构、超灵敏跃迁和寿命测量为研究镧系离子的局部对称性、配位环境和溶液物种提供了丰富信息。然而，作者强调，对 Eu³⁺ 光谱的解读必须谨慎，避免过度解释，并建议将光谱学方法与 X 射线晶体学、EXAFS、NMR 等其他技术结合，以获得对含镧系体系的准确描述。
