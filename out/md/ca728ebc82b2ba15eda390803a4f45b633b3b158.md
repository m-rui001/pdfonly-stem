# 一类预定义时间稳定动力系统

*英文原题：* A Class of Predefined-Time Stable Dynamical Systems · 2017 · https://doi.org/10.1093/imamci/dnx004

本文提出“预定义时间稳定”这一新的稳定性概念：系统收敛时间（settling time）不仅对一切初始条件一致有界（即固定时间稳定），而且其上界是系统参数中的一个显式可调项，可以事先设定。该文进一步区分了弱、强两种预定义时间稳定性：强预定义时间稳定性要求设定时间恰为收敛时间的最小上界，从而克服了既有固定时间稳定方法中收敛时间界估计过于保守的问题。作者给出完整的 Lyapunov 刻画，并据此构造了一类一阶预定义时间稳定系统，应用到滑模控制器设计与多智能体一致性算法中。

## 稳定性概念与 Lyapunov 刻画

作者首先回顾全局固定时间吸引（Definition 2.1，Polyakov 2012）：非空集合 M 对系统 (1) ẋ = f(t,x;ρ) 是全局固定时间吸引的，若任意解在有限时间 t = t₀ + T(x₀) 到达 M，且收敛时间函数 T 被某个正数 Tₘ 一致界定。由于 Tₘ 的取法不唯一，作者定义了收敛时间上界集合 (2)，并定义最小上界 T_f = inf T = sup T(x₀)（Definition 2.3）。在此基础上引入两个新定义（Definition 2.4）：若存在 Tc(ρ)>0 使得对一切 x₀ 有 T(x₀) ≤ Tc，则 M 是全局弱预定义时间吸引的，Tc 称为弱预定义时间；若 sup T(x₀) = Tc，则 M 是全局强预定义时间吸引的，Tc 称为强预定义时间。对含扰动系统 (4)，收敛时间依赖扰动轨迹 ω，上述定义相应推广（Definition 2.5）。

弱预定义时间稳定性的充分条件是下述 Lyapunov 不等式（Theorem 2.1）：若存在连续径向无界函数 V，使得 x ∈ M ⟺ V(x)=0，且沿系统轨线有

V̇ ≤ −(1/(pTc)) exp(Vᵖ) V^{1−p}，  (5)

其中 Tc>0, 0<p≤1，则 M 全局弱预定义时间吸引，弱预定义时间为 Tc。证明中对 (5) 积分得到 V(t) ≤ [ln(1/((t−t₀)/Tc + exp(−V₀ᵖ)))]^{1/p}，从而 T(x₀) ≤ Tc[1−exp(−V₀ᵖ)] ≤ Tc。然而该不等式不能保证强预定义时间性质。Theorem 2.2 指出：若 (5) 取等号，即

V̇ = −(1/(pTc)) exp(Vᵖ) V^{1−p}，  (6)

则精确收敛时间为 T(x₀) = Tc[1−exp(−V₀ᵖ)]；因 V 径向无界，sup_{x₀}[1−exp(−V₀ᵖ)] = 1，故 sup T(x₀) = Tc，即全局强预定义时间稳定，强预定义时间为 Tc。对扰动系统 (4)，Theorem 2.3 给出对应条件：若 sup_{d∈Ω} V̇ = −(1/(pTc)) exp(Vᵖ)V^{1−p} (式 7)，则 M 全局强预定义时间吸引。

## 一类强预定义时间稳定系统及参数影响

作者构造了预定义时间镇定函数（Definition 2.6）：

Φ_{m,q}(x) = (1/(mq)) exp(‖x‖^{mq}) x / ‖x‖^{mq}，  (8)

其中 m ≥ 1，0 < q ≤ 1/m。其 Maclaurin 展开为 Φ_{m,q}(x) = (1/(mq))[x/‖x‖^{mq} + x + Σᵢ₌₂^∞ (‖x‖ⁱ x)/(i! ‖x‖^{mq})]，可见 0<q<1/m 时连续但非 Lipschitz，q=1/m 时不连续。对 x∈R 可写为 Φ_{m,q}(x) = (1/(mq)) exp(|x|^{mq}) |x|^{1−mq} sign(x)（0<q<1/m）或 Φ_{m,q}(x) = exp(|x|) sign(x)（q=1/m）。

Lemma 2.1 给出核心系统：

ẋ = −(1/Tc) Φ_{m,q}(x)，  (10)

当 Tc>0, m≥1, 0<q≤1/m 时全局强预定义时间稳定，即 x(t)=0 对所有 t ≥ t₀+Tc 成立。证明取 V=‖x‖ᵐ，沿轨线计算得 V̇ = −(1/(qTc)) exp(V^q)V^{1−q}，正好满足 Theorem 2.2 的等式条件。对 R³ 中的数值例（x_ss=[3,0,−1]ᵀ, Tc=0.1, m=1, q=1/2），Figure 1 显示各初始条件均在 Tc=0.1 内收敛。

为分析参数 mq 的影响，令 W(t)=‖x(t)‖。W 满足等式版本 (5) 且 p=mq，故 Ẇ(t) = −(1/(mqTc)) exp(W^{mq}) W^{1−mq} (式 11)，精确收敛时间 T(x₀) = Tc[1−exp(−W₀^{mq})]。在收敛瞬间 W(T+t₀)=0，故 Ẇ(T+t₀) = −0^{1−mq}/(mqTc)，即 0<mq<1 时一阶导为 0，mq=1 时极限为 −1/Tc。二阶导 Ẅ(T+t₀) = (1−mq)·0^{1−2(mq)}/(mqTc)²，故 0<mq<1/2 时为 0，mq=1/2 时极限为 2/Tc²，mq>1/2 时为无穷——这解释了为什么 mq>1/2 时收敛看起来不光滑。初始响应陡峭度由 Ẇ(t₀) = −(1/(mqTc)) exp(‖x₀‖^{mq})‖x₀‖^{1−mq} 刻画；Figure 2 显示对每个 ‖x₀‖ 存在使 |Tc Ẇ(t₀)| 最小的 mq 值，偏离过远会导致数值模拟困难。作者据此给出 mq 选取建议（Figure 3）：在 (0,1/2] 内取使初始响应最缓的值，同时保证收敛光滑性。

对含测量噪声的系统 ẋ = −(1/Tc) Φ_{m,q}(x+v)（式 12），数值实验（高斯噪声，零均值、标准差 0.1，Euler 法步长 0.01，从 x(0)=0 积分至 t=400）计算平均绝对误差。结果显示：Tc 越小噪声影响越大（收敛越陡）；mq 的影响非单调——(1/(mq)) 和 exp(‖x+v‖^{mq}) 随 mq 增大而增大，但 1/‖x+v‖^{mq} 随 mq 增大而减小，实验表明二者在 mq 靠近 (0,1] 中部时取得最佳平衡（Figure 4）。

## 预定义时间滑模控制器

考虑系统 ẋ = u + ∆(t,x)（式 13），目标是在预定义时间 Tc 内镇定到 x=0。针对三类扰动情形，作者给出系列控制器。**（1）消失扰动 k∆(t,x)k ≤ δ‖x‖：** Lemma 4.1 给出弱预定义时间控制器 u = −((1/Tc)+kmq)Φ_{m,q}(x)，k≥δ，其 Lyapunov 导数为 V̇ ≤ −(1/(qTc)) exp(V^q)V^{1−q}，满足 Theorem 2.1；Lemma 4.2 给出强预定义时间控制器 u = −(1/Tc)Φ_{m,q}(x) − δx，利用 xᵀ∆ ≤ δ‖x‖² 证得 sup V̇ = −(1/(qTc))exp(V^q)V^{1−q}，由 Theorem 2.3 得强预定义时间稳定。**（2）非消失有界扰动 k∆(t,x)k ≤ δ：** Lemma 4.3 的连续控制器 u = −(1/Tc)Φ_{m,q}(x) 只能保证一致最终有界，界为 ‖x‖ ≤ [(mq/(1−mq)) W(mq·(mqTcδ)^{1/(1−mq)})]^{1/(mq)}，其中 W(·) 为 Lambert 函数；系统在 Tc 内进入该区域。为提高鲁棒性，令 mq=1（此时 Φ 记为 Φ₁），得到不连续控制器。Lemma 4.4（弱）：u = −(1/Tc + k)Φ₁(x)，k≥δ；Lemma 4.5（强）：u = −δx/‖x‖ − (1/Tc)Φ_{m,q}(x)，其中 0<q≤1/m。两者证明思路与消失扰动情形类似。

基于积分滑模思想（Matthews & DeCarlo 1988; Utkin & Shi 1996），Lemma 4.6 给出积分弱预定义时间控制器：u = −(1/(Tcn−Tci))Φ_{mn,qn}(x) − (1/Tci)Φ_{mi,qi}(σ) − δσ/‖σ‖，其中 σ=x+z，ż=(1/(Tcn−Tci))Φ_{mn,qn}(x)，Tcn>Tci>0。证明：子系统 σ̇ 在强预定义时间 Tci 内到达 σ=0，此后系统化为 ẋ=−(1/(Tcn−Tci))Φ_{mn,qn}(x)，由 Lemma 2.1 在 Tcn−Tci 内到达 x=0，总时间不超过 Tcn；但因 σ 收敛不恰好发生在 Tci，Tcn 不能保证为最小上界，故为弱预定义时间。Lemma 4.7 引入 Heaviside 阶跃 h(t−Tci)（式 23），使扰动项增益可任意取 k≥δ 且仍是强预定义时间稳定，证明分 Tc⁻ᵢ=Tci 和 Tc⁻ᵢ<Tci 两种情形讨论。

Example 4.1 用标量族 ẋ = cos(t/α) − sign(x) − (1/Tc)Φ_{m,q}(x)，x(0)=α 验证 Lemma 4.5：扰动 ∆=cos(t/α) 满足 k∆k≤1=δ，取 Tc=1, mq=0.4。Figure 5 显示各 α 对应轨迹均在 Tc=1 内到达 0；Figure 6 显示精确收敛时间 T(α) 随 α 增大趋近 Tc=1——因为 α 增大时初值变大、扰动趋近最坏情形常数 1。

对一般仿射系统 ẋ = f(t,x) + B(t,x)u + ∆(t,x)（式 27），设滑模变量 σ(x)，D(x)=G(x)B(t,x) 可逆，作者给出三个一阶滑模控制器（均匹配扰动假设）：未扰情形 Lemma 4.8：u = −D⁻¹(Gf + (1/Tc)Φ_{m,q}(σ))，使 σ̇=−(1/Tc)Φ_{m,q}(σ)，直接由 Lemma 2.1 得强预定义时间滑模；消失扰动情形 Lemma 4.9：u = −D⁻¹(Gf + (1/Tc)Φ_{m,q}(σ) − δσ)，规约到 Lemma 4.2；非消失扰动情形 Lemma 4.10：u = −D⁻¹(Gf + δσ/‖σ‖ + (1/Tc)Φ_{m,q}(x))，规约到 Lemma 4.5。Example 4.2 用双积分器 ẋ₁=x₂, ẋ₂=u+∆（|∆|≤δ）演示：误差变量 e₁=(x₁−x₁ᵣ)/k, e₂=ė₁+x₂/k²，控制律 u = −k²(e₂−e₁) − k²[kc sign(e₂) + (1/Tc)Φ_{m,q}(e₂)]（式 36），取 kc=δ/k²，由 Lemma 4.5 保证 e₂=0 在 Tc 内到达；滑动面上 ė₁=−ke₁ 指数稳定。数值例（Tc=0.5, k=10, kc=0.01, m=1, q=1/2, x₁ᵣ=5, ∆=sin(3t), δ=1）的仿真（Figure 7、8）验证了收敛时间。

## 预定义时间一致性算法

最后，将上述框架应用于完全图上的一致性算法。图论基础（Godsil & Royle 2001）：Laplacian L=Q−A 半正定对称；完全图 n 个节点时 L 的特征值为 0（单重）和 n（n−1 重）。对完全图 n 节点网络，作者提出算法

ẋᵢ = uᵢ,  uᵢ = (1/(2nTc q)) · exp(Zᵢ(x)^q)/Zᵢ(x)^q · Σ_{j∈Nᵢ}(xⱼ−xᵢ)，  (38)

其中 Zᵢ(x) = (dᵢ+1)Σ_{j∈Nᵢ}(xⱼ−xᵢ)²，0<q<1/2。令 e=−Lx 为一致性误差，Lemma 5.1 证明 Le=−ne（因完全图 Laplacian 特征值为 0 和 n），且可验证对完全图有 Zᵢ(x) = n‖e‖²。于是误差动力学化为

ė = −(1/Tc) Φ_{2,q}(e)，  (41)

即 Lemma 2.1 的标准形式（m=2），故误差在强预定义时间 Tc 内到达 0，即 x₁=⋯=xₙ 对所有 t≥t₀+Tc 成立（Theorem 5.1）。Example 5.1（10 节点完全图，Tc=1, q=0.5，初始条件随机）的仿真显示网络在 t=Tc 前达成一致（Figure 9）。Remark 5.1 指出，推广到高阶滑模、动态网络和数字实现仍需进一步研究；作者在结论中再次强调：本方法的核心优势是收敛时间上界与系统增益有显式直接关系，且强预定义时间稳定性保证该上界同时是最小上界。

**结论**
文章的核心贡献在于：第一，提出预定义时间稳定的严格定义（弱/强），并给出实用的 Lyapunov 充分条件（Theorem 2.1–2.3）；第二，构造了收敛时间上界等于设定参数的显式系统（Lemma 2.1），其收敛时间上界不对初始条件保守过估；第三，将该工具应用于滑模控制（一阶、含积分滑模扩展）与完全图一致性协议。局限性与未来方向包括：高阶滑模设计、一般图拓扑下的一致性、数字实现中的离散化问题。
