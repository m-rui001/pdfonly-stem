# 基于颜色衰减先验的快速单幅图像去雾算法

*A Fast Single Image Haze Removal Algorithm Using Color Attenuation Prior* · Qingsong Zhu, Jiaming Mai, Ling Shao · 2015 · DOI: 10.1109/tip.2015.2446191

本文提出一种简单而有效的颜色衰减先验，用于单幅雾霾图像的去雾。其核心思路是：雾霾浓度与像素亮度、饱和度之差正相关，而雾霾浓度又与场景深度正相关，因此可用亮度与饱和度之差建立场景深度的线性模型；通过监督学习确定模型参数后即可恢复深度图，再结合大气散射模型估计透射率并恢复场景辐照度，从而去除雾霾。实验表明该方法在效率与去雾效果上均优于当时的主流算法。

## 大气散射模型与去雾问题的转化

论文以McCartney于1976年提出、后经Narasimhan和Nayar进一步推导的大气散射模型描述雾霾图像的形成：

$$\mathbf{I}(x) = \mathbf{J}(x)t(x) + \mathbf{A}(1 - t(x)), \quad t(x) = e^{-\beta d(x)}$$

其中 $x$ 为像素位置，$\mathbf{I}$ 为雾霾图像，$\mathbf{J}$ 为场景辐照度（即无雾图像），$\mathbf{A}$ 为大气光，$t$ 为介质透射率，$\beta$ 为大气散射系数，$d$ 为场景深度；$\mathbf{I}$、$\mathbf{J}$、$\mathbf{A}$ 均为RGB空间中的三维向量。由于 $\mathbf{I}$ 已知，去雾的目标是估计 $\mathbf{A}$ 与 $t$，再据式(1)恢复 $\mathbf{J}$。

论文强调场景深度 $d$ 是最关键的信息：在均匀大气条件下 $\beta$ 可视为常数，若已知深度即可由式(2)估计透射率。理想情况下 $d(x)$ 的范围为 $[0,+\infty)$，当 $d(x) \to \infty$ 时 $\mathbf{I}(x) = \mathbf{A}$；若 $d(x)$ 足够大，$t(x)$ 趋于很小，$\mathbf{I}(x)$ 近似等于 $\mathbf{A}$。因此论文不直接用式(3)计算大气光，而是引入阈值 $d_{thresold}$，用 $\mathbf{I}(x) = \mathbf{A},\ d(x) \geq d_{thresold}$ 来估计 $\mathbf{A}$。论文指出该约束在多数情况下容易满足：户外雾霾图像通常含有距观察者数公里之遥的远景，属于远景区域的像素应具有很大的深度。假设每幅雾霾图像都有远景，则 $d(x) \geq d_{thresold},\ x \in \{x | \forall y: d(y) \leq d(x)\}$，进而 $\mathbf{A} = \mathbf{I}(x),\ x \in \{x | \forall y: d(y) \leq d(x)\}$。在此条件下，去雾任务可进一步转化为深度信息恢复问题，而从单幅雾霾图像获取深度图本身仍是难题。

## 颜色衰减先验

论文从人脑能在无额外信息下快速识别雾霾区域这一现象出发，对大量雾霾图像进行实验以寻找统计规律，发现雾霾图像中像素的亮度与饱和度随雾霾浓度变化而剧烈变化。图2以自然场景为例：无雾区域饱和度相当高、亮度适中，亮度与饱和度之差接近零；中度雾霾区域饱和度急剧下降、颜色褪去，同时亮度上升，差值变大；浓雾区域更难辨认场景固有颜色，差值比中度雾霾区域更高。

论文通过回顾成像过程解释这一规律。无雾条件下，场景元素反射来自照明源（如直射阳光、漫射天光和地面反射光）的能量，到达成像系统时能量损失很小，户外图像通常色彩鲜艳。雾霾天气下成像包含两种机制（直接衰减与大气光）：一方面，直接衰减由反射能量减少引起，对应式(1)中的 $\mathbf{J}(x)t(x)$ 项，像素强度以乘性方式下降，故亮度趋于降低；另一方面，由环境照明散射形成的白色或灰色大气光增强亮度并降低饱和度，对应式(1)中最右项 $\mathbf{A}(1-t(x))$，其对观测值的作用是加性的。由于多数情况下大气光起更重要作用，雾霾区域表现为高亮度、低饱和度，且雾越浓大气光影响越强。因此论文利用亮度与饱和度之差估计雾霾浓度，并在图4中展示该差值随雾霾浓度增加而增大。

由于雾霾浓度一般随场景深度变化，论文假设场景深度与雾霾浓度正相关，得到：

$$d(x) \propto c(x) \propto v(x) - s(x)$$

其中 $d$ 为场景深度，$c$ 为雾霾浓度，$v$ 为场景亮度，$s$ 为饱和度。论文将这一统计规律称为颜色衰减先验，并通过HSV颜色模型给出几何描述：图5(a)为HSV颜色模型，图5(b-d)分别为近景、中距与远景深度；向量 $\mathbf{I}$ 表示雾霾图像，过原点并将其投影到水平面，设 $\mathbf{I}$ 与其投影的夹角为 $\alpha$，当 $\alpha$ 在0到90度之间变化时，$\alpha$ 越大则 $\tan\alpha$ 越大，表明 $\mathbf{I}$ 在V方向的分量与在S方向的分量之差越大；随深度增加 $v$ 增大、$s$ 减小，故 $\alpha$ 增大，即 $\alpha$ 与深度正相关。论文同时指出式(7)只是观察的直觉结果，不能精确表达 $d$、$v$、$s$ 之间的关系，后续将建立更稳健的表达式。

## 场景深度恢复：线性模型、训练与参数学习

论文将亮度与饱和度之差近似表示雾霾浓度，建立线性模型：

$$d(x) = \theta_{0} + \theta_{1}v(x) + \theta_{2}s(x) + \varepsilon(x)$$

其中 $x$ 为图像中的位置，$d$ 为场景深度，$v$ 为雾霾图像的亮度分量，$s$ 为饱和度分量，$\theta_{0},\theta_{1},\theta_{2}$ 为未知线性系数，$\varepsilon(x)$ 为表示模型随机误差的随机变量，可视为随机图像，采用零均值、方差 $\sigma^{2}$ 的高斯密度（即 $\varepsilon(x)\sim N(0,\sigma^{2})$）。由高斯分布性质有 $d(x) \sim p(d(x) \mid x, \theta_{0}, \theta_{1}, \theta_{2}, \sigma^{2}) = N(\theta_{0} + \theta_{1}v + \theta_{2}s, \sigma^{2})$。

论文强调该模型的重要优势是保边性。对式(8)求梯度得 $\nabla d = \theta_{1}\nabla v + \theta_{2}\nabla s + \nabla\varepsilon$。由于实际中 $\sigma$ 不会太大，$\varepsilon(x)$ 趋于很小并接近零，$\nabla\varepsilon$ 小到可忽略；论文给出 $600\times 450$、$\sigma=0.05$ 的随机图像 $\varepsilon$ 及其梯度图像 $\nabla\varepsilon$（图6(e)、图6(d)），二者都很暗。因此在 $\sigma$ 较小时 $d$ 的边缘分布独立于 $\varepsilon$。又因 $v$ 与 $s$ 实际上是雾霾图像 $\mathbf{I}$ 分解出的两个单通道图像（HSV颜色空间的值通道与饱和度通道），式(10)保证只有当 $\mathbf{I}$ 有边缘时 $d$ 才有边缘。图6示例中，$\theta_{1}$ 设为1.0、$\theta_{2}$ 设为-1.0，$\varepsilon$ 为上述随机图像，所得Sobel图像 $\nabla d=\theta_{1}\nabla v+\theta_{2}\nabla s+\nabla\varepsilon$ 与雾霾图像的Sobel图像相似，说明 $\mathbf{I}$ 与 $d$ 具有相似的边缘分布，从而保证在深度不连续处附近也能较好恢复深度信息。

训练样本由雾霾图像及其对应的真实深度图构成，但户外场景深度难以可靠测量，现有深度相机（如Kinect）无法获取准确深度信息。受Tang等人准备训练数据的方法启发，论文从Google Images和Flickr收集无雾图像，用于生成合成深度图及相应雾霾图像。生成过程为：对每幅无雾图像生成同尺寸随机深度图，其像素值取自开区间(0,1)上的标准均匀分布；生成随机大气光 $\mathbf{A}(k,k,k)$，其中 $k$ 在0.85到1.0之间；再根据式(1)和式(2)用随机深度图 $d$ 与随机大气光 $\mathbf{A}$ 生成雾霾图像 $\mathbf{I}$。论文共使用500幅无雾图像生成训练样本（500幅随机深度图和500幅合成雾霾图像）。

参数学习采用最大似然。关注联合条件概率 $L = p(d(x_{1}), \dots, d(x_{n}) \mid x_{1}, \dots, x_{n}, \theta_{0}, \theta_{1}, \theta_{2}, \sigma^{2})$，其中 $n$ 为训练雾霾图像中的像素总数，$d(x_{\mathrm{n}})$ 为第 $n$ 个场景点的深度，$L$ 为似然。假设各场景点随机误差独立（即 $p(\varepsilon_{1},\dots,\varepsilon_{\mathrm{n}})=\prod_{\mathrm{i=1},\dots,\mathrm{n}} p(\varepsilon_{i})$），可将 $L$ 写为 $\prod_{i = 1}^{n} p(d(x_{i}) \mid x_{i}, \theta_{0}, \theta_{1}, \theta_{2}, \sigma^{2})$，进而 $L = \prod_{i = 1}^{n} \frac{1}{\sqrt{2\pi\sigma^{2}}} e^{-\frac{dg_{i} - (\theta_{0} + \theta_{1}v(x_{i}) + \theta_{2}s(x_{i}))}{2\sigma^{2}}}$，其中 $dg_{i}$ 表示第 $i$ 个场景点的真实深度。问题转化为求使 $L$ 最大的 $\theta_{0},\theta_{1},\theta_{2}$ 与 $\sigma$；为方便起见，论文最大化对数似然 $\ln L$，即 $\operatorname*{arg}_{\theta_{0}, \theta_{1}, \theta_{2}, \sigma} \ln L = \sum_{i = 1}^{n} \ln\left(\frac{1}{\sqrt{2\pi\sigma^{2}}} e^{-\frac{dg_{i} - (\theta_{0} + \theta_{1}v(x_{i}) + \theta_{2}s(x_{i}))}{2\sigma^{2}}}\right)$。

先对 $\sigma$ 求偏导并令其为零：$\frac{\partial \ln L}{\partial \sigma} = -\frac{n}{\sigma} + \frac{1}{\sigma^{3}} \sum_{i = 1}^{n} (dg_{i} - (\theta_{0} + \theta_{1}v(x_{i}) + \theta_{2}s(x_{i}))) = 0$，由此得 $\sigma^{2}$ 的最大似然估计 $\sigma^{2} = \frac{1}{n} \sum_{i = 1}^{n} (dg_{i} - (\theta_{0} + \theta_{1}v(x_{i}) + \theta_{2}s(x_{i})))^{2}$。对线性系数 $\theta_{0},\theta_{1},\theta_{2}$ 则用梯度下降估计，分别对 $\ln L$ 求偏导得：$\frac{\partial \ln L}{\partial \theta_{0}} = \frac{1}{\sigma^{2}} \sum_{i = 1}^{n} (dg_{i} - (\theta_{0} + \theta_{1}v(x_{i}) + \theta_{2}s(x_{i})))$，$\frac{\partial \ln L}{\partial \theta_{1}} = \frac{1}{\sigma^{2}} \sum_{i = 1}^{n} v(x_{i})(dg_{i} - (\theta_{0} + \theta_{1}v(x_{i}) + \theta_{2}s(x_{i})))$，$\frac{\partial \ln L}{\partial \theta_{2}} = \frac{1}{\sigma^{2}} \sum_{i = 1}^{n} s(x_{i})(dg_{i} - (\theta_{0} + \theta_{1}v(x_{i}) + \theta_{2}s(x_{i})))$，更新式为 $\theta_{i} := \theta_{i} + \frac{\partial \ln L}{\partial \theta_{i}},\ s.t.\ i \in \{0, 1, 2\}$。论文说明该式用于动态迭代，符号 $:=$ 不表示数学等号，而是将左端 $\theta_{\mathrm{i}}$ 的值设为右端的值。学习过程见Algorithm 1：输入训练亮度向量 $v$、饱和度向量 $s$、深度向量 $d$ 与迭代次数 $t$，输出 $\theta_{0},\theta_{1},\theta_{2}$ 与 $\sigma^{2}$；初始化 $\theta_{0} = 0; \theta_{1} = 1; \theta_{2} = -1$，每轮迭代中计算 $temp = d[i] - \theta_{0} - \theta_{1} * v[i] - \theta_{2} * s[i]$，累加 $wSum$、$vSum$、$sSum$、$sum$，更新 $\sigma^{2} = sum / n$ 与 $\theta_{0} = \theta_{0} + wSum; \theta_{1} = \theta_{1} + vSum; \theta_{2} = \theta_{2} + sSum$。

论文使用500个训练样本、包含1.2亿个场景点训练线性模型，共517个epoch，最佳学习结果为 $\theta_{0}=0.121779$、$\theta_{1}=0.959710$、$\theta_{2}=-0.780245$、$\sigma=0.041337$。系数一旦确定即可用于任意单幅雾霾图像，本文后续恢复场景深度均使用这些参数。

在深度估计阶段，论文指出该模型在特定情形下可能失效：图像中的白色物体通常亮度高、饱和度低，模型倾向于将其视为远处，导致深度估计不准。图8中第一幅图像的白鹅即为模型难以处理的区域，在原始深度图中被错误估计为高深度值。为此论文考虑邻域像素，基于场景深度局部恒定的假设处理原始深度图：$d_{r}(x) = \min_{y \in \Omega_{r}(x)} d(y)$，其中 $\Omega_{r}(x)$ 是以 $x$ 为中心的 $r\times r$ 邻域，$d_{r}$ 为尺度 $r$ 的深度图。图8(c)显示新的深度图 $d_{15}$ 能较好处理白鹅区域，但出现块状伪影；论文用引导图像滤波[43]平滑，图8(d)为最终恢复的深度图，块状伪影被有效抑制。为检验假设有效性，论文从Google Images、Photosig、Picasaweb和Flickr等知名图片网站收集大量户外雾霾图像数据库，按式(8)和式(21)用亮度与饱和度分量计算每幅雾霾图像的场景深度图。图9(a)为若干户外雾霾图像，图9(b)为对应估计深度图，图9(c)为无雾图像及其估计深度图；恢复的深度图在无雾区域颜色较暗、在浓雾区域颜色较亮，符合预期。

## 场景辐照度恢复与实验验证

大气光估计方面，由于已恢复输入雾霾图像的深度图，场景深度分布已知。图10(a)为某雾霾图像的估计深度图，亮区域代表远处。根据式(6)，论文选取深度图中最亮的前0.1%像素，并在对应雾霾图像 $\mathbf{I}$ 中这些最亮像素里选择强度最高的像素作为大气光 $\mathbf{A}$（见图10(b)与图10(c)）。

已知场景深度 $d$ 与大气光 $\mathbf{A}$ 后，可由式(2)估计介质透射率 $t$ 并恢复式(1)中的场景辐照度 $J$。为方便，将式(1)改写为 $\mathbf{J}(x) = \frac{\mathbf{I}(x) - \mathbf{A}}{t(x)} + \mathbf{A} = \frac{\mathbf{I}(x) - \mathbf{A}}{e^{-\beta d(x)}} + \mathbf{A}$。为避免产生过多噪声，将透射率 $t(x)$ 限制在0.1到0.9之间，最终恢复场景辐照度的函数为 $\mathbf{J}(x) = \frac{\mathbf{I}(x) - \mathbf{A}}{\min\{\max\{e^{-\beta d(x)}, 0.1\}, 0.9\}} + \mathbf{A}$，其中 $J$ 即所需的无雾图像。

论文指出散射系数 $\beta$ 在均匀区域可视为常数，代表单位体积大气向各方向散射光的能力，间接决定去雾强度。图11展示不同 $\beta$ 的效果：图11(e-g)为不同 $\beta$ 下恢复的透射率图，图11(b-d)为对应去雾结果。较小的 $\beta$ 导致透射率小，结果在远处仍显雾霾（图11(b)与图11(e)）；过大的 $\beta$ 可能导致透射率高估（图11(d)与图11(g)）。因此处理含浓雾区域的图像需要适中的 $\beta$，多数情况下 $\beta = 1.0$ 已足够。

实验部分，论文在多种雾霾图像上测试，并与He等人[29]、Tarel等人[46]、Nishino等人[49]、Meng等人[50]的方法比较。所有算法在MatlabR2013a环境、P4-3.3GHz PC、6GB RAM上实现。所提方法参数初始化为 $r=15$、$\beta=1.0$、$\theta_{0}=0.121779$、$\theta_{1}=0.959710$、$\theta_{2}=-0.780245$、$\sigma=0.041337$；为公平比较，四种对比方法的参数按[29]、[46]、[49]、[50]设为最优。

在真实图像定性比较中，由于各算法对一般户外图像都能取得较好结果，难以视觉排序，论文选择含大面积白色或灰色区域的挑战性图像进行比较，因为多数现有去雾算法对白色不敏感。图12(a)为待去雾图像，图12(b-e)分别为Tarel等人[46]、Nishino等人[49]、He等人[29]、Meng等人[50]的结果，图12(f)为所提算法结果。Tarel的结果去除了大部分雾霾且细节恢复良好，但存在明显过增强（如第一幅图像天空区域过暗、最后一幅图像中女性面部变褐），原因是Tarel算法基于He等人算法，而后者存在透射率高估的固有问题；此外图12(b)在间断处出现光晕伪影（第一幅图像的山、第二幅图像的植物叶片），因为[46]使用的“中值的中值滤波”不是保边滤波器。Nishino等人的结果有类似问题，倾向于过度增强局部对比度，图12(c)中恢复图像过饱和且失真，尤其第三幅图像（衬衫颜色变暗）。He等人的结果视觉上更好（图12(d)），远处浓雾去除良好且无光晕伪影，但在白色物体区域（如第三幅图像的衬衫）仍出现颜色失真，原因是[29]恢复透射率基于暗通道先验，其准确性强烈依赖该先验的有效性；当场景亮度与大气光相似时该先验失效，透射率估计不可靠；此外大气光也是[29]计算透射率的重要因素，需准确估计大气光，而He等人估计大气光的方法有局限，估计结果为近似值，故其算法易高估透射率。Meng等人的结果与He等人接近（图12(e)），因为Meng等人虽通过加入边界约束改进了DCP方法[29]，但未解决图像颜色与雾霾之间的歧义问题。与四种算法相比，所提结果无过饱和，图12(f)中天空与云清晰，山体细节适度增强。

在合成图像定性比较中，论文在已知真实图像的立体图像上测试五种算法。图13(a)为由无雾图像及已知深度图合成的雾霾图像，图13(b-f)为五种算法结果，图13(g)为真实图像。这些无雾图像及其真实深度图取自Middlebury立体数据集[57]-[61]。Tarel等人的结果与真实图像差异较大，明显偏暗（图13(b)中dolls图像的红色头发玩具、books图像中的书）。Nishino等人的结果有类似问题，如dolls图像中玩具颜色变为黄色、moebius图像背景变暗。He等人的结果更接近真实图像但仍有不准确（图13(d)），如books图像背景比应有颜色暗。Meng等人的结果同样存在过增强（图13(e)），cones图像中面具颜色与图13(g)相差甚远。相比之下，所提结果无过饱和问题，保持了物体原有颜色（图13(f)）。

定量比较采用均方误差（MSE）与结构相似性（SSIM）[62]评估图13结果。MSE计算式为 $e = \sqrt{\frac{1}{3N}} \sum_{c \in \{r, g, b\}} \|\mathbf{J}^{c} - \mathbf{G}^{c}\|^{2}$，其中 $J$ 为去雾图像，$G$ 为真实图像，$J^{c}$ 表示 $J$ 的某颜色通道，$G^{c}$ 表示 $G$ 的某颜色通道，$N$ 为图像 $G$ 中的像素数，$e$ 为衡量去雾图像与真实图像差异的MSE；$J$ 与 $G$ 尺寸相同，因其与雾霾图像 $I$ 对应。低MSE表示去雾结果令人满意，高MSE表示去雾效果不可接受。图14显示各算法MSE：Nishino等人结果总体MSE最高，主要因前述过增强；Tarel等人结果在前三幅图像优于Nishino等人，但在books图像更差；Meng等人结果按总体表现排第三；He等人结果总MSE为0.0167，比其他三者小两倍以上；所提方法在所有情况下MSE最低。SSIM方面，图15显示Nishino等人结果的SSIM均低于0.7，表明图像中大量结构信息丢失；Tarel等人SSIM与Meng等人相近，但均未达到0.8；He等人在四幅图像中SSIM明显高于其他三者；所提结果取得最高SSIM，优于四种算法。

复杂度方面，给定尺寸 $m\times n$、半径 $r$ 的图像，当式(8)中线性系数 $\theta_{0},\theta_{1},\theta_{2}$ 已获得时，所提去雾算法复杂度仅为 $O(m\times n\times r)$。表I给出与He等人[29]（用引导图像滤波[43]加速）、Tarel等人[46]、Nishino等人[49]、Meng等人[50]的时间消耗比较：441×450分辨率下分别为9.866s、4.141s、91.661s、6.171s、1.420s；600×450下为12.228s、8.229s、104.670s、4.468s、2.219s；1024×768下为36.896s、69.294s、317.386s、10.231s、4.278s；1536×1024下为73.571s、218.033s、649.722s、17.334s、9.636s；1803×1080下为90.717s、351.139s、861.360s、21.567s、12.314s。可见所提方法远快于其他方法，即使输入雾霾图像很大也能高效处理，其高效率主要得益于基于颜色衰减先验的线性模型显著简化了场景深度与透射率的估计。

**讨论与结论**
论文总结：提出一种基于雾霾图像像素亮度与饱和度之差的新型线性颜色衰减先验；利用该简单而强大的先验为雾霾图像场景深度建立线性模型，并用监督学习方法学习模型参数，从而较好恢复深度信息；借助所得深度图可容易地恢复雾霾图像的场景辐照度。实验结果表明所提方法具有极高效率与出色去雾效果。

论文同时指出一个尚待解决的共性问题：大气散射模型中的散射系数 $\beta$ 在非均匀大气条件下不能视为常数[55]，例如距观察者数公里之遥的区域应具有很低的 $\beta$ 值。因此基于大气散射模型的去雾算法在某些情况下易低估透射率。由于几乎所有现有单幅图像去雾算法都基于常数 $\beta$ 假设，亟需更灵活的模型；可考虑更先进的物理模型[63]来克服这一挑战，该问题留待未来研究。
