# 多层石墨烯中的分数量子反常霍尔效应

**Fractional quantum anomalous Hall effect in multilayer graphene** · 2024 · https://doi.org/10.1038/s41586-023-07010-7

本文报道在菱面体五层石墨烯/六方氮化硼（hBN）莫尔超晶格中，于零磁场下观测到整数和分数量子反常霍尔效应（IQAHE和FQAHE）。作者在莫尔填充因子 v = 1, 2/3, 3/5, 4/7, 4/9, 3/7, 2/5 处观察到量子化的霍尔电阻 Rxy = h/(ve²)，并在 v = 1/2 附近观察到类似复合费米液体（CFL）的行为。作者认为该平台为研究零磁场下的电荷分数化和非阿贝尔任意子编织提供了理想条件，且材料质量优于此前唯一观测到FQAHE的扭曲MoTe₂。

## 研究背景与实验体系

分数量子霍尔效应（FQHE）在二维电子气中的实现是电子关联与拓扑效应交织的经典范例。理论预言，通过工程化具有非零陈数（Chern number）的拓扑平带，可在零磁场下实现类似态。作为FQAHE的先驱，整数量子反常霍尔效应（IQAHE）已在磁性拓扑绝缘体和二维材料莫尔超晶格中实现。此前，FQAHE仅在扭曲MoTe₂（t-MoTe₂）的填充因子 v > 1/2 处被观测到。石墨烯基莫尔超晶格因其晶格缺陷更少，被理论认为可能承载更丰富的分数量子态，但在本工作之前，尚未有任何石墨烯体系报告FQAHE的观测。

本工作研究的体系是菱面体五层石墨烯（RG）与hBN形成的莫尔超晶格。紧束缚计算表明，当层数从N=2增加到5时，零位移场（D）下的能带色散变得更平，但N>5时价带会因三角翘曲效应而退化。在非零D下，带边态获得更大的贝里曲率，结合hBN的莫尔势，可形成拓扑平带。作者指出，该实验体系相比扭曲TMD莫尔超晶格有三个优势：石墨烯材料质量更高；与石墨烯的电接触更好；异质双层莫尔超晶格的扭转角不均匀性对莫尔周期的影响更小。本工作研究的五层RG/hBN体系，其莫尔周期约为11.5 nm，扭转角约0.77°，此前尚无具体的理论分析或预测。

设备测量在稀释制冷机中进行，电子温度约100 mK，采用标准锁相放大技术。由于设备几何结构无法直接测量纯的Rxx或Rxy，作者使用磁场对称化/反对称化方法（在B = ±0.1 T下测量）以及Onsager互易关系来解耦纵向和霍尔电阻。作者强调，±0.1 T的磁场仅用于抑制微米级器件在零磁场下磁畴随机翻转导致的电阻尖峰，而所观测的物理现象在B = 0时是稳健的。

## 相图与拓扑平带

图1b和1c展示了在混合室温度T = 10 mK下，纵向电阻Rxx和横向电阻Rxy作为电荷密度ne（填充因子v）和位移场D的函数。数据在B = ±0.1 T下采集，并分别进行了对称化和反对称化处理。相图中，一个倾斜的条带区域内出现大的电阻值。在v ≤ 1/2区域，出现大的Rxx且Rxy围绕零值大幅波动；在v = 2/5到1区域，Rxy变大并随v逐渐变化。在v = 1, 2/3, 3/5, 2/5处，Rxx出现局部最小值，Rxy出现平台。v = 1对应的电荷密度比t-MoTe₂小约5倍，这归因于本体系更大的莫尔周期。在v ≤ 1/2处观测到的具有大Rxx的绝缘态占据了一个宽的连续填充因子范围，这不同于整数填充的关联绝缘体或分数量子态，可能源于平带内的电子结晶形成零磁场维格纳晶体。与IQAHE和FQAHE观测于大正D区不同，在D < 0时，作者在整数填充因子v = 2, 3, 4处观测到关联绝缘态。倾斜条带的斜率被归因于有限电荷密度对外加D场的部分屏蔽效应。

图1d展示了基于紧束缚模型的莫尔能带结构计算结果。作者使用了一个现象学模型，在无莫尔的k·p哈密顿量上对所有层施加相同的超晶格势 V(r) = -2V₀∑cos(gᵢ·r + φ)，其中V₀ = 10 meV，φ = 0。该模型包含了石墨烯-hBN的晶格失配（ε = 0.017）和扭转角（θ = 0.744π/180），以复现11.5 nm的莫尔周期。当层间电势差Δ = 75 meV时，模型产生了一个|C|=1的极窄（带宽< 5 meV）且与其他能带隔离的最低导带，其全局带隙清晰。相反，最低价带则宽得多（带宽> 45 meV），拓扑平庸（C=0），且与相邻莫尔带能量重叠。

## 整数与分数量子反常霍尔效应

在v = 1处，作者观察到陈数C = ±1的IQAHE。在D/ε₀ = 0.97 V/nm，T = 0.1 K时，Rxy在零磁场下量子化为±h/e²，Rxx小于5 Ω。该量子化态在高达1.6 K的温度下依然保持。通过Streda公式分析，该态的色散与C = ±1的斜率相符。从约0.6 T开始，出现与C = 2和C = 3整数量子霍尔态对应的Rxx的谷值，其增量ΔC = 1表明v = 1处一个电子占据一个莫尔原胞，自旋简并完全解除。IQAHE平台宽度对应的电荷密度约为3×10¹⁰ cm⁻²，比t-MoTe₂中的相应平台窄约10倍。

在v = 2/5至1的广泛区间内，作者观测到6个分数量子反常霍尔态。通过精细的Rxx和Rxy映射以及Rxy (v) 的线切，可以清晰地看到在v = 2/5, 3/7, 4/9, 4/7, 3/5和2/3处，Rxy = h/(ve²)的平台以及Rxx的对应谷值。磁场回滞扫描显示这些态的Rxy在零磁场处量子化，且Rxx远小于Rxy。在朗道扇形图中，这些分数量子态对应的谷值演化为倾斜的线条，其斜率与基于Streda公式的计算结果一致。作为D的函数，所有FQAH态的Rxy平台和Rxx谷值随填充因子增加而向更高D移动，这与相图中倾斜条带的形状相符。这些态类似于零磁场下的Jain序列。与t-MoTe₂中FQAHE仅存在于v > 1/2不同，本工作观测到的分数量子态位于半填充的两侧，作者将此归因于石墨烯器件在低电荷密度下更好的电接触。观测到的最窄FQAH平台宽度约为10¹⁰ cm⁻²，比t-MoTe₂中观测到的3/5态窄约10倍。

## 半填充处的反常霍尔效应与相变

在v = 1/2附近，作者观测到不同于FQAH态的行为。在填充因子从4/9到4/7的宽范围内，Rxy随ne和v近似线性变化，而Rxx没有明显谷值。在v = 1/2处，Rxy恰好等于2h/e²。这种行为与高磁场下二维电子气半填充朗道能级中的复合费米液体（CFL）的特征相似，表明该态没有电荷能隙。变D测量揭示了该CFL态两侧的两种不同相变。在更高D一侧，系统进入一个谷极化的金属态，其特征是Rxy值在一个平台范围内（D/ε₀约0.9至0.94 V/nm）恒定，然后随D增加而单调下降，同时Rxx先增后减。在更低的D下，Rxy接近零，而Rxx保持数kΩ量级。作者将此高D侧的转变解释为CFL到费米液体的连续相变，并指出该相变近期才在FQAHE体系的理论中被提出，在t-MoTe₂中尚未被观测到。在更低D一侧，系统转变为v ≤ 1/2的关联绝缘态。

作者总结，他们在第一个莫尔导带的半填充两侧均观测到了IQAHE和FQAHE。这一结果展示了RG/hBN体系在层数、位移场和扭转角方面的巨大可调性，为研究零磁场下的新型量子相变、电子晶体和CFL行为提供了平台，并指向了可能的高陈数平带和更奇异的非阿贝尔任意子态。此外，石墨烯体系中FQAHE与超导性的共存，为利用同一器件内的横向结实现非阿贝尔编织提供了可能。
