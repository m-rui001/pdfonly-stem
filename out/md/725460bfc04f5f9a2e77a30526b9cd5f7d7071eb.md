# Fe掺杂TiO₂光催化降解水中4-叔丁基苯酚：性能、机理与矿化路径

Degradation and mineralization of 4-tert-butylphenol in water using Fe-doped TiO₂ catalysts · Scientific Reports 9:19284 (2019) · DOI: 10.1038/s41598-019-55775-7

该研究针对内分泌干扰物4-叔丁基苯酚（4-t-BP）在水中的光催化降解与矿化展开。4-t-BP是一种烷基酚类内分泌干扰物，具有难生物降解性、高雌激素效应和生态毒性，已在污水厂出水中被检出，属于新兴关注污染物。异相光催化虽已广泛用于去除水中难降解有机物，但4-t-BP的光催化矿化研究极少，其降解路径亦不明确。本研究采用湿浸渍法制备了不同铁掺杂量（Fe/Ti重量比0.5%、1%、2%、4%）的Fe-doped TiO₂催化剂，以商品P25 TiO₂为基底，在254 nm紫外光下考察其对4-t-BP的降解与矿化性能，并探究H₂O₂添加的影响。核心发现是：4% Fe/TiO₂取得最高TOC去除率（86%）；单独UV/H₂O₂虽能100%转化4-t-BP但TOC去除仅31%；铁掺杂量增加显著减少中间产物并促进CO₂生成；降解遵循伪二级动力学。

## 催化剂制备与结构表征

Fe-doped TiO₂催化剂以湿浸渍法制备：将3 g P25 TiO₂（21 nm，≥99.5%）悬浮于100 mL超纯水中，加入适量FeCl₂（98%），搅拌24小时后水洗三次，80 °C干燥12小时，研磨后在马弗炉中500 °C煅烧6小时。XRD图谱显示所有合成催化剂均与基底TiO₂相似，在2θ = 25.3°、37.8°、48.0°、54.0°、55.1°处为锐钛矿相特征峰（ICDD No. 86-1048, 86-1157），2θ = 27.4°处为金红石相峰。所有掺杂样品均未观察到含铁晶相，这与先前研究一致，原因是铁离子半径（0.64 Å）与钛离子（0.68 Å）相近，铁可能进入TiO₂晶格取代钛或占据间隙位，或以无定形铁氧化物细颗粒形式高度分散。Scherrer方程计算的晶粒尺寸在17–24 nm范围内：TiO₂为20.56 nm，0.5% Fe/TiO₂为18.68 nm，1%为21.03 nm，2%为19.31 nm，4%为17.24 nm。XRF分析4% Fe/TiO₂样品显示：TiO₂ 96.174%、Fe₂O₃ 3.597%、CaO 0.078%、SiO₂ 0.011%、Cl 0.139%，Fe₂O₃/TiO₂比值为3.74%，证实铁以氧化物形式掺杂。SEM/EDS元素面扫显示所有样品中铁相在TiO₂表面分布均匀，反应后表面形貌未改变，存在颗粒团聚现象；TEM测得颗粒尺寸约20 nm。UV-Vis光谱（200–750 nm）显示，仅4% Fe/TiO₂在200–365 nm范围呈现显著增强的吸收，归因于铁离子d电子与TiO₂导带/价带之间的电荷转移跃迁。

## 光催化性能、反应机理与过程评价

TiO₂在紫外光下产生电子-空穴对：TiO₂ + hν → e⁻cb + h⁺vb（式1），电子还原O₂生成超氧自由基（e⁻cb + O₂ → O₂⁻•），空穴氧化H₂O生成羟基自由基（h⁺vb + H₂O → OH• + H⁺）。Fe³⁺可捕获光生电子生成Fe²⁺（Fe³⁺ + e⁻cb → Fe²⁺），Fe²⁺可被吸附O₂氧化回Fe³⁺并生成O₂⁻•（Fe²⁺ + O₂(ads) → Fe³⁺ + O₂⁻•），也可将Ti⁴⁺还原为Ti³⁺（Fe²⁺ + Ti⁴⁺ → Fe³⁺ + Ti³⁺）；同时Fe³⁺可捕获空穴生成Fe⁴⁺（Fe³⁺ + h⁺vb → Fe⁴⁺），Fe⁴⁺与OH⁻反应生成羟基自由基（Fe⁴⁺ + OH⁻ → Fe³⁺ + HO•），即铁离子通过充当h⁺/e⁻捕获中心抑制复合、增强光活性。但铁浓度过高时Fe³⁺/Fe²⁺循环也构成复合中心（Fe³⁺ + e⁻cb → Fe²⁺；Fe²⁺ + h⁺vb → Fe³⁺），且过量铁沉积在TiO₂表面可形成Fe(OH)²⁺颗粒，在290–400 nm范围与TiO₂竞争光子吸收。4-t-BP的总反应为C₁₀H₁₄O + O₂ → CO₂ + H₂O。

光催化实验在循环批式环隙反应器中进行：总处理体积250 mL，辐照体积56.8 mL，流速178 mL min⁻¹，6 W Osram灯发射254 nm紫外光，催化剂用量1 g L⁻¹，4-t-BP初始浓度30 mg L⁻¹（TOC实测24.5 ± 0.5 mg L⁻¹，理论值23.96 mg L⁻¹），暗吸附1小时达平衡后开灯计时，反应60分钟，H₂O₂添加实验使用88.31 mg L⁻¹ H₂O₂。初始pH约6.3，反应结束时降至约3.8。4-t-BP去除率方面，基底TiO₂最高（97%），所有Fe掺杂催化剂为92–93%。吸附容量qe按qe = (C₀ − Ce)V/m计算：铁含量越高qe越大，但整体偏低。动力学拟合表明伪二级模型（1/Ct − 1/C₀ = −k₂t）优于伪一级，速率常数k₂为：TiO₂ 0.0100 L mol⁻¹ min⁻¹（R²=0.9486），0.5% Fe/TiO₂ 0.0072（R²=0.9918），1% 0.0069（R²=0.9995），2% 0.0061（R²=0.9947），4% 0.0064（R²=0.9917）。TOC去除方面，UV照射60分钟后基底TiO₂去除73%；铁掺杂从0.5%增至4%，TOC去除从65%升至86%，其中2% Fe/TiO₂（73%）与TiO₂持平，4% Fe/TiO₂（86%）最高。文献中铁掺杂最佳浓度报道不一（如Zhu等报道0.40% Fe-TiO₂优于P25；Zhao等发现1% Fe最佳；Anwar等用6% Fe-TiO₂高效降解亚甲基蓝），说明最佳掺杂量依赖目标物和条件。TOC去除高于4-t-BP去除可归因于中间产物比母体化合物更难氧化，体系中母体与中间产物竞争氧化剂；基底TiO₂更有利于4-t-BP转化，而4% Fe/TiO₂更有利于深度矿化至CO₂。

H₂O₂的添加研究基于异相光Fenton机理：Fe³⁺ + H₂O + hν → Fe²⁺ + H⁺ + OH•（式15），H₂O₂ + hν → 2HO•，H₂O₂ + e⁻cb → HO• + OH⁻，以及Fenton反应H₂O₂ + Fe²⁺ → Fe³⁺ + HO• + OH⁻。结果显示UV/H₂O₂在30分钟内即100%转化4-t-BP，但TOC去除仅31%，说明H₂O₂虽能快速破坏母体分子但对碳氧化为CO₂的活性有限。在H₂O₂存在下，铁含量越高4-t-BP去除越低：从0.5% Fe/TiO₂的95%降至4% Fe/TiO₂的87%，但两者最终TOC去除均为59–61%。总体上H₂O₂添加对TOC去除无益，与前人报道的矛盾结论一致——有研究认为UV与氧化剂和光催化剂协同增效，另有研究归因于氧化剂与催化剂竞争紫外光子，或H₂O₂吸附在催化剂表面降低活性，还可能因H₂O₂在反应初期即被消耗完。

中间产物分析定量了乙酸和甲酸——它们是矿化为CO₂和H₂O之前最后的中间体。通过碳平衡可间接计算其他中间体和CO₂的量：OC中间体=最终TOC总量−TOC(4-t-BP)−TOC(乙酸+甲酸)（式20）；OC(CO₂)=初始TOC总量−最终TOC总量（式21）。结果发现：铁掺杂量从0.5%增至4%使中间产物碳含量显著下降，CO₂生成相应增加，即更高的铁含量促进深度氧化；UV/H₂O₂虽快速完全转化4-t-BP但不增加中间体和酸生成。关于降解路径，文献报道的4-t-BP中间体包括：Wu等（2016）在UV光解和H₂O₂氧化中检出4-叔丁基邻苯二酚、4-叔丁基苯酚二聚体、6-叔丁基-3-甲基苯甲醚、苯-1,4-二醇及2-壬烯-1-醇、2-癸烯-1-醇、2-十二碳烯醛；Wu等报道UV/S₂O₈²⁻过程生成2,4-二叔丁基苯酚和4-叔丁基苯酚二聚体；Xiao等用Bi₄O₅I₂纳米片可见光降解4-t-BP，反应2小时未检出中间体，15分钟时仅见少量乙酸异丁酯、乙酸丁酯和极少量乙苯。

催化剂稳定性通过测定反应后溶液中铁浸出量评价：0.5–2% Fe/TiO₂检出0.01 ppm Fe，4% Fe/TiO₂为0.14 ppm；添加H₂O₂后浸出增加（0.5%时为0.04 ppm，4%时为0.40 ppm）。对4% Fe/TiO₂，溶液中的铁量分别相当于催化剂上铁总量的0.35%（无H₂O₂）和1%（有H₂O₂），因此铁浸出可忽略不计，不是影响催化性能的因素。能耗评估采用电能耗除以去除量（electric energy per order, EEO = P·t·1000 / (V·60·log(C₀/Cf))），基于TOC计算：UV+4% Fe/TiO₂最低（28 kWh/m³/order），UV+TiO₂和UV+2% Fe/TiO₂为42，UV+1%为47，UV+0.5%为53，H₂O₂添加使能耗升高（4%时为59，0.5%为62），UV/H₂O₂最高（147），总体范围为28–147 kWh/m³/order。铁掺杂增加降低能耗，与文献中EEO范围（4–958 kWh/m³/order）一致。

## 材料与方法

试剂：4-叔丁基苯酚（99%，Sigma-Aldrich）为目标污染物，TiO₂ P25（纳米粉，21 nm一次粒径，≥99.5%）为基底光催化剂，FeCl₂（98%）为掺杂前驱体，H₂O₂溶液（37.6% w/w，Skat-Reactiv）为羟基自由基源，所有试剂未经纯化直接使用，实验用水为Direct-Q 3UV超纯水。4-t-BP储备液：1000 mL、300 ppm，每周配制并于5.6 °C储存；工作液稀释至30 ppm，HPLC实测30 ± 1 ppm。催化剂表征手段：XRD（SmartLab，Rigaku，Cu Kα辐射，2θ = 10–80°）、SEM（Auriga Cross Beam 540，Carl Zeiss）、TEM（JEM-2100，Jeol，配EDS）、XRF（PANalytical Axios，标准无标样半定量分析，0.5 g样品在He气氛下）、UV-Vis（Evolution 60 S，Thermo Fisher，200–750 nm，样品在乙醇中超声5分钟）。晶粒尺寸按Scherrer方程D = 0.9λ/(βcosθ)计算，λ = 1.54060 Å。反应器为自制循环装置：250 mL溶液经蠕动泵（Heidolph 5006，178 mL min⁻¹）循环通过内置6 W Osram灯的环隙光反应器（辐照体积56.8 mL），非辐照部分磁力搅拌，Mettler Toledo LE409电极连续监测pH。每个实验重复两次取均值，以标准误作图。催化剂使用前在水浴中超声10分钟（FB15055，Fisher Scientific）。H₂O₂实验添加88.31 mg L⁻¹ H₂O₂。分析方法：TOC用Multi N/C 3100（Analytik Jena），4-t-BP用HPLC Agilent 1290 Infinity II定量，乙酸和甲酸用离子色谱（930 Compact IC Flex，Metrohm），铁含量用原子吸收光谱AAnalyst 400（Perkin Elmer）。TOC和AAS样品经0.45 μm再生纤维素滤膜过滤，HPLC和IC样品经0.2 μm RC膜过滤。去除效率按式(24)计算：(1 − Ct/C₀) × 100%。

## 结论

本研究成功以湿浸渍法制备了四种铁掺杂量的Fe/TiO₂催化剂（0.5–4 wt.%），并系统评价了它们在紫外光下对4-t-BP的降解和矿化性能。主要结论如下：（1）SEM/EDS证实所有催化剂表面铁相分布均匀；（2）4-t-BP在UV/Fe/TiO₂或UV/H₂O₂下均较易降解，但因中间产物积累导致TOC去除率较低，其中4% Fe/TiO₂的碳矿化率最高（86%）；（3）铁掺杂量增加使中间产物浓度降低、CO₂生成增加，即促进深度矿化；（4）光催化降解遵循伪二级动力学，速率常数范围0.0064–0.0100 L mol⁻¹ min⁻¹；（5）反应后溶液铁浸出量低至可忽略（4% Fe/TiO₂在无/有H₂O₂时分别为0.14和0.40 ppm），催化剂稳定性良好。
