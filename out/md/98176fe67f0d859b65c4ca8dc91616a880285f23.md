# CuInP₂S₆室温层状铁电体的极化稳定性与尺寸效应

CuInP₂S₆ – Room Temperature Layered Ferroelectric · 2015 · https://doi.org/10.1021/acs.nanolett.5b00491

本文通过环境与超高真空扫描探针显微镜，直接证实了层状范德华晶体CuInP₂S₆（CITP）在室温下具有稳定的铁电极化，并揭示了其尺寸效应：厚度大于100 nm的薄片呈体相般的畴结构，50 nm以下极化消失。作者将这一现象归因于退极化场导致的极化不稳定性，并指出高偏压下极化翻转伴随铜离子迁移与表面损伤，表明可动Cu离子可能参与内部屏蔽。这一发现为在范德华晶体中实现准二维与单层极性材料提供了新路径。

## 材料背景与实验目标

CITP属于唯一已知在室温及以上具有铁电极化的范德华层状晶体家族。其结构由硫框架构成，八面体空隙由Cu和In阳离子填充，P–P对在互连的硫笼内形成三角排列。在Tc = 315 K处发生从顺电相到铁电相的一级相变，伴随铜亚晶格有序化及铟亚晶格阳离子偏离中心位置（C2/c → Cc对称性），自发极化方向垂直于层平面。此前对CITP及其硒取代衍生物的研究主要基于中子散射、拉曼等体块技术，本研究是首次对该结构进行局域铁电表征。作者旨在探究剥离的二维薄片中的铁电性质、尺寸效应及铁电相稳定性的极限。

## 环境与超高真空下的畴结构与极化翻转

在环境条件下对解理的体块单晶进行压电力显微镜（PFM）研究，单频PFM和波段激发PFM（BE-PFM）均显示丰富的畴网络，畴尺寸约1–3 μm。压电响应相位在畴壁处翻转π弧度，证实了面外极化取向。畴在单原子台阶及高于30 nm的台阶束上保持连续，直接确认了自发极化的三维有序性。表面均匀分布的部分剥离区域（约200 nm宽、0.5 nm深）完全无PFM响应，其性质与起源未知。

用针尖作为极化电极在不同电压下写入方形畴。±2 V直流偏压下可见极化翻转，但正偏压响应更明显；±4 V时两个方向均观测到翻转但仍不完全，且正偏压引发可逆的球形颗粒状表面形貌变化；±5 V时几乎整个实验区域均被极化，颗粒形成再次出现。初步结果显示颗粒尺寸随偏压增大而增大，可能源于铜在表面的还原。

为排除环境气氛的影响，作者在超高真空（UHV，基础压力1×10⁻¹⁰ mbar或更优）中进行BE-PFM与波段激发极化翻转谱（BEPS）。原位解理并立即成像得到的畴结构与环境条件类似，尺寸约1–3 μm的上下极化畴及部分剥离的梯形无响应区均保留。环境与UHV下BE-PFM图像无明显差异，表明外部屏蔽过程不影响畴形成。BEPS数据（1 Vac，±10 Vdc）在−6.5至+6.5 V区间表现出典型铁电行为：幅度回滞与180°相位翻转；而超出该区间（−10至−6.5 V及6.5至10 V）幅度与相位回滞突然崩溃。作者将其归因于非局域电化学过程中环境对反反应位点可及性的影响。环境下的形貌变化与真空回滞的独特特征提示CITP具有离子导电行为——已确立Cu离子的离子电导活化能低至0.73 eV。由于局域电场极大，离子运动可能被激活；铁电翻转阈值可能与离子运动阈值重叠或交错，使得纯铁电翻转的观测与解释颇具挑战。但这些过程不影响已形成的畴结构，仅在强场下变得显著。

## 薄片尺寸效应与理论模型

在环境条件下研究剥离的CITP薄片（厚度50 nm至0.5 μm，沉积于Si/SiO₂衬底）。BE-PFM与单频PFM在50 nm厚的薄片中仍能检测到响应，但更薄时响应过弱或Tc被抑制。存在厚度梯度时，厚度大于100 nm的区域呈现体相般行为，畴对比度良好；50 nm时幅度与相位信号仍可分辨畴。自由悬浮薄片在100 nm以下表现出体相般畴行为，而50 nm及以下畴对比度迅速消失（伴随畴面积直方图的变化）。该行为与CITP中可动离子载流子对铁电极化的内部屏蔽一致，因为化学表面屏蔽应能将铁电性维持到更小尺度，且与UHV观测不符。

为定量描述，作者采用适用于正规铁电体的Landau-Ginzburg-Devonshire（LGD）理论。单畴铁电膜中面外极化分量P₃(z)的平衡一维分布由欧拉-拉格朗日边界问题给出（式1）：

```
∂²P₃/∂z² = αP₃ + βP₃³ + γP₃⁵ − g ∂²P₃/∂z² − ∂φ/∂z
边界条件：(P₃ + λ∂P₃/∂z)|_{z=+L/2} = 0, (P₃ − λ∂P₃/∂z)|_{z=−L/2} = 0
```

其中α、β、γ为2-6次LGD展开系数，g为极化梯度系数，λ为外推长度，L为膜厚，α = αₜ(T − T_C)。电势φ由泊松方程（式2）及开路边界条件确定：

```
εᵇ₃₃ ∂²φ/∂z² = (1/ε₀)(∂P₃/∂z − ρ(φ))
D₃ ≡ ε₀εᵇ₃₃ ∂φ/∂z − P₃ = 0 （在z = ±L/2处）
```

电荷密度采用半导体形式ρ(φ) = 2en sinh(eφ/k_BT)。在相变邻近区域用德拜近似（eφ/k_BT ≪ 1），德拜半径R_d = √(k_BT/(2ε₀εᵇ₃₃e²n(T)))，室温下估计为几纳米至20 nm（对应载流子浓度10²²至10²⁵ m⁻³）。膜从铁电相进入顺电相的临界厚度L_cr由特征方程（式3）给出：

```
L_cr = 2κ arctan( (g κ / (α* λ)) (1/κ² + 1/ξ²) (1 + λ/ξ) + ξ/κ ) ≈ πκ
```

其中κ ≈ R_d^{−1/2}√(εᵇ₃₃ε₀|α|)为屏蔽长度，ξ = √(εᵇ₃₃ε₀g)为关联长度，α* = αₜ(T − T*_FE)（含应变修正），T*_FE = T_C + β²/(4γαₜ) + u_m/(4Q₁₂αₜ(s₁₁+s₁₂))。式3在L ≫ ξ且α < 0时有效。

为获取CITP的体相LGD势，作者考虑经典1D 2-6次自由能展开ΔF = (α/2)P₃² + (β/4)P₃⁴ + (γ/6)P₃⁶ − P₃E₃，并设α = (T − T₀)/(ε₀C_CW)。利用实测介电常数温度依赖及室温自发极化值2.55 μC/cm²，得到T₀ = 292 K、C_CW = 7.2×10³ K、β = −2.3×10¹² m⁵/(F·C²)、γ = 3.5×10¹⁵ m⁹/(F·C⁴)。临界厚度随材料参数变化可达50–1000 nm，且几乎不依赖外推长度（L_cr ≈ πκ近似严格）。图5b的“膜厚–温度”相图显示单畴铁电相与多畴态之间的复杂形状，源于半导体性质的贡献。对高载流子密度10²⁵ m⁻³的估算给出单畴极化态临界厚度约200 nm；实验观察到多畴态存活至约50 nm。作者指出，无外延应变时多畴态在超薄极限也可能被抑制，外延应变会重整α*并进一步降低临界厚度。

## 结论与展望

实验观测明确证实了层状范德华晶体中存在稳定的铁电极化，证据包括畴结构、可重写极化与回滞环。尽管退极化效应似乎在厚度低于约50 nm时抑制了极化畴，但在更低温度或多畴态下极化可能仍存在，只是超出当前技术的分辨率。作者强调这类材料值得深入研究，特别是范德华间隙间原子有序耦合机制（决定三维铁电序）及硫代磷酸盐过渡金属家族中丰富的离子取代可能性。更重要的是，清洁极性表面在几乎所有铁电材料中此前都难以实现，而本研究表明CITP表面稳定且保持铁电序，为范德华外延耦合铁电与电子功能开辟了新途径。

**方法与材料**
CITP晶体通过化学输运反应制备，呈薄板状、c轴垂直于表面。介电测量覆盖20 Hz–3 GHz频段。超薄片采用机械剥离（“Scotch tape法”）制备于Si/SiO₂衬底（SiO₂厚约300 nm）。环境PFM使用Cypher AFM（Asylum Research），Pt-Cr镀层悬臂梁；UHV测量使用Omicron AFM/STM（基础压力1×10⁻¹⁰ mbar），样品原位解理。所有薄片沉积于绝缘衬底，因此未进行导电与翻转测量。
