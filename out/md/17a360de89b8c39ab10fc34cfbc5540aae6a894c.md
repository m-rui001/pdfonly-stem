# 交通场景结构预测与车道检测的深度神经网络

> Deep Neural Network for Structural Prediction and Lane Detection in Traffic Scene · 2016 · https://doi.org/10.1109/tnnls.2016.2522428

本文主张深度神经网络不仅应自动化输入表示，还应在输出端引入任务特定的结构预测。针对车道检测问题，作者提出两种网络：一是多任务卷积网络，同时输出目标存在性与几何属性（位置和朝向）；二是采用循环神经元层的结构感知网络，利用记忆自动推断局部线索的全局结构，无需显式车道模型。两种网络均在真实交通场景中验证，优于传统检测器。

## 引言与相关工作

深度神经网络已在大规模视觉任务中取得突破，但多数现有网络将输出简化为类别标签，缺乏对目标空间结构的建模。车道检测这类任务需要同时考虑局部图案和全局布局：例如图1中，一个7×7的图像块（c）因包含车道标记而被识别为边界，而（b）虽无可见标记，却能借由整体边界结构被推断为边界；（a）则因周围环境被判定为误检。因此，作者提出在输出端引入结构预测。

传统方法多依赖手工特征检测局部线索，再通过显式车道模型（如[6][7][8]）推断全局结构。概率场模型（如CRF）虽能编码结构，但设计能量函数和局部特征困难，且难以表示全局支撑的目标。作者改用LSTM捕捉序列中的长程依赖，将车道检测建模为序列预测问题。

## 多任务卷积网络

第一个网络基于LeNet结构，输入为图像中的矩形区域（ROI），经两次卷积（5×5和3×3）与2:1最大池化后，分支为两个任务：分类任务判断目标（车道线段）是否存在，回归任务估计线段在ROI中的几何属性。几何属性定义为两个参数：d为线段到ROI中心的带符号距离（“-”表示上方，“+”表示下方），θ为线段与水平方向的夹角。由于采用逆透视映射（IPM）图像，每个像素对应地面0.1m×0.1m区域，因此几何参数有明确的物理意义。

设输入特征图为{X_p}，卷积核为{W_q,p}，激活函数f，则输出H_q = f(Σ_p X_p * W_q,p + b_q)。分类和回归分支各有独立的单隐层，隐层神经元输出为z_i = h(Σ_j U_ij y_j + c_i)。分类输出p = σ(Σ_i φ_i z_i^C + b^C)，回归输出(d, θ)^T = Σ_i ψ_i z_i^R + b^R。分类损失用负对数似然L_C = -log p^g (1-p)^(1-g)，回归损失用带开关的平方误差L_R = [(d- d̂)^2 + (θ- θ̂)^2]·g，其中g为真实标签。前馈时由预测p控制开关，反向传播时由真实标签g控制，从而仅在目标存在时回传回归误差。

该网络的优势在于：较大的ROI（28×20像素）包含更多上下文信息，同时通过回归估计可进一步精化位置，避免了传统滑动窗口的盲搜。实验中，CNN在车道标线检测中优于SVM、MLP和简单强度凸起滤波器，ROC曲线的AUC值更高。CNN的检测分数综合了分类置信度与几何距离：s = y - α|d|，其中y是分类器的对数概率，α=10（原文写为“α = P atchRadius = 10”，PatchRadius为半宽）。图11显示CNN对靠近真实边界的点给出更高分，而SVM易受背景杂波干扰。

## 循环神经网络

第二个网络在卷积特征提取（单次5×5卷积+2:1池化，无非线性激活）后接入一层LSTM单元，再经前馈层输出预测。LSTM单元包括输入门、遗忘门、输出门和内部状态，公式如下：

状态更新：a^{t+1}_i = c^{t+1}_i a^t_i + b^{t+1}_i g(Σ_j w_ij x^{t+1}_j + Σ_k u_ik h^t_k)，输出h^{t+1}_i = d^{t+1}_i σ(a^{t+1}_i)，其中b、c、d分别为输入门、遗忘门、输出门，它们的输入为a^{α,t+1}_i = g(Σ_j w^α_ij x_j + Σ_k u^α_ik h_k + v^α_i a_i)，执行顺序为输入门→遗忘门→状态→输出门→输出。

应用于车道检测时，将IPM图像划分为50个窄条（10×80像素），每个条带内再做16个5×5小块的二分类预测，条带从左到右依次输入网络，利用LSTM记忆跨条带结构。该设计使模型能推断虚线段所在的无标记虚拟边界。训练时，通过少量标注图像可生成大量条带序列样本（平移条带位置并相应调整标签）。

实验中，在作者数据集和Caltech数据集（4个视频片段）上比较RNN、CNN（去除循环层）和SVM（在独立小块上训练）的ROC曲线。RNN的AUC在作者数据集上为0.99，在Caltech上为0.93–0.99，CNN为0.83–0.97，SVM仅为0.64–0.90。SVM性能大幅下降的原因是正样本中包含虚拟边界（无可见线索），独立小补丁分类器无法利用上下文。可视化结果（图14）也显示RNN能更完整地捕捉边界。

为验证RNN的规则学习能力，作者构造合成数据：每行25个小框，模式“–”开启正状态，直到“|”关闭。RNN在训练时使用25长的序列，测试时用50长无关闭符的序列，统计表明1–3个“–”能触发持续正预测，且跳过8个空格时出现一些误判，但总体泛化良好（AUC=1.00 vs CNN的0.80）。

## 实验、集成与结论

多任务CNN在合并场景中应用，三摄像头图像合成IPM图，检测车道标记并估计几何属性。CNN的检测区域较大，可采用主动搜索：检测到线段后，在预测位置±3像素内用强度凸起滤波器精化，并沿朝向移动，避免了密集滑动窗口。

在更高层面的车道建模中，将RNN作为基础检测器，与SVM、CNN对比。采用RANSAC拟合直线或二次曲线（2或3个控制点），建模误差为目标像素到最近模型曲线的平均距离。图19显示RNN作为基础检测器的误差分布更窄，优于CNN和SVM，且增加RANSAC迭代次数（50→200）可降低误差。

结论指出：多任务CNN通过共享底层特征同时完成检测和几何估计；RNN利用内部记忆自动捕获结构信息，无需显式模型，并能与更高层建模集成。该框架可推广到其他视觉感知任务，不限于车道检测。
