# 微生物形成稳定土壤碳：地下输入比地上输入更高效

*N. Sokol, M. Bradford · Nature Geoscience · 2018 · DOI: 10.1038/s41561-018-0258-6*

## 研究问题与三条候选机制

地上与地下植物碳输入对稳定土壤有机碳（SOC）库的相对贡献长期存在争论，直接影响碳循环的建模与管理。地下根际途径（即碳从活根输出）在理论上被认为比地上途径更高效地形成稳定土壤碳，但相关机制很少被实证检验或定量。作者用标准化碳输入的土壤微宇宙，针对溶解性有机碳（DOC）经微生物生物量到矿物稳定态 SOC 库这一“DOC–微生物路线”，检验三条被提出的机制：（1）物理迁移距离；（2）碳化合物进入区域的微生物丰度（根际 vs 主体土壤）；（3）碳输入的频率与体积（不频繁的“脉冲” vs 频繁的“滴注”）。

作者指出，历史上地上结构性残体被视为土壤碳的主要来源和 SOC 积累速率的主要控制因素，但近期研究日益认为地下碳输入的贡献被严重低估，根际沉积释放的不稳定 DOC（如根系分泌物）是慢循环 SOC（下称“稳定 SOC”）的重要前体和关键来源；同时，难降解的地上凋落物碳被视为相对低效的稳定 SOC 来源。多项研究报道地下输入对 SOC 的贡献可超过地上输入，甚至将地下途径视为稳定 SOC 的主导来源；但叶片凋落物淋溶 DOC 研究也表明地上来源可向土壤输送大量碳。地下途径之所以受支持，是因为其独特性——促进碳输入与矿质土壤直接、紧密接触——被认为赋予单位碳更高的稳定化效率。

作者进一步指出，这些机制虽具吸引力，但缺乏确凿的实证支持且未被很好量化，尤其是在控制碳质量与数量混杂作用的情况下。作者强调，通过 DOC–微生物路线稳定地上与地下输入，其机制解析至关重要，因为稳定 SOC 中可能有高达 50–80% 来自微生物。三条机制具体为：第一，地上 DOC（如凋落物淋溶物）必须经过更长、更迂回的路径到达矿质土壤，包括穿过有机层，DOC 可能在此被吸收或经微生物呼吸释放回大气（机制 1）；第二，地上淋溶 DOC 弥散分布于微生物丰度和活性相对较低的主体土壤，而地下根系 DOC 直接进入矿质土壤中空间受限、微生物密集的根际（机制 2），由于微生物残体是 DOC–微生物路线下 MASOC 库的主要碳源，根际更高的微生物丰度应提高碳输入被同化、合成代谢并转化为微生物产物、进而进入稳定 MASOC 库的机会；第三，地下根际 DOC 输入通常在整个生长季以连续、低体积的“滴注”进入，促进稳定的微生物合成代谢与周转，而地上 DOC 输入在降水事件中以不频繁的“脉冲”淋溶进入土壤剖面（机制 3），脉冲虽可短暂激发微生物生物量与活性，但暂时扩大的群落也可能共代谢掉大量新形成的 MASOC。

作者认为，若这些途径差异在时空上普遍适用，则将其纳入模型对准确刻画和预测陆地碳循环可能是必要的；已有观点认为地下碳输入的稳定化不能仅作为其数量与质量的函数来建模，而必须额外用系数表征其更高的稳定化效率。然而，多数传统土壤有机质模型虽包含区分植物材料质量的系数，却不建模区分地上与地下碳输入途径对稳定 SOC 形成效率的差异。此外，多数探讨地上与地下对稳定 SOC 库贡献的实验，通常使用不能将碳质量与数量作用同特定途径效应解耦的碳化合物或茎叶/根系生物标志物（如角质与软木脂）。因此，基于现有实证知识，地下 DOC 途径是否应被刻画为通往稳定 SOC 形成的更高效通道，以及若如此其具体机制特征为何，仍是悬而未决且紧迫的问题。

## 微宇宙实验设计与 DOC 进入模拟

为专门针对地下与地上途径效应，作者使用土壤微宇宙，重建了有机层、矿质层、主体土壤区域和根际，并围绕一根微孔塑料“根”（Fig. 1b；Supplementary Fig. 1）。作者检验了三条机制在 DOC–微生物路线到矿物稳定化中的具体作用（Fig. 1a）。尽管地下根系 DOC 通常以频繁滴注经根际沉积进入根际，地上 DOC 凋落物淋溶物通常经降水事件以脉冲进入主体土壤，作者仍采用完全交叉实验设计以辨别三条机制间的交互作用。因此，作者设置了八种位置 × 频率组合（四种位置、两种频率），插入相同质量与质量的 DOC：（1）地上与地下；（2）近根际与远根际；（3）滴注与脉冲。实验期间，每个处理将含固定量 ¹³C 标记葡萄糖（99 atom% ¹³C）的溶液插入八种位置 × 频率组合之一（见 Fig. 1b 处理 1–8），同时将未标记葡萄糖插入其余七个位置，确保所有微宇宙经历完全相同的条件。作者选择葡萄糖作为模型 DOC 化合物，因为单体碳水化合物是地下根系分泌物和地上凋落物淋溶物的常见组分，且通常被土壤微生物快速高效地合成代谢。

作者成功在塑料根周围生成了人工根际环境（下称“根际”）。根际总微生物生物量（¹²C+¹³C）浓度平均比主体土壤高约 25%，处于野外观测值范围内（Supplementary Table 3）。设计模拟了高淋溶温带森林生态系统在生长季前几个月（十周实验期）的情境，此时根系分泌与凋落物淋溶通量（经降水事件）均高。DOC–微生物路线的 SOC 形成主要发生在这些短时间尺度上。

作者追踪了 ¹³C-葡萄糖在多个土壤碳库中的回收，包括 MASOC、颗粒有机碳、微生物生物量碳（MBC）和土壤溶液中残留的 DOC。作者主要关注 MASOC 的形成，因为该库包含被认为周转时间最长（数百年至数千年）的稳定 SOC 子集。“稳定 ¹³C-MASOC”通过将物理分级分离得到的 MASOC 库（总 ¹³C-MASOC）暴露于化学稳定化测定（将 <53 μm 组分与 6 M 盐酸回流）来鉴定。作者选择这一两步方法，是因为（1）DOC–微生物路线主要与有机-矿物组分相关；（2）有机-矿物吸附的化学稳定性是其土壤持久性的重要决定因素，且通常与其他稳定性指标（如长期培养“生物稳定化”测定）相关。

## 进入途径、进入区域与进入频率

**进入途径。** 直接进入矿质土壤的地下途径是通往稳定 ¹³C-MASOC 库更高效的通道。跨处理看，约 9% 的地下 ¹³C-葡萄糖输入转化为稳定 ¹³C-MASOC，而地上输入约为 5%（Supplementary Table 2）。这一近两倍差异部分归因于地下输入绕过了有机层（Supplementary Fig. 2）：地上葡萄糖供应保留在有机层中的比例远高于地下输入（约 36 倍），减少了最终到达矿质层的地上碳量（机制 1）。

一旦葡萄糖进入矿质土壤——无论作为地上还是地下输入——其矿物稳定化的关键决定因素是土壤微生物生物量同化与转化的比例。为检验葡萄糖与矿质表面直接相互作用的强度，作者对灭菌的过筛矿质土壤样品进行了吸附测定：土壤样品与 ¹³C-葡萄糖溶液振荡 24 h，其每克干土加入的 ¹³C-葡萄糖浓度与每个微宇宙根际加入的相同；随后将分离的 MASOC 组分暴露于上述化学稳定化测定，发现在无微生物群落时，仅约 0.3% 加入的 ¹³C-葡萄糖回收为稳定 ¹³C-MASOC（Supplementary Table 2），与先前显示葡萄糖与矿物相反应性低的研究一致。相反，当存在微生物群落时，约 3–13% 加入的 ¹³C-葡萄糖回收为稳定 ¹³C-MASOC（Fig. 2a；Supplementary Table 2）。而且该范围内的值与微生物群落合成代谢的 ¹³C-葡萄糖总量正相关：考虑整个微宇宙的 ¹³C 收支，MBC 库中回收的 ¹³C 总量与稳定 MASOC 库中的 ¹³C 总量之间存在强线性关系（Fig. 2b；决定系数 r²=0.70）。这些观察共同确认，微生物对 ¹³C-葡萄糖的摄取与转化是其高效矿物稳定化的重要前体。

总体而言，主体土壤稳定的 ¹³C-葡萄糖比根际多 170%（Fig. 2a），尽管根际土壤每克土壤形成的稳定 ¹³C-MASOC 浓度显著更高（Fig. 3a）。由于相同量的 ¹³C-葡萄糖被插入主体与根际区域，而两者土壤质量相差一个数量级（根际与主体土壤之比=1/10），根际中稳定的 ¹³C-葡萄糖总量较低，表明每克土壤加入的 ¹³C-葡萄糖量超过了根际在实验期内的稳定化潜力。这种超出根际稳定化容量的现象，与作者观察到的 MBC 库中回收的 ¹³C 总量与稳定 ¹³C-MASOC 库中每克土壤 ¹³C 量之间的饱和关系一致（Fig. 3b；r²=0.63）。这种饱和效应可能是土壤可利用矿质表面存在最大有机碳负载速率（“碳饱和”）和/或活性微生物群落代谢 incoming 碳底物的能力有限的证据。无论如何，这一观察指向 DOC 以低浓度输入进入主体土壤区域的一个潜在好处：DOC 在主体矿质土壤中更广泛分布，可能有助于避免在空间更受限的根际土壤中遇到的潜在最大稳定化速率。

**进入区域。** 尽管根际总体上形成的稳定 MASOC 少于主体土壤，但作者发现每克根际土壤形成的 ¹³C-MASOC 中约 59% 是稳定的，而每克主体土壤仅约 50%（Fig. 3a；Supplementary Table 4）。这一稳定 ¹³C-MASOC 比例的差异表明，根际微生物群落可能比主体土壤群落更高效地形成稳定 ¹³C-MASOC。具体而言，作者发现根际中每单位 ¹³C-MBC 形成的稳定 ¹³C-MASOC 量比主体土壤高 83%。因此，假设所测 ¹³C 库能代表 ¹³C-葡萄糖经微生物生物量流入稳定 ¹³C-MASOC 库的过程，这表明一旦葡萄糖被合成代谢，根际群落可能更高效地从合成代谢碳形成稳定 MASOC（机制 2）。作者承认，其设计无法将碳浓度效应与群落效应解耦：每克根际土壤接受的葡萄糖是每克主体土壤的 10 倍，且含有 1.25 倍的微生物生物量。为分离这些潜在的群落与浓度效应，作者进行了后续测定（见下文“底物浓度 vs. 微生物群落效应”）。

**进入频率。** 在微宇宙土壤中，当根际输入以频繁、低体积滴注进入时，每克土壤总 ¹³C-MASOC 中稳定的百分比最高（双向交互，P=0.02；Supplementary Table 8）。尽管脉冲根际输入比根际滴注输入刺激了更高的每克土壤 ¹³C 微生物合成代谢（Supplementary Fig. 3），并伴随每克土壤更多 ¹³C-MASOC 的形成，但形成的 ¹³C-MASOC 中稳定的比例更小（Fig. 3a,b）。具体而言，作者发现每克土壤 ¹³C-MBC 与每克土壤稳定 ¹³C-MASOC 之间的正关系是非线性的。在 ¹³C-MBC 值较高端（>70 μg ¹³C-MBC/g 土壤）——代表脉冲根际输入——每克土壤更高的 ¹³C-葡萄糖微生物合成代谢并未产生与较低 ¹³C-MBC 值时相同的每克土壤稳定 ¹³C-MASOC 增益。也就是说，当地下根际碳进入以滴注而非脉冲发生时，每单位 ¹³C-MBC 的稳定 ¹³C-MASOC 形成最高（Fig. 3b）。先前研究表明，与不频繁脉冲葡萄糖输入相比，频繁低体积葡萄糖输入促进更稳定的微生物生物量同化与周转以及更低的呼吸（机制 3）。作者的结果提示类似动态：频繁的地下根际输入可能促进被同化的 ¹³C-葡萄糖更连续地流入稳定 MASOC 库。

## 底物浓度 vs. 微生物群落效应，及对碳循环的意义

作者试图模拟根际与主体土壤 DOC 输入的代表性浓度，因此无法将碳浓度（每单位土壤）的潜在效应与结果至少部分源于根际与主体微生物群落差异效率的可能性解耦。为此，作者进行了后续测定，检验在所有其他条件（如碳输入浓度）相等时，根际与主体群落是否差异性地稳定葡萄糖。该测定从采集矿质土壤的同一地点分离根际与主体微生物群落（下称“野外分离群落”，以区别于上述主微宇宙实验）。作者分别将每种微生物接种物加入灭菌的人工土壤微宇宙（黏土+石英砂），其背景碳极低（经次氯酸钠反复洗涤去除，调至 8 M）。该土壤处理用于确保微生物群落主要消耗 ¹³C-葡萄糖，限制因土壤有机质中其他化合物引起的潜在底物身份效应。

为确定 ¹³C-MBC 与 ¹³C-MASOC 的关系，作者通过使用四种不同体积的起始接种物（每种三次重复，每个群落 n=12）在野外分离的根际与主体土壤微生物群落密度中生成范围。两种野外分离微生物群落在微宇宙间显示出相似的 ¹³C-MBC 量范围（Fig. 4）。然而，作者发现——与主研究结果一致——根际群落每单位 ¹³C-MBC 形成的稳定 ¹³C-MASOC 比主体群落多约 121%（Supplementary Table 9）。此外，根际群落表现出 ¹³C-MBC 与稳定 ¹³C-MASOC 之间的强正关系（Fig. 4a 左图），而主体群落则无明显关系（Fig. 4a 右图）。当作者将 ¹³C-MBC 对活性微生物生物量（通过底物诱导呼吸测定）回归时，观察到类似关系，表明每单位 ¹³C-MBC 增加，根际群落比主体群落表现出显著更大的微生物活性增加（Fig. 4b）。这些发现提示，未来关于根际对稳定 SOC 形成重要性的研究，应考虑微生物群落间差异可能作为驱动地上与地下途径效率的额外机制。

**对碳循环的意义。** 通过聚焦于 DOC–微生物路线到矿物稳定化中提出的机制，作者展示了若干增强地下根际 DOC 途径通往稳定 MASOC 库效率的特征（Table 1）。总体而言，地下进入比地上进入效率高 190%，归因于直接进入矿质土壤（机制 1）。进入根际导致每克土壤稳定的碳比进入主体土壤多 340%，归因于根际群落更高的效率与活性（机制 2），尽管由于根际观察到的饱和稳定化速率，主体土壤总体上稳定了更多碳。最后，在根际中，当地下输入以频繁滴注而非不频繁脉冲进入时，形成的稳定 MASOC 比例最高（机制 3；回归系数= -10.8，双向交互 P=0.02，Supplementary Table 8）。

然而值得注意的是，在整个微宇宙的 ¹³C 收支中，当 ¹³C-葡萄糖以地上脉冲进入主体土壤（如凋落物淋溶物）时，矿物稳定的 ¹³C 总量多于以地下滴注进入根际（如根系分泌物），这是由于根际的空间限制（Table 1）。地上与地下 DOC 的定量重要性由微宇宙中根际与主体土壤之比（1/10）决定，因为主体土壤更大的总土壤体积促进了更大的总矿物稳定化。为广泛说明根际与主体之比如何影响各输入途径的重要性以及稳定的 ¹³C 总量，作者使用主实验测得的根际与主体 ¹³C 浓度，在一系列代表性根际与主体之比上生成粗略投影。作者显示，当根际与主体之比收窄（如至 1/4，如草地矿质土壤上层），“根系分泌物”模拟途径对稳定 SOC 库的碳贡献比“凋落物淋溶物”模拟途径多约 20%，且稳定的碳总量相对于实测 1/10 比增加约 25%。然而，当根际与主体之比变宽（如至 1/25，如某些森林生态系统），地上输入的相对重要性增加，但形成的稳定 MASOC 总量相对于实测 1/10 比减少约 15%（Fig. 5）。

作者指出，越来越多呼吁将地上与地下植物碳输入的差异稳定化更好地纳入模拟模型，尤其是经微生物形成途径稳定的 DOC 输入。本研究试图识别据称构成地下根际 DOC 途径通往稳定 MASOC 库效率基础的特定机制，独立于碳质量与数量。研究显示，地上与地下碳输入途径的多个特定特征可能影响稳定 MASOC 的形成速率，包括主体与根际土壤微生物群落组成的潜在差异。重要的是，由于研究在实验室微宇宙中进行以精确针对所提出的机制，这种设计简化了自然土壤系统的关键方面。因此，关键下一步是在纳入可能影响野外稳定 MASOC 形成的众多因素的研究中，辨别所检验途径特征的相对重要性。例如，碳化合物身份、菌根状态、微生物群落结构、土壤养分有效性、土壤深度和不同时间尺度都可能塑造稳定 MASOC 库的形成、大小与持久性。作者认为，若要在变化环境中准确理解与预测陆地碳循环过程，考虑最终控制 SOC 储量的广泛因素的工作似乎至关重要。

**方法**
**土壤采样与微宇宙设计。** 矿质土壤与有机层材料采自康涅狄格州南部温带混交硬木林（41°19′57.6″N 72°54′36.9″W），优势树种包括 Acer spp.、Carya spp.、Liriodendron tulipifera 和 Quercus spp.。土壤为 Inceptisols，主要属 Holyoke 系列，分类为 loamy, mesic Lithic Dystrudepts。矿质土壤采自 A 层顶部 15 cm 并过 2 mm 筛（clay=13.0% sand=63.8% silt=23.2% pH=5.7, C=4.1% N=0.2%）。有机层材料采自凋落物层正下方，过 4 mm 筛，然后在 53 μm 筛上用去离子水反复冲洗去除矿物，室温风干。所有土壤材料储存于 4°C 直至使用。

矩形丙烯酸土壤微宇宙仿照 Keiluweit 等设计，高 20 cm、宽 25 cm、深 1 cm（见 Supplementary Fig. 1）。人工根（Micro Rhizon Sampler，长=10 cm，直径=2.5 mm，Soilmoisture Equipment）置于每个微宇宙中心，矿质土壤按野外容重（0.92 g cm⁻³）填充至 12 cm 深（略长于根的微孔段）。有机层材料以 0.25 g cm⁻³ 密度填充于矿质层之上至 5 cm 深（矿质+有机总深=17 cm）。填充后，微宇宙在 20°C 黑暗预培养一周，期间通过注射泵将无机营养液（330 μM KCl、70 μM KH₂PO₄ 和 70 μM MgSO₄）每日插入人工根（0.5 mL/天）。整个实验中，加入的葡萄糖溶解于同一营养液。

根际土壤定义为距根半径 8 mm 的区域（总计 21 干克当量）。尽管指定根际区域略大于经典定义（约 2 mm），但完全在根系分泌物可从根扩散的观测距离范围内，选择该区域是为获得足够土壤样品进行所有必需测定。主体土壤定义为微宇宙中剩余矿质土壤（总计 210 干克当量）。总体根际与主体土壤质量比为 1/10。

重要的是，尽管人工根际接受不稳定糖输入和营养液（类似真实根际），但缺乏野外根际常见的若干关键组分（即从根输出的全套碳化合物、根边缘细胞、根黏液、菌根及其他组分）。作者选择该实验室微宇宙系统以专门针对 DOC–微生物路线到矿物稳定化，而非其他 SOC 稳定化形式如团聚体形成或化学难降解颗粒有机碳，后两者与比矿物稳定化更短的周转时间相关。虽然实验设计可能排除了菌根真菌、腐生真菌和高分子量根碳输入，但证据表明这些元素主要参与其他共存的 SOC 稳定化形式（如菌根真菌和其他土壤真菌贡献化学难降解残体并在团聚体形成中起关键作用，根毛和根黏液等根输入亦然）。相反，DOC–微生物路线到矿物稳定化主要由低分子量碳输入供给，这些输入被表面相关土壤微生物合成代谢，且一些证据表明这些矿物表面相关微生物（及其对矿物稳定 SOC 库的 necromass 贡献）主要是细菌。因此，尽管实验室设计中土壤系统要素被简化，该方法旨在模拟温带森林生态系统中微生物形成矿物稳定 SOC 过程的主导要素，使作者能在无混杂因素下检验三条提出的更高效地下形成机制。

**碳添加。** 为检验三条影响稳定化效率的提出机制间的交互作用（所有八种处理见 Fig. 1b），每个处理将固定量（八周内 81.25 mg ¹³C）的 99 atom% ¹³C 标记葡萄糖（Cambridge Isotope Laboratories）加入八种可能处理组合（四种位置、两种频率；每处理 n=6；共 48 个微宇宙）中的单一位置 × 频率组合。另设六个仅含未标记葡萄糖的微宇宙，提供自然丰度 atom% 值以计算不同碳库中的 ¹³C 标记量。

四种位置的碳输送如下：（1）地上进入主体土壤：溶液经注射器沿有机层表面均匀分布，根际两侧各留 1 cm 缓冲带；（2）地上进入根际：溶液注射于人工根正旁边的有机层表面；（3）地下进入主体土壤：溶液经 6 英寸针头注射器输送，利用微宇宙玻璃上绘制的网格均匀分布于主体土壤所有区域（避免同一位置重复输送）；（4）地下进入根际土壤：溶液经注射泵通过人工根输送（允许碳持续输送到同一位置）。两种频率包括低体积频繁滴注（每天 0.5 mL 溶液，每周三次；共 24 次插入=12 mL）和高体积不频繁脉冲（每四周一次 6 mL 溶液；共 2 次插入=12 mL）。脉冲事件的水量基于美国东北部森林相对高体积降雨脉冲事件的降水，而根系分泌速率基于先前人工根系分泌物实验。作者确认根际碳输入向主体土壤的迁移极小，反之亦然（见下文及 Supplementary Table 6）。

为维持所有微宇宙相似条件，未标记葡萄糖被插入未被特定处理的七个位置 × 频率组合，使所有微宇宙在有机层、根际和主体土壤接受相同总量的葡萄糖碳。因此，处理间唯一差异是含 ¹³C 标记的位置 × 频率组合。对于 ¹³C-葡萄糖直接进入根际的处理（Fig. 1b 处理 3、4、5、6），碳添加速率平均为每天 0.5 mg ¹³C/周/干克土壤，代表根系分泌每日碳添加的中间范围。对于 ¹³C-葡萄糖直接进入主体土壤的处理（Fig. 1b 处理 1、2、7、8），碳添加速率平均为每天约 0.05 mg ¹³C/周/干克土壤，代表温带森林有机层 DOC 通量的较高范围。八周添加期内，整个微宇宙每干克矿质土壤共加入 2.81 mg 碳（¹³C-葡萄糖+¹²C-葡萄糖）。八周碳添加期后，微宇宙再培养一周，允许微生物对最后葡萄糖添加的同化与周转。

此外，对灭菌矿质土壤进行吸附测定，以确定无微生物群落时葡萄糖吸附到矿质土壤的程度。土壤通过 121°C 高压灭菌 30 min 灭菌；该程序执行两次，中间 24 h 培养期。灭菌土壤子样（5 干克当量）与 50 mL 溶液振荡 24 h，溶液含与八周期间加入根际相同浓度的 ¹³C-葡萄糖。

**SOC 分级与化学稳定化测定。** 微宇宙通过小心切取有机层、主体土壤和根际土壤收获。风干的根际与主体土壤子样（9 干克当量）与 30 mL 六偏磷酸钠溶液振荡 18 h 以分散团聚体，然后通过 53 μm 筛彻底冲洗，分离颗粒有机碳组分（>53 μm）和 MASOC 组分（<53 μm）。所有土壤组分（包括有机层材料子样）干燥至恒重，球磨并称重用于元素 C 和 N 百分比（Costech ESC 4010 Elemental Analyzer）及同位素 δ¹³C 分析（连续流同位素比质谱仪，精度 ±0.2%，Thermo Delta Plus Advantage；δ¹³C=[(¹³C/¹²C)sample/(¹³C/¹²C)standard]-1)×1,000‰。

随后将干燥 MASOC 组分的子集暴露于化学稳定化测定：0.5 g MASOC 与 25 mL 6 M HCl 在 100°C 回流 16 h。倒出酸可水解组分后，酸不可水解（矿物稳定）组分用去离子水冲洗四次，离心分离，干燥，随后测定元素 C 百分比和同位素 δ¹³C。作者选择该测定基于假设：¹³C-葡萄糖的更多微生物加工将导致 ¹³C-MASOC 中酸可水解比例更低。这基于酸可水解组分含更多化学不稳定材料（如糖，如葡萄糖），而酸不可水解组分含更多化学抗性化合物。虽然碳化合物的化学难降解性与其作为矿物稳定 SOC 的长期持久性不相关，但葡萄糖已知与固体矿物相的直接吸附弱，因此若未先转化为微生物残体（许多比葡萄糖本身更耐酸水解），易通过物理化学剥离淋溶下土壤剖面。因此，作者假设 ¹³C-MASOC 中更大的酸不可水解比例与 ¹³C-葡萄糖的更多微生物加工相关，因而相对于完整 ¹³C-葡萄糖也具有更长周转时间。

稳定 ¹³C-MASOC 组分的值随后与原始 ¹³C-MASOC 组分（总 ¹³C-MASOC）比较。该测定中因人为错误丢失六个样品，剩余土壤不足以重跑测定（地下-根际-滴注两个，地下-根际-脉冲一个，地上-根际-滴注三个）。使用标准同位素混合模型确定所有碳库的 ¹³C 值：C_label-derived = C_total × (atom%¹³C_after - atom%¹³C_control) / (atom%¹³C_glucose - atom%¹³C_control)，其中 C_total 是碳总量，atom%¹³C_after 是实验结束时碳库的 atom% 值，atom%¹³C_control 是未标记对照中碳的 atom% 值，atom%¹³C_glucose 是标记底物的 atom% 值。

作者以浓度（每干克根际或主体土壤）和整个微宇宙 ¹³C 收支两种方式呈现稳定 ¹³C-MASOC 形成、总 ¹³C-MASOC 形成及所有其他 ¹³C 库的结果。由于主要关注 ¹³C 形成，作者主要以 μg ¹³C 图形呈现结果。但也呈现整个微宇宙中每个碳库回收的 ¹³C-葡萄糖百分比（见 Supplementary Table 2）以及每克土壤回收百分比（见 Supplementary Tables 5 和 6）。图形上，整个微宇宙 ¹³C 收支的 μg ¹³C 和“回收 ¹³C-葡萄糖百分比”结果相同，但每干克根际与主体土壤的 ¹³C 浓度不同（因为进入根际的 ¹³C-葡萄糖浓度高于主体土壤）。

**微生物生物量。** MBC 和 DOC 通过改良氯仿熏蒸提取程序测定。熏蒸和未熏蒸（对照）土壤样品均在摇床上与 0.5 M K₂SO₄ 水平振荡 4 h。提取物的总有机碳在总有机碳分析仪（Shimadzu）上测量，提取物的 δ¹³C 在 Thermo GasBench 耦合 Thermo Delta Plus XP 同位素比质谱仪（Thermo Fischer Scientific）上测量。作者计算 ¹³C-MBC 为熏蒸与未熏蒸样品间 ¹³C 的差异，然后除以校正因子 0.45 将提取碳转换为生物量碳。总 MBC 计算为熏蒸与未熏蒸样品间总 C 的差异，除以相同校正因子。主微宇宙实验和涉及野外分离根际与主体土壤群落的额外测定均使用相同校正因子。

**野外分离根际 vs. 主体微生物群落测定。** 野外分离根际与主体土壤微生物接种物采自上述同一位点。根际土壤通过轻轻摇动采样区树木根系分离；摇动后仍附着于根的土壤小心取下，指定为野外分离根际微生物群落。主体土壤微生物群落（非根际土壤）从同一采样区未与活根关联的土壤分离（定义为野外分离主体微生物群落）。

为制备微生物接种物，将土壤子样与 Milli-Q 水涡旋（1/50 质量(g)/体积(mL)浓度）为根际和主体微生物群落制备土壤浆液。为生成不同大小的微生物群落，每个处理加入的接种物量每级增加五倍：10 μL、50 μL、250 μL 和 1,250 μL 起始接种物（值基于 Kallenbach 等）。每个微生物群落总重复 n=12（每个起始接种物水平 n=3）。土壤+接种物用解剖针彻底混合，确保微生物群落均匀分布于矿质土壤。为匹配不同水平的微生物接种物并帮助限制实验期微生物生长，实验开始时加入不同量的全强度 Hoagland 溶液以提供以下 N 量：0.01 mg、0.05 mg、0.25 mg 和 1.25 mg（值基于 Kallenbach 等）。随后所有微宇宙重量水分标准化为 20%，使所有土壤处于 65% 持水量。三周实验期间，土壤维持 20°C 和 65% 持水量。

三周实验期间五次（第 1、5、9、13、17 天），将 99.9 atom% ¹³C 标记葡萄糖以约 0.05 mg ¹³C/周/干克土壤速率（与主微宇宙实验主体土壤相同）注射到每个微宇宙。用灭菌解剖针将 ¹³C-葡萄糖添加物与土壤彻底混合，确保 ¹³C-底物均匀分布。实验结束时收获土壤，通过上述相同技术测量 ¹³C-MBC 和稳定 ¹³C-MASOC。此外，通过改良底物诱导呼吸技术测量所有样品的活性微生物生物量：土壤子样与过量易降解碳底物（自溶酵母）混合；加入碳底物后，管在摇床上振荡 1 h，在 20°C 培养 4 h，用红外气体分析仪（Li-Cor Biosciences, Model 8100）测量 CO₂ 排放。

**统计分析。** 所有统计分析使用统计软件包 R 3.3.2 版（http://cran.r-project.org/）。线性回归模型使用因子“进入途径”（地上 vs. 地下进入）、“进入区域”（根际 vs. 主体土壤）、“进入频率”（频繁滴注 vs. 不频繁脉冲）及其交互作用拟合。非显著交互项（P>0.05）从模型中剔除。首先，模型针对与整个微宇宙碳收支相关的所有响应变量拟合（如每微宇宙 ¹³C-MASOC；见 Supplementary Table 7）。其次，模型针对相同响应变量但涉及单克根际或主体土壤中碳库浓度拟合（如每克土壤 ¹³C-MASOC；见 Supplementary Table 8）。检查残差的正态性和方差齐性。对于保留因子，认为 P<0.05 显著，P<0.10 边际显著。
