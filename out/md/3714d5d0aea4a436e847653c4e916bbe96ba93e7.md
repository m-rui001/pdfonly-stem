# 洪水预测中的机器学习模型：文献综述

> Flood Prediction Using Machine Learning Models: Literature Review (2018, doi: 10.3390/w10111536)

## 引言与背景

洪水是最具破坏性的自然灾害之一，其建模高度复杂。机器学习（ML）方法在过去二十年中凭借更好的性能和成本效益，显著推进了洪水预测系统的发展。本文旨在展示ML模型在洪水预测中的最新进展，并识别最适合不同预测任务的模型。作者特别关注那些对ML模型进行了鲁棒性、准确性、有效性和速度定性比较的文献。结果表明，混合化、数据分解、算法集成和模型优化是改进ML方法最有效的策略。

传统上，物理模型和统计模型（如ARMA、MLR、ARIMA等）被用于洪水预测，但存在计算强度大、短期预测能力不足等问题。ML模型仅基于历史数据即可数值化洪水的非线性，且开发快速、所需输入少。然而，ML模型的性能依赖于训练数据的质量与覆盖范围，存在“泛化问题”，不同算法在短期与长期预测上的表现可能差异显著。本文以预测提前期（lead time）为核心，将任务分为短期（提前期大于一周视为长期）与长期预测，并将ML方法分为单一方法和混合方法进行综述。

## 检索方法与ML方法概述

作者通过系统检索，使用25个洪水资源变量关键词、25个ML算法关键词和4个预测术语，共获得6596篇文章，经质量筛选（SNIP、CiteScore、SJR、h-index）最终纳入180篇原创研究。预测模型通常基于雨量计、雷达或卫星等来源的降雨和水位数据，数据分为训练、验证和测试集。主要ML算法包括人工神经网络（ANN）、多层感知器（MLP）、自适应神经模糊推理系统（ANFIS）、小波神经网络（WNN）、支持向量机（SVM/SVR）和决策树（DT）及其集成形式。ANN是最流行的方法，但存在泛化问题；MLP是ANN的先进形式；ANFIS结合神经网络和模糊逻辑，具有高学习能力；WNN结合小波变换，能改善时间序列分解；SVM基于结构风险最小化，适合非线性回归；决策树（如CART、随机森林）快速且适合集成。集成预测系统（EPS）通过组合多个模型提高准确性和降低不确定性。

## 短期预测：方法与实证结果

短期预测对于城市区域及时预警至关重要。在单一方法中，多项研究比较了ANN与统计或物理模型，例如Danso-Amoako等获得R²=0.70；Panda等发现FFANN优于ANN和MIKE 11；Ghose用BPNN预测日径流效率达96.4%，R²=0.94；NARX网络在短期提前期上优于BPNN（平均R²=0.7）；ELM与SVM精度相似但更快；SVM在极端降雨预测中优于ANN；SVR在区域洪水频率分析中优于ANN；DT中ADT模型表现最佳。表2给出了各单一方法的复杂度、易用性、速度、精度和输入数据类型的定性比较。

在混合方法中，ANFIS在实时山洪预测中显著优于ANN（Jimeno-Sáez等）；ANFIS在水位预测中1–3小时提前期表现优秀；CART在沉积物模拟中优于ANFIS、SVM和MLP（Choubin等）；SVM-FR集成模型在敏感性评估中成功率高；HEC-HMS-SVR和HEC-HMS-ANN在台风降雨径流预测中表现良好，其中SVR泛化能力更佳；WNN在日降雨预测中R²=0.9；WBANN结合小波和bootstrap提高了预测精度；RSVRCPSO（RNN+SVR+CPSO）在降雨预测中优于SVRCPSO；EPS（集成MLP、SVM、RF）降低了不确定性。整体上，对于超过2小时的提前期，混合模型（ANFIS、WNN）优于单一模型。ANFIS的平均相关系数高于0.80，适合1–3小时提前期；WNN在日预测中优于MLP和ANN；分解技术（DWT、自回归、季节算法）能显著提高长提前期预测的准确性。

在比较分析中，作者给出了评价指标：相关系数（CC）和均方根误差（RMSE）定义如下：

CC = q(∑(xi−x)(yi−y) / √[∑(xi−x)²][∑(yi−y)²])   (1)

RMSE = √[∑(Xobs,i−Xmodel,i)² / n]   (2)

其中xi、yi分别为观测值和预测值，x、y为其均值。一般R²>0.8可接受，RMSE越低越好。作者强调，不同研究中RMSE单位可能不同，因此比较时做了归一化处理。

## 长期预测、比较分析与结论

长期预测（周、月、年）对水资源管理至关重要。单一方法中，ANN在数据不完整时仍能有效预测（Elsafi）；BPNN用于季风降雨预测（Singh）；SVM在径流预测中优于ANN和ARMA（Lin等）；RT用于森林洪水预测。混合方法中，自回归ANN优于ARMA和ARIMA（Valipour等）；WNN在月径流预测中优于ANN；KSOFM-NNM在洪水流量预测中优于MLP和GRNNM；WNN-BB（块bootstrap）在长达一年的提前期预测中表现鲁棒；ANFIS在季节性降雨预测中优于ANN和物理模型；M-EMDSVM在长提前期径流预测中优于ANN和SVM；EEMD-ANN在月预测中显著提升精度；WLGP（小波线性遗传编程）月流量预测精度达0.87。图9和图10显示，长期预测中单一方法以ANN、SVM较好；混合方法中分解和集成方法表现更优。

比较分析表明，大多数分解算法（如WNN）的精度优于未分解的时间序列，但WNN对长提前期仍不理想。混合模型如WARM（WNN+自回归）可提升至一年。数据分解方法（小波、DWT、EMD等）极大提高了混合模型的稳定性与准确性。集成方法（EPS）提高了泛化能力并降低了不确定性。本文总结了四个主要改进趋势：新颖混合化、数据分解、集成方法和优化器算法。未来应关注空间洪水预测，但本文未涉及。

论文结论：目前ML洪水预测研究仍年轻，共回顾了6000多篇文章并识别出180篇比较研究。通过将模型按提前期和单一/混合分类，发现混合化、数据分解、集成和优化是改进预测质量的关键技术。
