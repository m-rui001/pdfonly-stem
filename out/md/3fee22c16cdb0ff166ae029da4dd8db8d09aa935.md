# 诱导锂超离子银辉石 Li_{6+x}P_{1-x}Ge_xS_5I 的高离子电导率及其全固态电池应用

英文原题：Inducing High Ionic Conductivity in the Lithium Superionic Argyrodites Li_{6+x}P_{1-x}Ge_xS_5I for All-Solid-State Batteries | 2018 | DOI: https://doi.org/10.1021/jacs.8b10282

本文通过异价取代（Ge^{4+} 取代 P^{5+}）系统调控银辉石型固态电解质 Li_{6+x}P_{1-x}Ge_xS_5I 的结构与离子输运，发现 Ge 取代可诱导 S^{2-}/I^- 位点无序，显著降低锂离子迁移活化能，使冷压态电导率达到 5.4 ± 0.8 mS cm^{-1}，烧结后达 18.4 ± 2.7 mS cm^{-1}，为目前报道最快的锂银辉石导体。该材料成功用于厚电极全固态电池，在 150 次循环中几乎无容量衰减，证明通过位点无序工程优化离子导体是有效的设计策略。

## 研究背景与结构基础

固态电池因采用固体电解质和锂金属负极而有望获得更高能量密度与安全性，但厚电极构型受限于固体电解质的低离子电导率。在多种锂硫代磷酸盐中，银辉石 Li_{6}PS_{5}X（X = Cl, Br, I）因结构多样备受关注。其晶体结构中，卤素离子构成面心立方晶格（Wyckoff 4a），PS_{4}^{3-} 四面体占据八面体位点（P 位于 4b），游离 S^{2-} 占据半数四面体空位（4d）。锂离子分布于 48h 和 24g 两个 Wyckoff 位点，围绕 S^{2-} 形成伪八面体笼。基于位点跳跃模型，存在三种不等价跳跃：48h–24g–48h 双跳、笼内 48h–48h 跳跃及笼间 48h–48h 跳跃，其中笼间跳跃是长程输运的速率决定步骤。此前研究表明，Cl 和 Br 银辉石具有明显的 S/X 位点无序，而 I 银辉石因 S^{2-} 与 I^- 尺寸失配而无无序，这与其高活化能和低电导率（1.3×10^{-6} S cm^{-1}）相关。受 Li_{6+x}P_{1-x}Si_xS_5Br 中异价取代成功的启发，本文选择晶胞更大的 I 银辉石体系，尝试将 Ge^{4+} 掺入 Li_{6}PS_{5}I，以诱导位点无序并改善输运。

## 实验方法

所有合成均在氩气气氛下进行，以 Li_{2}S、P_{2}S_{5}、GeS、S 和 LiI 为前驱体，按化学计量混合后在碳涂覆石英管内于 550 °C 反应两周。中子粉末衍射采用 FRM II 反应堆 SPODI 高分辨衍射仪，波长 λ = 1.54817(2) Å，样品装于薄壁钒罐中旋转测量；X 射线衍射使用 Cu Kα 辐射，2θ 范围 10°–90°。Rietveld 精修使用 TOPAS-Academic V6 软件，对 X 射线数据排除 10–26.5° 的低角区以消除 Kapton 膜背景干扰，精修参数包括尺度因子、背景、峰形、晶格参数、原子坐标、各向同性位移参数及阴离子占有率。电化学阻抗谱在 –20 至 60 °C 温度范围、7 MHz 至 100 mHz 频率下测量，样品为镀金冷压片。变温 ^{7}Li 核磁共振（77.8 MHz）采用静态模式，通过四极回波实验测量线宽变窄，并采用饱和恢复序列测量 T_{1} 弛豫时间。全固态电池采用 Li_{6.6}P_{0.4}Ge_{0.6}S_{5}I 电解质，NCM-622 正极（70:30 质量比与电解质混合，面载量 6.80 mAh cm^{-2}，厚约 160 μm）、LTO 负极（50:50 混合，容量 7.04 mAh cm^{-2}，厚约 340 μm），电解质隔层约 450 μm，在 30 kN 压力（~2650 bar）和 60 °C 下组装并测试，循环电流密度按正极理论容量 200 mAh g^{-1} 计算。

## 结果与讨论

**结构表征：Ge 溶解度与位点无序**
通过 X 射线和中子衍射对 Li_{6+x}P_{1-x}Ge_xS_5I（x = 0, 0.15, 0.25, 0.3, 0.6, 0.8, 0.9, 1.0）进行结构精修。所有样品均存在少量 LiI 或 Li_{4}GeS_{4} 等杂质相（约 1.6–3.4 wt.%），但不足以显著影响离子输运。晶格参数随 Ge 含量增加而增大，直至约 80 at.% 名义 Ge 时达到溶解度极限；Ge 在 4b 位点占有率在约 70 at.% 后不再增加，更高名义含量只会增加 Li_{4}GeS_{4} 杂质相。由于 Ge^{4+} 的离子半径（0.39 pm，应为 Å 量级但原文如此）大于 P^{5+}（0.19 pm），(P/Ge)S_{4} 四面体体积随 Ge 占据增大。值得注意的是，原本在 Li_{6}PS_{5}I 中不存在的 S^{2-}/I^- 位点无序在 Ge 含量约 20 at.% 时开始出现，并随 Ge 增加逐渐增大，在溶解度极限附近达到约 7%。无序的产生可能与晶胞膨胀或锂浓度增加有关。中子衍射数据进一步显示，额外锂离子优先占据 24g 位点，导致 48h–24g–48h 双跳距离增大（因库仑排斥增强），而笼间跳跃距离略微减小。同时，Li(48h)S_{3}I 多面体体积及 Li(24g)S_{3} 三角平面面积增大，意味着扩散瓶颈加宽，有利于锂离子迁移。

**离子输运：电导率与活化能的变化**
阻抗谱分析表明，随 Ge 和锂含量增加，总电导率提升超过三个数量级，最高达到 σ = 5.4 ± 0.8 mS cm^{-1}（冷压态，298 K），对应组成 Li_{6.6}P_{0.4}Ge_{0.6}S_{5}I。将冷压片在 823 K 烧结十分钟后，电导率进一步增至 18.4 ± 2.7 mS cm^{-1}，归因于颗粒接触改善。活化能随 Ge 取代先保持恒定，而后在 x_{R} ≈ 0.25 附近出现拐点，显著下降，这是电导率骤增的主要原因。核磁共振研究选取 x = 0, 0.25, 0.6 三个样品。对于未掺杂 Li_{6}PS_{5}I，线宽变窄分析给出活化能 0.49 eV，对应的跳跃频率外推至室温约 1×10^{6} s^{-1}；而 Ge 取代样品运动速率过快，超出该方法的敏感窗口。T_{1} 弛豫测量则扩展至纳秒尺度：x = 0 和 x = 0.6 的样品表现出对称的弛豫峰，活化能高低温一致；但 x = 0.25 样品显示两个不同斜率，表明存在两种类型的运动——低温活化能 E_{a,low} = 0.11 eV，较高温度下 E_{a,high} = 0.21 eV。结合银辉石中三种跳跃过程的理论，作者认为低温过程对应 48h–24g 双跳或笼内跳跃，高温过程对应笼间跳跃。对于 x = 0.6 样品，在可观测窗口内只有单一运动过程，活化能较低，与阻抗数据吻合。利用爱因斯坦-斯莫卢霍夫斯基和能斯特-爱因斯坦方程，根据跳跃频率和 Li-Li 距离估算扩散系数与电导率：Li_{6}PS_{5}I 估算值为 2.6×10^{-5} S cm^{-1}，与阻抗结果接近；Li_{6.25}P_{0.75}Ge_{0.25}S_{5}I 估算为 3.9 mS cm^{-1}，x = 0.6 样品估算为 7.5 mS cm^{-1}，均与阻抗测量值基本一致。这些结果支持活化能降低（尤其是速率限制的笼间跳跃）是高电导率的关键。

**结构-输运关联：无序与渗透阈值**
将活化能和 S^{2-}/I^- 位点无序随 Ge 含量的变化并列，可以观察到无序出现与活化能急剧下降之间存在明显相关性。理论上，银辉石中 S^{2-} 和 I^- 各自构成相互贯穿的面心立方晶格，随机分布时键渗透阈值预计在 12%。然而，锂离子围绕 S^{2-} 形成四个直接连接 I^- 位点的团簇，每个团簇通过三个 48h 位点面向 I^-，每个 S^{2-} 替换到 I^- 位点可打开三条低能笼间通道，因此随机分布下渗透阈值仅为约 4%。这一高多重性结构使得即便很小的无序程度也能实现长程渗流。作者指出，虽然无序度仅约 7%，但其对输运的显著影响正是源于这种几何特征。位点无序改变迁移离子的局域势能景观，从而大幅降低活化能。

**全固态电池厚电极验证**
鉴于烧结后的电导率值最高，但实际电池通常使用冷压电解质，因此采用冷压的 Li_{6.6}P_{0.4}Ge_{0.6}S_{5}I 构建厚电极全固态电池。正极（NCM-622/SE 70:30）厚度约 160 μm，负极（LTO/SE 50:50）约 340 μm，隔层约 450 μm。在 0.25 C、60 °C 下，首次充电容量 120.8 mAh g^{-1}，首次放电 88.8 mAh g^{-1}，随后在形成稳定界面后放电容量稳定在 99.3 mAh g^{-1}。未使用碳添加剂或界面修饰，电池在 0.25 C 下循环 50 次无容量衰减，并相继在 0.5 C 和 1 C 下各循环 50 次仍保持稳定，150 次循环后无明显衰减。60 °C 下电池总电阻低于 13 Ω cm^{2}（原文写作 13 Ω cm，疑为面积比电阻）。这一结果证明高电导率硫代磷酸盐电解质可在无有害界面反应的厚电极电池中实现稳定高性能。

## 结论

本文系统研究了 Li_{6+x}P_{1-x}Ge_xS_5I 中异价取代对结构与输运的影响。Ge^{4+} 取代 P^{5+} 不仅增大晶胞体积、拓宽锂离子扩散通道，更重要的是诱导了 S^{2-}/I^- 位点无序，而该无序在面心立方互穿晶格中仅需约 4% 即可达到渗透阈值。位点无序的出现与活化能急剧下降直接相关，使冷压电导率提升至 5.4 ± 0.8 mS cm^{-1}，烧结后达 18.4 ± 2.7 mS cm^{-1}。基于此快离子导体构建的厚电极全固态电池在 150 次循环中无容量衰减。该工作揭示位点无序可作为优化固态电解质离子输运的强有力策略，为设计更高性能全固态电池提供了新途径。
