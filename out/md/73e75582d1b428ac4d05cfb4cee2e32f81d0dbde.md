# 工业信息物理系统中基于模型的分布式控制与滤波综述

A Survey on Model-Based Distributed Control and Filtering for Industrial Cyber-Physical Systems · 2019 · https://doi.org/10.1109/tii.2019.2905295

本文围绕以微分动力学模型描述的工业信息物理系统（CPS），系统综述了分布式滤波与分布式控制的研究现状。核心主张是：由于工业CPS在地理空间部署与能量、通信资源上固有的限制，集中式方法难以满足其可靠性与可扩展性需求，因此分布式滤波与控制成为必要选择。文章重点梳理了传感器网络上的分布式滤波算法（尤其是Kalman类与非Kalman类结构）、移动机械臂的分布式协同控制、微电网基于下垂特性的分布式控制，以及考虑网络攻击时的分布式安全控制，并提出了若干未来研究挑战。

## 分布式滤波：从Kalman框架到非Kalman结构

传感器网络是工业CPS实现实时感知与监控的基础。分布式滤波算法通过通信拓扑在节点间交换必要数据，使各节点既能本地处理信息，又能通过一致性策略逼近全局性能。文章用一个线性时变模型设定滤波问题：`x_{k+1} = A_k x_k + w_k`，传感器`i`的测量为`y_{i,k} = C_{i,k} x_k + v_{i,k}`，其中`w_k`与`v_{i,k}`是零均值白高斯噪声，协方差分别为`Q > 0`与`R_i > 0`。在此框架下，局部Kalman滤波由预测、更新与增益计算构成，其中增益`K_{i,k} = P_{i,k}^- C_{i,k}^T (C_{i,k} P_{i,k}^- C_{i,k}^T + R_i)^{-1}`。文章将Kalman类分布式算法归纳为六种典型结构，逐一说明了其更新形式、通信需求与特性。第一种是Kalman一致性滤波（Algorithm 1），它在局部Kalman滤波后增加对信息矩阵`Ω_{i,k}`与信息向量`q_{i,k}`的L步一致性迭代，其优势在于即使局部传感器不可检测，在权重一致可检测假设下仍能保证估计一致有界；后续扩展包括无迹Kalman与容积Kalman框架（如变分贝叶斯一致性容积Kalman滤波，以及混合一致性容积Kalman滤波）。第二种是扩散Kalman滤波（Algorithm 2），其核心是用扩散策略替代一致性迭代，在测量更新后直接以邻居信息加权求和获得估计，因此避免了Kalman两次更新之间的一致性迭代，提高了新测量信息的融合效率；扩散权重可通过协方差交集方法优化，在时变拓扑满足一定连通性条件时能保证误差协方差有界。第三种（Algorithm 3）基于邻居估计的累积误差设计一致性项，滤波结构为`x̂_{i,k} = x̂_{i,k}^- + F_{i,k} A_k q_{i,k} + K_{i,k}(y_{i,k} - C_{i,k} x̂_{i,k}^-)`，其中`q_{i,k} = Σ_{j∈N_i}(x̂_{j,k-1} - x̂_{i,k-1})`；由于引入累积误差会导致滤波误差动力学耦合。第四种（Algorithm 4）仅通过邻居创新的加权和`q_{i,k} = Σ_{j∈N_i} α_{ij}(y_{j,k} - C_{j,k} x̂_{i,k}^-)`来实现一致性，借助梯度法同时设计两个增益，最小化滤波误差协方差上界的迹，该算法以牺牲一致性性能为代价获得高可扩展性与低计算、通信负担。第五种（Algorithm 5）允许对每个邻居采用独立的增益`K_k^{ij}`，如`x̂_{i,k} = x̂_{i,k}^- + Σ_{j∈N_i∪{i}} α_{ij} K_k^{ij}(y_{j,k} - C_{i,k} x̂_{i,k}^-)`，提供了更多设计自由度，但计算量相应增加且依赖全局误差协方差，因此可扩展性较差。第六种是“一致性+创新”滤波（Algorithm 6），通过伪观测`z_{i,k}`嵌入目标状态的线性变换`G_k x_k`，算法在时不变情形下只需全局可检测性与网络连通性即可收敛。文章从计算复杂度与通信负担两方面比较了这些算法：在状态维数为`n`时，矩阵求逆为`O(n^3)`，矩阵乘法为`O(nsm)`；Algorithm 1需要3次矩阵求逆、12次矩阵乘法并传输`Θ_i n(n+2)(L+1)`个数据，计算复杂度低但通信量较高；Algorithm 2需要`2Θ_i + 2`次求逆与`4Θ_i + 6`次乘法并传输`2Θ_i n`个数据，通信负担最低。文章将该六种算法在计算负担、通信负担与可扩展性三个维度上的表现汇总于TABLE I。

并行于Kalman类算法的发展，有限时域分布式滤波中对时变系统的研究也持续增长。非Kalman方法不依赖一致性或扩散策略，而是通过设计滤波器结构（增益充当融合权重）来实现邻居信息的分布式融合。文章归纳了四种典型滤波器结构：结构I为经典Luenberger观测器形式`x̂_{i,k+1} = A_k x̂_{i,k} + Σ_{j∈N_i∪{i}} α_{ij} K_{ij,k} γ_{j,k}`；结构II在结构I基础上同时引入邻居创新与一致性误差项，包含两组增益`K_{i,k}`与`L_{i,k}`；结构III为全耦合形式`x̂_{i,k+1} = Σ_{j∈N_i∪{i}} α_{ij}(K_{ij,k} x̂_{j,k} + L_{ij,k} y_{j,k})`，拥有最多的设计参数，适用于含未知时滞、不确定性与弱非线性的复杂对象；结构IV则仅用自身创新加邻居一致性误差`x̂_{i,k+1} = A_k x̂_{i,k} + K_{i,k} γ_{i,k} + L_{i,k} Σ_{j∈N_i} δ_{ij,k}`。这三种增益设计的主流方法为：后向递推Riccati差分方程（BRDE）、递归线性矩阵不等式（LMI）与集合成员方法。BRDE方法最早将有限时域H∞性能与标称H2代价结合并借助Moore-Penrose伪逆求解；递归LMI方法将有限时域H∞-一致性概念与滤波误差的有界一致性联系起来；集合成员方法则提供包含真值的可靠区间，适合硬约束工程问题。文章指出，这些方法在分析随机网络诱导现象时通常需要增广滤波误差，所得设计条件依赖全局拓扑信息，这极大限制了其在大规模传感器网络中的应用：在线执行时要求网络规模小且拓扑信息公开。在计算与通信负担方面，结构III计算复杂度最高，而结构II至IV都需要传输`2(Θ_i + 1)n`个数据，通信负担相同；TABLE III汇总了这些非Kalman结构的性能对比。在无穷时域扩展方面，分布式H∞滤波的研究包括：针对多项式非线性随机系统构造多项式Lyapunov函数并用参数相关LMI求解增益；针对Markovian随机切换拓扑，给出保证均方意义下与概率1意义下H∞水平的充分条件；也有研究考虑了事件触发通信、采样数据与时滞等场景。与有限时域相比，无穷时域滤波器参数可离线获得，可扩展性有所提升，但设计条件仍依赖增广误差动力学，时滞分析工具可在一定程度上降低保守性，不过会牺牲部分计算性能。文章还从Bayesian与粒子滤波视角回顾了分布式滤波：在概率视角下，分布式Kalman滤波可借助Bayesian解释研究局部后验PDF的合理形式及其与最优后验分布的关系；分布式粒子滤波按融合对象可分为计算粒子权重、计算后验参数与计算似然参数三类；在处理非线性/非高斯模型时，分布式粒子滤波通常优于标准Kalman滤波。

在分布式滤波之外，传感器网络的功率调度控制旨在通过MAC协议或传感器调度最小化能耗、延长生命周期。调度策略通常用一组确定性或随机二元变量表示传感器是否被调度，滤波误差协方差（FEC）的演化高度依赖这些变量。已有研究可归纳为四类：给定调度约束下的FEC优化、给定平均能量约束下的FEC优化、给定FEC约束下的能量优化，以及FEC与能量的联合优化。对于有限时域，最优策略的典型特征是将所有传输安排在时域的特定部分，或以尽可能均匀的方式限制传输次数；在无穷时域情形，通常采用平均FEC指标，可用贪心算法与凸优化方法求最优策略，且最优策略可被有限长度的周期调度近似逼近。涉及能量约束时，常用Markov决策过程揭示最优调度策略的结构，滤波稳定性的充要条件依赖于高能量数据包接收率或信道恢复率，但这类方法需要来自远端估计器的反馈信息。

在硬件平台方面，文章提到UC Berkeley设计的Mica平台采用Atmel Atmega处理器并运行TinyOS操作系统；在文献[73]中，Particle、µNode与Sindrion三个平台采用面向服务方法设计，前两者经英国BP石化工厂验证，分别集成PIC18f6720与MSP430微控制器；文献[74]在Tmote Sky传感器网络上实现了扩散Kalman滤波算法用于定位，权重离线优化以在稳态下获得较小估计误差协方差；另有工作在FPGA上执行顺序离散Kalman滤波，实现对主动配电网的实时状态估计。

## 分布式控制：从机械臂协同到分布式模型预测控制

分布式控制在工业CPS中广泛应用于机械臂系统与电网。移动机械臂系统因更高的自由度而成为提升工业自动化效率与灵活性的重要技术，其运动学与动力学可用Euler-Lagrange（EL）方程建模。对于冗余机械臂，逆运动学问题由于方程数少于决策变量数而具备额外设计自由度，可依据一定最优准则（如最小关节速度、最小跟踪误差）并考虑实际约束（如关节极限、避碰）构建带约束二次规划（CQP）问题：`min_{q̇} f(q̇, ṙ_d - q̇)`，约束为`q̇ ∈ Ω`与`g(J(q)) = 0`。根据Karush-Kuhn-Tucker条件，最优解可由递归神经网络求解。考虑邻居机械臂间的局部通信时，需要加入仅依赖邻居信息的辅助约束，例如文献[83]中基于抗噪零化神经网络的分布式方案可使位置误差指数收敛。另一种路径是利用神经网络或自适应神经网络逼近机械臂的非线性运动学函数（包括建模不确定性、输入死区、输出约束与力矩扰动），其核心思想是先用Lyapunov候选函数推导理想控制器，再用神经网络逼近未知部分，例如`Wσ(q, q̇) = C(q, q̇)q̇ + G(q)`（`W`为网络权重，`σ`为激活函数，`C(q, q̇)q̇`为向心与Coriolis力矩，`G(q)`为重力）。在分布式协同控制中，控制器需要嵌入同时依赖接收信息与通信拓扑的误差项以补偿偏离预定理想轨迹的漂移，并在零空间做分解以处理非完整与独立约束。此外，多个移动机械臂的协同控制可转化为多智能体系统（MAS）的一致性控制问题，每个智能体用工作空间模型`M̃_i(q_i)θ̈_i + C̃_i(q, q̇)θ̇_i + G̃(q_i) = B̃(q_i)τ_i`描述；近年事件触发一致性协议因节省通信与能量资源而备受关注。文章指出，线性多智能体系统的现有成果并不能有效解决网络化EL系统固有非线性带来的挑战，更不用说各种网络诱导现象与通信协议的影响。

分布式模型预测控制（DMPC）受益于在优化问题中显式处理约束的能力。文章按三种耦合情形组织论述。第一种是耦合约束情形：多个子系统动力学解耦但全局状态与控制受耦合约束，例如`Σ_{i=1}^m g_i(x_i, u_i) ≤ 1`。通过Lagrangian对偶，耦合约束对应的对偶变量可视为一致性变量，从而将DMPC转化为分布式一致性优化问题，可用分解方法、交替方向乘子法、对偶加速梯度法等求解。串行DMPC方案在某一时隙只优化一个子系统而保持其余不变，灵活性强但最优性不明确。概率耦合约束可表示为`P{Σ_{i=1}^m g_i(x_i, u_i) ≤ b} ≥ p`，允许约束违背概率低于预设阈值，随机管方法可在保证递归可行性与闭环稳定性的同时满足概率约束。第二种是耦合动力学情形：子系统间的相互影响被看作有界互扰，各子系统先向邻居发送未来参考轨迹并保证实际轨迹位于某个界内，再用标准MPC工具求解局部优化问题，由此发展出管式DMPC方法。已有方法的主要不足在于互扰有界性带来的保守性和局部优化导致的全局性能欠缺，改进方案包括共享契约集、在线重构终端集、切换代价函数，以及针对事件触发与多速率机制的变量补偿预测方案；为提升全局性能，也可用迭代协调算法以分布式方式求解集中式优化问题。第三种是耦合代价函数情形：子系统间的连接通过耦合代价函数`J_i = J(x_i, u_i, {x_j, u_j})`实现，通常需要预先给定解耦子系统的状态反馈控制律以存在约束允许不变集，该集合对闭环系统镇定与DMPC方案可行性有重要作用。

## 微电网分布式控制与安全控制

微电网是典型的工业CPS，其运行通常采用包含主控制与二次控制的分层控制架构。主控制通过下垂机制实现分散控制，目的是稳定微电网并在逆变器间实现比例负载分配，但会导致母线电压与频率偏离额定值，且在母线电压不等时产生无功分配不均。为克服这些缺陷，需要在分布式架构下设计二次控制来更新局部主控制的设定点。文章从四种建模与控制思路展开论述。第一种是基于d-q参考坐标系的大信号非线性模型与传统下垂特性的分布式控制。模型可写为`ẋ_i = f_i(x_i) + g_i(x_i)u_i + h_i(x_i)D_i`，输出为`y_{i1} = v_{odi}`与`y_{i2} = w_i = -d_{pi} P_i + u_{2,i}`。基于部分反馈线性化，可设计基于一致性误差的辅助控制器，例如电压控制的辅助控制器为`u_{i,aux} = -κ_i[Σ_{j∈N_i} α_{ij}(v_{odj} - v_{odi}) + p_i(v_{odi} - v_ref) + Σ_{j∈N_i} α_{ij}(d_{qj} Q_j - d_{qi} Q_i)]`，其中至少存在一个引脚增益`p_i > 0`；频率控制则在控制策略中嵌入有功功率分配调节误差`Σ_{j∈N_i} α_{ij}(d_{pj} P_j - d_{pi} P_i)`以保持主控制中实现的等成本增量。已有方案包括用迭代学习方法实现有功共享精度与电压/频率恢复的鲁棒二次控制、在稀疏通信网络与加性信道噪声下的改进控制器、有限时间内恢复电压幅值与频率的一致性控制器。文章指出，多数方法的控制器增益依赖Laplacian矩阵特征值（本质上是全局信息），而文献[119]设计的完全分布式自适应控制器仅利用DG单元动力学模型与邻居信息；引脚节点选择与引脚强度设计问题仍未有效解决。第二种是基于平均化概念的分布式控制，其常规控制器结构为`ω_i = ω* - d_{pi} P_i - u_i^ω`与`E_i = E* - d_{qi} Q_i - u_i^E`，对应的分布式二次控制为`κ_i^ω u̇_i^ω = -(ω_i - ω*) - Σ_{j∈N_i} α_{ij}(u_i^ω - u_j^ω)`与`κ_i^E u̇_i^E = -β_i(E_i - E*) - Σ_{j∈N_i} α_{ij}(Q_i/Q_i^* - Q_j/Q_j^*)`，其中扩散平均项用于维持有功共享，此类控制器称为分布式平均比例积分控制器。第三种是基于角度下垂特性的控制，模型为`d_{pi} θ̇_i = ΔP_i^* - Σ_{j=1}^N l_{ij} sin(θ_i - θ_j) - u_i`，其中`d_{pi} > 0`为下垂系数，`θ_i`为母线相角，`u_i`为二次控制输入，`l_{ij}`为逆变器间线路的纯虚导纳幅值，`ΔP_i^*`为逆变器额定注入设定点与母线负荷需求之间的功率失配。典型的分布式二次控制器为`κ u̇_i = d_{pi} θ̇_i - Σ_{j=1}^N α_{ij}(u_i/d_{pi} - u_j/d_{pj})`。当`θ_i ≃ θ_j`时该控制模型可简化为平均化形式。文献[131]推导了局部指数稳定平衡点存在唯一的充要条件，文献[130]在功率失配条件下保证了频率调节与最终有界性，文献[133]设计的简化分布式控制器对通信链路丢失和分布式能源故障具有鲁棒性。第四种是基于状态空间模型的方法，将每个控制区域看作单机单负荷系统，可写为`ẋ_i = A_{ii} x_i + Σ_{j≠i} A_{ij} x_j + B u_i + Γ_i n_{di}`，状态可选取为多区域电力系统的`x_i = [Δω_i, ΔP_{ti}, ΔP_{gi}, ΔP_{tie}^i]^T`（频率偏差、发电机机械功率、汽轮机阀门位置、联络线净功率流），或直流微电网的`x_i = [V_i, I_{ti}, φ_V, φ_I, φ_V^I, φ_I^I]^T`（负载电压、滤波电流、主控制动力学状态、二次电压控制器动力学状态）。分布式控制形式为`u_i = K_i x_i + Σ_{j≠i} K_{ij} x_j`或基于一致性控制的`u_i = K_i Σ_{j≠i} α_{ij}(x̂_j - x̂_i)`。该框架下的研究包括：针对通信时滞的时滞相关稳定性判据、时滞裕度与控制增益关系的分析、时变拓扑与时滞对闭环性能的影响、以及基于动态一致性算法的事件触发方案（用于电压调节与比例电流分配）。需要指出，文献[137]中自适应策略的设置需要全局GPS信号，相较文献[136]条件更严。

在安全控制方面，针对工业CPS的典型网络攻击包括拒绝服务（DoS）攻击、重放攻击与欺骗攻击等。文章回顾了防御者视角下利用攻击识别信息或必要的攻击信息（攻击强度或频率）增强安全性的研究。例如，结合广义累积和算法的Kalman滤波框架可实现快速攻击缓解与系统恢复，能识别结构化虚假数据注入攻击；基于梯度下降的递归算法可处理欺骗攻击下的分布式滤波问题；利用混合Bernoulli随机集描述攻击存在与否的联合信息的分布式滤波器已在电力网络广域监控中测试。在控制侧，攻击弹性协同控制方案包括通过识别与隔离异常网络元素来实现系统恢复、级联保护设计，以及在操作者-车辆网络中利用辅助滚动时域控制实现抗攻击的分布式弹性编队控制。此外，有研究用一致性概念估计DG利用率（通过虚拟电厂）和母线功率不平衡（通过原始-对偶分解）来分别实现弹性功率调节与抗数据完整性攻击的直流最优潮流。文章指出，现有安全研究几乎都假设系统动力学较简单，这导致理论结果与工程应用之间存在差距。

## 结论与开放性挑战

文章在结论部分明确了当前研究的共性局限与未来方向。已有成果大多依赖耦合矩阵的特征结构或对拓扑结构的特定假设，难以直接应用于存在带宽、能量或即插即用约束的实际系统；可行的思路是为随机变化拓扑寻找合适的连通性条件，或为一般切换拓扑建立驻留时间条件。具体挑战包括：在资源约束下，现有分布式滤波方案尚不能同时满足计算负担、通信负担与可扩展性要求，原因主要在于交叉协方差计算、增广方法以及一致性迭代；概率意义下的滤波性能指标更适合含随机现象的实际工程，但数学分析难度较大。在微电网领域，Q/V与P/f下垂控制适用于感性线路，Q/F与P/V形式适用于阻性线路，但面对复杂线路阻抗或P/Q调节不精确时，现有策略因P与Q方程耦合而难以保证可靠性能。多个引脚控制虽被视为分布式二次控制的有效方案，但引脚节点选择与引脚强度设计仍未有效解决，其数据稀疏性使间歇控制框架成为有意义的分析方向。在网络安全方面，攻击检测结果尚未有效用于改善控制或滤波性能，将攻击检测（如χ2检测器结合指示函数）集成到分布式滤波与控制策略中是值得研究的方向。最后，文章提及深化理论在实际工程中的应用（移动协同机械臂的近似动态控制、智能电网分布式能量管理、电力系统SCADA、冶金与石化工业过程控制等）。
