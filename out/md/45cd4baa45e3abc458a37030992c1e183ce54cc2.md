# 激光腔孤子微梳：无背景、高效率的可调谐微梳新方案

元数据：Laser cavity-soliton microcombs · 2019 · DOI: 10.1038/s41566-019-0379-5（原文链接给出）

本文在克尔微腔中实验演示了一种全新的时间腔孤子——激光腔孤子（laser cavity-soliton）。与常规由泵浦背景维持的Lugiato-Lefever孤子不同，激光腔孤子直接由增益介质供能，固有地无背景光，因此具有极高的能量效率。实验测得亮孤子光谱带宽超过50 nm，平均注入功率低于等效Lugiato-Lefever孤子阈值的6%，模式效率达75%（理论上限预测为96%），而Lugiato-Lefever亮孤子的理论极限仅为5%。此外，仅通过改变主腔长度即可将重复频率调谐超过1 MHz，无需任何主动反馈。这些结果将激光腔孤子的物理与多模系统特性相结合，为微梳的高效生成与控制提供了新范式。

## 背景与问题

微腔频率梳（'micro-combs'）已在光谱学、通信、微波光子学、频率合成、测距、量子源、计量学和天文梳等领域带来重要突破，其中时间腔孤子是核心机制。然而，常规微腔孤子基于Lugiato-Lefever方程描述，以连续波（CW）为背景，导致光谱中有一个主导模式占据大部分功率，亮孤子的模式效率理论上限仅5%，实际器件通常在1.6%至5%之间。此外，重复频率的调控需要复杂的高速探测、微波信号处理和快速腔致动，或采用脉冲泵浦、反向泵浦、耦合微腔外差等方法。激光腔孤子已在空间构型（如半导体激光器）中实现全光可重配置存储器等突破，近期也在时间和时空域被观察到。其本质区别在于能量直接取自增益介质，无需任何背景光，因此是最节能的腔孤子类。本文将这种能力引入微梳，通过将克尔微腔嵌入放大光纤环中，实现高效宽谱梳产生。

## 原理与模型

装置原理如图1a所示：非线性微腔（腔a）嵌入一个更长的放大光纤腔（腔b）内。光纤环中传播的脉冲受激光增益带宽限制，在微腔中通过克尔非线性展宽至超过增益带宽。模型上，工作基于多分量（'矢量'）激光平均场方程组，将微腔场与主腔'超模'场耦合。超模由一组等间隔的主腔模式构成，其相对间隔由微腔自由谱范围（FSR）F_a决定。第m阶超模共振频率f_m^(b)与微腔共振频率f_m^(a)的关系为：

$$f_m^{(b)} = f_m^{(a)} - (\Delta - q - m\,\delta) F_b, \tag{1}$$

其中F_b为主腔FSR，q为整数定义超模阶次，Δ为主腔频率偏移（归一化到F_b），δ为FSR失配（两腔不可公度时出现）。q=0的零阶超模与微腔共振光谱重叠最大，高阶超模耦合损耗更大。数值例子中，δ代表群速度失配，Δ代表载波频率偏移。矢量孤子方程中所有耦合场锁定到同一群速度v和载波频率偏移φ，因此第n个梳齿频率为：

$$f_n^{(S)} = f_n^{(a)} + (\phi - n\,v) F_b. \tag{2}$$

实验中使用的主腔FSR约77 MHz，微腔FSR约48.97 GHz。平均场模型的关键参数：归一化耦合系数κ = π ΔF_A T_b ≈ 2π（微腔线宽ΔF_A≈140 MHz，约为主腔FSR的两倍），归一化色散ζ_a=1.25×10⁻⁴、ζ_b=3.5×10⁻⁴（对应|β_a|≈-20 ps²/km，|β_b|≈60 ps²/km），增益带宽σ≈1.5×10⁻⁴（对应650 GHz滤波）。模型方程（归一化形式）为：

$$\partial_t a + \frac{i\zeta_a}{2}\partial_{xx} a + i|a|^2 a = -\kappa a + \sqrt{\kappa}\sum_{q=-N}^N b_q, \tag{3}$$

$$\partial_t b_q + \delta \partial_\tau b_q + \frac{i\zeta_b}{2}\partial_{xx} b_q - 2\pi i(\Delta - q)b_q = \sigma\partial_{xx} b_q + g b_q - \sum_{p=-N}^N b_p + \sqrt{\kappa}\,a, \tag{4}$$

其中a和b_q分别为微腔和放大腔的光场包络，t是归一化时间（以主腔往返T_b=12.5 ns为单位），x是空间坐标（|x|<1/2，以微腔往返长度归一化，对应T_a=20 ps）。κ、g、σ分别代表耦合、饱和增益和光谱滤波带宽。孤子解通过数值延拓找到（考虑11个超模，N=5），稳定性用线性扰动分析和传播（61个超模，N=30）验证。

## 实验结果与效率对比

实验在反常色散、保偏的Yb-Er共掺光纤腔中进行，包含延迟线、偏振光学元件、隔离器和10 nm可调带通滤波器（等效高斯线宽ΔF_F=650 GHz）。微腔为高折射率掺杂硅集成谐振器，FSR~48.97 GHz，线宽ΔF_A<140 MHz，Q值约1.3×10⁶，传输损耗60%。腔内光谱用激光扫描光谱仪测量（校准用6.95 MHz马赫-曾德尔和250 MHz参考梳），输出用自相关仪、光谱分析仪和射电探测表征。

图3给出了不同腔内功率下的激光腔孤子测量。光谱带宽可达50 nm，与具有相似色散特性的谐振器中观察到的腔孤子相当，且与理论（图3中红线）吻合良好。自相关显示多个非等距脉冲（如三脉冲态），这是局域态的特征。通过腔内扫描光谱测量（图3b,d,f）确认振荡模式相对于微腔共振中心红移约32–36 MHz，与理论预测一致（φ负值代表红移）。蓝移的小模式仅出现在中心共振，归因于孤子尾部的微扰。反馈实验中，提高增益导致光谱带宽增加（图3c,d），形状偏离sech形出现侧翼，与调制不稳定性定性一致。降低增益则谱宽变窄（图3e,f）。这些结果与理论模型精确匹配，并解释了先前观察到的Type I和Type II梳（非局域图案）为何不满足稳定孤子条件。

效率对比的核心在图4。激光腔孤子的输入峰值功率低于Lugiato-Lefever孤子阈值的50%，由于注入场为脉冲，平均功率更低于该值的6%。模式效率方面，理论计算激光腔孤子亮态的最大效率为96%，图3实验中测量的三个态效率均大于75%。而Lugiato-Lefever亮孤子理论极限为5%，暗孤子为50%，现有器件通常仅1.6%–5%。图4b-c直观显示：Lugiato-Lefever孤子有强CW背景导致中心梳齿主导，激光腔孤子无背景，每个梳齿功率密度更高。激光腔孤子存在于克尔双稳态阈值之下，仅需单CW态和零背景。

## 重复率控制与结论

通过延迟线改变主腔长度（调节δ），保持增益和损耗以维持孤子态，实验实现了重复频率的大范围调谐。图5中，三种腔长（调节范围约150 μm）对应两等距孤子/往返，腔内功率分别为20、25、30 mW。以Comb 1为参考，Comb 2和Comb 3的重复频率分别变化1.9 MHz和3.2 MHz。理论计算（图5c）表明，在实验可达到的δ范围内，孤子稳定性保持而其速度v改变，从而改变重复频率。此外，这些局域态可通过手动调节光纤腔参数（长度、增益电流、偏振损耗）获得，与被动锁模激光器类似，因此可采用遗传算法等实现自适应控制和自启动。

结论：本文报道了微梳中时间激光腔孤子的观测。该机制将克尔微梳的大带宽能力与激光腔孤子的无背景、高效率和多模系统可调性结合，通过双腔配置实现对重复频率等关键性质的简单控制。这一新型微梳工作模式将为微梳走出实验室迈向实际应用铺平道路。
