# 评估大语言模型在表示几何与空间关系的文本描述方面的有效性

*OCR 原题：Evaluating the Effectiveness of Large Language Models in Representing Textual Descriptions of Geometry and Spatial Relations · 登记题名与正文冲突，登记 DOI 暂不归属*

本文评估大型语言模型（LLM）在编码几何对象及其空间关系方面的能力。作者用 GPT-2 和 BERT 对几何的 well-known text（WKT）格式进行编码，再将嵌入送入分类器或回归器，检验其在下游任务中的有效性。实验表明，LLM 生成的嵌入能保留几何类型并捕捉部分空间关系（准确率最高约 73%），但在数值估计和检索空间相关对象方面仍存在困难。

## 研究动机与问题

深度学习在地理科学中表现优异，但模型常依赖针对特定下游任务的手工特征，难以泛化。表示学习将学习过程分解为任务无关的数据表示与下游任务两步，因此有效的位置表示应保留距离、方向、空间关系等关键空间信息，便于分类器或其他预测器提取知识。在 GeoAI 研究中，地理空间数据虽格式规范、可被 GIS 软件直接理解，却并非都能直接接入深度学习模型。

ChatGPT 的成功使 LLM 受到广泛关注。LLM 在大规模文本语料上训练，已习得跨领域知识，代表性模型包括 BERT 和 GPT 系列。尽管网络架构不同，这些 LLM 在 NLP 基准上可达最优性能。研究者已开始探索将 LLM 引入 GIS 研究，如地理空间语义任务和自动化空间分析工作流，这些研究显示 LLM 能从语义角度理解与推理地理空间现象。但 GIS 中精确的几何与空间关系未必以自然语言表达，LLM 仅凭这些基本构件的文本描述重建物理世界存在困难，这正是本研究的动机。

在 GIScience 中，空间关系指空间对象间关于其几何属性的联系，在空间查询、推理和问答中作用重要。用自然语言描述空间关系对人类感知环境和导航至关重要。拓扑空间关系方面，RCC-8 和 DE-9IM 模型被广泛使用；基于 DE-9IM，已有研究为复杂几何命名了 crosses、disjoint、touches、overlaps、within 五个谓词，OGC 又补充了 equals、contains、intersects 以便计算。谓词也可用于描述主体与客体间的距离或方向，模糊逻辑可将精确度量转换为 near、far 等叙述性谓词。然而，日常语言中谓词的语境语义与上述形式化过程之间仍存在差距，导致理解上的分歧与模糊。LLM 能否充分捕捉人们用谓词描述空间对象的方式，以及如何利用这类知识用 LLM 表示地理空间语境，尚待确定。

## 方法

研究通过一组下游任务评估 LLM 表示几何及其空间关系的能力。工作流含三个主要模块：第一模块用 GIS 工具提取单个几何的属性（几何类型、质心、面积）及其空间关系（成对几何间的谓词与距离）；第二模块用 LLM 编码几何的 WKT 格式，例如 `LINESTRING (3010,1030,4040)`，其中包含几何类型与有序坐标，本研究不考虑地图投影；最后将 LLM 得到的嵌入与真值属性或空间关系一起送入分类器或回归器，评估基于 LLM 嵌入的有效性。

论文所用记号见表 1：$g$ 为可在 GIS 工具中处理的几何实例（如 Point、LineString、Polygon）；$WKT(g)$ 为 $g$ 的 WKT 格式；$Enc(g)$ 为用 LLM 编码 $WKT(g)$ 得到的位置编码；$Type(g)$ 为几何类型；$Centroid(g)$ 为质心；$Area(g)$ 为面积；$rel$ 为表示空间关系的谓词，取值为 {equals, disjoint, intersects, crosses, touches, contains, within, overlaps} 之一，由 OGC 定义并在 GeoPandas 中实现；$Rel(g_i,g_j)$ 为主体 $g_i$ 与客体 $g_j$ 间的空间关系；$Dist(g_i,g_j)$ 为两对象间的最小欧氏距离；$[Enc(g_i);Enc(g_j)]$ 为 $g_i$ 与 $g_j$ 嵌入的拼接；$Enc(rel,g)$ 为短语 rel+WKT(g) 的嵌入，例如 "within Polygon((00,01,11,10,00))"。

下游任务设计见表 2。任务 1–5 的目标直接：训练神经网络分类/回归模型以最佳逼近 GIS 工具计算的真值，均使用多层感知机（MLP）作为分类器或回归器。任务 6 考察能否由几何 $g_i$ 的邻居 $g_j$ 及其空间关系 $Rel(g_i, g_j)$ 预测 $g_i$，采用最近邻检索评估 LLM 是否恰当习得空间谓词含义：推理时给定对象 $g_j$ 和空间关系 rel，检索 $Enc(rel, g_j)$ 的 top-k 最近邻，检验它们是否属于主体集合 ${g_i|Rel(g_i, g_j)=rel}$，以此评估 LLM 通过空间谓词关联地理对象的能力。

具体任务为：T1 几何类型分类，输入 $Enc(g)$，目标 $Type(g)$；T2 面积计算回归，输入 $Enc(g)$，目标 $Area(g)$；T3 质心推导回归，输入 $Enc(g)$，目标 $Centroid(g)$；T4 空间谓词分类，输入 $[Enc(g_i);En(g_j)]$，目标 $Rel(g_i,g_j)$；T5 距离度量回归，输入 $[Enc(g_i);En(g_j)]$，目标 $Dist(g_i,g_j)$；T6 位置预测检索，输入 $Enc(rel,g_j)$，目标 ${g_i|Rel(g_i,g_j)=rel}$。

## 实验

由于没有现成基准数据集，作者在美国威斯康星州麦迪逊构建了真实多源地理空间数据集：用 OSMnx 下载 OpenStreetMap 路网数据（含 links 与 intersections），使用按 SLIPO 分类的兴趣点（POI），以及 Microsoft Building Footprints。评估聚焦 Point、LineString、Polygon 三种几何类型的空间对象及其空间关系。数据构建如下：1）每种几何类型随机选 4,000 个样本，Point 数据含 2,000 个道路交叉口和 2,000 个 POI，LineString 数据为 4,000 条道路 link，Polygon 数据为 4,000 个建筑轮廓，共 12,000 个样本用于下游任务，并计算每个多边形的面积与质心。2）对谓词 disjoint，随机生成几何对并检查其空间关系是否为 disjoint；对其他谓词，用空间连接识别空间相关对象。对每种主体/客体几何类型与空间谓词的组合，为谓词预测和距离度量任务各保留 400 个三元组（subject, predicate, object），并计算主体与客体间的最小距离。3）进一步为位置预测任务构建数据：除步骤 2 中空间连接的主客体外，还用 $0.003^{\circ}$ 的缓冲半径关联相邻的 disjoint 几何，将谓词 "disjoint" 替换为 "disjoint but near"；对除 disjoint 外的每个谓词，每种几何类型选 200 个与 5 个以上主体以同一谓词相关的对象。所有计算用 Python 的 GeoPandas 完成。本研究考虑 crosses、disjoint (but near)、touches、overlaps、within、equals、contains 等谓词，不考虑 intersects，因其与 disjoint 相反。下游任务数据按 80% 训练、5% 验证、15% 测试划分。

编码方面，基于 GPT-2 和 BERT 两个 LLM 执行评估任务。受计算与内存资源限制，GPT-2 和 BERT 的最大输入序列长度分别为 1024 和 512 tokens。由于 LineString 和 Polygon 的 WKT 可能超出长度限制，采用滑动窗口方法：将长输入序列切分为 512 tokens 的小段，相邻段重叠 256 tokens，每段分别由 LLM 处理，再对 token 嵌入取平均，生成整个几何序列的最终嵌入。

训练 MLP 时，作者假设 LLM 学到的嵌入可有效用于下游几何相关任务，故所有任务均使用简单神经网络架构（MLP）。输入层为 LLM 生成的嵌入层，随后是用于正则化的 dropout 层，接着是采用 ReLU 激活函数的单隐藏层，最后以输出线性层结束，输出层神经元数依具体任务而定。为便于训练，对面积计算和距离度量任务的目标值取对数；质心推导任务对目标值做 min-max 归一化。损失函数结合变换尺度与原始尺度上的均方误差（MSE），但报告性能时仅用目标值的原始尺度。

## 结果与结论

如表 3 所示，基于 GPT-2 和 BERT 嵌入的下游任务性能相近，这可由二者在子词分词和基于 transformer 架构上的相似性理解。T1 几何类型在验证集和测试集上均达 100% 准确率，符合预期，因为几何类型是文本中常出现的词。T2 面积计算中，所有几何的 MAPE 在 GPT-2 上验证/测试为 13124/11700，BERT 为 12251/10850；仅 Polygon 时 GPT-2 为 45.1/44.1，BERT 为 40.7/41.9。T3 质心推导 RMSE 在 GPT-2 上为 0.037/0.037，BERT 为 0.029/0.029。T4 空间谓词在不含几何类型时 GPT-2 准确率 62.6/65.7，BERT 为 63.8/68.7；含几何类型时 GPT-2 为 73.7/71.0，BERT 为 73.1/72.3。T5 距离度量仅 disjoint 时 RMSE 在 GPT-2 上为 0.064/0.063，BERT 为 0.057/0.075。T6 位置预测 Precision@5 在 GPT-2 和 BERT 上均为 0.03。

T1–T3 针对单个几何评估。T1 的 100% 准确率符合预期。考虑到经纬度的单位为度，面积与质心计算中观察到显著误差（以 MAPE 和 RMSE 衡量），且增加或减少模型复杂度并不能缓解该问题，提示对 token 嵌入取平均时可能丢失信息，或坐标在分词过程中被碎片化。在 T2 中对所有几何训练回归器，未能成功学到 Point 和 LineString 的面积为 0；即便单独对 Polygon 训练回归器，结果仍不理想。T3 中由高维嵌入计算出的质心常落在研究区之外。T4–T6 评估嵌入捕捉空间关系的能力。一个有趣发现是，结合几何类型后空间谓词预测更好，准确率从 62%~68% 提升至 71%~73%，这可归因于不同几何类型组合间空间关系的不平衡。然而 T5 距离度量任务即便仅限 "disjoint" 关系，仍难以准确估计数值。T6 的差表现说明，即便 LLM 能以一致方式编码空间关系与几何，仅用平均方法生成嵌入也不足以支持空间推理和直接进行几何操作。因此，改进从文本描述定位空间对象的设计，可提升 LLM 在 GeoAI 中的应用。

总体而言，结果表明 LLM 生成的嵌入已编码 WKT 格式几何中存在的几何类型与坐标。但需注意，嵌入的性能并非在所有评估任务中都稳定符合预期。虽然 LLM 生成的嵌入能保留几何类型并捕捉部分空间关系，但由于分词过程中量级的丢失，在估计数值和检索空间相关对象方面仍存在挑战。尽管可通过修改记号或应用思维链提示来缓解该问题，本研究仍强调需要改进对底层地理空间数据细微性与复杂性的捕捉，并整合领域知识，以支持使用 LLM 的各种 GeoAI 应用。
