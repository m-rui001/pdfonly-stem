# 二维杂化卤化物钙钛矿：原理与前景

*Two-Dimensional Hybrid Halide Perovskites: Principles and Promises* · Lingling Mao, Constantinos C. Stoumpos, Mercouri G. Kanatzidis · 2018 · DOI: 10.1021/jacs.8b10851

本文是一篇 Perspective，主张二维（2D）杂化卤化物钙钛矿并非三维（3D）钙钛矿的简单衍生，而是一类结构类型更丰富、可调性更强、并因天然多量子阱（MQW）电子结构而具备独特光电性质的半导体材料家族。作者以结构—性质关系为主线：先回顾历史，再按八面体连接方式与层取向建立分类，随后聚焦 [100] 取向的多层 RP、DJ、ACI 相，讨论层厚、间隔阳离子、钙钛矿化阳离子与固溶体、温度与压力等外部刺激如何调控量子阱的介电与光学性质，最后落到太阳能电池、LED、光电探测器、激光与非线性光学等器件成果，并提出未来方向。

## 历史脉络与结构分类

作者将 2D 卤化物钙钛矿的源头追溯到 Weber 1978 年关于 $\mathrm{CH_3NH_3PbX_3}$ 的工作，更早还有 Wells（1893）关于 CsPbX₃、Moller（1957–1959）以及 Auger 和 Karantassis（CsSnX₃, 1925; CsGeX₃, 1935）的报道。2009 年 Miyasaka 等报道基于 MAPbI₃ 纳米晶的液基染料敏化太阳能电池，2012 年出现三个关键节点：Kanatzidis 等报道以 CsSnI₃ 作为空穴传输层和光吸收层的全固态染料敏化电池（效率约 10%）；Miyasaka、Snaith 等报道基于 MAPbI₃ 固态层的器件；Park 等独立确认 MAPbI₃ 固态层钙钛矿。此后钙钛矿太阳能电池效率超过 23%。作者强调该领域更接近溶液加工染料敏化电池（Gratzel cell）的“知识后代”，而非传统 Si、CdTe、CuInSe₂ 电池的自然演化，并大量借用了有机光伏技术。3D 钙钛矿的组成局限在于 ABX₃ 中只有三种 A 位阳离子（$\mathrm{Cs^+}$、$\mathrm{CH_3NH_3^+}$、$[\mathrm{HC(NH_2)_2}]^+$）能维持 3D 角共享无机骨架，有时仅形成亚稳化合物；2D 卤化物钙钛矿 $\left(\mathrm{A'}\right)_{\mathrm{m}}\left(\mathrm{A}\right)_{\mathrm{n}-1}\mathrm{B}_n\mathrm{X}_{3n+1}$ 通过化学维度降低提供了组成多样性的重要出口。

2D 钙钛矿中，单价（m = 2）或二价（m = 1）阳离子可插入阴离子 2D 钙钛矿片层之间。有机阳离子既作为绝缘势垒在二维方向限域载流子，又作为介电调节剂决定光生电子—空穴对所受静电力。交替的有机—无机层形成晶体学有序的 2D 多量子阱电子结构，通过自组装自下而上自然形成。其结构相干性类似人工合成的 III-V 族半导体异质结，且由于高有机/无机介电对比，产生巨大电子—空穴结合能，使激子即使在环境温度下也易于观察。

在结构类型上，2D 卤化物钙钛矿遵循决定钙钛矿片层生长的立体化学规则。实验观察到三种八面体连接模式：角共享、边共享和面共享。与 3D 结构主要取决于 A 位阳离子相对尺寸不同，2D 钙钛矿对 A' 位尺寸限制少得多（A 位仍遵循 3D 规则），因为阳离子只需填入层间空间。决定阳离子能否作为间隔层的因素包括：i) 在钙钛矿锚定位点的净正电荷与取代程度，即 $\mathrm{RNH_3^+}>\mathrm{R_2NH_2^+}>\mathrm{R_3NH^+}>\mathrm{R_4N^+}$ 偏好递减；ii) 氢键能力；iii) 立体化学构型，即柔性脂肪烃 > 刚性芳香烃，以及质子化位点上的取代；iv) 空间填充能力，即线性互穿阳离子 > 支化不规则阳离子。满足这些条件的阳离子很多，因此许多阳离子可稳定规则（角共享）2D 钙钛矿结构。但在少数情况下，阳离子施加的构型应变打破标准连接模式，稳定边共享或面共享网络。这些网络几乎从不单独以边共享或面共享连接形成，因为二维面积填充困难或面共享几乎不可能，而是与部分角共享接触组合形成。例如 $(\mathrm{mpz})_2\mathrm{Pb}_3\mathrm{Br}_{10}$（mpz = N-甲基哌嗪）由重复边共享二聚单元（红色高亮）组成，再以角共享方式连接完成 2D 层。$[(\mathrm{H_2en})_7(\mathrm{C_2O_4})_2]_n(\mathrm{Pb_4I_{18}})_n\cdot4n\mathrm{H_2O}$（en = 乙二胺）是罕见纯角共享结构，但不属于 (100)、(110) 或 (111) 取向。在 $\mathrm{(tms)_4Pb_3Br_{10}}$（tms = 三甲基锍）中，面共享单元三聚体（红色高亮）在两个末端顶点共享角，完成类似 9R 钙钛矿多型的 2D 层。八面体连接方式决定金属—卤化物轨道重叠，进而影响带隙。实验和理论均确认带隙按“角共享 < 边共享 < 面共享”增大。这或许在特殊钙钛矿“倒置”带结构中可预期，因为角共享提供最强金属—卤素键，使 ns² 孤对电子“失稳”并推至价带顶；随着边共享和面共享中 σ 键减弱，孤对电子稳定并局域在价带深处，同时导带底能量升高，导致带隙打开。这些 2D 非钙钛矿（perovskitoids）的结构多样性可进一步调节杂化钙钛矿的光学性质。

主要 2D 卤化物钙钛矿由角共享八面体组成，按沿母体 3D 结构特定 (hkl) 面切割的晶体学层切片方向，可分为 (100)、(110) 和 (111) 取向结构。(100) 和 (110) 取向 2D 钙钛矿通式为 $A'_2A_{n-1}B_nX_{3n+1}$ 或 $A'A_{n-1}B_nX_{3n+1}$（$A'=1+$ 或 $2+$，$A=1+$ 阳离子，$B=\mathrm{Pb^{2+},Sn^{2+},Ge^{2+},Cu^{2+},Cd^{2+}}$ 等，$X=\mathrm{Cl^-,Br^-,I^-}$），而 (111) 取向 2D 钙钛矿通式为 $A'_{n+1}B_nX_{3n+3}$（n > 1，B 价态为 3+、混合价平均 3+ 或异金属，例如 $\mathrm{Cu^{2+}}$ 和 $\mathrm{Sb^{3+}}$）。(100) 取向 2D 钙钛矿在分类树中占主导，是最常获得的 2D 钙钛矿结构。除标准 2D 钙钛矿外，非常规 (100)、(110)、(111) 取向钙钛矿也取得显著进展，许多新化合物被发现，拓宽了卤化物钙钛矿家族结构工程的前景。

(100) 取向钙钛矿结构变化的一个有趣延伸是将维度降低概念与有序双钙钛矿结构结合。由此得到的单层和双层溴化物 $\mathrm{(BA)_4(AgBi)Br_8}$ 和 $\mathrm{(BA)_2Cs(AgBi)Br_7}$ 代表 (100) 型的特殊情形，由丁胺 $\mathrm{(BA^+)}$ 阳离子与 Ag(1+) 和 Bi(3+) 交替形成 $\mathrm{(MBr_{6/2})^-}$ 八面体，满足 2D 钙钛矿层的电荷和离子尺寸要求，而丁铵阳离子双层起分离无机层的常规作用。另一个有趣的 2D 钙钛矿变体是异配位 (100) 取向层状钙钛矿。杂化化合物 $\mathrm{(MA)_2PbI_2(SCN)_2}$ 与全无机化合物 $\mathrm{Cs_2SnI_2Cl_2}$ 和 $\mathrm{Cs_2PbI_2Cl_2}$ 代表 $\mathrm{K_2NiF_4}$ 原型的独特衍生物，其中沿钙钛矿平面和垂直方向的晶格位置被不同化学物种占据。在这些化学有序结构中，较大的杂原子（前者为 $\mathrm{SCN^-}$，后者为 $\mathrm{I^-}$）装饰层表面，而较小杂原子负责钙钛矿沿层的角共享扩展。这三种化合物与其余杂化无机—有机钙钛矿显著不同，因为层间分离“自然”发生，无需大体积有机间隔层，似乎是由于两种杂原子的离子尺寸失配实现。

波纹状 [110] 取向结构远不常见，因为能稳定它的阳离子很少，通常是小而高度对称的阳离子或柔性双齿阳离子。直到最近，唯一已知构建单元是最常见的“2×2”波纹变体。然而新结果表明波纹“长度”可增加到“3×3”甚至“4×4”波状结构（波纹长度定义为一个单元中的八面体数，例如 (EDBE)PbBr₄ 结构中的“2×2”）。(110) 取向钙钛矿层本质上高度畸变，常由位点特异性氢键或其他次级键合稳定。因此，(110) 取向钙钛矿常在室温表现白光发射，被认为由自陷激子（STE）形成引起，例如 (EDBE)PbBr₄（“2×2”）和 α-(DMEN)PbBr₄（“3×3”）。最近还实现了不对称“3×2”波状结构，在 $[\mathrm{CH(NH_2)_2}][\mathrm{C(NH_2)_3}]\mathrm{PbI_4}$ 中，这是更广泛的 (210) 取向 2D 钙钛矿家族的第一个成员。

(111) 取向 2D 钙钛矿通式为 $\mathrm{A'_{n+1}B_nX_{3n+3}}$，实际上是一类缺陷钙钛矿。与其他层状钙钛矿构型不同，(111) 取向钙钛矿是 M 位缺陷的，因为沿 3D 立方胞体对角线切割选择性“消除”金属位点，而其他切割面消除中性 $\mathrm{BX_2}$ 片段。因此，仅含 $\mathrm{B^{2+}}$ 的卤化物 (111) 取向 2D 钙钛矿不能形成，沿体对角线切割的结构偏好保持电荷奇偶性的替代 3D 多型构型。因此，这类材料中唯一的同价 p 区化合物由第 15 族 $\mathrm{B^{3+}}$ 离子（$\mathrm{B=Bi,Sb,As}$）组成，属于准层状 $\mathrm{Cs_3Cr_2Cl_9}$ 型 0D $[\mathrm{B_2X_9}]^{3-}$ 二聚体或 $\mathrm{Cs_3Bi_2Br_9}$ 型 2D $(\mathrm{B_2X_9})^{3-}$ 缺陷钙钛矿层。最近 Solis-Ibarra 等通过合成异金属化合物 $\mathrm{Cs_4(CuSb_2)Cl_{12}}$ 绕过了电荷失配障碍，这是唯一已知的 n > 2 例子。在该异双金属钙钛矿中，$\mathrm{Cu^{2+}}$（或 $\mathrm{Mn^{2+}}$）离子可插入 $\mathrm{Sb^{3+}}$ 片层之间，形成通式 n = 3 结构的首个例子。

## [100] 取向 2D 钙钛矿：间隔阳离子的结构导向效应与层厚调控

(100) 取向 2D 钙钛矿是迄今最丰富的一类，已探索了多种阳离子模板。其几何平面的无机—有机界面不仅允许大量“间隔”阳离子插入 2D 钙钛矿之间，还允许钙钛矿本身模板化“构建”，以逐层方式在间隔层间自组装。这些模块化多层结构最早在氧化物钙钛矿中发现，用于扩展同源系列。沿用氧化物钙钛矿命名，(100) 取向氧化物钙钛矿可进一步分为 Ruddlesden-Popper (RP) 相、Dion-Jacobson (DJ) 相和 Aurivillius 相，通式分别为 $A'_2A_{n-1}B_nO_{3n+1}$、$A'A_{n-1}B_nO_{3n+1}$ 和 $\left(\mathrm{Bi_2O_2}\right)\left(\mathrm{A_{n-1}B_nO_{3n+1}}\right)$。在卤化物钙钛矿中，除 Aurivillius 相尚未报道外，大多数结构类型已实现，可能由于 $\left(\mathrm{Bi_2O_2}\right)^{2+}$ 对卤化物形成的反应性。但完全可能使用反应性较低的岩盐型层，如 $\mathrm{(Ba_2F_2)^{2+}}$ 形成此类层。与氧化物钙钛矿一样，间隔阳离子性质重要。从化学式即可看出，间隔阳离子电荷决定 2D 钙钛矿结构类型。RP 和 DJ 类均存在于卤化物家族，通式分别为 $A'_2A_{n-1}B_nX_{3n+1}$ 和 $A'A_{n-1}B_nX_{3n+1}$（$\mathrm{A'=}$ 层间“间隔”阳离子）。卤化物钙钛矿独有的新结构类型是层间空间交替阳离子 (ACI) 型，不同阳离子沿层间空间有序排列。ACI 与 RP、DJ 的差异直接反映在通式 $\mathrm{A'A_nB_nX_{3n+1}}$ 中，因为 A 位“钙钛矿化”阳离子（$\mathrm{MA^+}$、$\mathrm{FA^+}$ 或 $\mathrm{Cs^+}$）不仅位于钙钛矿板层中，还与指定间隔阳离子 A 一起填充层间。有趣的是，胍（$\mathrm{GA^+}$）是唯一报道能形成 ACI 型结构的 A' 阳离子，表明与“钙钛矿化”阳离子（$\mathrm{MA^+}$、$\mathrm{FA^+}$ 或 $\mathrm{Cs^+}$）尺寸相似的小阳离子偏好形成 ACI 相。

所有已知结构类型的晶体结构在 Figure 5 中展示。并排比较 RP、DJ 和 ACI 同源系列的 n = 3 成员，说明它们在三个晶体学方向上的结构差异与相似性。对于 RP 相 $(\mathrm{BA})_2(\mathrm{MA})_2\mathrm{Pb_3I_{10}}$ 和 $(\mathrm{PEA})_2(\mathrm{MA})_2\mathrm{Pb_3I_{10}}$，层偏移一个八面体单元，显示 $(\frac{1}{2},\frac{1}{2})$ 面内位移。相反，DJ 相 (3AMP)(MA)₂Pb₃I₁₀ 的层没有任何位移，完美堆叠在彼此之上，无 (0,0) 位移。ACI 型结构介于两者之间，结合 RP 和 DJ 结构类型的层堆叠特征，显示 $(\frac{1}{2},0)$ 位移。显然，层间距离随间隔阳离子 A' 选择而变化，这是决定这些量子阱结构激子 PL 发射的关键因素之一。通常，RP 相层间距离较大，因为它们需要双层间隔有机阳离子，这不可避免地将层间距从约阳离子长度的 1.5 倍（如 BA 情况下的互穿）增加到超过阳离子长度两倍（如 PEA 情况下无重叠）。因此，在 RP 相中，层被良好“隔离”，没有钙钛矿—钙钛矿相互作用，从而产生直接来自各层空间电子限域 (n) 的激子发射。相反，ACI 相，尤其是 DJ 相，要求有机阳离子紧密嵌入由钙钛矿层重叠堆叠构型在层间空间形成的钙钛矿“口袋”中。层间紧密接近产生弱钙钛矿—钙钛矿相互作用，可 readily 在激子位置观察到，显示明显红移。Figure 5 所示 RP、DJ 和 ACI 相的代表性层间距离分别约为 7 Å、4 Å 和 3 Å。然而，特别是对于 RP 相，BA 的值代表下限，因为已报道更长的层间距离可达约 26 Å，例如在 $\left(\mathrm{C_{18}H_{40}N}\right)_2\mathrm{PbI_4}$ 中，使用了巨大的烷基铵阳离子 $\mathrm{CH_3(CH_2)_{17}NH_3^+}$。

虽然激子发射趋势主要取决于量子限域，但给定 n 成员内的结构细微差别也会对其产生显著影响。这些与 2D 钙钛矿晶格畸变有关，畸变最小的晶格（就 B-X-B 角而言）具有最小的激子发射能量，与 3D 钙钛矿的带隙趋势完全对应。这可以从晶体的光致变色变化中 readily 观察到，在 n = 1 RP 系列中从低温低对称结构到高温高对称结构，或通过 DJ 系列中给定温度下阳离子模板效应引起的结构变化。在选定的情况下，当 RP、DJ 和 ACI 的完整同源系列合成和表征已实现时，可以分析其结构—性质相关性。比较所有家族的 n = 1 到 3，激子发射能量（由室温 PL 发射确定）对所有系列均降低。然而，相对发射能量显著不同，遵循系统趋势，发射能量按“3AMP (DJ) < GA (ACI) 4AMP (DJ) < BA (RP)”顺序降低。这一特定趋势的起源与由八面体连接 Pb-I-Pb 角定义的结构畸变以及晶体结构中的层间距都很好地相关。较大的角代表较小的畸变，通常导致系列间 PL 发射能量相对变窄。然而，n = 1 是该趋势的例外，(GA)(MA)PbI₄ 具有较大的平均 Pb-I-Pb 角，但 PL 发射能量仍略高于 (3AMP)PbI₄，可能是由于 (GA)(MA)PbI₄ 的大面外畸变。这一偏差表明还有其他因素，如晶格各向异性或键长变化，也在决定量子阱结构光学性质中起作用。需要指出的是，随着层变厚（更高 n 成员），所有结构类型的 Pb-I-Pb 角差异变得非常小，表明晶格畸变不再是决定因素，层间距开始成为主导因素。然而，在所有其他条件相同的情况下，结构畸变仍然重要，如 3AMP 和 4AMP DJ 钙钛矿中，后者的 Pb-I-Pb 角始终较大，从而导致系统较低的激子发射。

(100) 取向 2D 钙钛矿最吸引人的特性之一是可以使用简单合成化学定制精确的 n 层厚度，从而精细调节量子阱电子结构。由于有利的几何结构保证层厚的“高保真度”，(100) 取向 2D 钙钛矿是这种“数字”生长的理想选择。实际上，仔细控制组成可以生成所有“量子化”RP 钙钛矿，直到 $\mathrm{(BA)_2(MA)_{n-1}Pb_nI_{3n+1}}$ 系列的 n = 7，这是迄今已知最厚的具有长程晶体学有序的 2D 钙钛矿。注意，氧化物基 RP 钙钛矿已观察到更高 n 成员，但形态效应阻止了有序高 n 成员（n > 5）的形成，因为这些化合物没有足够的热力学稳定性。这种不稳定的机制是歧化反应 (1)：

$$
\left(\mathrm{RNH}_3\right)_2(\mathrm{MA})_{\mathrm{n}-1}\mathrm{Pb}_{\mathrm{n}}\mathrm{I}_{3\mathrm{n}+1} \xrightarrow{disproportionation} \left(\mathrm{RNH}_3\right)_2(\mathrm{MA})_2\mathrm{Pb}_3\mathrm{I}_{10} + (n-3)\mathrm{MAPbI}_3 \quad (1)
$$

其中大的钙钛矿板层倾向于分解为热力学更稳定的相，如较薄的 2D 钙钛矿板层和 3D 钙钛矿。例如，BA 系列的 n = 5 成员经历非常缓慢的歧化反应，在数周内分解为 $\mathrm{MAPbI_3}$ 的水合形式 $\mathrm{(MAPbI_3\cdot H_2O)}$ 和 n = 3 的 2D 成员。随着钙钛矿层厚度增加，堆叠轴尺寸也增加，逐渐从原子尺度（n=1 时几 Å）移动到纳米尺度（n=7 时几 nm）。层尺寸甚至可以按照通式 (2) 粗略预测：

$$
\mathrm{d}_{(001)} = \mathrm{a}^*\mathrm{n} + \mathrm{x}
$$

其中完整无机—有机层厚度 $\mathrm{d}_{(001)}$ 由 3D 钙钛矿的晶格参数 $\mathrm{(a^*)}$（$\mathrm{MAPbI_3}$ 约 6.3 Å）、完整有机层厚度 (x)（$(\mathrm{BA})_2^{2+}$ 双层约 7 Å，$(3\mathrm{AMP})^{2+}$ 单层约 3 Å）和无机层数 (n) 决定。由于其长程晶体学有序，块体材料的相纯度可以通过 X 射线衍射图中的“指纹”反射追踪。因此，低于特征 3D 钙钛矿反射 $\mathrm{d}_{(110)}=6.26\mathrm{\AA}$ 和 $\mathrm{d}_{(001)}=6.34\mathrm{\AA}$（对于四方 $\mathrm{MAPbI_3}$）的所谓基低角 Bragg $(00l)$ 峰（当 c 为堆叠轴时）反射（或 $(h00)$ 或 $(0k0)$，取决于堆叠轴晶格参数）数量，精确地定义了钙钛矿层数。

维度变化可以 readily 在量子阱的光学吸收光谱演化中看到。当 3D 钙钛矿维度降低形成 2D 层时，多层 2D 系列的光学吸收边也随 n 值减小而能量增加。以 $\mathrm{(BA)_2(MA)_{n-1}Pb_nI_{3n+1}}$ 系列为代表，吸收边从 1.52 eV（n = ∞）蓝移到 2.43 eV（n = 1）。同时，除了特征卤化物钙钛矿尖锐吸收边外，n < 5 成员开始出现类激子峰，随着 n 进一步减小而更明显。PL 发射遵循相同趋势，显著差异是发射峰最大值现在与类激子特征和吸收边的交叉点重合，范围从 1.6 eV（n = ∞）到 2.35 eV（n = 1）。2D 钙钛矿中发射与吸收的差异尚未很好理解，但与 3D 钙钛矿的相应吸收和发射光谱没有不同。然而，当考虑 2D 卤化物钙钛矿中激子结合能的大小时，复杂性进一步增加，在低温下 n=1 成员可高达 $\mathrm{E_b}\sim500\mathrm{meV}$。为了将巨大激子结合能与观察到的光谱相协调，已提出替代电子结构模型，包括将卤化物钙钛矿的有效维度从 2D 降低到准 1D 模型。尽管这方面的理论研究仍在进行中，但显然 2D 卤化物提供的广泛可调性为设计具有未探索光物理性质的新材料提供了极好的平台，可用于先进光电器件。

尽管过去五年 2D 钙钛矿发展迅速，但分离含有不同于 $\mathrm{MA^+}$ 的 A 位阳离子作为“钙钛矿化剂”的同源系列钙钛矿仍然非常困难。除了乙铵 $(\mathrm{EA^+})$ 和异丙铵 $(\mathrm{IPA^+})$ 可以产生线状（即不属于同源系列）2D 化合物 $(\mathrm{EA})_2(\mathrm{EA})_2\mathrm{Pb_3X_{10}}$（$\mathrm{X=Cl,Br}$）和亚稳的 $(\mathrm{IPA})_2(\mathrm{IPA})\mathrm{Sn_2I_7}$（其中有机阳离子同时占据同一化合物中的 A' 和 A 位）外，使用常见的 $\mathrm{Cs^+}$ 和/或 $\mathrm{FA^+}$ 钙钛矿化剂无法扩展 2D 钙钛矿同源系列。虽然纸面上看似可能，但 $\mathrm{Cs^+}$ 和 $\mathrm{FA^+}$ 对形成 $\mathrm{CsPbI_3}$ 和 $\mathrm{FAPbI_3}$ 钙钛矿（两者均为亚稳）的内在不稳定性显然也传递到 2D 钙钛矿。与 3D 钙钛矿中热力学相是非钙钛矿相不同，在 2D 钙钛矿中热力学产物似乎是同源系列的 n = 2 成员。这已在许多 2D 钙钛矿家族中得到证明，从 RP 到 ACI 再到双钙钛矿，因此可以初步得出结论：是钙钛矿化剂本身抑制了同源系列的形成，尽管更高 n 成员可能形成，但它们显然不是这些体系的热力学产物。为了绕过这一障碍，一些研究者转向 3D 钙钛矿中熟悉的补救方法：在 A 位混合阳离子以调节容忍因子。尽管这种方法在混合组成用于浇铸薄膜时在改善器件方面取得了一些成果，但完全缺乏结构表征使薄膜的确切组成存疑。然而，在少数情况下已实现结构表征，表明 FA 的掺入是可能的，如 n = 4 DJ 钙钛矿 (3AMP)(MA)₂.₂₅(FA)₀.₇₅Pb₄I₁₃（我们实验室未发表结果）。

2D 钙钛矿中的混合阳离子固溶体方法不仅限于 A 位阳离子，还探索了金属合金化和卤化物混合。混合金属或卤化物非常吸引人，因为它们可以显著改变钙钛矿中的能带能级。概念上，它们还可以选择性地取代到不同层中。然而，与 3D 钙钛矿类似物相比，这些体系尚未引起太多关注，且仅限于少数例子。金属合金化迄今已在单层混合 Pb 和 Sn 体系 $(\mathrm{HA})\mathrm{Pb}_{1-x}\mathrm{Sn}_x\mathrm{I}_4$ 和 $(\mathrm{BZA})_2\mathrm{Pb}_{1-x}\mathrm{Sn}_x\mathrm{I}_4$（$\mathrm{HA=}$ 组铵，$\mathrm{BZA=}$ 苄铵）以及混合 Sn 和 Ge 体系 $(\mathrm{PEA})_2\mathrm{Ge}_{1-x}\mathrm{Sn}_x\mathrm{I}_4$ 中探索。在前者中，Pb/Sn 混合产生 3D 钙钛矿“典型”的反常带隙趋势，不遵循两个母体化合物之间的 Vegard 定律。特别是在 $(\mathrm{BZA})_2\mathrm{Pb}_{1-x}\mathrm{Sn}_x\mathrm{I}_4$ 情况下，所有中间组成（x=0.25, 0.5, 0.75）的带隙（1.86 eV、1.84 eV 和 1.82 eV）均低于纯 Sn 化合物（1.89 eV）。正如 3D 钙钛矿先例所预期，在混合 Sn/Ge 体系中，带隙随 Sn 含量增加线性减小，从 x=0 的 2.13 eV 到 x=0.5 的 1.95 eV。卤化物混合在 2D 钙钛矿中也鲜有实践研究（与 3D 材料和 0D 纳米晶中的广泛探索相反），主要用于 Cl/Br 体系以优化白光发射的量子产率，如 (EDBE)[PbBr₄₋ₓClₓ]、EA₄Pb₃Br₁₀₋ₓClₓ 和 (PEA)₂PbBrₓCl₄₋ₓ，其中少量 Cl 添加可显著拓宽 PL 发射带宽。在 $(\mathrm{PEA})_2\mathrm{SnI}_x\mathrm{Br}_{4-x}$ 系列中混合 Br 与 I 导致激子发射从 2.66 eV（x=0）移动到 1.97 eV（x=4），而在完整系列 $(\mathrm{PEA})_2\mathrm{PbY}_x\mathrm{Z}_{4-x}$ 中，通过调整 Cl、Br 和 I 二元混合物之间的卤化物含量，可以访问 2.4 eV（Y=I, x=4）到 3.8 eV（Z=Cl, x=0）之间的整个光谱。

## 外部影响下的 2D 钙钛矿：温度与压力效应

与 3D 卤化物钙钛矿非常相似，2D 钙钛矿在非环境温度和压力等外部影响下表现出极大的结构多样性。柔性无机层之间软有机间隔层的存在使结构响应更加复杂，因为两层试图独立适应外部刺激。在二维中，钙钛矿固有的类液体动态无序与支配有机间隔层晶体堆积的弱色散力混合，产生真正的杂化材料。2D 钙钛矿的温度依赖行为强烈证明了材料的杂化性质，特别是 n = 1 钙钛矿，其在高温下显示有机层的特征“熔化”（即动态无序），而无机层的“熔化”发生在较低温度。有机层的“熔化”对晶体结构有显著影响，因为它与层间距相关，通常沿堆叠方向晶格常数出现大跳跃，如 $\left(\mathrm{C_nH_{2n+1}NH_3}\right)_2\mathrm{PbI_4}$（n=12, 16, 18）情况，以及无机层对称性增加，通常从畸变单斜到畸变较小的正交空间群。“熔化”温度强烈依赖于直链烷基铵间隔层中烷基链长度，在 BA 阳离子情况下降至略低于室温（约 5°C）。自然，将钙钛矿层厚度增加到 n > 1 会增加相变复杂性，因为与 $\mathrm{MAPbI_3}$ 3D 钙钛矿相关的结构变化开始与有机间隔层诱导的结构变化竞争。有趣的是，钙钛矿厚度的增量变化似乎不影响有机层的“熔化”，其几乎保持恒定，但对对应于 $\beta-\gamma$ 相变（在 3D 钙钛矿中）的相变有显著影响，该相变随 n 减小向更高温度移动。温度诱导相变在 2D 钙钛矿中常见，尤其是在单层体系中。例如，$\left(\mathrm{C_7H_{15}NH_3}\right)_2\mathrm{PbI_4}$ 在 253 K 到 293 K 之间显示三个相。化合物的带隙相应于结构畸变程度（即 Pb-I-Pb 角）变化，角越大，带隙越小（晶体颜色越深）。

最近，对钙钛矿施加压力被证明为了解其晶格软性质提供了有用见解。压力也被用作操纵 3D 钙钛矿光学和电学性质的有效工具。一系列实验技术，从施加静水压力到机械压痕、非弹性散射和共振声学光谱，已被用于理解应力下的晶格变形参数。在此背景下，研究 2D 钙钛矿的可压缩性变得越来越有趣，因为 2D 钙钛矿的各向异性和两个软有机与无机亚晶格的组合可能产生不寻常现象。取决于施加压力的方向，晶格将畸变，导致八面体倾斜和方向性键收缩，而有机层可作为缓冲层缓解过量应力。事实上，$\mathrm{(BA)_2(MA)_{n-1}Pb_nI_{3n+1}}$ 同源系列就是这种情况，其在压缩时表现出特征结构变化，具体反映在 Pb-I-Pb 角变窄和 Pb-I 键长缩短。施加各向同性压力最初在相对较低压力下沿层堆叠轴收缩晶格（约 7 GPa (n=1)；约 4 GPa (n=2)；约 3 GPa (n=3)；约 2 GPa (n=4)；约 0.5 GPa (n=∞)）。随后是面内变形， readily 在高压下层的 Pb-I-Pb 角变化中观察到，在非晶化之前，材料开始表现几乎各向同性。结构变化伴随材料吸收变化，显示带隙初始减小，因为钙钛矿变得更对称。当有机分子可压缩性饱和时，层内开始发生变化，导致钙钛矿层内对称性降低，导致吸收边蓝移。一旦第二次变形饱和，2D 钙钛矿吸收再次开始单调下降，类似于 3D 钙钛矿。晶格常数和能带隙也随压力增加而收缩。当使用不同有机阳离子作为间隔层时，吸收和发射趋势存在显著差异。例如，单层 n=1 钙钛矿 (EDBE)CuCl₄ 在压力从 0.3 GPa 增加到 4.9 GPa 时颜色从黄色变为橙色，因为它经历 α 到 β 相变，随后在高压下吸收边单调下降。(EDBE)CuCl₄ 中缺乏初始吸收下降或许可以通过间隔层 (2+) 与无机层之间更强的机械耦合来合理解释，这可以通过环境压力下 n = 1 成员之间的相干声学声子振荡来 readily 探测。评估外部刺激下 2D 卤化物钙钛矿的性质，显然它们构成一类非常规的“可延展”半导体，其性质可以在温度和压力的微小变化内剧烈改变， clearly 为材料设计和性质工程提供了充足空间。

## 光电器件应用与未来方向

几种 2D 钙钛矿已部署在实际器件中，表现出卓越性能。其独特优势源于纳米结构模板和增加的有机组分含量。其杂化无机—有机性质允许开发多功能材料，比 3D 钙钛矿具有增强的环境稳定性、减少的离子迁移和易于调节的电学性质。相反，增加的有机含量略微稀释了功能活性钙钛矿层，因此在一定程度上降低了最大理论光电流转换。高激子结合能限制了 2D 钙钛矿的扩散长度，扩散长度随有机间隔层含量减少而增加。尽管不如 3D 对应物高，但在 $\mathrm{MA}_{n-1}\mathrm{PEA}_2\mathrm{Pb}_n\mathrm{I}_{3n+1}$ 体系中，50% PEA 的载流子迁移率可达约 10 $\mathrm{cm^2V^{-1}s^{-1}}$。尽管起步略有劣势，2D 钙钛矿已证明其价值，最初成功演示的 $(\mathrm{PEA})_2(\mathrm{MA})_2\mathrm{Pb}_3\mathrm{I}_{10}$ 产生 4% 的功率转换效率 (PCE)，随后被 $(\mathrm{BA})_2(\mathrm{MA})_2\mathrm{Pb}_3\mathrm{I}_{10}$ 超越，其表现出相似的 PCE。然而，重大突破来自 $(\mathrm{BA})_2(\mathrm{MA})_3\mathrm{Pb}_4\mathrm{I}_{13}$，其使用热浇铸方法表现出 12.52% 的 PCE，对光和湿气均显示出令人印象深刻的长期稳定性。

自 2D 钙钛矿太阳能电池首次演示以来，通过混合 A 阳离子 (FA/MA) 和 (Cs/MA) 策略在 BA 体系中取得了小幅改进。有趣的是，更高 n 成员并未提高效率，导致 n = 5 成员的最佳 PCE 约 10%。通过向 $(\mathrm{ThMA})_2(\mathrm{MA})_2\mathrm{Pb}_3\mathrm{I}_{10}$ 体系（$\mathrm{ThMA=2}$-噻吩甲铵）中添加 MACl，PCE 可从 1.74% 显著提高到超过 15%。通过采用所谓的“准 2D 钙钛矿”，针对高层数（例如“n = 10, 50, 60”）的标称组成，PCE 可进一步提高。这种常见策略为各种阳离子和不同 2D 体系提供了更高效率（约 15%）的太阳能电池（n=60 PEA；n = 10, ALA（烯丙铵））。Sargent 等的工作说明了掺入不同有机间隔层（BA、PEA 和 ALA）的效果，他们发现 ALA 体系具有最高寿命、扩散长度和迁移率，与 BA 和 PEA 相比达到最高效率。这种方法成功扩展到铅溴基体系，为 $^{
