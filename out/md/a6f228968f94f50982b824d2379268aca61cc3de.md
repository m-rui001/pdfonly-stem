# PLUMED 联盟：推动分子模拟的开放性、透明性与可重复性

*The PLUMED consortium: A community effort to promote openness, transparency and reproducibility in molecular simulations*

登记题名：Promoting transparency and reproducibility in enhanced molecular simulations；年份：2019；DOI：https://doi.org/10.1038/s41592-019-0506-8

本文宣布成立 PLUMED 联盟（The PLUMED consortium），其使命是改变科学家交流分子动力学（MD）协议的方式，以提升透明度并最大化新研究的影响力。联盟通过持续、社区驱动的 PLUMED 开源库开发来实现这一目标，同时集体推动增强采样 MD 模拟的良好实践，并培训社区新成员。

MD 模拟已成为表征复杂过程机制、解释实验测量和预测分子系统行为的重要工具。这一成就源于 60 多年的持续创新：精确的运动方程积分器、有效的恒温器、高效的静电相互作用计算方法、量子/经典/粗粒化层面的物理化学描述、大量加速构象采样的技术、复杂的分析工具、更强大的计算机以及新的高效易用软件。这些进展使 MD 成为强大的通用计算显微镜，应用于物理、化学、生物和材料科学等领域，并可在从化学反应（需量子描述）到整个细胞动力学（目前需超粗粒化表示）的不同时空尺度上使用。MD 已被认可为计算科学中成熟的技术（2013 年诺贝尔化学奖），但创新仍在加速涌现，开放挑战包括延长标准模拟可及的时间尺度、基于机器学习的降维方法以理解 MD 产生的高维数据，以及通过整合量子化学或实验数据改进分子力学力场准确性的新集成方法。尽管在定义 MD 模拟准备、执行和分析的良好实践方面已付出巨大努力，但要使其在不同 MD 代码和计算平台间可重复、可共享、可比较，并最终以标准化方式验证结果，仍有许多工作要做。

本文提出的倡议源于一个认识：上述许多挑战无法由单个研究者有效克服，整个模拟社区的协同努力更可能成功。近年来已启动多项重要倡议以改善模拟数据和知识的交流方式，包括：SimTK（生物医学计算社区共享软件、数据和模型的平台）；Open Force Field Initiative（与分子软件科学研究所 MoSSI 协调开发，改进 MD 模拟所用计算机模型）；BioExcel（计算生物分子研究卓越中心，改善生物分子软件并传播最佳实践和专业知识）；Living Journal of Computational Molecular Science（发布定期更新的“活”教育综述和最佳实践论文）；Materials Cloud（材料科学资源共享平台）；AiiDA（管理、保存和传播现代计算科学模拟、数据和工作流的灵活可扩展基础设施）；E-CAM 卓越中心（支持工业界和学术界的高性能模拟）；RosettaCommons（贡献和共享 ROSETTA 源代码以进行计算建模和蛋白质结构分析的中心枢纽）；NOMAD 实验室（维护材料科学总能量计算输入输出文件的最大存储库）；The Materials Project（提供已知和预测材料的计算信息的开放网络访问）；Qresp（策展、发现和探索可重复科学论文的工具）；nanoHUB（共享纳米科学模拟软件和教育工具的平台）。Scientific Data 已编制更详尽的数据存储库列表。

然而，这些倡议的有效性受到阻碍，因为在同一研究项目中使用多个 MD 代码以及同时在多个代码上进行开发很困难，每个代码都有不同目标并针对特定应用优化。虽然若干方法有潜力跨领域和平台使用，但 MD 代码间缺乏互操作性阻碍了其适用性。十年前创建 PLUMED 开创了解决此问题的策略：一个开源库，可与许多不同 MD 代码结合使用（见 Box 1）。该库包含一系列不同方法，包括增强采样算法、自由能方法以及分析 MD 模拟产生的大量数据的工具。此后开发了类似的可互操作库，如分子模拟程序的集体变量模块（Colvars）和高级广义系综模拟软件套件（SSAGES）。

最近，PLUMED 纳入了超出其核心开发者最初构想的功能。通过一系列技术创新和允许外部贡献轻松纳入代码的基础设施开发（见 Box 2），PLUMED 已演变为灵活的开源库。目前，PLUMED 可与最先进的经典和从头算 MD 代码一起使用，如 ACEMD、Amber、DL_POLY、GROMACS、LAMMPS、NAMD、OpenMM、ABIN、CP2K、i-PI、PINY-MD 和 Quantum Espresso。此外，PLUMED 还被用于增强分析工具（如 VMD）以及平台（如 HTMD 和 OpenPathSampling）的能力。当新技术在 PLUMED 中实现时，可迅速传播给庞大而多样的用户群。事实上，PLUMED 使所有这些技术对每个人都可访问且易于使用。PLUMED 对所有 MD 代码和分析工具使用简单统一的语法，进一步加速了跨社区的影响。PLUMED 提供的互操作性最终允许不同 MD 软件间的交叉验证以及计算化学、生物物理和材料科学不同领域间的思想交叉融合。

开源 PLUMED 库的成功不仅归功于核心开发者的贡献，也归功于整个用户和开发者社区的努力。为认可这一工作模式，本文宣布成立 PLUMED 联盟，其使命是改变科学家交流 MD 协议的方式，以提升透明度并最大化新研究的影响力。联盟实现这一目标的主要方式是通过持续、社区驱动的 PLUMED 开源库开发，欢迎联盟所有成员及其他研究人员添加新代码。此外，联盟还将集体推动增强采样 MD 模拟的良好实践，以鼓励最高标准的科学可重复性。最后，联盟将积极参与向社区最新成员介绍和培训通过 PLUMED 库传播的方法。

为提高 MD 模拟的清晰度和透明度，我们创建了一个名为 PLUMED-NEST 的公共存储库，鼓励联盟所有成员及其他研究人员使用它来共享其 PLUMED 输入文件以及复制其同行评审论文和预印本中呈现的计算所需的所有数据（见 Box 3）。该存储库不仅促进科学可重复性，还将作为新手用户通过计算化学、物理和生物学领域的真实应用学习 PLUMED 中实现的基础和高级技术的工具。在这方面，存储库还将帮助我们开发资源，用于教育和培训社区新一代科学家——这一目标目前通过组织用户会议、线下和在线教程来实现，并将继续实现。

PLUMED 联盟将是一个开放社区，由现任和过去的开发者、贡献者以及所有其工作部分基于 PLUMED 同时推动 PLUMED 开发和传播的研究人员组成。联盟成员名单将在 PLUMED 网站上定期更新，现任 PLUMED 开发者将作为该社区的协调者。我们坚信，这种统一核心开发者和代码贡献者的新颖组织，是反映社区驱动努力的最具代表性的方式，而社区驱动努力是开源软件开发的核心和灵魂，是任何方法学进步的关键部分。因此，我们欢迎所有认同我们愿景的未来成员。

**Box 1：PLUMED 库概述**

PLUMED 是一个开源 C++ 库，可与许多最先进的 MD 代码接口。其基本功能是：i) 从主代码检索当前原子位置；ii) 计算额外量，如系统的粗粒化表示（集体变量）和外部偏置势；iii) 将外部力传回 MD 代码，从而修改动力学。PLUMED 提供使用成熟增强采样方法（如伞形采样、元动力学和 steered MD）以及更新方法进行 MD 模拟所需的所有功能。这些技术可与描述物理、化学、材料科学和生物学中复杂过程的大型集体变量工具箱结合使用。PLUMED 还可通过 driver 实用程序在预计算轨迹上事后计算这些描述符，并执行各种其他分析，如降维或重加权。

PLUMED 可通过单个文档齐全的 API 与宿主代码接口，该 API 支持从多种语言（C、C++、FORTRAN 和 Python）访问，因此与社区中使用的大多数代码兼容。PLUMED 许可证（L-GPL）允许其与专有软件接口。若干 MD 代码（包括 AMBER、LAMMPS、DL_POLY、i-PI 和 OpenMM）现已原生实现与 PLUMED 的接口。

PLUMED 当前结构是模块化的，即可以在不改变代码核心的情况下添加新功能。新的集体变量和新的偏置或分析方法既可以随主核心分发，也可以作为单独的动态库加载。PLUMED 易于扩展的证据是独立小组在 GitHub 上创建的官方存储库分支数量以及贡献给 PLUMED 的附加模块数量不断增加（见 Box 2）。

**Box 2：当前 PLUMED 模块概述**

目前，已有六个模块由核心开发者之外的团体贡献给官方 PLUMED 发行版。所有这些模块独立于 PLUMED 核心，需要在配置 PLUMED 时激活。最大的贡献模块（VES）实现了变分增强采样方法，包括若干基函数、目标分布和优化算法。DRR 模块实现了用于增强采样和自由能计算的扩展系统自适应偏置力方法。EDS 模块实现了实验导向模拟方法，以自适应构建线性约束，确保偏置集体变量采样新的目标均值。最近，另外三个模块被贡献给 PLUMED，分别实现了称为对数平均力动力学的增强采样方法、置换不变向量（一种用于分析和模拟有序或无序形式之间转变（如晶体成核）的通用材料结构表示），以及一种寻找配体解离的多个不同反应路径的方法，可在 MAZE 模块中使用。最后，PLUMED-ISDB 模块由 PLUMED 开发者的一部分贡献，能够将不同类型的实验数据（如核磁共振波谱、小角 X 射线散射和冷冻电镜测量）整合到 MD 模拟中。通过这些模块贡献的所有集体变量和增强采样方法都可以与 PLUMED 中实现的所有其他功能无缝结合。每个模块都附有集成在在线 PLUMED 文档中的文档和教程。

**Box 3：PLUMED-NEST，PLUMED 联盟的公共存储库**

已创建一个公共存储库来收集 PLUMED 联盟成员和其他 PLUMED 用户的贡献。该存储库名为 PLUMED-NEST，托管 PLUMED 输入文件以及复制使用 PLUMED 进行的增强采样模拟或分析结果所需的所有数据的链接。目前，PLUMED-NEST 已包含 40 多个计算生物学、化学和材料科学领域的应用和方法开发示例。

所有存入 PLUMED-NEST 的 PLUMED 输入文件都会自动测试，以验证它们是否仍与当前和开发版本的代码兼容。此外，输入文件中的关键词显示为手册中文档的链接，以便用户轻松访问有关所计算内容的更多信息。还可以向输入文件添加上下文教程式信息，从而提供有关特定文件所计算内容的额外细节。最后，我们设想在存储库中包含的输入文件上加入评论功能，从而向原始论文作者提供直接反馈。

PLUMED-NEST 将发挥多种功能：i) 通过为用户提供一个与社区分享重复已发表论文中报告的模拟或分析所需所有信息的地方，促进科学可重复性；ii) 作为教育目的的真实示例存储库，从而补充 PLUMED 网站上已有的教程；iii) 使 PLUMED 开发者能够识别哪些功能最常用，从而指导他们改进 PLUMED 核心代码和文档。
