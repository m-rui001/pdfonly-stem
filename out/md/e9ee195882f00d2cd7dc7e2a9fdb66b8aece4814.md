# 二维层状金属硫族化物纳米晶的高性能赝电容

原文：High Performance Pseudocapacitor Based on 2D Layered Metal Chalcogenide Nanocrystals（2015）· https://doi.org/10.1021/nl504764m

本文报道了少层 TiS2（2D-TiS2）纳米晶的结构与电化学储能性质。与传统微米级体相 TiS2（B-TiS2）相比，二维形貌使锂离子嵌入/脱出过程中的晶格变化大幅缩小（体积变化仅 2% 对 10%），电荷存储机制由扩散控制转变为电容控制，从而同时获得高能量密度和高功率密度。作者结合原位同步辐射 X 射线衍射、循环伏安动力学分析和无粘结剂膜电极测试，将 2D 形貌对结构演变与储锂动力学的影响进行了定量关联。

## 背景与材料合成

1970 年代对体相 TMD 的储能研究已相当深入，TiS2 是最早进入中试的锂离子电池正极材料，也是所有层状二硫族化物中最轻的。TiS2 属半金属，无需导电添加剂；且在整个 LixTiS2（0 ≤ x ≤ 1）组成范围内保持同一晶体对称性，避免了相变引起的迟缓反应动力学。Conway 在 1990 年代曾指出 TiS2 具有赝电容特征，但不清楚其嵌入动力学是否真正有别于体相。本文采用热注入法合成尺寸可控的 2D-TiS2 纳米晶：将 CS2 注入含 TiCl4 和油胺的溶液，在 300 °C、N2 气氛下反应 15 min。通过调节反应条件可得到平均直径约 50、100、270 nm，厚度分别约 2–3、4–5、7–10 层的纳米片。TEM 显示其为 (001) 面堆叠的 1T 相结构，层间距约 5.7 Å；XRD 中 (110) 峰相对 (101) 和 (001) 峰明显更强更窄，表明结晶优先生长在 (hk0) 方向。Scherrer 尺寸比值 τ110/τ101 显示晶粒越薄时尺寸越小，且 τ110 小于 TEM 直径，说明纳米晶可能为多晶或含有缺陷。各向异性生长源于 (100)/(010) 面与 (001) 面表面能差异，油胺配体优先稳定富硫的 (001) 面，进一步促进二维生长；反应时间增长时，纳米片发生团聚和并合，形成更大更厚的六边形晶体。

## 结构表征与原位 XRD

作者用原位同步辐射 XRD 追踪了 Li+ 嵌入过程中 B-TiS2 与 2D-TiS2 的晶格参数变化。嵌锂前，B-TiS2 的 c 轴为 5.66(6) Å，a 轴为 3.41(5) Å，与文献值（c=5.69 Å，a=3.41 Å）一致。当 Li+ 插入时，(110) 与 (101) 峰向低 Q 方向移动，d 间距增大；a 轴增大源于 Ti4+（0.745 Å）被较大的 Ti3+（0.810 Å）取代，c 轴增大则因为 Li+ 嵌入范德华层间迫使层间距扩张。B-TiS2 完全嵌锂后 c 轴增至 6.17 Å，a 轴增至 3.43 Å，与先前原位研究相符。2D-TiS2 的初始状态即显示更大的晶格：c 轴 5.80(5) Å，a 轴 3.43(1) Å；作者将其归因于范德华间隙中过量 Ti 阳离子或无序导致的晶格常数增大（与 LiCoO2 纳米颗粒和介孔薄膜中的纳米尺寸效应类似）。嵌锂时，2D-TiS2 的 c 轴仅扩至 5.93 Å，体积变化只有 2%，而体相材料为 10%。这是纳米尺度降低嵌锂体积变化的直接结构证据。进一步循环表明，首圈后 Li+ 可逆嵌入/脱出几乎不再引起 2D-TiS2 的可测晶格变化。

## 器件性能与结论

为验证实际器件潜力，作者将 50 nm 2D-TiS2 纳米晶制成自支撑膜电极（直径 1 cm，1.6 mg），组装成 TiS2/电解液/锂 Swagelok 电池，在 1.5–3 V 间以 0.5–10 A g−1 进行恒流充放电。充放电曲线无平台，说明 Li+ 插入未发生一级相变。在 2.2C（0.5 A g−1）下可逆嵌入 0.66 mol Li，电流增至 44C（10 A g−1）时容量降至 70 mAh g−1（0.31 mol Li）。2D-TiS2 膜电极在 30 s 充放电时间内达到 320 F g−1 的比电容。综合结构数据，2D-TiS2 在循环中仅发生 2% 的晶格体积变化，远小于体相的 10%，这不仅有利于快速储锂（表面限速而非固相扩散），也保证了无粘结剂多孔电极在体积变化下仍保持结构完整。作者认为，2D 形貌使电解液充分接触整个表面，导致电容性存储占主导；且 Li+ 插入不诱导相变，因此具备同时实现高能量密度和高功率密度的可能性。该工作为少层 TMD 材料在电化学储能中的应用提供了新的思路。
