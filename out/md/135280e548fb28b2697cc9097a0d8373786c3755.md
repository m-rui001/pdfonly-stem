# 联合深度学习用于土地覆盖与土地利用分类

> Joint Deep Learning for land cover and land use classification. 2018. DOI: https://doi.org/10.1016/j.rse.2018.11.014

本文首次提出并演示了一种联合深度学习（Joint Deep Learning, JDL）框架，用于同步分类土地覆盖（LC）与土地利用（LU）。JDL将像素级多层感知器（MLP）与基于对象的卷积神经网络（OCNN）通过马尔可夫过程迭代耦合：LU分类以LC条件概率为输入，LC分类同时利用LU条件概率与原始影像作为输入，从而在迭代中互相细化。在南安普敦（S1）和曼彻斯特（S2）两个大型城市与郊区航空影像上的实验表明，JDL在约10次迭代时同时达到LC与LU的最优精度，平均总体精度分别为90.18%和87.92%，显著高于各自的三类基准方法。

## 引言与问题

土地覆盖描述地表物理状态（“是什么”），土地利用反映人类功能（“在做什么”），两者覆盖同一地理空间且层级嵌套。传统研究通常分别分类LC或LU，忽视了二者内在的层级关联。超高空间分辨率（VFSR）影像的复杂光谱与空间结构使LC分类困难，而LU与光谱响应的间接关系、城乡景观的异质性更增难度。基于像素的方法受椒盐噪声和类内方差限制，基于对象（OBIA）的方法面临分割尺度选择与过/欠分割问题。传统LU分类的像素级、移动窗口和对象级方法均依赖浅层模型与手工特征，难以表达高层语义。深度卷积神经网络（CNN）具有平移不变性，能学习层级特征，但其块状预测会在像素级LC/LU边界产生模糊。既有改进如混合MLP-CNN、区域决策融合、中心点增强CNN、全卷积网络（FCN）以及对象CNN（OCNN）等均只处理单一层级。本文的核心认识是LC与LU在空间和层级上相关，可以由联合分布刻画，由此提出JDL框架。

## 方法

JDL由三个基本组件构成：MLP、CNN（具体为对象CNN，OCNN）和迭代的马尔可夫过程。MLP是前馈全连接网络，通过反向传播学习输入到输出的映射，本文用于像素级LC分类。CNN通过卷积和池化层提取层级化空间特征；OCNN是对每个图像对象（多边形）以最小外接矩形中心点为中心裁剪图像块进行分类，从而保留对象边界。JDL的联合分布假设LC和LU为两个随机变量，通过无向图迭代形成马尔可夫过程，联合分布分解为各变量条件概率之积：`p( x ) = ∏ p( xv | x pa ( v ) )`（式1，其中v从1到k）。这里x_v表示LC或LU类，x_{pa(v)}为其父变量。令C_LC={C_LC1,...,C_LCm}为m个LC类样本集，C_LU={C_LU1,...,C_LUn}为n个LU类样本集。分类依据最大后验（MAP）准则：`C* = arg max p(C_i | F)`（式2）。通过贝叶斯定理：`p(C_i | F) = p(C_i) p(F | C_i) / p(F)`（式3），因p(F)对各类相同，故`C* = arg max p(C_i) p(F | C_i)`（式4）。本文不指定先验，联合分布等同于建模的条件分布。LC条件概率由像素级MLP初估，输入OCNN学习LU；LU概率与原图再作为MLP下一轮输入。第i轮联合分布为：`P(LandCover_i, LandUse_i) = P(LandCover_i, LandUse_i | LandCover_{i-1}, LandUse_{i-1})`（式5）。假设函数f，则`P(LandCover_i, LandUse_i) = f(LandCover_{i-1}, LandUse_{i-1}, Image, SegmentImage, C_LC, C_LU)`（式6），其中LandUse_0为空图，SegmentImage为对象分割标签图。每轮内，LC条件概率为`P(LandCover_i) = P(LandCover_i | LandUse_{i-1})`（式7），MLP训练为`MLPModel_i = TrainMLP(concat(LandUse_{i-1}, Image), C_LC)`（式8），LC预测为`LandCover_i = MLPModel_i.predict(concat(LandUse_{i-1}, Image))`（式9）。LU条件概率为`P(LandUse_i) = P(LandUse_i | LandCover_i)`（式10），OCNN训练为`OCNNModel_i = TrainCNN(LandCover_i, C_LU)`（式11），LU预测为`LandUse_i = CNNModel_i.predict(cast(LandCover_i, SegmentImage))`（式12）。JDL具有四个优势：能自动联合分类两个层级；通过互补增强同时提高二者精度；显式建模空间层级关系；增强鲁棒性并支持小训练样本。

## 实验与结果

研究区为英国南安普敦（S1）和曼彻斯特（S2），影像由Vexcel UltraCam Xp航摄于2012-07-22和2016-04-20，四波段（R,G,B,NIR），空间分辨率50 cm。S1范围23250×17500像素，S2为19620×15450像素。DSM仅用于分割。共定义10个LC类（黏土屋顶、混凝土屋顶、金属屋顶、沥青、铁轨、裸土、林地、草地、作物、水域）。LU类在S1有11类（高密度住宅、商业、工业、中密度住宅、高速公路、铁路、公园与休闲、农业区、停车场、再开发区、海港与海水），S2有10类（增加运河）。类别定义参考Urban Atlas和CORINE等。地面参考多边形覆盖超过80%，随机分为50%训练和50%验证，按面积比例分层抽样，对稀疏类增加样本。LC每类约600样本，LU每类超过1000样本。

模型参数在S1交叉验证确定，直接用于S2。MLP学习率0.2，动量0.7，训练800轮，最优结构为两个隐含层各16节点。对象分割采用层级区域生长算法，尺度参数优化为40，S1和S2分别得到61,922和58,408个对象。OCNN结构类似AlexNet，输入窗口96×96，多数卷积核3×3（首层5×5），滤波器数64，池化为2×2最大池化，全连接层24个神经元，softmax输出，学习率0.01，训练600轮。基线方法：LC对比MLP、SVM、MRF；LU对比MRF、OBIA-SVM、像素CNN。

迭代实验：每轮迭代重复10次随机划分训练/测试，报告平均OA。S1和S2的LC OA从约81%随迭代升至迭代10时约90%，此后稳定；LU OA从约77.5%和78.1%升至约87%并在迭代10后稳定。因此迭代10为最优。视觉上，早期迭代存在阴影误分类（如林地阴影误为铁轨）、裸土与沥青混淆、椒盐效应、混凝土屋顶与沥青混淆等，随迭代增加由空间上下文逐步消除；LU中停车场与高速公路、农业与再开发区、商业与工业等混淆在迭代10被准确区分。

基准对比：迭代10时，JDL-LC OA在S1和S2分别为89.64%和90.72%，高于MRF（84.78%/84.54%）、SVM（82.38%/82.26%）、MLP（81.29%/82.22%）。JDL-LU OA为87.58%和88.26%，高于CNN（84.08%/83.32%）、OBIA-SVM（80.26%/80.42%）、MRF（79.38%/79.26%）。JDL在数量不一致和分配不一致指标上也最小，LC平均不一致S1和S2分别为6.93%和6.73%，LU为9.98%和9.16%。逐类精度：LC中黏土屋顶、金属屋顶、草地、沥青、水域超过90%，水域最高（S1 98.52%，S2 98.33%）；草地精度从约70%提升至90%以上，林地提升至约88%。LU中公园、停车场、铁路、再开发区等超过90%，海港海水98.44%、运河98.72%。商业和工业类提升显著（S1分别+12.36%和+17.48%）。

样本鲁棒性：将每类训练样本缩减至10%、30%、50%后，JDL-LC和JDL-LU是最不敏感的方法。LC在缩减10%、30%、50%时平均OA分别约88%、80%、73%；LU分别约85.5%、80%、73%。而MRF和CNN在50%缩减时低于60%，JDL的鲁棒性明显更好。

## 讨论与结论

JDL通过联合分布建模LC和LU的依赖，像素级MLP提供光谱区分和边界，块状CNN提供高层空间特征，二者互补。迭代过程使MLP逐步引入空间上下文（如消除阴影），CNN则因LC精化获得更准确的起点，从而保留小特征和边界。JDL比标准CNN更少依赖样本量。该框架可推广到更多数据源和更复杂的层级结构。

JDL首次统一了LC和LU分类，在VFSR影像上获得显著优于基准的精度，实现自动联合分类，并能推广至多层级嵌套（如林地细分等）。未来将扩展至超光谱、SAR和LiDAR数据，以及时间序列的LC/LU变化检测。
