# 有机混合价态介导的铁(III)半醌金属–有机框架中的电子导电、亚铁磁有序与还原插入

**Electronic Conductivity, Ferrimagnetic Ordering, and Reductive Insertion Mediated by Organic Mixed-Valence in a Ferric Semiquinoid Metal–Organic Framework** (2015) · DOI: https://doi.org/10.1021/jacs.5b10385

本文报道了一例由Fe(III)中心和顺磁性半醌类配体dhbq（2,5-二氧代苯醌/1,2-二氧代-4,5-半醌）构建的三维网络固体(NBu4)2FeIII2(dhbq)3（1），它在298 K下具有0.16(1) S/cm的电导率，是当时金属–有机框架（MOF）中报道的最高值之一。作者通过多种光谱、慢扫描循环伏安、变温电导和磁化率测量，明确该导电性源于配体混合价态，并首次在MOF中观察到Robin–Day Class II/III混合价特征。进一步通过化学还原得到Na0.9(NBu4)1.8FeIII2(dhbq)3（2），比较两种材料的导电性和磁有序温度差异，并将其归因于两种配体氧化态的比例变化，确立了过渡金属–半醌体系作为实现MOF内长程电子通信可调控平台的价值。

## 引言与背景

长程电子通信及其衍生的电荷迁移和磁耦合强烈依赖于参与原子间的距离。金属–有机框架通过网状化学可设计出低密度多孔材料，但多数MOF本质上是离子型固体，带隙大、缺乏长程电子通信，这主要源于大体积抗磁性配体与亲氧金属离子导致金属间距过大，切断了电荷传输和磁耦合所需的轨道交叠。要获得导电或磁性有序的MOF，关键在于调控金属–配体前沿轨道的重叠和能量匹配，使金属和配体均具有开壳层、相近的氧化还原电位，并最大化轨道重叠以促进电荷离域。2,5-二羟基苯醌（H2dhbq）是一种已知的氧化还原活性配体，其三种价态（dhbq2–、dhbq3–、thb4–）均可进入配位体系，其中dhbq3–是顺磁性自由基桥联配体。本文利用Fe(III)与混合价dhbq2–/3–构筑的框架，实现了高导电性和高温磁相互作用，并首次报道MOF中的Class II/III混合价行为，还展示了通过还原插入精确调控电子和磁性。

## 合成、结构与配体混合价态证据

**合成与晶体结构。** 化合物1的合成在厌氧条件下，以2,5-二氨基苯醌为前体（原位水解为dhbq2–），与三倍摩尔量的Fe(SO4)·7H2O及过量四丁基溴化铵在pH 3.0的去离子水中，120 °C下加热24小时，得到黑色立方晶体，产率43%。若直接使用H2dhbq则仅得到无定形固体。单晶X射线衍射表明1结晶于立方空间群I-43d，由两个对映异构的(10,3)-a网互穿构成三维结构；与常见的二维蜂窝状dhbq配位固体不同，该拓扑中同一手性网上相邻金属中心具有相同手性。四丁基铵阳离子位于孔道中，几乎完全填充，77 K N2和195 K CO2吸附测试均确认无微孔性。晶体学数据还显示Fe–O键长为2.008(7)和2.031(7) Å，明显短于Fe(II)–dhbq体系，而C–O键长（1.281(11)、1.308(12) Å）略长于典型dhbq2–配合物（1.26–1.29 Å），初步提示配体被还原。**Mössbauer谱**在100 K下给出异构体位移δ=0.574(2) mm/s、四极分裂|ΔEQ|=1.279(5) mm/s，与高自旋Fe(III)一致，且20–300 K间无显著变化；20 K以下出现磁有序相关的六线峰。结合电荷平衡，1的配体价态应为dhbq3–:dhbq2– = 2:1，即每个Fe中心周围有两个自由基配体和一个二价配体。

**慢扫描循环伏安与化学还原。** 利用锂参比和对电极，在0.1 M LiBF4/碳酸丙烯酯中，以30 μV/s的扫描速率对1进行慢扫描CV，观察到准可逆还原至x=3.7（假定组成为Lix[NBu4]2FeIII2(dhbq)3），法拉第效率77%；首个峰对应1.1 e–/mol，推测为剩余dhbq2–还原为dhbq3–。总还原量近4 e–/mol，对应所有三个配体还原至thb4–，但进一步电化学还原导致框架分解。化学还原采用四氢呋喃中化学计量的钠萘（sodium naphthalenide），得到2。ICP分析确定Fe:Na为2.23(1):1，元素分析显示约10%的NBu4+被Na+交换，因此2的组成为Na0.9(NBu4)1.8Fe2(dhbq)3，即每摩尔1引入0.7个电子。粉末XRD显示2的衍射图样与1几乎完全重合，表明骨架结构未变。2的Mössbauer谱（δ=0.570(3) mm/s，|ΔEQ|=1.252(7) mm/s）与1几乎相同，证明还原发生在配体而非Fe中心，因此2中配体价态比应为dhbq3–:dhbq2– = 2.7:0.3。进一步用四倍量还原剂得到Na3.2(NBu4)1.8FeIII2(dhbq)3，Mössbauer显示两个铁位点（51%和49%），均属FeIII，表明至少到3 e–/mol的还原仍是配体基，先生成dhbq3–再生成thb4–。但由于多铁位点复杂性，该材料未深入讨论。

**光谱证据：红外与紫外–可见–近红外。** 红外光谱中，1和2均在1510–1450 cm–1范围内呈现宽峰，归属为C=O伸缩振动；该峰在纯dhbq2–体系中通常尖锐且波数更高，还原为dhbq3–时红移约50 cm–1，因此宽峰支持dhbq2–/3–共存。同时近红外区出现强吸收，提示配体间电荷转移（IVCT）。UV-Vis-NIR漫反射光谱显示，1和2均在4500–14000 cm–1范围有宽吸收带，νmax分别为7000和6300 cm–1，归属为配体间IVCT。已知分子Fe(III)半醌–邻苯二酚配合物在约5200 cm–1处有类似但更窄的IVCT带。由于Mössbauer已确认铁全部为Fe(III)，该IVCT必然来自有机dhbq2–/3–。两谱在低能侧4500 cm–1处呈现陡峭吸收边，这是Robin–Day Class II/III混合价的典型特征，也是MOF中首次观察到此类混合价。21500 cm–1处的高能吸收被暂指认为π–π*跃迁。这些低能IVCT带指示热激活电荷传输，激励作者进行电导率研究。

## 电子导电性及其机制

对1和2的压片进行两点直流电导率测量。1在室温下电导率为0.16(1) S/cm，在开路电压±1 V内呈欧姆行为，为当时三维连接MOF中的最高值；2的电导率显著降低，为0.0062(1) S/cm。变温电导（70–300 K）显示两者均为半导体行为，符合Arrhenius依赖，1的活化能为110 meV，2为180 meV。这些结果支持电子在dhbq2–/3–氧化还原流形内跳跃的导电机制：还原为2后，dhbq2–位点被填充，自由基dhbq3–缺少最近邻的空位来跳跃，载流子迁移率下降，因此导电性降低。同时，随着更多dhbq2–被还原成dhbq3–，载流子密度应增加，但实验表明迁移率对电导率的决定作用更大。作者还指出，该框架的立方对称性避免了低维导体压片测量中的织构效应。

## 磁性质与结论展望

由于dhbq3–自由基的存在，作者研究了磁行为。1的直流磁化率在0.1 T下显示强金属–自由基磁相互作用，最终在8 K出现磁有序（交流磁化率确认）。250 K以下显著偏离Curie–Weiss行为，这归因于局部磁有序或铁磁/反铁磁竞争导致的磁玻璃态特征。250–300 K的Curie–Weiss拟合给出θ=134 K和C=6.1 emu·K/mol，表明高温下铁磁相互作用占主导，但低温磁化曲线呈渐近近似线性上升，饱和磁化强度为7.3 μB/mol，明显低于铁磁耦合预期（10.95 μB/mol），而接近亚铁磁耦合预期（8.94 μB/mol），因此低有序温度源于竞争相互作用最终导致亚铁磁有序。2由于具有更高密度的自由基桥（更接近完全dhbq3–桥联），磁有序温度升至12 K，θ=144 K，C=5.90 emu·K/mol；300 K下χMT为11.2 emu·K/mol（1为10.9），相差0.3 emu·K/mol，与额外0.7个S=1/2自旋的贡献（0.26）接近。2的饱和磁化强度为7.11 μB/mol，低于1，且矫顽力更大（350 Oe vs 100 Oe），符合更多自由基与Fe(III)反铁磁耦合的预期。作者指出，高θ值与低有序温度的矛盾可能通过更换抗衡阳离子来解决，例如在二维草酸盐体系中阳离子可改变有序温度达17 K，并援引Néel提出的TC ∝ z（磁邻居数）关系。

总之，本文通过配体混合价实现了MOF中的高电子导电（0.16 S/cm）和亚铁磁有序（8 K），并首次在MOF中观察到Robin–Day Class II/III混合价。化学还原被精确控制到0.7 e–/mol，得到导电性和磁性变化相关的2。这项工作展示了通过后合成氧化还原调控MOF电子结构的潜力，并指出过渡金属–半醌体系有望应用于储能电极和磁电多铁材料。理论计算预测，若氧化至电荷中性FeIII2(dhbq2–)3并活化，可具有高达5070 m2/g的表面积，且该体系理论上可支持每化学式单元8个电子的氧化还原活性。
